# 日本史を10年単位で見る — 企画・実装計画

## 1. 企画概要

**1800年から現代までの日本史を、各時代の社会構造・制約・情勢を定点観測する形で読む。**

一般的な通史のように「重要事件を年代順に並べる」ことだけを目的とせず、各時点で次の問いに答えることを中心にする。

- その時代の政治は、どの制度・権力関係の上で動いていたか
- 経済・人口・身分・都市・農村はどのような状態だったか
- 外交・軍事・技術・情報環境は政治判断をどう制約していたか
- 同時代人にとって何が「当たり前」だったか
- 前の時代から何が変わり、何が変わらなかったか
- 次の変化を生む構造的な緊張や課題は何だったか

基本単位は10年とするが、歴史変化の速度に応じて時間解像度を変える。

> 歴史を「事件の列」ではなく、社会システムの状態遷移として読む。

---

## 2. 基本方針

### 2.1 同時代の視点を優先する

後世から結果を知った状態で、過去を一直線の前史として描かない。

たとえば、ある制度や事件を「のちの○○につながるもの」とだけ説明するのではなく、まずその時点の人々が利用できた情報・制度・技術・選択肢の中で理解する。

各年代ページでは、可能な限り次を区別する。

- **当時確認できた事実**
- **当時の認識・予想・争点**
- **後世から見て確認できる結果**
- **歴史学上の解釈**

### 2.2 政治史を主軸にする

通史の主軸は政治史とする。

ただし政治を独立した出来事として扱わず、必要に応じて以下を接続する。

- 経済史
- 社会史
- 人口史
- 農村史・都市史
- 外交史
- 軍事史
- 科学技術史
- 交通・通信史
- 教育史
- 思想史・宗教史
- 文化史
- 災害史・環境史
- 労働史
- メディア史
- 地理・空間構造

### 2.3 出来事より構造を追う

重要事件については、出来事の説明だけで終わらせず、可能な範囲で次の連鎖を見る。

```text
事件
↓
直接的な背景
↓
制度・経済・社会構造
↓
その構造を生んだ長期変化
↓
事件後に何が変化したか
```

### 2.4 「変化」と「持続」を同時に見る

各ページでは、新しく起きたことだけでなく、前の時代から残り続けている制度・慣行・価値観も扱う。

歴史上の転換点でも、社会全体が一斉に切り替わったようには書かない。

---

## 3. 時間粒度

原則は10年単位だが、現代に近づくほど変化速度が大きくなるため、必要に応じて粒度を上げる。

初期案：

| 時期 | 基本粒度 | 方針 |
|---|---:|---|
| 1800–1850 | 10年 | 幕藩体制・商品経済・人口・対外環境の長期変化 |
| 1850–1870 | 5年程度 | 幕末・維新期は政治変動が速いため高解像度化 |
| 1870–1910 | 10年 | 明治国家の制度形成と社会変化 |
| 1910–1945 | 5年程度 | 政党政治・社会変動・戦時体制を細かく追う |
| 1945–1970 | 5年程度 | 占領・復興・高度成長期 |
| 1970–2000 | 5〜10年 | 経済・人口・都市・産業構造を重視 |
| 2000–2020 | 5年程度 | IT・人口・経済・政治・社会変化 |
| 2020以降 | 1〜3年も可 | 同時代史として必要に応じて細分化 |

この区切りは固定ルールではない。内容上の転換点が明確な場合は、年代ページ内部で節を細分化する。

## 4. 年代ページの標準構造

各年代ページは、可能な限り共通フォーマットを使う。

### 4.1 冒頭サマリー

#### この時代を一言で

100〜300字程度で、その時代の特徴を要約する。

#### 社会のスナップショット

| 項目 | 状態 |
|---|---|
| 政治体制 |  |
| 政治の主要争点 |  |
| 経済 |  |
| 社会構造 |  |
| 人口 |  |
| 都市・農村 |  |
| 外交・国際環境 |  |
| 軍事・治安 |  |
| 技術・交通・通信 |  |
| 教育・知識 |  |
| 文化・宗教 |  |
| 最大の構造的課題 |  |

### 4.2 本文

基本候補：

1. 政治
2. 統治制度・中央と地方
3. 経済
4. 身分・階層・社会
5. 農村
6. 都市
7. 人口
8. 外交・国際環境
9. 軍事・治安
10. 交通・通信・情報
11. 科学・技術
12. 教育・知識
13. 文化・宗教
14. 災害・環境
15. 人々の暮らし

すべてを毎回埋める必要はない。年代ごとに重要な軸へ比重を寄せる。

### 4.3 各年代で必ず置く比較

#### 前の時代から何が変わったか

| 項目 | 前回 | 今回 | 変化 |
|---|---|---|---|
| 政治 |  |  |  |
| 経済 |  |  |  |
| 社会 |  |  |  |
| 対外環境 |  |  |  |
| 技術・情報 |  |  |  |

#### 変わらず残ったもの

制度・慣行・地域差など、「まだ変わっていないもの」も明示する。

### 4.4 その時代の問い

各年代に1〜3個、構造理解につながる問いを置く。

例：

- この制度は、なぜこの時点では維持できていたのか
- 経済成長は政治体制を強くしたのか、弱くしたのか
- 外圧が政治危機へ転化する条件は何だったのか
- 災害はどのような経路で政治問題になったのか

答えを暗記するためではなく、本文を読む観点として使う。

### 4.5 当時の常識

同時代人にとって当然だった制度・生活・社会通念を短く並べる。

現代の常識を過去へ投影しないための補助線とする。

### 4.6 次の時代への論点

「次に何が起こるか」ではなく、この時点ですでに存在した構造的な緊張・制約・未解決問題を整理する。

## 6. 構造史

テーマ史よりさらに抽象度を上げ、「日本社会を長期間拘束・駆動した仕組み」を追う。

候補：

- 幕藩体制
- 石高制と貨幣経済
- 中央集権化
- 官僚制
- 税制
- 土地制度
- 国民国家化
- 産業化
- 都市化
- 人口転換
- エネルギー
- 物流
- 情報速度
- 教育と人的資本
- 災害対応能力
- 社会保障
- 国際秩序への接続

各記事では、制度名の説明だけでなく、

```text
成立条件
→ 安定していた理由
→ 内部矛盾・外部環境の変化
→ 制度変容
→ 次の構造
```

という流れを意識する。

## 7. 地理・主題地図

### 7.1 MapLibre を採用する

地理情報が歴史理解に有効な場合は、**MapLibre** を使ったインタラクティブな主題地図を作る。

ただし、**各年代ページに必ず地図を置くことはしない。**

「位置を表示できるから載せる」のではなく、空間分布・距離・地域差・ネットワークが論点の理解に寄与するときだけ使用する。

### 7.2 地図を使う候補

- 藩領・行政区画
- 主要都市・人口分布
- 街道・宿場・航路
- 港・開港場
- 鉱山・産地
- 鉄道網の拡大
- 電信・通信網
- 工業地域・工場立地
- 軍事施設
- 戦場・戦線
- 空襲・災害
- 人口移動
- 都市圏拡大
- 高速道路・新幹線
- 土地利用
- エネルギー・物流網

### 7.3 主題地図の原則

地図には可能な範囲で以下を持たせる。

- タイトル
- 対象年・対象期間
- 凡例
- 出典
- データの基準・定義
- 注記
- popup / tooltip
- 地図が示す歴史的論点

背景地図より主題データを主役にする。

### 7.4 地図の表現

用途に応じて以下を使い分ける。

- **面**：藩領、行政区、人口密度、土地利用
- **線**：街道、鉄道、航路、戦線
- **点**：都市、港、鉱山、工場、施設
- **時系列**：複数年代の比較・スライダー・切替
- **フロー**：物流、人口移動、交易など

### 7.5 データ形式

初期は扱いやすさを優先する。

- GeoJSON
- CSV + 緯度経度
- PMTiles（データ量が増えた場合）
- 必要に応じてベクトルタイル化

記事本文と地理データを分離し、同じ主題地図を複数ページから再利用できる設計にする。

## 8. 史料・出典方針

サイトの信頼性を保つため、事実・統計・地理データは可能な限り出典へ到達できる形にする。

優先順位の目安：

1. 一次史料・公的統計・公文書
2. 研究機関・大学・博物館・公的機関
3. 学術書・査読論文・専門的研究書
4. 信頼できる概説書
5. 補助的な二次情報

### 8.1 史料と解釈を分ける

本文では以下を混同しない。

- 史料に直接書かれていること
- 統計から読み取れること
- 研究者による解釈
- 本サイトの説明上の整理

評価が分かれる論点は、単一の断定へ潰さず主要な解釈と根拠を示す。

### 8.2 数値

人口・物価・生産量などは、可能な限り以下を明記する。

- 年
- 地域
- 単位
- 推計か実測か
- 出典
- 定義上の注意

## 10. 地図コンポーネントの方向性

記事からは、地図実装の詳細を意識せず参照できる形を目指す。

概念例：

```md
<Map
  map="ports_1860"
  caption="1860年前後の主要港・開港場"
/>
```

地図側に以下を集約する。

- MapLibre style / source / layer 定義
- 表示範囲
- 凡例
- popup
- 出典
- 対象年代
- 記事へのリンク

同じ地理データを年代史・テーマ史・構造史から再利用可能にする。

## 11. 初期コンテンツ計画

まず **1800〜1850年代** を作り、企画フォーマットを固める。

### Phase 1: 江戸後期の定点観測

- 1800年前後
- 1810年前後
- 1820年前後
- 1830年前後
- 1840年前後
- 1850年前後

目的：

- 年代ページの標準フォーマット確立
- 政治・経済・社会を接続する書き方の確立
- 10年間の差分表示の検証
- MapLibre 主題地図の利用基準確立
- 史料・出典表記ルール確立

### Phase 2: 幕末を高解像度化

1850年代以降について、必要なら5年単位または重要局面単位へ細分化する。

### Phase 3: 明治以降

年代史を進めながら、並行してテーマ史・構造史を追加する。

## 13. UI / UX の基本思想

### 13.1 読み方を複数用意する

- 年代順に読む
- テーマから読む
- 地図から読む
- 構造史から読む

### 13.2 年代移動を簡単にする

各年代ページに最低限、

- 前の年代
- 次の年代
- 年代一覧
- 関連テーマ

への導線を置く。

### 13.3 情報を階層化する

本文の密度が高くなりすぎないよう、

- 冒頭要約
- 本文
- 詳細補足
- 史料
- 注記

を分ける。

## 14. 執筆上の注意

### 避けるもの

- 結果を知った後世の視点だけで説明する
- 単純な「進歩」「衰退」で全体をまとめる
- 一つの事件ですべてが変わったように描く
- 政治史と経済史を無関係な別章として扱う
- 現代の国境・行政区・価値観をそのまま過去へ投影する
- 地図を装飾として置く
- 出典の異なる数字を無条件に比較する

### 目指すもの

- 制約条件を明示する
- 地域差を意識する
- 同時代の選択肢を復元する
- 因果関係と単なる前後関係を区別する
- 複数分野を一つの社会構造として接続する
- 「なぜその時点ではそうなっていたのか」を説明する

## 15. 完成形

最終的には、

```text
1800
 ↓
1810
 ↓
1820
 ↓
...
 ↓
現代
```

という年代方向の変化と、

```text
政治
経済
人口
社会
都市
技術
交通
情報
外交
文化
地理
```

というテーマ方向の変化を交差させる。

さらに MapLibre の主題地図によって、文章・年表だけでは見えにくい

- 空間分布
- 地域差
- 接続性
- 距離
- 拡大・縮小
- ネットワークの変化

を可視化する。

**「いつ何が起きたか」だけではなく、「その時代の日本社会はどのようなシステムで、なぜその状態にあり、どこが変化したのか」を読むための日本史サイト**を目標とする。
