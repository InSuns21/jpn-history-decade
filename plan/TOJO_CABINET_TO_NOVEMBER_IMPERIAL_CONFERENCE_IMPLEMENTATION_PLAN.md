# 1. このフェーズを1941年10月18日〜11月5日に切る理由

前フェーズは10月16日の第三次近衛内閣総辞職と、17日の豊田貞次郎外相から野村吉三郎大使への交渉継続訓令までで終えた。内閣は倒れたが、対米交渉回路そのものは切れていなかった。

10月18日、東条英機内閣が成立する。東条は首相に加えて陸相・内相を兼ね、外相には東郷茂徳、海相には嶋田繁太郎、大蔵相には賀屋興宣が就任した。新内閣の成立を「その日に対米開戦を決定した」とは扱わない。むしろこの時点で重要なのは、**近衛内閣が一致できなかった国策を、新内閣が自らの責任で再検討する意思決定回路が作り直されたこと**である。

10月23日の第59回大本営政府連絡会議は東条内閣成立後最初の連絡会議となり、9月6日御前会議決定の「帝国国策遂行要領」をそのまま引き継ぐのか、新しい方針を作るのかを含めた再検討に入る。以後、作戦の長期見通し、対ソ関係、船舶損耗・造船、主要物資、独伊協力、米英蘭の分離可能性、外交妥結の見込みなどが連日検討される。

この再検討は、単に「開戦するか否か」の二択ではない。10月30日には東条首相から、概括すると

1. 戦争を極力避けて現状を耐える
2. 直ちに開戦を決意し、政策を戦争へ集中する
3. 戦争を決意して準備を完成しつつ、外交を続けて妥結を求める

という三つの政策方向が提示される。したがって、10月中の連絡会議を「すでに開戦が決まっていて形式的に追認した会議」と書かず、**複数の政策選択肢を、資源・輸送・作戦・外交の制約と突き合わせる再評価過程**として扱う。

11月1日から2日未明にかけての第66回大本営政府連絡会議では、この再検討が結論段階へ入り、対米交渉要領と国策遂行要領がまとめられる。ここでも政府、陸軍省、参謀本部、海軍、外務省の認識を一枚岩にしない。参謀本部内には交渉断念・早期開戦を求める強い意見がある一方、政府の正式な政策は外交を継続する形で調整される。

11月5日の第7回御前会議で、新しい「帝国国策遂行要領」と対米交渉の甲案・乙案が正式決定される。これは12月1日の開戦決定とは別段階であり、同日から直ちに戦争状態へ入るわけでもない。まず甲案を提示し、不成立なら譲歩度を高めた乙案へ進む外交手順が確定する。

このため本フェーズは、**東条内閣成立 → 国策の白紙的再検討 → 政策選択肢の比較 → 11月1日の収束 → 11月5日の正式再決定**で一つの状態遷移をなす。11月6日以後は、決定された甲案・乙案を実際の外交交渉へ投入し、米側の回答を受ける別の状態へ移るため次フェーズとする。

# 7. A41 — 国策再検討の資源・船舶・南方作戦空間 map necessity / data-quality judgment

## 判定対象

10月23日以後の国策再検討では、南方作戦の所要期間、主要物資、液体燃料、船舶損耗・造船、資源獲得後の輸送が政策判断へ組み込まれる。

一方、既存地図には次がある。

- A38: 南部仏印の基地・進駐空間
- A39: 石油供給制約と南方資源空間
- A40: 南方作戦準備地域と対象方面

このためA41は、既存3地図を言い換えて再掲するだけなら **no-map** とする。採用するには、10月23日〜11月5日の再検討で新たに重要となった「資源獲得地・海上輸送・船腹制約・作戦対象方面」の関係を、既存A39/A40では示せない形で説明できる必要がある。

### map necessity判定で確認する問い

- 国策再検討の中心問いは空間配置を見ないと理解しにくいか、それとも表・本文の方が適切か
- 蘭印等の資源獲得地から日本までの海上輸送距離・海域が船舶制約の理解を改善するか
- A39の石油供給関係、A40の準備地域・対象方面との差分を明確にできるか
- 10月時点の計画・見通しと、12月以後の実際の侵攻ルート・占領地資源輸送を混同しないか
- schematic LineStringを使う場合、実航路と誤読させない不確実性表現を維持できるか

### データ品質方針

- 時点の異なる作戦計画を一つの確定ルートへ統合しない
- 海上LineStringを使う場合はMAP_AUDIT_STANDARDのcartographic waypoint規則を適用する
- 船舶損耗・造船量など数量自体は地図の線幅へ安易に符号化せず、表・本文の方が適切か先に判断する
- 既存A39/A40の再掲で足りる場合は新規地図を作らない
- LineString / Polygon採用時はHuman Visual Audit必須
- point-onlyで既存監査済みUIを厳密に再利用する場合だけ規約上の再利用例外を検討する

## 判定結果 — **no-map**

A41は **no-map** とする。

- 10月24〜25日の第60・61回連絡会議では、船舶損耗・造船能力・主要物資需給が再検討されたが、示された造船見通しは戦域別・航路別ではなく総量の能力評価である。
- 10月29〜30日の第64・65回連絡会議でも、鉄の供給見通しは「船腹300万トンを必要とし、それを維持するため毎年60万トンの造船が必要」という総量条件として議論されている。これは特定の資源地—日本間航路へ数量を割り当てた資料ではない。
- 空間理解として必要な「蘭印等の資源供給地と日本の関係」はA39「石油供給制約と南方資源空間」が、「南方作戦の準備地域と対象方面」はA40「外交期限と南方作戦準備の空間」が既に担当している。A41を新設しても、史料上の新しい空間状態よりA39/A40の合成再掲になりやすい。
- 本フェーズで新しく重要になったのは、資源の所在地ではなく、**資源を獲得しても船腹・損耗・造船・民需輸送・復旧を通じて継続的に運べるかという throughput / capacity 制約**である。これは地図の位置・線より、本文と数量表で比較する方が意味を損なわない。
- 線幅を船腹量・損耗量へ対応させるには航路別配分データが不足する。逆に、12月以後の実際の侵攻路・占領後輸送路を流用すると、10月23日〜11月5日時点の見通しへ後知恵を逆投影する。
- schematic LineStringで「資源地→日本」を描く案もA39の供給関係線との差分が弱く、実航路・計画航路と誤読されるリスクに見合う追加情報がない。

**data-quality judgment:** 連絡会議史料は船腹・造船・液体燃料・鉄の総量評価を確認する資料としては十分だが、A41固有の航路別・資源別輸送geometryを構成する根拠としては不足する。したがって、データ不足を模式線で補うのではなく、地図を作らないことを品質上の選択とする。

参照：JACAR「1941年10月24日 第60回大本営政府連絡会議」「1941年10月25日 第61回大本営政府連絡会議」「1941年10月29日 第64回大本営政府連絡会議」「1941年10月30日 第65回大本営政府連絡会議」。

# 8. Crosscutting publication gate — ✅ completed（2026-10-05）

## S13「日米交渉と経済圧力」— ✅ pass / extension required

## S10系列「産業社会の負担と保護」— hold / no extension

今回の数値・見通しをS10系列へ足すと、国内の負担配分史よりJH104〜JH106の国力評価を再掲する比重が高くなる。再編済みS10系列は既存の中心問いを維持し、本フェーズの資源・船舶制約はS13の「時間」と年代記事で受ける。

# 9. phase-end audit necessity judgment — ✅ no-audit

2026-10-05にJH103〜JH106、A41 no-map、S13延長を横断し、独立監査が必要な具体的仮説が残るかを判定した。

候補論点は実装内で次のように解消済みである。

- **東条内閣成立 = 10月18日に開戦決定**：JH103は政権交代と国策再検討の開始を扱い、開戦決定を置いていない。
- **「白紙還元」だけで政策過程を説明**：JH103は1941年同時代記録と1945年近衛回想を分け、10月23日以後の具体的再検討を本文の主線にした。
- **10月23〜30日 = 既定開戦方針の形式的追認**：JH104/JH105は作戦、対ソ、船舶、造船、主要物資、外交を再計算し、10月30日に三つの政策方向が比較された過程を実装した。
- **「軍部」一枚岩化**：JH103〜JH106は陸軍省、参謀本部、海軍、外務省、大蔵省、首相の制度的位置と見通しを分離した。
- **資源不足 → 即時開戦 / 南方資源獲得 → 長期戦解決**：JH104/JH105とA41 no-mapは取得・輸送・船腹・損耗・造船・民需輸送を分け、S13も資源条件を政策時間の入力として扱った。
- **10月30日の三方針 = 11月5日の正式決定**：JH105で比較段階、JH106で11月1日の収束と5日の正式決定を分離した。
- **11月1日連絡会議 = 御前会議決定**：JH106は連絡会議の結論と11月5日の御前会議を別段階として記述した。
- **11月5日 = 12月1日の最終開戦決定**：JH106とS13は12月1日までの交渉と妥結時の武力発動中止条件を明示した。
- **甲案・乙案 = 11月26日米側覚書への回答**：JH106とS13は両案を11月1〜5日に形成・決定されたものとして時系列を固定した。
- **11月1日以後の外交 = 一律の偽装外交**：JH106は参謀本部内部意見と政府正式方針を分け、S13は甲案→乙案と妥結時停止条件を正式な政策手順として扱った。

以上から、複数記事を改めて独立監査しなければ判定できない未解決仮説は残っていない。PROJECT_WORKFLOW_STANDARD 5.2 / 5.3に従い、定型的な全体監査は追加せず、次工程を `npm run check` とする。
