# 1. このフェーズを1940年9月27日〜11月30日に切る理由

9月27日、日独伊三国条約が調印された。条約第三条は、欧州戦争または日中戦争に現に参加していない国から締約国の一国が攻撃された場合の相互援助を定めた。一方、調印前日の枢密院審査では、攻撃該当性や援助方法について三国協議と各国の判断が介在する説明がなされている。したがって、三国同盟を「その日に対米参戦が自動確定した条約」とは扱わず、対米抑止を意図した外交制度と、その解釈・運用の余地を分けて扱う。

国内では、7〜8月の既成政党解党を受け、10月12日に大政翼賛会が発足した。帝国議会・議員資格を残したまま、首相を総裁とする全国組織が中央から地方へ配置される新しい政治参加・動員回路が設けられた。ただし発足時点で一枚岩の「一国一党」が完成したわけではなく、旧政党系を含む諸勢力の抱合、組織の法的位置づけ、地方行政との関係をめぐる調整が続く。12月14日の実践要綱や1941年の改組は後段階として分ける。

対外経済では、米国が9月26日に公表した鉄鋼屑規制が10月15〜16日に実施段階へ入り、10月16日以後、鉄鋼屑の輸出許可は西半球諸国と英国に限られる制度へ移った。同じ10月16日、日蘭会商では三国同盟が日本・蘭印関係を害するものではないとの共同コミュニケが出されたが、小林一三代表は21日に帰国へ向かった。石油業者代表による交渉は11月に一応の妥結をみたものの、日本側が求める水準には届かなかった。会商自体は終結せず、後任の芳沢謙吉派遣へ続くため、「10月に蘭印交渉が完全決裂した」とは書かない。

中国戦争処理では、南京国民政府は3月30日に成立していたが、日本政府は即時承認せず、阿部信行特使による国交調整交渉と、松岡外相のもとでの対重慶和平工作を並行させた。11月13日の御前会議で支那事変処理要綱と日華基本条約・日満華共同宣言締結について最終的な意思確認がなされ、11月28日の大本営政府連絡懇談会で南京政府承認が決定された。11月30日に日華基本条約・日満華共同宣言が調印され、日本は南京政府を正式に承認した。

終点を11月30日とすることで、**三国同盟後の外交配置、国内新体制の組織化、南京政府「成立→交渉→正式承認」**という三つの状態遷移を一つのフェーズで閉じられる。

# 6. A33 — 1940年秋の外交・制度空間 map necessity / data-quality judgment

## 判定 — no-map

**map necessity: no-map / data-quality judgment: public mapを成立させるだけの地理的問いがない。**

JH74〜JH76を実装した結果、このフェーズの中心は距離・交通経路・戦線の広がりではなく、**条約・承認・交渉・軍事駐留・国内組織という異なる制度関係が同時進行したこと**にあると確認した。

### 候補別の判定

| 候補 | 地理データ | 判定 |
|---|---|---|
| 日本・ドイツ・イタリアの三国同盟 | 東京・ベルリン・ローマの代表点は高確度で置ける | 不採用。都市間LineStringは外交条約を交通路・軍事回廊のように見せ、距離自体も中心問いではない |
| 北部仏印への軍事駐留 | A32のpoint / schematic LineString / approximate Polygonを再利用可能 | 不採用。空間構造はA32ですでに説明済みで、再掲しても1940年秋の新しい制度状態を説明しない |
| バタビアの日蘭会商・石油交渉 | バタビアの代表点は高確度で置ける | 不採用。東京―バタビアを結ぶ線は交渉経路・輸送路・石油供給路のいずれを意味するか曖昧で、point-onlyでも本文以上の理解を増やさない |
| 南京政府・重慶政府・満洲国 | 南京・重慶・新京等の代表点は高確度で置ける | 不採用。11月30日の正式承認、日華基本条約、日満華共同宣言、日本軍駐留・交通権限、重慶側の抗戦継続は同じ種類の空間関係ではない |
| 南京政府の「法域」・日本軍占領域 | 概略polygon自体は作成可能 | 不採用。A31と同様、名目的管轄・日本軍の軍事占領／実効権限・重慶側支配を単一面へ圧縮する誤読リスクが高い |

### data-quality judgment

点位置そのものは東京・ベルリン・ローマ・バタビア・南京・重慶などで十分な精度を確保できる。A32の北部仏印geometryも再利用可能である。

しかし、A33で必要なのは「どこにあるか」より、**誰が誰を承認し、どの条約・交渉・軍事権限がどの主体間に成立したか**という関係の種類である。ここへLineStringを引くと、条約関係・承認関係・交渉接触・資源輸送を同じ「接続」として見せる危険がある。Polygonを置くと、南京政府の法形式と日本軍の軍事的実効権限、中国各地の支配状況を同じ「領域」として見せやすい。

したがって、**利用可能なgeometryの精度不足ではなく、geometryで表す対象と歴史的問いの不一致**を理由としてno-mapとする。これは MAP_AUDIT_STANDARD.md の「地図を作れること自体を採用理由にしない」「geometryが支えられる主張と問いを一致させる」という方針に沿う。

### A31 / A32との接続

- A31で避けた、南京政府の名目的管轄・地域行政・日本軍占領権力・重慶側実効支配を単一polygonへ圧縮する問題は、11月30日の正式承認後も解消しない。
- A32の北部仏印進駐・援蒋ルート地図は、港・交通軸・国境戦闘域という明確な空間問いを持つため採用できた。A33には同等の独立した空間問いがない。
- 制度関係を図示する必要が生じた場合は、MapLibre地図ではなく、条約・承認・交渉・軍事権限を線種別に扱える制度関係図として別途検討する。

### 監査工程

A33はno-mapのため、GeoJSON / map definitionを追加せず、Data Audit / Style Audit / Human Visual Auditは発生しない。

次工程は **Crosscutting publication gate** とする。

# 7. Crosscutting publication gate

## 判定

**S05 / S09 / S10 を延長、S02 は hold、新規横断記事は追加しない。**

JH74〜JH76を年代記事として完成させたうえで、出来事の再掲ではなく既存横断記事の比較軸そのものが増えるかを判定した。

### S05「政治参加の回路」— pass

1940年7〜9月のS05は、主要な既成政党が解党した一方、帝国議会・議員資格が存続し、「代表を置く制度」と「代表を継続的に組織する制度」が分離した移行状態まで扱っている。

10月12日の[[term:taisei-yokusankai-1940|大政翼賛会]]発足により、この空白へ、首相を総裁とし、中央本部から道府県・市町村支部、中央・地方の協力会議へつながる全国組織が置かれた。ここで加わる比較軸は「大政翼賛会という組織ができた」という事件の再掲ではなく、**選挙・議会が存続したまま、政党とは異なる全国的な国民運動組織が、中央と地域社会を結ぶ新しい組織回路として配置されたこと**である。

発足時点では旧政党の候補者選定・党議拘束・議会内交渉をそのまま一対一で継承したとは扱わない。12月14日の実践要綱や1941年の法的位置づけ変更も後段階へ残す。

したがってS05は1940年11月30日まで延長する。

### S09「対外支配の制度差」— pass

S09は1940年3月30日の南京国民政府成立後について、「中央政府形式」「華北政務委員会などの地域行政」「日本軍の軍事権限」「重慶国民政府の実効支配」「日本による外交承認」を別の層として整理し、9月には北部仏印でフランスの主権・植民地行政を残したまま日本軍の駐留権限が重なる制度類型を追加している。

11月30日には[[term:japan-china-basic-treaty-1940|日華基本条約]]と[[term:japan-manchukuo-china-joint-declaration-1940|日満華共同宣言]]が調印され、日本政府は南京国民政府を正式承認した。JACARが示す付属・秘密文書には、日本軍の特定地点への駐留、交通上の便宜、日本人軍事・技術顧問などの取り決めも含まれる。

ここでS09へ加わるのは、**「成立しているが日本から未承認」の政府形式から、「正式な国交・条約関係を持つ政府形式」へ移りながら、日本軍の具体的な軍事・交通上の権限が同時に残る制度状態**である。外交承認が加わっても、法形式・軍事的強制力・地域ごとの実効支配が一つへ統合されたわけではないという比較軸が明確になる。

したがってS09は1940年11月30日まで延長する。

### S10「産業社会の負担と保護」— pass

S10は1940年7月21日までに、価格・賃金・給与・物資・工場・土地・海運・石炭・米穀へ行政統制が広がり、企業・労働者・農家・家計の選択条件が法令によって狭められる過程を扱っている。

11月8日の「勤労新体制要綱」と23日の[[term:dainihon-sangyo-hokokukai-1940|大日本産業報国会]]結成は、ここへ別種の負担配分回路を加える。企業・職場単位の産業報国会を全国組織へ接続し、経営側と労働者を同じ事業所組織へ組み込み、生産力増強・勤労動員・職場秩序を継続的に運営する仕組みが強化された。

これは賃金額・徴用・設備利用を命令で直接制約する制度の追加だけではない。**行政統制を企業の日常的な労務管理・職場組織へ接続し、負担配分の比較を個別の命令・利用制約から、事業所組織を通じた継続的な勤労動員・生産協力へ広げる軸**になる。

したがってS10は1940年11月30日まで延長する。

### S02「石高制・貨幣経済・財政」— hold

9月27日〜11月30日の主要変化には、三国同盟、米鉄鋼屑規制の実施、日蘭資源交渉、大政翼賛会、大日本産業報国会、南京政府正式承認がある。

この区間では、S02が追う租税、公債、特別会計、通貨制度、中央銀行信用という比較軸に新しい制度状態は確認できない。米国の輸出規制や蘭印石油交渉は資源調達条件を変えるが、それ自体は日本の財政金融制度の状態遷移ではない。

したがってS02は今回延長しない。

### 新規横断記事 — no

「枢軸外交」「南方資源外交」「新体制運動」を独立記事化すると、現段階ではJH74〜JH76とS05 / S09 / S10の再編集になる比重が高い。

1941年には資産凍結、南部仏印進駐、日米交渉、日蘭会商の終結など比較材料が増えるため、外交・資源制約を独立した長期軸にする必要性はその時点で再判定する。

## 次工程

**S05 / S09 / S10 extension** を実装する。S02と新規横断記事には変更を加えない。
