# 1. このフェーズを1941年12月2日〜12月25日に切る理由

前フェーズの終点12月1日には、対米英蘭開戦が国家意思として正式決定された。しかし、この決定と実際の戦争開始は同一の手続ではない。12月2日以後、軍の作戦実施日が確定し、外務省はなおワシントンの野村吉三郎・来栖三郎両大使を通じて外交連絡を続け、大本営政府連絡会議は対米覚書の文案・手交時刻、宣戦詔書、タイ・中国・独伊への措置を詰めていく。

12月2日には連合艦隊へ「ニイタカヤマノボレ一二〇八」が発せられ、12月8日を作戦開始日とする実施段階へ入った。ここは12月1日の国家意思決定とは別の境界である。同時に12月3日まで日米外交の応酬は残り、12月4・6日の大本営政府連絡会議で最終通告の文案・送信・手交時刻や宣戦手続が具体化された。

12月6〜7日には「対米覚書」が14分割でワシントンへ送られ、ルーズヴェルト大統領から昭和天皇への親電も発せられた。12月7日米時間午後1時の手交が訓令された一方、実際の手交は午後2時20分となった。真珠湾攻撃開始後の手交となった事実は重要だが、対米覚書自体を宣戦詔書と同一視しない。また、真珠湾だけを「開戦の唯一の始点」とせず、日本時間12月8日にはマレー半島方面でもほぼ同時に作戦が始まったことを扱う。

12月8日には戦闘開始と宣戦詔書が重なるが、攻撃開始、外交文書手交、国内の宣戦手続には時差と制度差がある。日本政府の宣戦詔書は米国・英国を対象とし、12月1日の開戦決定に含まれた蘭印方面の作戦構想や、オランダとの戦争状態を同じ一文で処理しない。

12月9〜11日には中国国民政府が日本・独伊への宣戦へ移り、マレー沖で英国主力艦2隻が航空攻撃によって沈没し、ドイツ・イタリアも米国へ宣戦した。戦争は日米二国間の衝突ではなく、欧州戦争・日中戦争・東南アジアの植民地戦争が結びつく段階へ進む。

12月12日には閣議が、対米英戦争と「支那事変」を合わせて「大東亜戦争」と呼称することを決定した。これは単なる名称変更ではなく、政府が既存の日中戦争と新しい対米英戦を一つの戦争枠組みへ統合して説明する制度上の変化である。その後、12月21日の日タイ同盟、12月23日のウェーク島占領、12月25日の香港降伏までを追うと、開戦初動が一時的攻撃から、同盟・占領・継続作戦を伴う戦争体制へ移るところまで一まとまりで読める。

このため本フェーズは、**開戦決定 → 作戦実施確定 → 最終外交通告 → 戦闘開始・宣戦 → 多正面戦争化 → 戦争の制度化と初期占領**という状態遷移として1941年12月2日〜25日に切る。

# 3. JH112 — 1941年12月2日〜12月5日

## 中心問い

> 12月1日の正式な開戦決定は、どのように軍の具体的な作戦実施日と外交上の最終手続へ変換されたのか。

## 必須テーマ

- JH111からの接続
  - 12月1日第8回御前会議は国家意思としての対米英蘭開戦決定
  - 戦闘開始、対外通告、宣戦詔書は未実施
- 12月2日
  - 連合艦隊へ「ニイタカヤマノボレ一二〇八」
  - 12月8日を作戦開始日とする実施確定
  - 「12月1日で全軍が自動的に攻撃開始」ではなく、命令伝達の制度段階を示す
- 12月2〜3日
  - 野村・来栖と米側の外交接触
  - 仏印増兵をめぐる米側照会と日本側回答
  - 東郷外相が乙案の立場をなお説明していたこと
- 12月4日 第75回大本営政府連絡会議
  - 対米最後通告文案
  - 打電・手交時刻を統帥部要求と接続
  - 満洲国・オランダへの措置
- 12月5日までの南方作戦部隊・真珠湾攻撃部隊の進行
  - 12月8日の実績から逆算せず、同時点で確認できる命令・移動だけを書く
- 12月6日の対米覚書送信決定は次ページへ送る

## JH111→JH112 接続確認

JH111は「開戦する」という国家意思で終わった。JH112では、**その意思がいつ・どの命令系統で「12月8日に作戦を開始する」へ変換されたか**を示し、御前会議と作戦開始を一続きの一手続にしない。

### JH112 implementation result — ✅ completed

- 12月2日の「ニイタカヤマノボレ一二〇八」を、12月1日の国家意思決定から12月8日の作戦実施日へ接続する軍事命令として実装
- 同日以後も野村・来栖の外交接触が継続したことを並行して扱い、東京との情報非対称を政策運用の一部として整理
- 12月3日の仏印増兵照会では、乙案の「南部から北部への移駐」と米側が観測した仏印全体の増勢を分け、外交提案の信頼性と現地配置の関係を補強
- 12月4日の第75回連絡会議では、外相が最終外交文書の文案、統帥部が作戦上の時刻条件を担う制度分担を具体化
- 図版は国立国会図書館所蔵・Wikimedia Commons Public Domainの連合艦隊極秘作戦命令資料を採用
- JH111との隣接接続確認済み

# 4. JH113 — 1941年12月6日〜12月7日

## 中心問い

> 戦闘開始時刻が迫る中、日本政府は外交文書・宣戦手続・軍事行動の時刻をどのように結びつけようとしたのか。

## 必須テーマ

- 12月6日 第76回大本営政府連絡会議
  - 対米最後通告
  - 宣戦詔書案
  - 対タイ交渉開始時期
  - 中国・独伊への措置
- 12月6日
  - 「対米覚書」送信を決定し、14分割でワシントンへ送信
  - 秘密保持のためタイピスト不使用を訓令
  - 野村・来栖はなお側面工作を報告
- ルーズヴェルト大統領から昭和天皇への親電
  - 米時間12月6日、日本側へ発せられた
  - 開戦を止めなかったという結果から、最初から無意味だったと書かない
  - 日本側での受領・伝達経路とタイミングを確認
- 12月7日
  - 東郷外相が対米覚書の手交時刻を米東部時間午後1時と訓令
  - 文言修正・大使館員への慰労電
  - 対米交渉の打切りを外交文書として確定させる段階
- 実際の手交は日本時間12月8日へ送る

## JH112→JH113 接続確認

JH112で作戦実施日は確定した。JH113では、**軍事上の発動時刻へ外交通告と宣戦手続を合わせるため、政府が文案・送信・手交時刻を詰める状態**へ進む。

### JH113 implementation result — ✅ completed

- 12月6日の第76回大本営政府連絡会議を、対米覚書・宣戦詔書案・対タイ交渉・中国／独伊措置を別工程へ分解する場として実装
- 対米覚書の14分割送信、受信後の即応準備、タイピスト不使用による機密保持を、外交文書を実施する通信・清書工程として整理
- 野村・来栖の側面工作継続を併記し、東京の開戦実施準備との情報非対称をJH112から継続
- ルーズヴェルト大統領の昭和天皇宛親電をFRUS/JACARで確認し、米東部時間12月6日発信 → 日本時間7日夜の受信・復号 → 8日0時15分の東郷外相への伝達へ時差付きで接続
- 12月7日の米東部時間午後1時手交訓令と最終文言修正まで実装し、実際の手交遅延はJH114へ送った
- 図版は国立国会図書館所蔵・Wikimedia Commons Public DomainのFRUS抜粋（ルーズヴェルト親電関係資料）を採用
- JH112との隣接接続確認済み

# 5. JH114 — 1941年12月8日

## 中心問い

> 1941年12月8日、日本では「戦争開始」がどの時刻・どの制度・どの戦域で成立したのか。

## 必須テーマ

- 日付・時差を最重要監査対象にする
  - 日本時間
  - ハワイ時間
  - ワシントン東部時間
  - マレー現地時間
- マレー半島方面での上陸・タイ領通過
  - 真珠湾攻撃より絶対時刻で先に戦闘が始まったことを確認
  - タイ軍との局地戦闘と、同日中の日本軍通過容認協定を分ける
- 真珠湾攻撃
  - ハワイ現地時間12月7日朝
  - 米太平洋艦隊・航空基地への攻撃
  - 作戦上の戦果と、空母・燃料施設等の未攻撃を後知恵で主題化しすぎない
- 対米覚書
  - 野村・来栖がハルへ手交したのは米東部時間12月7日14:20
  - 攻撃開始後の手交となった事実
  - 対米覚書は交渉打切り文書であり、日本の宣戦詔書と同一文書ではない
- 宣戦の詔書
  - 日本時間12月8日に米国・英国へ宣戦
  - 枢密院・上奏・詔書の手続
- フィリピン・香港・グアム等への攻撃開始
- 「真珠湾だけで太平洋戦争が始まった」という単一戦域化を避ける
- オランダ関係は12月1日の開戦決定・蘭印作戦と、日本の12月8日宣戦詔書の対象国を分ける

## JH113→JH114 接続確認

JH113では、外交・宣戦・軍事を同期させる準備が進んだ。JH114では、**その同期が完全には成立せず、戦闘・外交文書手交・宣戦詔書が別の時刻で実施された**ことを事実に沿って示す。

### JH114 implementation result — ✅ completed

- 12月8日を一つの「開戦時刻」へ圧縮せず、ルーズヴェルト親電伝達、マレー方面作戦、真珠湾攻撃、対米覚書手交、宣戦詔書、タイ通過容認を別工程として実装
- FRUSのワシントン時刻を使い、真珠湾攻撃開始（13:20）→対米覚書手交（14:20）の順序を確認
- Australian War Memorialの整理により、コタバル上陸が真珠湾空襲より早く始まった多戦域性を明示
- 対米覚書の遅延は復号・清書・面会工程の実施結果として扱い、意図的遅延とは断定しない構成にした
- 宣戦詔書は東条首相の上奏→10:50〜11:00枢密院審議→米英への宣戦という国内手続として整理し、12月1日の対米英蘭開戦決定と制度範囲を分離
- タイでは進入時の局地戦闘と同日中の日本軍通過容認を分け、12月21日の日タイ同盟へ飛ばさない
- フィリピン・グアム・ウェーク・香港にも触れ、真珠湾単独の開戦像を避けた
- 図版はPublic Domainの「米英に対する宣戦の詔書」文書画像を採用
- JH113との隣接接続確認済み

# 6. JH115 — 1941年12月9日〜12月11日

## 中心問い

> 開戦直後の数日で、日米英の戦争はどのように中国戦線・欧州戦争・東南アジア戦線と結びついたのか。

## 必須テーマ

- 12月9日
  - 中国国民政府が日本に正式宣戦し、独伊にも戦争状態を宣言
  - 1937年以来の「事変」処理と正式な国家間戦争の制度差
- マレー・フィリピン・香港での初動
  - 航空優勢・基地攻撃・陸上進撃を戦域ごとに分ける
- 12月10日
  - 英戦艦 Prince of Wales と巡洋戦艦 Repulse が日本海軍航空隊により沈没
  - 艦隊航空援護の欠如と航空攻撃の意味
  - 「戦艦が無意味になった」と単純化せず、この戦闘が示した作戦条件を具体化
- 12月11日
  - ドイツ・イタリアが米国へ宣戦
  - 米国も独伊との戦争状態へ
  - 三国同盟第三条の機械的自動発動としてだけ説明せず、ドイツ・イタリア側の政治判断を分ける
- ウェーク島最初の上陸攻撃失敗
  - 「緒戦は全部一方的勝利」という物語を避ける
- 12月12日の戦争呼称決定は次ページへ送る

## JH114→JH115 接続確認

JH114は同日の開戦手続と初撃を扱う。JH115では、**初撃の後に他国の宣戦・戦域拡大・海空戦の結果が重なり、日米英の戦争が既存の世界大戦へ接続される**ことを示す。

### JH115 implementation result — ✅ completed

- 12月9日の中国国民政府による対日正式宣戦と独伊との戦争状態宣言をFRUS一次史料で確認し、1937年以来の戦闘継続と正式宣戦を分離
- 12月10日のマレー沖海戦を、Prince of Wales・Repulseの出撃目的、有効な航空援護を欠いた作戦条件、日本海軍航空隊による撃沈という具体的な因果で実装
- 12月11日のウェーク島第一次上陸攻撃失敗を反映し、開戦初動の戦果が戦域ごとに分かれたことを示した
- 12月11日の独伊対米宣戦と米国側の宣戦手続を実装し、三国同盟第3条と各国政府の実際の宣戦判断を分離
- NHHC所蔵・Wikimedia Commons Public Domainのマレー沖海戦写真（80-G-413520）を採用
- JH114のnextIssuesを直接受け、JH114との隣接接続確認済み

- 中国政府の宣戦布告資料

# 7. JH116 — 1941年12月12日〜12月25日

## 中心問い

> 開戦の「初撃」は、どのように公式な戦争概念・同盟関係・占領統治へ変わっていったのか。

## 必須テーマ

- 12月12日閣議決定「今次戦争ノ呼称並ニ平戦時ノ分界時期等ニ付テ」
  - 対米英戦と「支那事変」を含め「大東亜戦争」と呼称
  - 平戦時分界を12月8日午前1時30分とする
  - 当時の政府用語として扱い、現代の中立的歴史用語と無説明で置換しない
- 公式宣伝・戦争目的の再構成
  - 「大東亜新秩序」「大東亜共栄圏」と戦争呼称の接続
  - 呼称決定を実際の占領政策の成果と同一視しない
- 12月16日以後のボルネオ等への進攻
  - 石油資源獲得と軍事占領の関係
- 12月21日 日タイ同盟
  - 12月8日の通過容認から軍事同盟へ制度段階が変わる
  - タイを日本の「占領地」と同一視しない
- 12月23日 ウェーク島占領
  - 11日の最初の上陸失敗から再攻撃・占領へ
- 12月25日 香港降伏
  - 英植民地統治から日本軍占領へ
  - 占領成立とその後の統治制度の形成を分け、詳細な占領統治は次フェーズ以後へ送る

# 8. A43 — 開戦初動の多正面作戦空間 map necessity / data-quality judgment

## 判定対象

12月8日以後、ハワイ、マレー、タイ、フィリピン、香港、グアム、ウェーク、ボルネオなど複数の戦域で同時並行に作戦が始まる。本文だけでは「同じ一日・同じ一週間にどれほど広い空間で作戦が走ったか」を把握しにくいため、地図必要性は高い。

ただし次の危険がある。

- 12月8日の攻撃地点と12月25日までの占領地域を同じ状態で塗り、時間差を消す
- 作戦計画線と実際の進攻路を混同する
- 直線LineStringで海上航路を描き、実航路を過剰主張する
- 現代国境を1941年の政治境界として読ませる
- 「日本軍が同時に全部を制圧した」ように見せる

## map necessity判定で確認する問い

- 初動戦域の相対配置を地図化することで、JH114〜JH116の中心問いが明確に改善するか
- Point中心で「攻撃開始」「継続戦闘」「占領成立」「同盟成立」を時点別に分けられるか
- 12月8日と12月25日の状態をtime sliceまたは明確な属性で分離できるか
- A42の「11月の集結・出撃準備」と主題重複せず、A43を「実戦開始後の戦域配置」として分けられるか
- LineString / Polygonを使わずとも中心問いに答えられるか

## データ品質方針

- まずPoint中心を既定案とする
- 各地点に eventDate / localDate / eventType / status を持たせる
- 時差が中心論点になる12月8日は、JST換算と現地日付を属性またはreading noteで区別する
- 進攻路・海上航路は、一次・公的戦史で経由geometryが確認できない限り描かない
- 12月25日時点の「占領」は都市・島・拠点単位で示し、広大な面支配をPolygonで即断しない
- タイは同盟・通過協定の制度類型として、占領地と同じカテゴリにしない
- 実装採用時はData Audit / Style Audit必須。time slice、LineString、Polygon、新しいinteractionを導入する場合はHuman Visual Audit必須

### 最終判定 — ✅ adopted / high

**map necessity: high / data-quality: sufficient for point-first implementation**

JH114〜JH116実装後に再判定し、A43は採用した。地図の問いは、**「12月8日に始まった主要戦域が、12月25日までにどの状態へ分かれたか」**とする。A42の「11月の集結・出撃準備」とは時点・問いを分離し、実戦開始後の広域配置を扱う。

実装は `opening-multifront-operations-1941`。ハワイ、マレー半島、ルソン島、グアム、ウェーク島、香港、ミリ、バンコクの8地点をPointで示し、12月25日時点の状態を「初撃後」「戦闘継続」「軍事占領成立」「国家間同盟成立」の4類型へ分けた。各Pointに `eventDate / localDate / eventType / status` を持たせ、真珠湾は現地時間12月7日と日本時間12月8日を併記した。

LineString / Polygon / time-slice UIは導入しない。海上航路・進攻路・戦線・占領範囲を描かず、フィリピン・マレーは12月25日時点で「戦闘継続」として後の占領結果を逆投影しない。タイは軍事占領地と別カテゴリにした。

Data Audit / Style Audit は passed。表示はA36・A42と同一のThematicMap point-only表示・ラベル・凡例・popup/touch interaction・広域zoom設計を再利用し、新しいinteractionを導入しないため、MAP_AUDIT_STANDARDのpoint-only再利用例外を適用して Human Visual Audit は `not-required-reused-pattern` とした。地図は12月25日までの結果を含むため、JH114へ先出しせず、JH116の `state-transition` 節直後へ配置した。

# 9. Crosscutting publication gate — ✅ completed

## S09系列「対外支配の制度差」— passing / 新規 S09-E

12月8日以後には、S09-Dが扱った「相手側の主権・行政を残した軍事アクセスと調停」だけでは整理できない制度状態が並んだ。

- タイ：12月8日の軍事通過容認を経て、12月21日に国家間同盟へ移行
- 香港・グアム・ウェーク：敵側守備隊の降伏後、日本軍の軍事占領が成立
- フィリピン・マレー：12月25日時点でも主要戦闘が継続し、占領成立前
- 中国占領地・南京国民政府：既存S09-Cで扱う政府形式と日本側実効権限の重なり

この差は、S09-Dを単純延長すると「軍事アクセス」と「敵国領の軍事占領」を一つの問いへ押し込むことになる。したがって、**S09-E `war-opening-alliance-occupation-1941`** を新設し、政府・条約主体の存続、守備隊降伏、軍事占領、継続戦闘を比較する独立した構造史として実装した。

S09-EはJH114〜JH116の年代順を再編集せず、12月25日時点の制度状態を横に比較する。A43のPoint地図とも比較軸は一致するが、地図を重複掲載せず、構造史本文では主権・政府・軍事支配の差に集中する。

## S13「日米交渉と経済圧力」— hold / 12月1日で終端維持

S13の中心問いは、軍事的既成事実、経済圧力、政策要求、準備時間の組合せが**交渉余地をどう変えたか**である。11月26日の米側包括案と12月1日の正式開戦決定で、「外交成功なら武力発動中止」という政策分岐は閉じている。

12月2〜8日の対米覚書送信・手交時刻・実際の手交遅延は、交渉条件の再編ではなく、すでに決まった開戦を外交・軍事の実施工程へ変換する問題である。JH112〜JH114が主体・時刻・手続を詳しく扱っており、S13へ追記すると終端を開戦実施史へ伸ばす重複になるため、**12月1日終端を維持**する。

## S10系列「産業社会の負担と保護」— hold

12月12日の平戦時分界と12月16日の南方経済対策要綱は重要だが、S10-D/Eの中心問いである国内の資金・物資・労働力・価格・企業・職場組織の配分制度を新段階へ変える材料としては不足する。

とくに南方経済対策要綱は、軍事占領地域の資源を戦争遂行へ接続する占領地経済政策であり、1941年5月までの国内物資配当・企業組織を扱うS10-Eへ入れると中心問いが変わる。具体的な国内配給・労務・企業統制の新制度が確認できる後続フェーズまで**hold**する。

## S05 / S12 — hold

- **S05**：1941年12月2〜25日に、議会・選挙・政党・翼賛会の参加回路を再編する新制度段階は確認できない。開戦手続や宣戦詔書を政治参加史へ寄せない。
- **S12**：秋丸機関・総力戦研究所について、この期間に新しい研究活動や、研究結果が開戦後の政策へ直接反映されたことを示す新史料は追加していない。年代記事の開戦経過を研究組織史へ再編集しない。

**Gate result:** S09-Eのみpassing。S13 / S10 / S05 / S12はhold。新規の別テーマ史は追加しない。

# 10. phase-end audit necessity judgment 候補仮説

独立監査を定型工程にはしない。フェーズ末に次の仮説が実装内で解消済みかだけ確認する。

- 12月1日開戦決定 = 12月2日作戦命令 = 12月8日戦闘開始、という制度段階の混同
- 「真珠湾攻撃だけが開戦」でマレー方面の先行・同時作戦を消す単一戦域化
- 対米覚書 = 宣戦布告、という文書役割の混同
- 覚書手交遅延を、計画された手交時刻・実際の攻撃開始時刻の検証なしに単一原因へ還元
- 12月8日の宣戦詔書が米英以外にも同じ形式で宣戦したかのような対象国混同
- 三国同盟を「日本の攻撃で独伊に自動参戦義務が発生した」と単純化
- 「緒戦は全面的圧勝」としてウェーク島最初の上陸失敗等を消す
- タイ同盟・香港占領・中国の南京政権を同じ「日本支配」に潰す
- 12月12日の「大東亜戦争」呼称を、現代の価値中立的な戦争名称として無説明使用する

隣接接続確認・A43監査・Crosscutting publication gateで解消済みなら独立auditは行わない。
