# 1. このフェーズを1941年7月25日〜9月5日に切る理由

7月24日まで、日本政府は南部仏印進駐によって米国の金融・輸出面の対抗措置が発動する可能性を具体的に予測していた。7月25日以後、その予測は実際の制度制約へ変わる。米国は日本資産を凍結し、金融・貿易取引を許可制の下へ置いた。米側史料には7月25日のホワイトハウス発表と7月26日付で扱う文書があり、日本側史料にも時差・受領時点による表記差があるため、実装時は**米国時間・日本時間・文書日付を区別し、一つの日付へ無理に圧縮しない**。

7月28日には日本軍が南部仏印へ実際に進駐し、29日には日仏印共同防衛議定書が調印された。前フェーズで扱った「進駐方針」「フランス側受諾」「現地細目合意」と、このフェーズの「実際の部隊進出」「正式議定書」を別段階として追う。

8月1日、米国は石油製品の既存輸出許可を大幅に取り消し、対日石油供給は資産凍結と輸出許可制度が組み合わさって急速に停止へ向かった。公開本文では「8月1日の一文書だけで全石油が即時完全停止した」と単純化せず、**資産凍結・輸出許可・決済手段・英蘭側措置が重なって供給が実質的に止まる制度過程**として説明する。

経済圧力が強まる一方、日本政府は外交回路を閉じなかった。8月7日前後には野村吉三郎大使を通じて日米首脳会談構想が具体化し、8月17日の野村・ルーズヴェルト会談では、米側が日本の基本政策の明確化を会談再開の前提として示した。8月26〜29日には近衛文麿首相のメッセージが整えられ、野村からハル、さらにルーズヴェルトへ手交された。

8月末から9月初めには、資源制約と外交交渉の時間認識が政府・統帥部の国策再検討へ接続する。9月3日の大本営政府連絡会議では「帝国国策遂行要領」が決定されるが、重要国策としての正式決定は9月6日の御前会議である。したがって本フェーズは**9月5日まで**とし、9月6日の御前会議を次フェーズの開始点に置く。

# 7. A39 — 資産凍結・石油供給制約と南方資源空間 map necessity / data-quality judgment

## 判定結果（2026-10-04）

**adopted / high。**

このフェーズでは、南部仏印進駐によって日本軍の基地・補給位置がマレー半島・蘭領東インドへ近づいた一方、7月末から8月にかけて米国・英国・蘭印の金融・輸出管理が重なり、石油を平時の商取引として日本へ運ぶ回路は急速に狭まった。A38は「基地要求地点と南方への距離」を示したが、A39は**資源が存在する場所へ軍事的に近づくことと、その資源を契約・決済・輸出許可・海上輸送によって取得できることは別問題だった**という逆転を空間的に説明する。これは本文の中心状態遷移そのものであり、地図化の必要性は高い。

ただし、A38と同じ地点をPointで再掲するだけでは新しい理解をほとんど増やさない。A39を独立地図として採用する条件は、**米国・蘭印から日本へ至る平時の石油調達回路を模式的なLineStringとして示し、南部仏印の基地位置・主要供給地域・輸出管理主体の空間関係を一枚で比較できること**とする。LineStringは実船の航跡や唯一の固定航路ではなく、史料で確認できる供給関係を読解するための模式線として扱う。

史料上の根拠は十分にある。FRUSの1941年10月7日付バタヴィア報告は、6月1日から7月28日までに蘭印から日本へ80,800トンの鉱油が送られ、7月28日の凍結規則発動後は事前支払済みの一隻分などを除いて石油引渡しが止まったと報告している。米国務省内部資料も、蘭印との石油取引がドル決済へ大きく依存し、米国の凍結統制がその停止要因になったと整理している。また8月時点の米側資料は、米国・英国・蘭印から日本への石油移動が、輸出許可・金融許可・輸送停止の組合せで実際に止まっていると記録する。したがって、個々のタンカー航跡を復元しなくても「主要供給圏と制度的に閉じた調達回路」という問いは一次史料で支えられる。

### 採用する空間問い

- 日本本土、南部仏印、蘭領東インド、米国側供給圏の相対位置
- 南部仏印のサイゴン・カムラン湾からマレー半島・蘭印方面への軍事的近接
- 米国・蘭印から日本へ向かっていた石油調達関係と、7月末〜8月にその回路を止めた輸出許可・金融許可の重なり
- 「南へ進めば資源へ近づく」という軍事地理と、「平時取引では資源へアクセスしにくくなる」という経済制度の逆方向の変化
- 制裁を一本の「包囲線」として描かず、供給地・輸出管理・決済・輸送を別の属性として読めること

### データ品質方針

- Map ID候補: `oil-supply-constraint-southward-space-1941`
- geometry: **Point + schematic LineString**
- geometryConfidence: **approximate / schematic**
- quality level: **Level C — Approximate / Schematic**
- Pointはサイゴン・カムラン湾、日本側受入れ地点、蘭印側の代表的な供給・管理地点、米国側の代表的供給圏など、史料・公的資料で役割を確認できる地点だけを採用する

# 8. Crosscutting publication gate — ✅ completed（2026-10-05）

## S10「産業社会の負担と保護」— ✅ pass / extension required

前フェーズでは、7月25日の資産凍結より前で切れていたため、国外調達の制度状態がまだ決定的には変わっておらず hold とした。今回はその保留条件が解消した。

7月25日以後、国外から資源を得る条件は、国内側の貿易統制や物資配当だけでなく、相手国側の資産凍結・輸出許可、ドル等による決済、蘭印側の取引条件、海上輸送、国内備蓄・用途別配分までを一続きの制約系として考える必要がある。とくに8月の石油供給制約は、「資源が存在する場所」と「日本が平時取引でその資源へアクセスできること」が別問題であることを明瞭にした。

延長では年代記事の制裁時系列を再掲せず、次の段階差を共通軸で比較する。

- 海外から商品を買う契約・取引上の権利
- 凍結資金やドル等を用いて代金を決済する能力
- 輸出国側の輸出許可
- 船腹・航路を含む海上輸送
- 日本国内の備蓄と用途別配分

これにより、S10の既存軸である「国外供給 → 輸出入統制 → 輸送 → 国内配当」を、1941年夏の**外部から供給回路そのものが閉じていく段階**まで進められる。A39はその空間関係を可視化し、S10は制度・負担・配分の比較を担当するため役割も重複しない。

## S09「対外支配の制度差」— hold / no extension

7月29日の日仏印共同防衛議定書は、7月21日の共同防衛了解を正式文書化し、南部仏印での日本軍駐留・基地利用を実施段階へ進めた点で重要である。ただしS09は前フェーズですでに、**フランスの主権・植民地行政を残したまま日本軍の駐留・基地利用を南部へ拡張する制度状態**を1941年7月24日まで比較軸へ追加している。

今回の正式議定書と実進駐は、その制度類型を法的・実務的に具体化するが、領有、総督府統治、租借、現地政府形式、軍事占領、調停・保障などと並ぶ新しい権限配分類型を追加するものではない。したがってS09本文を延長するとJH94の経緯再掲が増えるため、今回は hold とする。必要な制度差はJH94から既存S09へ接続して読める。

## 新規テーマ「日米交渉と経済圧力」— ✅ pass / new article required

前フェーズでは、日米交渉と南部仏印政策は並行していたものの、経済圧力の制度転換がまだ発動していなかったため defer した。今回はその条件が変わった。

1941年夏には、

- 7月末の資産凍結

- 9月初頭の外交判断時期と戦争準備時期の接続
が同時に作用するようになった。

この組合せは、年代記事を時系列に並べ直すだけでは捉えにくい。新規記事の中心問いは、**交渉条件・軍事的既成事実・経済圧力・政策上の時間制約が、日米双方の選択肢と交渉余地をどう変えたか**とする。

CONTENT_AUTHORING_STANDARDの横断記事要件に照らすと、次を満たす。

1. **年代記事とは異なる中心問いがある**：何が起きたかではなく、複数の圧力が交渉可能集合をどう変えたかを扱う。
2. **複数年代の比較が必要**：1941年春の交渉開始、6月の米側回答、7月の南部仏印・資産凍結、8月の石油・首脳会談、9月初頭の政策時間を比較しなければ構造が見えない。
3. **年代記事の再編集では成立しない**：比較軸を「要求／譲歩」「軍事的位置」「金融・輸出制約」「外交・軍事の時間」に置き、同じ軸を時点横断で追う。
4. **既存横断記事だけでは吸収できない**：S10は供給・負担・配分、S09は対外支配の法的制度差、S12は国力分析と政策決定への変換が中心であり、外交交渉の選択肢そのものを比較する記事は存在しない。
