## 1. フェーズ境界・記事数の根拠

JH137は6月7日、ミッドウェー島の米側保持、日本空母4隻の喪失、米空母ヨークタウン沈没、キスカ・アッツ占領までを記述している。次の時期に持ち越したのは **(a)** 日米双方の航空・海上戦力再編、**(b)** 北方拠点の増援・防空・補給・住民対応、**(c)** 米側の次期反攻目標と指揮範囲、**(d)** 珊瑚海で海上攻略が頓挫したポートモレスビー方面の新たな進攻手段である。JH138はこの4件を出発点とし、6月3〜7日の海戦経過を再掲しない。

**4本**を採用する。6月8〜17日は北方占領の実際の負担とミッドウェー後の態勢変化、6月18〜30日は米軍の反攻命令に向かう司令部間調整とパプア防備、7月1〜11日は7月2日の米統合指令・同9日前後の海軍作戦命令と日本軍の基地構築、7月12〜21日は上陸作戦の命令具体化と21日のパプア北岸上陸という、それぞれ異なる状態遷移を持つ。**7月21日**は日本軍がパプア北岸へ上陸し、計画段階から現地の軍事的既成事実へ進んだ境界である。7月22日以降のオーエンスタンリー山脈方面の実戦展開・8月7日のガダルカナル上陸は次フェーズで扱う。

4本を日数均等に割らない。7月中旬に独立した新しい変化が薄ければJH140・JH141を再検討し、記事本数合わせのために同じ反攻準備を二度説明しない。逆に、7月21日の上陸とその後の地上戦を一記事へ押し込まない。

### JH138 — 6月8〜17日

**中心問い:** 日本側の空母戦力喪失後、北方で占領した二島と周辺住民・米軍基地をめぐる現実の戦争負担はどう始まったか。

- JH137の7日までの結果を1〜2文の前提へ圧縮。6月8日以後の日本艦隊の帰投、米軍の損耗回復・情報集計は史料にある範囲で記述。海戦後に何が正式に中止・延期されたかは命令の主体・発令日・対象を分けて検証する。
- 米軍がキスカの占領を確認した経過、6月11〜14日頃の米側航空攻撃、島内の日本軍守備・補給・滑走路／水上機施設の実情をNPS・米軍記録で照合する。米軍の反撃を直ちに奪還上陸作戦と書かない。
- アッツのウナンガン住民に対する日本軍の拘束・後日の移送と、アトカなどの島で米当局が行った住民避難・建物の破壊を別の責任主体として時点別に記述。住民被害や死者の後年集計をこの期間内の既知情報として置かない。
- **図版判定:** NPS・米公刊写真・日本側当時の報道写真を調査し、権利と撮影日が揃えば採用、揃わなければ理由付きnoImage。

### JH139 — 6月18〜30日

**中心問い:** 米軍は限定された航空・艦艇・上陸戦力を、北方防備から南太平洋の次の攻勢へどう振り分けようとしたか。

- 6月後半の統合参謀本部／海軍の方針調整と、6月25日にキングが南太平洋司令部等へ伝えた下ソロモン攻勢の準備方針を公刊史で確認。7月2日の正式な統合指令と分離する。戦後の「米軍は攻勢へ転じた」という評価を、6月時点の確定命令に置き換えない。
- オーストラリア—ニューカレドニア—フィジー等への補給線確保、ラバウルからの日本軍航空行動、ツラギ基地の状況を、輸送時間と陸上航空支援の範囲として説明。
- パプアでは6月24日の豪州第39大隊B中隊のココダ方面派遣とパプア歩兵大隊の防備をAWMで照合。日本軍の海上侵攻中止後の陸路検討は日本側命令の時点を別途確認し、7月21日の上陸結果を予告的に断言しない。
- **図版判定:** AWMのパプア北岸・ココダ道資料、米海軍・海兵隊の南太平洋航路・基地写真を検討。

### JH140 — 7月1〜11日

**中心問い:** 米側の反攻方針はどの指揮系統と地域目標へ具体化し、日本軍の基地建設と占領地増援は何を変えたか。

- 7月2日のマーシャル・キング連名指令を、サンタクルーズ・ツラギ等の第一段階／ソロモン・ニューギニア／ラバウルをめぐる後続段階の区別として記述。ニミッツ、ゴームリー、マッカーサーの統率範囲、航空・上陸戦力の不足を説明し、後から知られる成功を前提にしない。
- 7月9日前後のニミッツの作戦命令と、翌段階のゴームリー作戦計画が決まるまでの調整を区別。公刊史で9日・10日という表記差がある場合は文書発令／伝達の対象と時刻を原史料で確認する。
- ガダルカナル島ルンガ岬付近の日本軍飛行場建設は、6月末の調査から7月初旬の工事進展として扱い、連合軍による発見・認識・攻撃計画との時点差を調べる。「7月6日に完成」などの未検証の精密日付は置かない。
- 7月1日のキスカ増援をNPSで確認。日本側のFS作戦その他の南太平洋構想について中止／延期の日時と文書上の意味を確認してから記述する。ミッドウェー戦の「敗北で全作戦即時中止」という一本道にはしない。
- **図版判定:** 1942年7月の作戦計画・飛行場偵察関連資料を検討。8月上陸後の写真を7月初旬の直接史料として流用しない。

### JH141 — 7月12〜21日

**中心問い:** 南太平洋で反攻に備える米側と、パプア北岸へ海上輸送・上陸する日本側は、同時期にどの地形・兵站制約に向き合っていたか。

- 7月16〜17日前後のゴームリー作戦計画など、WATCHTOWERの上陸兵力、海上・航空支援、輸送・荷揚げの役割を米海軍公刊史で確認。8月7日の成果をこの時点の確実な未来として書かない。
- 日本側はラバウル等の後方拠点、パプア北岸への船団輸送、ゴナ・ギルワの着上陸地点とココダ道・オーエンスタンリー山脈越えの補給制約を具体化する。豪軍・パプア側の既存警戒配置との接続も示す。
- **7月21日**の先遣隊上陸はAWM・豪州退役軍人省の記録を優先。上陸した兵員数は史料の集計範囲（先遣隊／一晩／後続増援）を明示し、23日以後の接触戦闘は次記事へ送る。
- **図版判定:** AWMのパプア戦役写真・地域概略図、米海軍の作戦計画図を検討し、撮影・作成日、著作権と使用目的を検証。

## 3. A49 — 「南太平洋の反攻目標とパプア北岸の交通制約」map necessity / data quality

**Historical question:** 米軍がツラギ・ガダルカナルを反攻初期目標とする一方、日本軍がゴナ・ギルワからポートモレスビーへ向かったとき、ラバウル・島嶼飛行場・海峡・山地・補給拠点が、移動・指揮・上陸後の輸送をどう制約したか。

- まず既存A47「南東方面への進攻と珊瑚海の空間」、A48「ミッドウェー・アリューシャン二方面作戦の空間」で説明できる範囲を比較。南太平洋の通信・航空支援範囲とパプア山地越えが新しい理解を与える場合のみ採用し、単にPointを増やすための地図を作らない。
- Point候補：ラバウル、ツラギ、ルンガ岬、エファテ／エスピリトゥサント、ポートモレスビー、ゴナ／ギルワ、ココダ。島・港・飛行場と当時の任務を区別し、7月21日段階の支配状態を確認する。
- 山脈横断・ココダ道のLineStringや作戦範囲Polygonを採用する場合は時点と幾何根拠・概略度を明示しData / Style / Human Visual Auditを必須とする。既存Point-onlyと同形式のみなら再利用監査例外の可否を記録し、見た目の特殊リスクを個別判断する。
- **現時点：判定待ち。** adopted / no-mapはJH141までの本文との重複を検証して決定する。

## 4. Crosscutting publication gate

年代記事の公開後、既存比較軸が本フェーズで実際に増えたかによって判定する。

- **S05-E「政治参加の回路」：** 日米の軍司令部間の指揮調整、内閣・帝国議会の政治参加機構との役割を分離。既存S05-Eに新たな政治制度の比較軸が加わらなければhold。
- **S09-F「軍事占領から占領統治へ」：** キスカ・アッツの駐屯・住民拘束、アトカ等での米当局の強制避難、ツラギの軍事基地、ゴナの上陸を、住民行政の確定した統治機構と区別する。地域比較に加えられる行政職掌・法的地位が確認できた場合だけ延長。
- **S10-D「戦時統制と資源配分」：** 艦船・航空隊・輸送船・燃料の作戦配分と、国内の船舶運営会・総動員法制の制度変更を区別する。制度上の新変化が確認できなければhold。
- **新規記事：** 年代4本と既存横断記事で説明済みの軍事史を総集編として重複させない。継続的な独立比較軸と出典がある場合のみ検討。

## 5. phase-end audit necessity judgment

独立監査は自動的に予定しない。JH137からの隣接確認、各記事の公開ゲート、Crosscutting gate、CIの後に、**複数記事・横断記事を同時に見ないと判断できない未解決矛盾が残る場合だけ**独立監査を実施する。

候補は、(1) ミッドウェー作戦の実戦での中止と後続の日本海軍南方作戦修正の日時・主体、(2) 米軍反攻指令の6月25日準備命令／7月2日統合指令／7月9〜17日実施計画の役割差、(3) 北方占領の軍事行動と住民対応の主体・時間差、(4) ポートモレスビー海上攻略中止と7月21日パプア北岸上陸の作戦手段の変化。隣接・通常ゲートで解消済みなら**no-audit**として完了する。
