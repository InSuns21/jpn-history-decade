# 構造史記事の意味的重複・留保主導スクリーニング（2026-10-09）

## 対象と方法

`content/structures/` の Markdown 全23本を対象とした。全記事について、見出し、節数・本文長、各節冒頭、否定・留保・読者指示の候補表現を確認した。問題の可能性が高い `kwantung-smr-rights`、`external-rule-institutions`、`local-administration-participation`、`manchukuo-occupied-china-rule`、`indochina-thailand-access-mediation` の本文について重点的に前後の論旨も点検した。

**これは全23本の史料再検証を終えたという意味ではない。** 文字列ヒットは診断材料であり、記事の不合格判定ではない。制度上の非同一性・条約上の制限は必要な史実であるため、削除ありきで扱わない。

判定軸：
1. 各節が独自の主体・行為・制度変更・負担・史料を追加しているか。
2. 前の節ですでに示した結論を、注意書きや言い換えで再提示していないか。
3. 「何ではないか」「どう読んではならないか」より具体的な出来事を先に述べているか。
4. 節末の総括が新しい比較軸をもたらすか、単なる要約になっているか。

### 完了確認の基準
