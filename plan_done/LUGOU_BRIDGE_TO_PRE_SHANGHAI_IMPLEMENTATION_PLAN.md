# 1. このフェーズを1937年7月7日〜8月12日に切る理由

1937年7月7日夜、北平郊外の盧溝橋付近で、日本の中国駐屯軍と中国第29軍系部隊の間に発砲を伴う衝突が起きた。事件直後には現地交渉と停戦が行われ、日本政府・軍中央にも不拡大・現地解決を求める判断があった。

一方、7月11日には現地停戦の動きと並行して、日本政府が関東軍・朝鮮軍などからの増援、さらに内地師団の派兵準備を決定した。アジア歴史資料センターは、当初は日中双方が不拡大方針を採ったが、戦力が逐次投入されて戦線が拡大したと整理している。

7月27日には日本政府が「北支那事変」に関して自衛行動をとると声明し、内地3個師団の華北派遣命令を出した。7月末には北平・天津周辺で大規模な戦闘へ移る。

次の明確な境界は8月13日の上海での日中両軍交戦開始である。華北の局地衝突・増援・北平天津方面の作戦と、上海で始まる華中の戦線拡大は、地理・軍種・外交・兵站・国際関係の条件が異なる。

したがってこのフェーズは、

```text
7月7日 局地衝突
→ 現地停戦・交渉
→ 7月11日 不拡大方針と増援決定の併存
→ 増援・交渉・再衝突
→ 7月27日 政府声明と内地3個師団派遣
→ 北平・天津周辺の大規模作戦
→ 8月12日 上海戦開始前夜
```

までを一つの状態遷移として扱う。

8月13日以後の上海戦、8月15日の政府声明、9月2日の「支那事変」への呼称変更は次フェーズへ送る。

# 3. JH37 — 1937年7月7日〜10日

**Status: completed / 2026-09-28**

## 中心問い

> 盧溝橋付近の一夜の軍事衝突は、なぜその場で終わらず政治・外交問題になったのか。それでも7月10日時点まで局地解決の余地が残っていたのはなぜか。

## 必須テーマ

- 7月7日夜の日本軍夜間演習と発砲
- 日本兵1名の一時所在不明と宛平県城への立入要求を、事件初期の交渉要素として説明
- 「第一発を誰が撃ったか」は断定を避け、確認可能な事実と後世の論争を分ける
- 中国駐屯軍と中国第29軍系部隊の制度的位置
- 宛平県城、盧溝橋、豊台、北平の位置関係
- 現地軍同士の交渉と、一時的な停戦
- 東京の陸軍省・参謀本部、日本政府と現地軍を別主体として扱う
- 南京国民政府、冀察政務委員会、第29軍を一枚岩にしない
- 7月11日の中央政府・軍の派兵判断は次ページへ送る

## JH36→JH37 接続確認

JH36末尾は、7月6日時点で中国駐屯軍と中国側諸主体が近接し、外交交渉と軍事的緊張が併存していたが、翌日の発砲も戦争拡大も確定していなかった状態で終わる。

JH37はその翌夜の衝突から始めるが、JH36の「可能性が複数残る状態」を否定しない。事件発生後も現地停戦・交渉が行われたことを示し、後の大規模戦争から事件初夜を逆算しない。

# 4. A20 — 盧溝橋事件初期の北平周辺政治・軍事空間

## map necessity

**候補: high / JH37実装時にData Auditを行って最終判定する。**

盧溝橋事件初期は、盧溝橋・宛平県城・豊台・北平・天津の距離関係が、

- なぜ日本軍がこの地域で演習していたのか
- なぜ宛平県城への立入りが交渉問題になったのか
- 現地軍と北平・天津の司令・行政拠点がどの程度離れていたか
- 後の北平天津方面作戦が、最初の衝突地点からどのように広がったか

を理解するうえで有効である。

## 初期方針

まず次の代表点だけを検討する。

- 盧溝橋
- 宛平県城
- 豊台
- 北平
- 天津

必要なら通州などを追加するが、事件・作戦理解に直接必要な地点だけに限定する。

## 厳格な制限

- 現代道路を1937年の軍事移動路として描かない
- 部隊の移動経路を根拠の薄いLineStringで結ばない
- 「日本軍支配地域」「中国軍支配地域」を粗いpolygonで塗らない
- 1937年7月の鉄道・道路geometryを使う場合は、時点と路線出典が確認できる場合だけ採用する
- 史料上の戦闘地点が広がりを持つ場合、精密な一点として偽装しない
- 現代OSMは背景地図であり、歴史的境界・道路網そのものではないと明示する

point-onlyで歴史理解が十分改善する場合は、線・面を追加しない。

# 5. JH38 — 1937年7月11日〜26日

**Status: completed / 2026-09-28**

## 中心問い

> 現地停戦が成立したのに、なぜ日本政府は同じ7月11日に増援を決めたのか。不拡大方針と派兵準備はどのように同時に存在し、その後の選択肢をどう変えたのか。

## 必須テーマ

- 7月11日の現地停戦協定
- 同日の日本政府・軍中央の判断
- 「不拡大・現地解決」と増援・動員準備を矛盾する一語で処理せず、目的・条件・主体を分ける
- 関東軍、朝鮮軍、内地師団の違い
- 陸軍省と参謀本部の役割差
- 中国駐屯軍への増援が現地の軍事力・交渉条件をどう変えたか
- 南京国民政府側の中央軍・外交判断と、冀察側の現地交渉を分ける
- 7月17日前後の蒋介石の対日方針は、当時の選択肢と条件の変化として扱う
- 再衝突・緊張の積み重なり
- 7月27日の日本政府声明・内地3個師団派遣は次ページへ送る

## 記述原則

「不拡大と言いながら派兵したから、最初から全面戦争を意図していた」と結果から単純化しない。

同時に「不拡大方針があったから、派兵は拡大に影響しなかった」とも書かない。

見るべきなのは、

```text
局地解決を目指す政治方針
+
交渉を有利にする／不測事態に備える軍事増援
+
増援を脅威と見る相手側の対応
```

が相互に作用し、局地解決の条件そのものを変えていった過程である。

# 6. JH39 — 1937年7月27日〜8月12日

**Status: completed / 2026-09-28**

## 中心問い

> 7月27日以後、華北での衝突はなぜ「現地事件」から大規模な軍事作戦へ変わり、北平・天津をめぐる戦闘が終わっても戦争終結にはつながらなかったのか。

## 必須テーマ

- 7月27日の日本政府声明
- 内地3個師団の華北派遣命令
- 7月末の北平・天津周辺での大規模作戦
- 北平・天津の軍事的占領と、これを「中国全体の降伏」と同一視しない
- 通州事件は、冀東政権保安隊・日本人／朝鮮人居留民など具体的主体を区別して扱う
- 通州事件をその後の戦争拡大の単一原因にしない
- 南京国民政府が華北での日本軍行動をどう認識し、軍事・外交対応を強めたか
- 中国共産党・国民政府の抗日協力が進む過程は、その時点の合意範囲と未解決対立を分ける
- 日本側で「北支那事変」として扱う制度・情報環境
- 8月9日の上海大山事件
- 上海には海軍陸戦隊、外国租界、南京政府側部隊など華北とは異なる主体・空間条件があることを導入
- 8月13日の上海での本格交戦は次フェーズへ送る

## 終点を8月12日にする理由

7月末までに華北では大規模作戦へ移ったが、それだけで戦線が中国中部へ自動的に広がったわけではない。

8月13日に上海で日中両軍が交戦を開始すると、

- 戦場が華北から華中へ拡大
- 陸軍だけでなく海軍・海軍陸戦隊の比重が増加
- 上海の国際都市・租界という外交条件が前面化
- 南京国民政府の中央軍投入
- 日本政府の8月15日声明

が重なり、別の制度状態に入る。

したがって8月12日をこのフェーズの終点とする。

# 8. 「宣戦布告なき戦争」の扱い

1937年夏以後、日本政府は中国との戦闘を「事変」と呼び、正式な宣戦布告を行わなかった。

ただしJH37〜JH39では、後の長期的な法的・経済的意味を先取りしすぎず、

- 当時政府が用いた呼称
- 軍事行動の実態
- 国際法・貿易・第三国との関係
- 後に「支那事変」へ呼称が広がる過程

を区別する。

「戦争と呼ばなかった＝戦争ではなかった」「宣戦布告しなかった＝法的効果がなかった」のどちらにも単純化しない。

このテーマが複数フェーズを通じて独立比較軸になるかは、次フェーズ以後のpublication gateで再判定する。

# 10. 横断記事publication gate候補

JH39まで実装後に判定する。

## S02「石高制・貨幣経済・財政」

派兵・動員に伴う追加軍事費が、1936〜37年前半の「拡張をどう支えるか」という財政構造を質的に変える場合のみ延長する。

単に軍事費が増えたという再要約なら延長しない。

## S05「政治参加の回路」

1937年総選挙後の議会・政党が、戦闘拡大と政府・軍の緊急意思決定へどの程度関与できたかを、既存の「参加から行政権形成への到達距離」で比較できる場合のみ延長する。

## S09「対外支配の制度差」

北平・天津占領後に、既存の冀察・冀東とは別の新しい統治制度・法的地位がこのフェーズ内に成立した場合のみ延長する。

軍事占領地域が広がっただけなら延長しない。

## S10「産業社会の負担と保護」

派兵・動員が家計、企業、農村、労働、物価、税・公債負担へ具体的に転嫁されたことを比較できる場合のみ延長する。

## 新規候補「局地衝突から国家戦争へ」

現地軍、参謀本部、陸軍省、内閣、外交、中国側中央政府の意思決定を、1931年満洲事変や1932年上海事変などと比較しなければ理解しにくい独立軸が成立する場合のみ候補化する。

JH37〜JH39の時系列を並べ替えるだけなら作らない。

## publication gate 判定 — 2026-09-28

| 候補 | 判定 | 理由 |
|---|---|---|
| S02「石高制・貨幣経済・財政」 | **延長** | 7月17日の予備金使用、北支事件費追加予算、8月の北支事件特別税・公債・借入によって、1936〜37年前半の計画的な軍備拡張から、実際の軍事行動を短期間で継続調達する財政へ質的に移った。単なる「軍事費増加」の再要約ではなく、戦費をどの財源で前借りするかというS02固有の比較軸が成立する。 |
| S05「政治参加の回路」 | **延長** | 7月の派兵・作戦判断が政府・軍の回路で先行した後、第71回帝国議会が北支事件費追加予算と特別税を審議した。選挙→議席→議会審議の回路と、緊急の軍事判断の回路がどこで接続するかを比較できるため、既存の中心問いを更新する。 |
| S09「対外支配の制度差」 | **延長しない** | 北平・天津方面の軍事的支配は変化したが、このフェーズ内の実装範囲では、新しい統治機構・法的地位が成立したことを独立比較軸として示す材料がない。軍事占領地域の拡大だけではgate条件を満たさない。 |
| S10「産業社会の負担と保護」 | **延長** | 北支事件特別税が所得・利得・配当・利子・物品などへ具体的な課税を設定し、公債・借入も併用された。戦費が現在の納税・取引と将来財政へどう配分されるかという、S02とは異なる「誰が負担するか」の比較軸が成立する。 |
| 新規「局地衝突から国家戦争へ」 | **新規作成しない** | 現時点ではJH37〜JH39そのものが「局地衝突→停戦と増援→大規模作戦」という状態遷移を詳細に扱っている。1931年満洲事変・1932年上海事変との比較軸は将来成立し得るが、このフェーズで新規記事を作ると年代記事の再編集になりやすい。上海戦以後に独立した比較問いが生じた時点で再判定する。 |

通過したS02・S05・S10だけを1937年8月12日まで延長した。S02は財源構成、S05は意思決定と議会審議の接続、S10は社会への負担配分を担当し、同じ追加予算を三記事で時系列再要約しないよう役割を分けた。

## phase-end audit necessity judgment — 2026-09-28

**独立監査は不要と判定する。** JH37〜JH39の隣接接続は各ページ実装時に確認済みで、publication gateでは横断記事との役割重複も判定した。今回新たに生じ得た具体的な横断問題はS02とS10が戦費財源を重複して説明することだったが、S02を「国家が何で調達するか」、S10を「その調達が誰へ・いつ負担を配分するか」と本文で明示的に分離した。S05も作戦判断そのものではなく、事後の予算・課税審議との接続を扱う。

したがって、複数記事を同時に再監査しなければ検出できない未解決仮説は残っていない。規約どおり、理由のないフェーズ末全体監査は追加せずCI / Pages確認へ進む。
