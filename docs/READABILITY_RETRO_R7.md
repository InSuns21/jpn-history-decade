## 4. 代表的な修正

### 4.1 1931年 — 満州事変前の複数主体を「回路」より先に置く

- 1931 のframingQuestionを、「制約問題」という分析語から、恐慌への対応、金本位制の維持、満洲権益、中国政治をめぐって各主体が何を選べたかという問いへ変更した。
- 中国東北部では張学良側が現地の治安・軍隊・行政を担い、南京国民政府が全国的な外交と主権回復を担っていたことを先に示し、「この構造」で一括しないようにした。
- 外務省の交渉、現地調査、中央政府間の処理を具体的に記述し、「制度回路」という見出し・総括を「政策上の選択肢」へ置き換えた。
- 1931年夏の日中摩擦を一文へ詰め込まず、『日本外交文書』に並ぶ複数案件を分割して説明した。
- 1931-09 では、政府の不拡大方針、関東軍の作戦、朝鮮軍越境、その後の政府追認を順に置き、軍事行動が次の軍事行動を呼びやすくなる仕組みを具体化した。

### 4.2 1932〜1933年 — 満洲国・国際連盟・政党政治を別々の手続で追う

- 1932 では、斎藤実が政党総裁ではないまま首相に就いたことと、予算・法律には帝国議会で政党の協力が必要だったことを分けて説明した。
- 五・一五事件後の政権形成を「別の政治回路」とせず、元老・宮中・軍・官僚の意向が後継首相選定へ強く働いた、と具体化した。
- summaryで血盟団事件・五・一五事件・斎藤内閣の三つの初出用語を一文へ集中させず、二文へ分割した。
- 1932-09 では、満洲国承認を日本政府が外交上支持する立場を確定した出来事として記述し、リットン報告書との制度判断の違いを後に置いた。
- 国際連盟脱退方針後も各国との外交・通商や別の国際会議は続いたことを、抽象的な「別の制度回路」ではなく具体的な外交関係として示した。
- 1933-06 の見出し「戦闘の停止を外交問題の解決へ読み替えない」を、「停戦後も日中間の政治・外交問題は残った」という肯定文へ変更した。

### 4.3 1934〜1935年 — 岡田内閣・天皇機関説・華北政策の主体を具体化

- 1934-07 では、岡田啓介が多数党総裁ではないまま首相に就き、予算・法案では政友会・民政党との交渉を必要とした、と具体的な政権運営へ戻した。
- 陸軍内部の見出しを「派閥名より人事と組織の衝突を見る」という読者指示から、「人事と組織をめぐる対立が表面化した」という歴史状態へ変更した。
- 天皇機関説問題では、国体明徴声明と教育・出版・人事への対応が、憲法条文を改正しないまま政府が公認する解釈を狭めた、と具体化した。
- 華北問題では、外務省、岡田内閣、支那駐屯軍、中国側の南京国民政府・華北担当者を先に置き、「この過程」という指示語を外した。
- 1935-08 では、相沢事件後に陸軍が軍法会議・人事・軍紀の手続を通じて事件を処理し、命令系統を維持する必要があったことを明示した。
- 国体明徴声明後も選挙・議会が続いたことと、政府が許容する憲法解釈が狭まったことを、否定フレーミングではなく二つの肯定的な状態変化として記述した。

### 4.4 1936年 — 二・二六事件後の権限と組閣条件をそのまま読める形へ

- 1936-02 のsummaryでは、「制度も消滅しなかった」と反論的に書かず、政府・宮中・陸軍中央がそれぞれの機構を通じて対応を続けた、とした。
- 1936-03 のframingQuestionは、「一つの軍事回路へ統一されなかった理由」ではなく、政府・陸軍・海軍・外務省・大蔵省がどの手続で政策を調整したかを問う形へ変更した。
- 粛軍・軍部大臣現役武官制の見出しも、否定形や「分けて見る」という読者指示を避け、人事再編、軍政・軍令の組織差、資格制限と候補者選定が組閣へ与える効果を直接示した。

## 5. Human Auditで確認したこと

9件すべてについて次を確認した。

- summary / framingQuestionだけでも、政府・内閣・陸軍・関東軍・政党・相手国などの主体と主要な出来事を追える。
- 1931年の日本政府、陸軍中央、関東軍、朝鮮軍を一つの「日本側判断」へ潰していない。
- 満洲国の建国・日本政府の承認、リットン報告書、国際連盟脱退通告を別々の制度上の出来事として扱っている。
- 五・一五事件後に政党内閣の慣行が中断しても、政党・帝国議会・総選挙が続いたことを具体的な制度として説明している。
- 天皇機関説問題で、法学説、政府声明、教育・出版・人事への行政上の波及を段階的に説明している。
- 皇道派・統制派を一枚岩の組織として扱わず、人事・軍紀・政策路線の対立を具体的に示している。
- 二・二六事件で、宮中・政府・陸軍省・参謀本部の役割を分け、行政戒厳下でも一般行政が継続したことを維持している。
- 1929 → 1931、1931 → 1931-09、1936-03 → 1937-01 の隣接接続を確認した。前後記事の中心問い・未解決論点と矛盾せず、背景説明の重複も増やしていない。
- 一般的な誤読防止はinterpretiveCautionsへ残し、本文・見出しでは歴史状態を肯定文で示した。

- source ID / URL: 変更なし
