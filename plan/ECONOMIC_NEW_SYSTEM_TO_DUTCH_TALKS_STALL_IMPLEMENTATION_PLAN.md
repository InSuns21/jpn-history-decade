# 1. このフェーズを1940年12月1日〜1941年1月21日に切る理由

11月30日までに、日本政府は南京国民政府を正式承認し、国内では大政翼賛会と大日本産業報国会という全国組織を発足させていた。一方、両組織が実際に何を担うか、経済統制を企業・業界へどう組み込むか、蘭印・仏印からどのように資源を確保するかは未確定のまま残った。

12月7日、閣議は「経済新体制確立要綱」を決定した。要綱は公益優先、官民協力、生産力増強を掲げ、重要産業を中心とする経済団体を政府の政策立案・実施へ接続する方針を示した。企画院案をめぐっては企業の所有・経営への統制範囲が争点となっており、決定された要綱を「企業私有の即時否定」や単純な全面国有化として扱わない。

12月14日には「大政翼賛会実践要綱」が発表され、10月の発足時には未確定だった運動の実践方針が具体化した。ただし、翌1941年2月の公事結社認定・政治活動禁止や、その後の改組は後段階である。12月14日時点で大政翼賛会の法的位置づけが最終確定したとは書かない。

対外経済では、芳沢謙吉特使が12月28日にバタビアへ到着し、日蘭会商を新しい代表のもとで再開した。12月30日には東京で日仏印正式経済交渉も始まり、北部仏印進駐後の関係が通商・資源条件の交渉へ広がった。

1941年1月16日、芳沢代表は蘭側へ具体的要求事項を示した。外務省『日本外交文書』は、1月21日の松岡外相の議会演説に蘭側が強く反発し、対案提出を再検討して会商が停滞したと整理している。したがって、**国内新体制の具体化と南方資源交渉の再始動が進み、日蘭会商が再び停滞へ入る1月21日**をフェーズ終点とする。

# 3. JH77 — 1940年12月1日〜12月13日

## 中心問い

> 11月までに整えられた国民運動・職場動員の組織へ、12月の経済新体制は企業・業界・政府の関係をどのように追加したのか。

## 必須テーマ

- JH76からの接続
  - 南京政府正式承認後も中国戦争は継続
  - 大政翼賛会と大日本産業報国会は成立済み
  - 芳沢特使派遣と日仏印正式経済交渉が準備中
- 12月7日 経済新体制確立要綱
  - 重要産業を中心とする経済団体
  - 政府の政策立案・実施と業界組織の接続
  - 公益優先、官民協力、生産力増強
  - 企業の所有・経営をめぐる企画院案と経済界の反発
  - 決定された要綱を「全面国有化」や「所有権廃止」と単純化しない
- 大日本産業報国会との役割差
  - 産報は職場・労務組織
  - 経済新体制は企業・業界・経済団体の組織化
  - 同じ「新体制」でも入口を分ける
- 12月14日の大政翼賛会実践要綱は次ページへ送る

## JH76→JH77 接続確認

JH76は11月30日、南京政府正式承認と国内動員組織の整備までを扱う。

JH77は翌12月から、**成立した組織をどう動かすか、企業・経済団体を国家計画へどう接続するか**という運用設計へ移る。

# 4. JH78 — 1940年12月14日〜12月31日

## 中心問い

> 大政翼賛会の実践方針が具体化する一方、南方資源外交はどの交渉主体と制度段階へ移ったのか。

## 必須テーマ

- 12月14日 大政翼賛会実践要綱
  - 10月発足時の組織枠から実践方針へ
  - 中央・地方組織と国民運動の関係
  - 1941年2月の公事結社認定・政治活動禁止を先取りしない
- 12月28日 芳沢謙吉特使がバタビア到着
  - 小林一三帰国後の会商を正式な新代表へ引き継ぐ
  - 11月の石油業者間妥結と政府間要求を分ける
- 12月30日 日仏印正式経済交渉開始
  - 10月のハノイ予備協議との段階差
  - 松岡＝アンリ協定・北部仏印進駐との接続
  - 1941年5月の協定成立は後段階
- 蘭印・仏印を「南方資源地域」と一括して同じ制度関係にしない
  - 蘭印：オランダ植民地当局との資源供給交渉
  - 仏印：フランス植民地行政存続下での正式経済交渉

## JH77→JH78 接続確認

JH77で経済新体制の国内制度方針が具体化する。

JH78は、**国内では大政翼賛会の活動方針、国外では蘭印・仏印との交渉主体と交渉形式**がそれぞれ具体化する段階を扱う。

# 5. JH79 — 1941年1月1日〜1月21日

## 中心問い

> 芳沢特使による具体的要求は日蘭会商を前進させたのか。日本政府の南方政策の表現は蘭印側の安全保障判断へどう作用したのか。

## 必須テーマ

- 1月16日 芳沢第一次提案
  - 具体的な資源・経済要求の提示
  - 蘭側が対案提出を検討する段階
  - 提案提出＝資源確保成功ではない
- 1月21日 松岡外相の議会演説
  - 日本側の南方・「大東亜」政策表現
  - 蘭側が仏印・タイと同列に扱われることへ反発
  - 対案提出再検討と会商停滞
  - 会商の正式打切りは1941年6月であり、この時点では「停滞」
- 日仏印正式経済交渉
  - 東京で継続中
  - 5月6日の妥結を先取りしない
- 中国戦争
  - 南京政府承認後も重慶国民政府との戦争は継続
  - 南方資源交渉の拡大を中国戦争終結の代替として扱わない

## JH78→JH79 接続確認

JH78は南方交渉の代表・形式が整ったところで終わる。

JH79は、**実際の要求提示と相手側反応によって交渉可能範囲が狭まり、日蘭会商が停滞へ移る**ところまでを追う。

# 6. A34 — 1940年12月〜1941年1月の南方資源交渉 map necessity / data-quality judgment

JH77〜JH79実装後に判定する。

候補：
- 東京
- バタビア
- ハノイ
- 仏印・蘭印の主要資源供給地／港
- 日本への資源輸送経路

ただし、単に「東京―バタビア―ハノイ」を線で結ぶだけでは、外交交渉・資源供給・軍事進駐という異なる関係を一つの交通線として誤読させる。

採用条件：
- 資源供給地域・港・輸送経路そのものが、交渉条件の理解を本文以上に改善する
- 蘭印と仏印で異なる法的・行政的関係を同じpolygon／LineStringへ圧縮しない
- approximate / schematic geometryを使う場合は、その主張上限を明示する

no-mapの場合は理由をplanへ記録し、map実装・Data / Style / Human Visual Auditは発生させない。

# 7. Crosscutting publication gate

JH77〜JH79実装後に判定する。

## S05「政治参加の回路」— high candidate

12月14日の大政翼賛会実践要綱が、10月発足時点の全国組織へ具体的な活動方針を追加する。

延長する場合は、政党解体後の参加回路というS05の比較軸へ変換し、年代記事の実践要綱説明を再掲しない。1941年2月の公事結社認定・政治活動禁止は後段階として残す。

## S10「産業社会の負担と保護」— high candidate

12月7日の経済新体制確立要綱は、企業・職場の勤労動員に加え、企業・業界団体を政府の計画・実施へ接続する組織設計を置く。

S10へ延長する場合は、
- 個別の価格・賃金・資産統制
- 大日本産業報国会による職場組織
- 経済新体制による企業・業界組織
を別の層として比較する。

## S09「対外支配の制度差」— hold unless state changes

日仏印正式経済交渉の開始は重要だが、1941年1月21日時点では5月の日仏印経済協定成立前である。

フランス植民地行政、日本軍駐留、経済交渉の関係について新しい制度状態が成立したと確認できる場合のみ延長する。単なる交渉開始ならhold。

## S02「石高制・貨幣経済・財政」— hold unless evidence changes

経済新体制は経済組織・産業統制の再編であり、租税・公債・通貨・中央銀行制度そのものの新しい状態遷移とは分ける。

この区間に財政金融制度の新しい比較軸が確認できる場合のみ延長する。

## 新規横断記事

原則追加しない。

南方資源外交は重要だが、1941年1月21日時点では蘭印・仏印の交渉が継続／停滞中であり、独立した長期記事にすると年代記事の再編集になりやすい。1941年春〜夏の日蘭会商打切り、日仏印経済協定、南部仏印進駐、資産凍結まで進んだ時点で再判定する。
