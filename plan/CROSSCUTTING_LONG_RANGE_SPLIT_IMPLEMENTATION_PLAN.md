## 1. 再編が必要な理由

現在の4本はいずれも、初期の中心問い自体は有効だが、年代実装が進むたびに関連する制度・負担・政策を追加した結果、複数の独立した問いを一つの記事で同時に処理するようになった。

この状態では、横断記事が

- 年代記事の要約を長期間つなぎ直す
- 後の状態から前の時代まで一本の因果鎖に見せる
- 既存のテーマ史と説明範囲が重複する
- 新年代を公開するたびに「関連するから延長する」こと自体が目的化する

という問題を起こしやすい。

再編後は、**「長期間を扱うこと」ではなく「複数年代を比較しないと答えられない一つの問い」を横断記事の単位**とする。

### 分割判断の原則

- 年数だけで等分しない。
- 政権交代や年号ではなく、中心問い・制度主体・比較軸が変わる地点で切る。
- 後年の出来事が同じ語を含むだけでは既存記事を延長しない。
- 同じ記事の framingQuestion に、独立して答えられる問いを「さらに」「また」「1941年には」のように継ぎ足し始めたら分割を優先する。
- 分割後の記事同士は内部リンクで接続するが、一つの一本道として読まないと理解できない構造にはしない。
- 新しい横断記事を増やすこと自体を目的にしない。隣接候補が同じ中心問いで自然に閉じるなら統合する。

## 2. S02「石高制・貨幣経済・財政」の分割

### 現状

1800年の石高・年貢・商人信用から、地租改正、日本銀行、金本位制、公債市場、1930年代の管理通貨・国債引受け、1937年の戦費調達までを一つの記事で扱っている。

比較可能ではあるが、少なくとも「幕藩財政」「近代財政国家」「恐慌後のマクロ政策」「戦時財政」は中心問いが異なる。

### 分割候補

#### S02-A 幕藩財政と貨幣経済
- **候補範囲:** 1800〜1868
- **中心問い:** 年貢・石高を基礎にした幕府・藩財政は、なぜ都市市場・貨幣・商人信用へ深く依存したのか。
- **主な比較軸:** 年貢、専売、藩札、借財、市場、商人信用、改革
- 明治政府の制度形成は結論として先取りせず、幕末時点の財政制約で閉じる。

#### S02-B 全国課税・中央銀行・通貨制度
- **候補範囲:** 1868〜第一次世界大戦期
- **中心問い:** 明治政府は、人と土地から全国的に徴税し、通貨・発券・信用を中央制度へ組み替える国家をどう作ったのか。
- **主な比較軸:** 地租改正、紙幣整理、日本銀行、国立銀行、公債、金本位制
- 産業化一般はS10系へ委ね、財政・金融制度に限定する。

#### S02-C 恐慌・管理通貨・財政政策
- **候補範囲:** 第一次世界大戦後〜1936
- **中心問い:** 戦後反動、金融不安、昭和恐慌を通じて、通貨・金融・財政政策の選択肢はどう変わったのか。
- **主な比較軸:** 金本位制復帰、金解禁、金融恐慌、金輸出再禁止、管理通貨、日銀国債引受け
- 「戦争へ向かう財政」として目的論化せず、1936年までの政策選択として閉じる。

#### S02-D 戦費調達と戦時財政
- **候補範囲:** 1937年以後
- **中心問い:** 日中戦争の拡大に対して、政府は一般会計・追加予算・公債・特別会計をどう組み合わせて戦費を継続的に調達したのか。
- **初期実装範囲:** 現行S02が根拠を持つ1937年11月12日まで。以後は別途必要性を判定して延長する。
- S10の物資統制とは「貨幣で予算を付けること」と「実物資源を配分すること」を分ける。

### migration

既存 `fiscal-transition` の本文・用語・source・relatedPeriods を機械的に複製せず、各主張を上記4問へ再配置する。重複する総説段落は一か所にだけ残す。

## 3. S05「政治参加の回路」の分割

### 現状

民撰議院設立建白書から地方議会、帝国議会、政党政治、普通選挙、軍部・外交の別回路、政党解党、大政翼賛会までを一つの「参加回路」として扱っている。

「参加の入口がどう作られたか」と「政党が政策形成をどう担ったか」と「翼賛体制で参加がどう再編されたか」は、比較軸こそ接続するが別の問いとして読める。

### 分割候補

#### S05-A 自由民権・地方議会・帝国議会
- **候補範囲:** 1874〜1890年代
- **中心問い:** 建白・請願・結社・地方議会・国会開設によって、政治要求を制度へ届ける入口はどう作られたのか。

#### S05-B 政党と政府
- **候補範囲:** 初期議会〜1918年前後
- **中心問い:** 衆議院の政党は、予算・立法・組閣を通じて政府へどこまで影響できるようになったのか。
- 元老、貴族院、官僚、軍部など、選挙外の決定回路を併記する。

#### S05-C 普通選挙と大衆政治
- **候補範囲:** 1918〜1920年代後半
- **中心問い:** 政党内閣と普通選挙は政治参加をどう広げ、その一方で治安維持法など政治活動を制約する制度とどう併存したのか。

#### S05-D 政党内閣の後退と翼賛体制
- **候補範囲:** 1930年代〜1941年1月21日
- **中心問い:** 政党内閣が常態でなくなった後、議会・政党・官僚・軍・翼賛組織の関係はどう組み替わったのか。
- 「普通選挙が大政翼賛会へ至った」という一本道にはしない。

### migration

既存記事の長期一本線を残さず、分割後の記事間は「前史」「後継」ではなく、比較可能な隣接テーマとしてリンクする。

## 4. S09「対外支配の制度差」の分割

### 現状

台湾・朝鮮・関東州・満鉄・満洲国・中国占領地・仏印・タイを、主権、行政、軍事権限、外交承認、保障という軸で一つの記事に集約している。

この記事は年代で切るより、**法的・制度的な支配形態そのもの**で分けた方が中心問いが明確になる。

### 分割候補

#### S09-A 台湾・朝鮮 — 領土編入と総督府統治
- **中心問い:** 日本領に組み込まれた地域では、主権・立法・行政・警察・軍事の権限がどのように配置されたのか。
- 台湾と朝鮮を「同じ植民地」として潰さず、制度差を比較する。

#### S09-B 関東州・南満洲鉄道 — 租借地と会社権益
- **中心問い:** 領土併合とは異なる租借権・鉄道権益・会社活動は、日本の行政・経済・軍事的関与をどこまで可能にしたのか。

#### S09-C 満洲国・中国占領地 — 国家形式と実効支配
- **中心問い:** 満洲国や中国占領地の政権形式では、国家・政府の外形と、日本軍・日本政府が持つ実際の権限はどう重なったのか。
- 「傀儡」の一語で制度差を省略せず、承認・行政・軍事・財政を分ける。

#### S09-D 仏印・タイ — 主権を残した軍事アクセスと調停
- **候補範囲:** 1940〜1941年7月24日
- **中心問い:** 相手国・植民地当局の主権や行政を形式上残したまま、日本は駐留・基地利用・調停・保障の権限をどう拡張したのか。
- 南部仏印進駐後の経済制裁・日米交渉はS13へ委ね、ここでは制度形態を中心にする。

### migration

制度類型の比較表は有効なので、各記事で共通の比較軸（主権／行政／軍事／外交承認／経済権益）を使う。ただし全類型を一枚の巨大表へ再統合しない。

## 5. S10「産業社会の負担と保護」の分割

### 現状

産業化による長時間労働・環境被害から、物価・失業・農村問題・都市生活、さらに1937年以後の資金・物資・労働統制、1941年の資産凍結・石油輸出統制・海上輸送までを一記事で扱う。

「産業化が生んだ社会問題」と「恐慌時の生活保障」と「戦時統制による配分」は中心問いが異なる。1941年の対外調達制約はS13とも重複する。

### 分割候補

#### S10-A 産業化と労働・環境負担
- **候補範囲:** 1890年代〜第一次世界大戦期
- **中心問い:** 工業化と企業成長は、工場労働・鉱山・周辺地域へどのような負担を生み、保護立法はどこまで対応したのか。

#### S10-B 都市化・物価・労働運動
- **候補範囲:** 第一次世界大戦期〜1920年代
- **中心問い:** 都市人口と賃金労働が拡大するなか、物価上昇・労働争議・住宅や生活費の問題は政治課題へどう変わったのか。

#### S10-C 恐慌・農村・社会政策
- **候補範囲:** 1920年代後半〜1936
- **中心問い:** 金融不安と昭和恐慌は、失業・農村債務・所得低下をどう広げ、政府・自治体・社会政策はどこまで対応したのか。

#### S10-D 戦時統制と生活・企業
- **候補範囲:** 1937〜1941年9月5日
- **中心問い:** 戦時動員の進展に伴い、資金・物資・労働力・価格・流通の配分は、企業・労働者・農家・家計の選択をどう変えたのか。
- 米国の資産凍結、石油輸出統制、対外交渉そのものはS13を主記事とし、S10-Dでは国内配分へ及ぶ効果だけ扱う。

### migration

「不足→統制→生活負担」を一つの抽象語で済ませず、誰が配分を決め、企業・労働者・農家・家計のどの選択が変わったかで整理する。

## 6. 共通実装手順

4本を一括で巨大改稿しない。**S02 → S05 → S09 → S10** の順を基本に、一系統ずつ次を完了してから次へ進む。

1. 既存記事の見出し・主張・用語・sources・relatedPeriods・内部リンクの inventory を作る。
2. 各段落を「どの新しい中心問いに必要か」で分類する。
3. どの記事にも不要な、年代記事の単純再掲・重複説明を削る。
4. 新しいMarkdownと `content/glossary/crosscutting/` 参照を作る。
5. 旧 routeKey / id への内部参照と外部ブックマークを壊さない移行方法を決める。
   - 既存routeを分割後の一記事へ継承する
   - または軽量な互換導線を実装する
   のどちらかとし、無言の404を作らない。
6. 各年代の `relatedCrosscutting` が本当に必要な記事だけを指すよう縮小する。
7. 第2章カード数が増えて一覧性を損なう場合は、構造史の系統別グルーピングを最小限追加する。UI再設計自体をこのPLANの目的にはしない。
8. 一系統ごとに content validation / link validation / `npm run check` を通す。

## 7. 規約へ反映する原則

実装時に `CONTENT_AUTHORING_STANDARD.md` の「横断コンテンツの必要性」へ、次の趣旨を追記する。

- 既存横断記事は、新年代と関連するという理由だけで自動延長しない。
- 新しい年代が**既存記事の中心問いへの答えを実質的に変える場合**だけ延長候補とする。
- 中心問いが別になる場合は、既存記事への追記ではなく、別記事・年代記事への委譲・内部リンクのいずれかを選ぶ。
- 長期記事で複数の独立した制度転換を一つの framingQuestion へ連結し続けない。

年数やrelatedPeriods数だけの機械的上限は設けない。100年を扱っても一問で閉じる記事はあり得る一方、10年でも問いが二つなら分ける。

## 8. Definition of Done

- S02 / S05 / S09 / S10 の4本について、既存の巨大な中心問いを分割し、各新記事が一つの問いで読める。
- 既存本文のコピー増殖ではなく、重複説明を削って再配置できている。
- 旧routeへの内部リンクまたは互換導線が壊れていない。
- glossary参照・source参照・relatedPeriodsが分割後の責務に一致している。
- 1941年の経済圧力・日米交渉はS13、反軍演説はS11、秋丸機関・総力戦研究所はS12など、既存テーマ史との重複を避けている。
- 第2章が「もう一つの通史」ではなく、独立した問いを選んで読める構成になっている。
- `CONTENT_AUTHORING_STANDARD.md` に自動延長抑制の原則が反映されている。
- `npm run check` green。
- GitHub Actions green。
- 公開面を変更した場合はPages deploy green。
- 完了後は本PLANを `plan_done/` へ移動する。
