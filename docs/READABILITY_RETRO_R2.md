## 1. 結論

1940年の14記事を全件Human Readability Auditし、14件すべてに実修正を行った。

R0でhigh候補だった6件は **6 → 0** となった。medium / low は合否ではなくレビュー補助であり、修正後に残るmedium候補11件も、人間監査で冒頭・本文・終端・留保分離を確認済みである。

このwaveで最も大きかった負債は、難語そのものより次の二点だった。

1. 同じ制度・手続・資源制約を、少し表現を変えて二度説明する反復。
2. 「回路」「構造」「政策枠組み」などの分析語が、議会手続・行政命令・交渉主体・期限より先に立つ文章。

とくに1〜3月の記事では反復説明を一本化し、7〜12月では抽象語を具体的な組織・会議・交渉手続へ戻した。

## 4. 代表的な修正

### 4.1 1〜3月 — 反復説明を一本化

- 1940-01-27: 工場・土地の使用収用、代表質問、懲罰手続の説明がほぼ二周していたため一本化。「発言できる回路／懲罰できる回路」を、代表質問・速記録削除・懲罰委員会・本会議議決という具体的手続へ戻した。
- 1940-03-07: 斎藤隆夫除名までの手続、棄権、南京政府成立前後の説明で重複していた段落を整理。「政策時計」を、議会会期・南京政府成立予定・対米通商という異なる期限へ具体化した。
- 1940-03-30: 南京政府の中央政府化、承認待ちの行政、軍事占領と行政範囲、石炭配給、米穀出荷の重複説明を一本化。

### 4.2 5〜8月 — 方針から実施主体へ

- 欧州本国の敗勢を「交渉条件」とだけ呼ばず、蘭印の資源供給要求、仏印の輸送停止・監視、既存植民地行政の利用へ分解。
- 政党解党では「政治参加の回路」を、議員・候補者・地方支部・支持団体をまとめていた政党組織の消失として説明。
- 第2次近衛内閣では、「国家意思決定回路」「政策表」を、閣議、官庁、大本営政府連絡会議、蘭印・仏印との個別交渉へ戻した。

### 4.3 9〜11月 — 同盟・大政翼賛会・中国戦争処理を具体化

- 三国同盟の長文を分割し、日本側の抑止意図と米国・蘭印側の反応を具体的に分離。
- 大政翼賛会は「組織回路」「二重構造」より先に、中央本部・地方支部・協力会議と帝国議会の役割差を示した。
- 南京政府承認と重慶和平工作は「二つの戦争処理回路」ではなく、承認日を動かす政府判断と11月13日・22日・28日の具体的な決定として整理した。

### 4.4 12月 — 「回路」から組織・会議・団体へ

- 経済新体制では、「国有化ではない」という反論型の見出しを、民営企業を残しつつ政府計画と業界組織による統制を強めた、という肯定文へ変更。
- 大政翼賛会実践要綱と臨時中央協力会議は、「上下の回路」ではなく、中央方針の伝達と地方・職域の意見集約という実際の機能で説明した。
- 年末の南方政策は、「交渉回路」ではなく、芳沢特使による日蘭会商と東京での日仏印正式経済交渉という別々の交渉体制で示した。

## 5. Human Auditで確認したこと

14件すべてについて次を確認した。

- summary / framingQuestion で主線が追える。
- 冒頭が具体的な主体・出来事へ入る。
- 本文で主語・動作・結果が抽象分析より先に出る。
- 長文分割後も因果・時系列・史料帰属が崩れていない。
- 終端が単なる本文再要約ではなく、次ページへ渡す状態・制約を残す。
- 一般的な誤読防止を本文へ戻していない。
- 1939年末 → 1940年初、1940年末 → 1941年1月の接続を再確認した。

## 6. 史実・出典・リンクへの影響

このwaveは可読性監査であり、新規歴史調査ではない。

- 新しい史実主張: 追加なし
- 既存の実質的な史実主張: 削除なし
- 重複していた説明: 統合・圧縮
- source ID / URL: 変更なし
- glossary term ID: 変更なし
- 地図・図版: 変更なし
- 年代境界・routeKey: 変更なし
