## 1. 結論

1939年開始の8記事を全件Human Readability Auditし、7件を実修正、1件（`1939-08-23`）を人間確認のうえ維持した。

R0でhigh候補だった1件は **1 → 0** となった。100字以上文、分析語先行、広い指示語、初出用語集中もすべて0になった。修正後に残るmedium候補3件は、固有名詞・日付・読点の集中によるscreeningであり、本文の主語・出来事・制度差を人間確認済みである。

このwaveで目立った負債は、ノモンハン事件を説明する際の「現地裁量 → 既成事実 → 中央の選択肢」という機序と、1939年秋の総動員行政を説明する際の「情報収集 → 配分 → 調整」という機序を、別見出しで何度も抽象的に言い換えていた点だった。関東軍・大本営、各省・内閣総理大臣、具体的な勅令・条約交渉を先に置き、重複する総括を削った。

## 4. 代表的な修正

### 4.1 1〜5月 — 政権継承・生産計画・対独伊外交の重複を整理

- `1939-01-05` では、平沼内閣への政策継承を同一記事内で繰り返していた小節を削除し、冒頭で主要閣僚・官庁・未解決案件を一度だけ具体化した。
- 国民職業能力申告令の対象条件を一文から二文へ分け、100字以上文を解消した。
- 生産力拡充計画の「資源・輸送・労力・技術・資金」の説明を別小節で再掲していた箇所を整理した。
- `1939-02-10` では、防共協定と軍事協定の違いを「枠組み」の比較から、参戦義務の有無という具体的な制度差へ戻した。
- 5月10日時点の終端は、本文全体を再要約せず、中国戦争・汪兆銘工作・対独伊交渉が未解決のまま翌日の満蒙国境衝突へ入る状態だけを残した。

### 4.2 5〜7月 — ノモンハンの「構造」を関東軍と大本営の行動へ戻す

- `1939-05-11` のsummaryは、満洲国・モンゴル人民共和国・ノモンハン事件・関東軍を一文へ集中させず、衝突、事件開始、日ソ増援の順に分けた。
- 「正のフィードバック」は、双方が強い反撃を重ねるほど増援が増え戦闘規模が拡大した、と具体的な行為へ言い換えた。
- 「現地が先に行動し中央が後から判断する構造」は、関東軍が現地判断で部隊を動かし、大本営が報告後に制止・追認を判断する時間差として記述した。
- `1939-06-14` では、タムスク攻撃を「通信・権限・作戦機会の速度差」と抽象化せず、関東軍が中央の再判断を待たず作戦を実施したため、大本営が実施後の状況を前提に対応した、とした。
- 両岸作戦の敵兵力見積もりは長文を分割し、情報担当と作戦担当の判断差を追いやすくした。

### 4.3 7〜9月 — 同じ制約の再説明を減らす

- `1939-07-26` では、8月20日以後の「中央の選択肢が狭まる」説明を、直前の戦場損耗と外交交渉の節に一本化した。
- 記事末で対米輸入・外貨・ノモンハン・国内生産を再度まとめていた二小節を削除し、state-at節を次の独ソ不可侵条約への接続に限定した。
- `1939-08-23` は、独ソ不可侵条約 → 平沼退陣 → 阿部内閣 → 欧州戦争不介入 → ノモンハン作戦中止・停戦の順が具体的に追え、screeningのmediumは固有名詞・日付密度によるものだったため、数値を下げるだけの改稿は行わなかった。

### 4.4 9〜12月 — 総動員行政を各省・首相・法域・施行日で説明

- `1939-09-16` の「この構造」は、占領地守備と新攻勢を同時に続ける軍需負担が統制を緩めにくくした、と具体化した。
- 「結節点」「情報回路」は、各省が競合する電力・外貨・輸送力・労働力を首相のもとで比較・調整する手続へ戻した。
- `1939-10-18` では、工場検査を「情報回路」と呼ばず、原料・部品の不足を行政へ伝え、資材配分の判断材料にする仕組みとして説明した。
- 12月末の法域・公布・施行の説明から「分けて見る必要がある」「統制を読むには」といった読者への読み方指示を外し、朝鮮と内地の法域差、12月29日公布・1940年2月1日施行という史実を肯定文で示した。
- 1939年末の日米条約問題は、1940年1月記事と重複しないよう、暫定取決めを探った状態と対米通商条件が次の制約として残ったことまでに圧縮した。

## 5. Human Auditで確認したこと

8件すべてについて次を確認した。

- summary / framingQuestion で、政府・軍・内閣・相手国の主体と主要な出来事を追える。
- ノモンハン事件で、関東軍・大本営・政府を一つの「日本側判断」へ潰していない。
- 防共協定と軍事協定、日米通商航海条約の終了通告と失効、公布と施行、内地と朝鮮の法域を区別している。
- state-at / state-transition節が本文の再要約になりすぎないよう整理した。
- 一般的な誤読防止はinterpretiveCautionsへ残し、本文では当時の主体・制度・制約を肯定文で記述した。
- 1938年12月22日〜1939年1月4日 → 1939年1月5日、および1939年10月18日〜12月31日 → 1940年1月1日の接続を確認した。
- 1939年末の日米条約失効準備を圧縮し、1940年1月記事が条約失効直前の実務と1月26日の失効を詳しく扱う役割を保った。
