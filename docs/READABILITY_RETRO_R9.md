## 1. 結論

1868・1872・1874・1878・1882・1886・1891・1896・1901の9記事を全件Human Readability Auditし、9件すべてを実修正した。

R0でhigh候補だった1872年は **high 1 → 0** となった。分析語先行は2→0、広い指示語は2→0、初出用語集中は5→3となった。100字以上文は3件残るが、いずれも人間確認済みであり、正式名称・制度説明・因果関係を保つため機械的には分割していない。

このwaveでは、明治国家形成を「中央集権化」「制度回路」「統治構造」といった分析語から始めず、新政府、地方官、議会要求者、政党、元老、軍、裁判所、台湾統治機関などの具体的な主体と制度から追えるよう修正した。

また、「〜ではない」「単純化すると」「〜と読む必要がある」といった仮想読者への訂正を本文の主文から外し、制度上の状態・主体・結果を肯定文で示す形へ改めた。

## 4. 代表的な修正

### 4.1 1868〜1878年 — 新政府形成と政治参加を具体的な行動で追う

- 1868では、諸藩を固定的な「新政府派／旧幕府派」に分ける読者訂正文を削り、朝廷への態度、会津処分、近隣藩、戦況に応じて各藩が選択したことを直接記述した。
- 1872では、summaryに集中していた戸籍法・壬申戸籍・学制、地券・徴兵令・地租改正を複数文へ分け、初出用語を段階的に導入した。
- 1874では、民撰議院設立建白書と佐賀の乱を「複数の回路」とまとめず、議会設置要求と武力反乱という異なる行動として示した。
- 1875年の元老院・大審院・地方官会議は、それぞれ立法・司法・地方官意見の機関として具体化した。
- 士族反乱では「士族全体が反政府ではない」という反論形を避け、新政府側で官僚・軍人として働く士族と反乱参加者の地域差を肯定文で示した。
- 1878では、「この仕組み」「この過程」を地方税・府県会、琉球藩廃止・沖縄県設置という具体名へ戻した。

### 4.2 1882〜1890年 — 財政・中央銀行・憲法準備を制度ごとに分ける

- 1882では、松方財政の影響を「すべて説明できない」とする留保中心の文から、地域の産業構造・借入関係・税負担・市場価格が負担差を生んだという直接説明へ改めた。
- 紙幣整理、日本銀行設置、銀兌換銀行券発行を、政府支出の抑制から中央銀行を通じた通貨・信用管理への移行として具体化した。
- 1886では、条約改正を司法制度整備と接続し、外国人判事問題を国内政治の反発へ結びつけた。
- 憲法・議会準備と政治運動規制を同時進行の政策として示し、「自由が一直線に拡大したわけではない」という読者訂正を本文から外した。
- 市制・町村制と府県制・郡制は、地方の階層ごとに自治と中央監督を異なる割合で組み合わせた制度として説明した。

### 4.3 1891〜1901年 — 議会運用・植民地統治・政党政治を結果から逆算しない

- 1891の大津事件では、「司法が完全に独立したわけではない」という評価を先に置かず、政府要求と裁判判断が実際に緊張した事件として説明した。
- 1892年の選挙干渉は、政府の介入と、それでも民党勢力が議席を維持した結果を並べ、二者択一の評価を避けた。
- 日清戦争は、朝鮮国内の政治危機、日清両軍派兵、撤兵問題、内政改革要求、王宮占領、海戦、宣戦布告という段階で示した。
- 台湾統治は「統治構造」という分析語から始めず、1895年に台湾を新たな統治対象へ組み込んだ事実から説明した。
- 1896では、台湾の軍事的制圧と行政制度整備、軽工業中心の工場制生産、隈板内閣の短命、北清事変後の外交制約を肯定文へ直した。
- 1901では、政党政治の発達と社会主義結社への警察介入を同じ段落で具体的に対比し、桂園時代も桂・西園寺の政治基盤と政策調整から説明した。
- 大韓帝国の節見出しを、読者への反論形から「中立を宣言した国家の主権が狭められる」という状態変化へ改めた。

## 5. Human Auditで確認したこと

9件すべてについて次を確認した。

- summary / framingQuestionで、その年代の主要主体と状態変化を追える。
- 「中央集権化」「立憲化」「政党政治」「植民地統治」といった分析語の前に、誰が何を決め、どの制度が変わったかを置いた。
- 1868年の新政府成立を、最初から全国を直接統治する近代国家が完成した出来事として書いていない。
- 自由民権運動、士族反乱、政党形成を一つの反政府運動へまとめていない。
- 内閣、枢密院、衆議院、貴族院、地方制度、裁判所を異なる権限の制度として説明している。
- 松方財政、中央銀行、金本位制を同じ金融改革の語で潰さず、紙幣整理・兌換・国際決済の役割を分けている。
- 日清戦争・台湾統治・日露戦争・大韓帝国への介入を、それぞれの法的地位・軍事過程・外交関係を保って記述している。
- 1865 → 1868、R9内の各隣接年代、1901 → 1906 の接続を確認した。
- 一般的な誤読防止は主張層へ戻さず、必要な制度上の境界だけを本文に残した。
