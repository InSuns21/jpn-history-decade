# 1. このフェーズを1941年10月18日〜11月5日に切る理由

前フェーズは10月16日の第三次近衛内閣総辞職と、17日の豊田貞次郎外相から野村吉三郎大使への交渉継続訓令までで終えた。内閣は倒れたが、対米交渉回路そのものは切れていなかった。

10月18日、東条英機内閣が成立する。東条は首相に加えて陸相・内相を兼ね、外相には東郷茂徳、海相には嶋田繁太郎、大蔵相には賀屋興宣が就任した。新内閣の成立を「その日に対米開戦を決定した」とは扱わない。むしろこの時点で重要なのは、**近衛内閣が一致できなかった国策を、新内閣が自らの責任で再検討する意思決定回路が作り直されたこと**である。

10月23日の第59回大本営政府連絡会議は東条内閣成立後最初の連絡会議となり、9月6日御前会議決定の「帝国国策遂行要領」をそのまま引き継ぐのか、新しい方針を作るのかを含めた再検討に入る。以後、作戦の長期見通し、対ソ関係、船舶損耗・造船、主要物資、独伊協力、米英蘭の分離可能性、外交妥結の見込みなどが連日検討される。

この再検討は、単に「開戦するか否か」の二択ではない。10月30日には東条首相から、概括すると

1. 戦争を極力避けて現状を耐える
2. 直ちに開戦を決意し、政策を戦争へ集中する
3. 戦争を決意して準備を完成しつつ、外交を続けて妥結を求める

という三つの政策方向が提示される。したがって、10月中の連絡会議を「すでに開戦が決まっていて形式的に追認した会議」と書かず、**複数の政策選択肢を、資源・輸送・作戦・外交の制約と突き合わせる再評価過程**として扱う。

11月1日から2日未明にかけての第66回大本営政府連絡会議では、この再検討が結論段階へ入り、対米交渉要領と国策遂行要領がまとめられる。ここでも政府、陸軍省、参謀本部、海軍、外務省の認識を一枚岩にしない。参謀本部内には交渉断念・早期開戦を求める強い意見がある一方、政府の正式な政策は外交を継続する形で調整される。

11月5日の第7回御前会議で、新しい「帝国国策遂行要領」と対米交渉の甲案・乙案が正式決定される。これは12月1日の開戦決定とは別段階であり、同日から直ちに戦争状態へ入るわけでもない。まず甲案を提示し、不成立なら譲歩度を高めた乙案へ進む外交手順が確定する。

このため本フェーズは、**東条内閣成立 → 国策の白紙的再検討 → 政策選択肢の比較 → 11月1日の収束 → 11月5日の正式再決定**で一つの状態遷移をなす。11月6日以後は、決定された甲案・乙案を実際の外交交渉へ投入し、米側の回答を受ける別の状態へ移るため次フェーズとする。

# 3. JH103 — 1941年10月18日〜10月22日

## 中心問い

> 近衛内閣が日米交渉と戦争準備の方針を統一できず総辞職した直後、東条内閣はなぜ9月6日国策をそのまま自動継承せず、改めて検討し直す必要があったのか。

## 必須テーマ

- JH102からの接続
  - 10月16日第三次近衛内閣総辞職
  - 10月17日豊田外相から野村大使へ、内閣交代後も日米交渉継続方針に変更なしとの訓令
- 10月18日 東条内閣成立
  - 東条英機：首相・陸相・内相兼任
  - 東郷茂徳：外相
  - 嶋田繁太郎：海相
  - 賀屋興宣：大蔵相
  - 新内閣を「即日開戦内閣」と短絡しない
- 組閣時の制度状態
  - 政府と統帥部は別系統の権限を持ち、大本営政府連絡会議で調整する
  - 近衛内閣の総辞職で9月6日国策が法的・制度的に自動消滅したわけではない
  - 新内閣が既定国策を自らの責任で再検討する必要
- 天皇から東条への組閣時の意向・指示
  - 「白紙還元」という後世の要約語だけを独走させず、同時代記録・公文書で確認できる範囲を分ける
  - 天皇の意向を、11月5日までの政府・統帥部の具体的検討を不要にする一方的政策決定として書かない
- 10月18〜22日の外交継続
  - 内閣交代後も野村大使を通じる日米交渉経路が存続
  - 東郷外相就任によって外交担当主体は交代するが、交渉自体がいったん消滅して再開したわけではない
- 10月23日の最初の連絡会議は次ページへ送る

  - 東条内閣成立後最初の連絡会議
  - 杉山元・永野修身両総長は早期の国策決定を要求

  - 9月6日国策をそのまま採るか、新しい国策を作るか自体を検討対象にする
- 再検討項目
  - 10月23日に具体的な検討項目を設定
  - 作戦、対ソ関係、船舶、主要物資、外交などを分解して扱う

  - 船舶損耗・造船能力
  - 主要物資需給

  - 取得、輸送、船舶損耗、製油・精製、占領後の復旧など複数の関門を区別する

# 7. A41 — 国策再検討の資源・船舶・南方作戦空間 map necessity / data-quality judgment

## 判定対象

10月23日以後の国策再検討では、南方作戦の所要期間、主要物資、液体燃料、船舶損耗・造船、資源獲得後の輸送が政策判断へ組み込まれる。

一方、既存地図には次がある。

- A38: 南部仏印の基地・進駐空間
- A39: 石油供給制約と南方資源空間
- A40: 南方作戦準備地域と対象方面

このためA41は、既存3地図を言い換えて再掲するだけなら **no-map** とする。採用するには、10月23日〜11月5日の再検討で新たに重要となった「資源獲得地・海上輸送・船腹制約・作戦対象方面」の関係を、既存A39/A40では示せない形で説明できる必要がある。

### map necessity判定で確認する問い

- 国策再検討の中心問いは空間配置を見ないと理解しにくいか、それとも表・本文の方が適切か
- 蘭印等の資源獲得地から日本までの海上輸送距離・海域が船舶制約の理解を改善するか
- A39の石油供給関係、A40の準備地域・対象方面との差分を明確にできるか
- 10月時点の計画・見通しと、12月以後の実際の侵攻ルート・占領地資源輸送を混同しないか
- schematic LineStringを使う場合、実航路と誤読させない不確実性表現を維持できるか

### データ品質方針

- 時点の異なる作戦計画を一つの確定ルートへ統合しない
- 海上LineStringを使う場合はMAP_AUDIT_STANDARDのcartographic waypoint規則を適用する
- 船舶損耗・造船量など数量自体は地図の線幅へ安易に符号化せず、表・本文の方が適切か先に判断する
- 既存A39/A40の再掲で足りる場合は新規地図を作らない
- LineString / Polygon採用時はHuman Visual Audit必須
- point-onlyで既存監査済みUIを厳密に再利用する場合だけ規約上の再利用例外を検討する

# 8. Crosscutting publication gate 候補

## S13「日米交渉と経済圧力」

**extension候補。**

前フェーズでは、外交期限が日本側条件の一本化と政権存立を拘束するところまで延長した。本フェーズでは、政権交代後に「時間」がさらに変質し、外交期限だけでなく、作戦準備・船舶・資源・物資の見通しを比較して国策を再決定する圧力になる。

ただし年代記事の会議列を再掲せず、既存の比較軸「要求・譲歩 / 軍事的位置 / 経済的選択肢 / 時間」で新しい状態が生じた場合だけ延長する。

## S10「産業社会の負担と保護」

**extension judgment候補。**

主要物資、液体燃料、鉄、船舶、造船能力が政策判断の入力として明示的に比較される。ただし、本フェーズで新しい国内配給・価格・労働・企業統制制度が成立しない場合、年代記事の国力見通しをS10へ移すだけになりうる。その場合はholdとする。

## S12「秋丸機関と総力戦研究所」

**comparison / hold judgment候補。**

10月末の政府・統帥部による公式な国策再検討は、既存S12で扱う総力戦研究と比較可能だが、秋丸機関・総力戦研究所そのものの新しい活動段階ではない。研究結果と政策決定の関係を新しい一次史料で確認できない限り、安易に「研究結果を無視して開戦した」という因果へ接続しない。

## S05 / S09

原則hold候補。政治参加制度や対外支配の新しい制度類型が成立する期間ではないため、publication gateで新規状態が確認できなければ延長しない。

新規横断記事は、既存S13/S10/S12で扱えない独立した長期比較軸が成立する場合だけ検討する。

# 9. phase-end audit necessity judgment 候補仮説

フェーズ末に独立監査を自動追加しない。以下の問題が年代記事・crosscutting gate内で解消されず、複数記事を同時に見ないと判定できない場合だけ独立監査する。

- 東条内閣成立 = 10月18日に開戦決定、という目的論化
- 「白紙還元」の一語で、天皇・政府・統帥部の制度的な再検討過程を消すこと
- 10月23〜30日の会議を、既定の開戦方針を形式的に追認しただけと書くこと
- 参謀本部、陸軍省、東条首相、海軍、外務省を「軍部」一枚岩としてまとめること
- 資源不足 = 即時開戦しか選択肢がなかった、または南方資源獲得 = 長期戦問題が解消する、と単純化すること
- 10月30日の三方針 = 11月5日の正式決定、と段階を潰すこと
- 11月1日の連絡会議結論 = その時点で御前会議決定済み、と書くこと
- 11月5日の御前会議 = 12月1日の対米英蘭開戦決定、と混同すること
- 甲案・乙案を11月26日の米側覚書への回答として逆時系列化すること
- 11月1日以後の外交を一律に「偽装外交」と書き、政府正式方針と参謀本部内部意見を混同すること

具体的な未解決仮説が残らなければ **no-audit** として通常のCI / Pages確認へ進む。

# 13. このフェーズでしないこと

- 東条内閣成立を、その日付だけで対米英開戦決定と同一視しない
- 「白紙還元」の通称だけで、具体的な国策再検討手続きを説明しない
- 東条個人の性格だけで政策再検討・開戦過程を説明しない
- 陸軍省と参謀本部、海軍、外務省の意見差を消して「軍部の方針」と一括しない
- 作戦期間・船舶・物資見通しを、後の実績値から逆算して当時すでに分かっていたこととして書かない
- 南方資源を獲得すれば輸送・船舶・精製・占領地復旧の制約も同時に解決すると書かない
- 10月30日の三方針を11月5日の正式国策と同一視しない
- 11月1日の連絡会議結論を御前会議決定と同一視しない
- 11月5日の御前会議を12月1日の開戦決定と同一視しない
- 甲案・乙案をハル・ノートへの回答として書かない
- 11月6日以後の甲案提示・来栖派遣・乙案提示・11月26日米側覚書を本フェーズへ先取りしない
- フェーズ末に理由のない独立全体監査を追加しない
