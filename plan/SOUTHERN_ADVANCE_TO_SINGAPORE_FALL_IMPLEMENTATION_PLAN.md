# 1. このフェーズを1941年12月26日〜1942年2月15日に切る理由

前フェーズの終点12月25日には、香港守備隊の降伏によって香港の軍事占領が成立した。一方、フィリピンではルソン島の攻略が続き、マレー半島でも日本軍はシンガポールへ向けて南下していた。したがって12月25日は「南方作戦完了」ではなく、戦域ごとの進行度が大きく分かれた時点だった。

12月26日、香港では第23軍軍政庁が置かれ、戦闘で獲得した地域を行政・治安・物資・住民管理へつなぐ工程が始まった。ここは、守備隊降伏という軍事結果から占領統治の実務へ移る明確な制度境界である。

フィリピンでは1942年1月2日に日本軍がマニラへ入り、翌3日にはマニラ防衛司令部が設けられた。しかし米比軍主力はバターン半島へ後退して戦闘を継続した。首都占領とフィリピン全域の軍事的制圧は同じ出来事ではない。

1月11日前後には、マレーでクアラルンプールが占領され、蘭印ではタラカン・メナド方面への上陸が始まった。南方作戦は英米拠点の攻略から、石油などの資源地帯を持つ蘭印の本格攻略へ広がる。同じ時期、連合国側もABDAの統合指揮を整え始めたため、日本側の進攻だけでなく守備側の指揮再編も並行して扱う必要がある。

1月23日のラバウル攻略は、東南アジアだけでなくニューギニア・オーストラリア北方に接する南西太平洋へ戦域が広がったことを示す。24日のバリックパパン上陸、30日前後のモールメン攻略、31日の英連邦軍のシンガポール島撤退まで進むと、マレー半島の陸上戦はシンガポール島防衛へ移った。

2月8日、日本軍はジョホール海峡を越えてシンガポール島への攻撃を開始し、15日に英連邦軍が降伏した。同時期にはアンボン、スマトラ・パレンバン方面でも日本軍の進攻が続いており、シンガポール陥落を南方全域の攻略完了とは扱えない。ただし、英帝国の東南アジア防衛の中核拠点が崩れ、次の局面で蘭印・ビルマ・フィリピン残存拠点の攻略が前景化するため、2月15日は自然なフェーズ終端になる。

このため本フェーズは、**初期占領の軍政化 → 首都・主要都市の占領と残存戦線の分離 → 蘭印・南西太平洋への戦域拡大 → マレー半島からシンガポール島への戦線移動 → シンガポール降伏**という状態遷移として1941年12月26日〜1942年2月15日に切る。

# 3. JH117 — 1941年12月26日〜1942年1月2日

## 中心問い

> 香港で軍事占領後の行政が始まる一方、フィリピンではなぜマニラ占領後も戦争が終わらなかったのか。

## 必須テーマ

- JH116からの接続
  - 香港は12月25日に守備隊降伏
  - フィリピン・マレーでは主要作戦継続
  - 南方経済対策要綱は資源確保を軍政・輸送実務へつなぐ入口
- 12月26日 香港第23軍軍政庁
  - 守備隊降伏から軍政実務への制度移行
  - 行政、治安、物資、住民、捕虜管理を「占領」の一語に圧縮しない
- ルソン島
  - 日本軍のマニラ進撃
  - 米比軍のバターン方面への計画的後退
  - マニラのopen city宣言と軍事的占領を区別
- 1942年1月1日
  - 連合国側の国際協力再編は、必要な範囲で国際環境として扱う
- 1月2日 マニラ占領
  - 首都占領とフィリピン全域の制圧を分離
  - バターン・コレヒドールの抗戦継続を次ページへ接続

## JH116→JH117 接続確認

JH116は香港降伏とフィリピン・マレーの継戦で終わる。JH117では、**降伏済み地域では占領統治が始まり、未制圧地域では戦線が再編される**という二つの後続工程を同時に示す。

# 5. JH119 — 1942年1月12日〜1月23日

## 中心問い

> 日本軍の南方進攻が複数戦域へ広がる中、連合国側の統合指揮は何を変え、何をすぐには変えられなかったのか。

  - 米英蘭豪の統合指揮形成
  - 組織成立と、兵力・航空機・艦艇・通信・距離など実際の制約を分離
- マレー南部
  - ゲマス、ムアル／バクリ等の戦闘
  - 局地的抵抗と戦線全体の後退を両立して書く
- 蘭印
  - タラカン・メナド後の次段階
  - 油田・飛行場・港湾という複数の作戦目的
- ビルマ方面
  - タイ領を利用した進攻の開始
  - タイ同盟と、タイ領を経由する対英作戦を制度上分ける
- 1月23日 ラバウル
  - 港湾・飛行場拠点としての意味
  - 南西太平洋への作戦空間拡大

## JH118→JH119 接続確認

JH118は、マニラ占領後もバターン防衛線が残り、マレーではクアラルンプール占領後にゲマス・ムアル方面へ戦線が移り、蘭印ではタラカン・メナドへの上陸が始まった状態で終わる。JH119では、**バターン継戦／ゲマス・ムアルの局地抵抗と全般後退／タラカン・メナドの拠点化／ビルマ主力進攻／ラバウル占領**を受け、同時にABDA統合指揮の成立を配置する。指揮制度の統合と現場の兵力・通信・補給条件を別段階として扱い、JH118で説明済みの占領・資源確保の一般論は圧縮する。

# 6. JH120 — 1942年1月24日〜1月31日

## 中心問い

> 1月末までに、南方作戦の各戦域はどの防衛線・資源拠点・交通結節点へ移ったのか。

  - 「油田占領＝即時に日本へ石油供給」としない
- ビルマ
  - モールメン攻略までの進展
  - シッタン・ラングーン方面へ続く戦線として整理

  - 1月31日、英連邦軍がシンガポール島へ撤退
  - ジョホール海峡のcauseway破壊

# 7. JH121 — 1942年2月1日〜2月15日

## 中心問い

> シンガポール降伏は、南方作戦全体の中で何を変え、何をなお未解決のまま残したのか。

## 必須テーマ

- 蘭印
  - アンボン占領
  - スマトラ／パレンバン方面への進攻
  - 2月14日の空挺作戦と15日の地上部隊進出
  - 資源施設・飛行場・海上交通の目的を分ける
- シンガポール
  - 2月8日 日本軍のジョホール海峡渡河・上陸
  - 島内の防衛配置、給水・弾薬・兵力などの制約
  - 2月15日 パーシヴァルの降伏
  - 英帝国の東南アジア防衛・海軍基地の意味
- 降伏後
  - 軍事占領成立と、その後の「昭南」行政・占領政策を分離
  - 香港占領地総督部の正式発足（2月19〜20日）などは次フェーズへ送る

  - バターン・コレヒドールでは抗戦継続
- ビルマ
  - ラングーン未占領
- 蘭印
  - ジャワ攻略は未完了

## JH120→JH121 接続確認

JH120は、1月31日に英連邦軍がシンガポール島へ撤退してコーズウェーを破壊し、蘭印ではバリックパパン・ケンダリ、ビルマではモールメンまで日本軍の前進拠点が広がった状態で終わる。JH121では、**アンボン守備隊降伏／シンガポール島への2月8日上陸／パレンバンの2月14日空挺攻撃と15日の地上進出／2月15日のシンガポール降伏**を次の状態変化として受ける。シンガポールでは海峡防衛から島内戦、軍事的降伏へ進む過程を具体化し、降伏後の占領行政は次フェーズへ送る。蘭印では空挺攻撃・地上進出・資源施設破壊・修復を分離し、2月15日時点でもバターン・ビルマ・ジャワが未決着であることを残す。

### 最終判定 — ✅ adopted / high

**map necessity: high / data-quality: sufficient for point-first implementation**

JH117〜JH121実装後に再判定し、A44は採用した。地図の問いは、**「1942年2月15日時点で、南方の主要戦域が占領後管理・軍事占領・継続戦闘・同盟国のどの段階に分かれていたか」**とする。A43の1941年12月25日時点から状態を更新し、単なる進攻地点の追加ではなく、軍事占領が行政・拠点化へ進んだ地域と、なお戦闘が続く地域を同時点で比較する。

実装は `southern-advance-status-1942-02-15`。香港、マニラ、バターン、タイ、シンガポール、タラカン、バリックパパン、ラバウル、ビルマ戦線、アンボン、パレンバンをPointで示し、「占領後の管理機構が稼働」「都市・拠点の軍事占領成立」「戦闘・攻略継続」「同盟国・作戦通過基盤」の4類型へ分けた。マニラとバターンを別Pointにし、首都占領をフィリピン制圧へ拡張しない。シンガポールは2月15日の降伏まで、パレンバンは2月14〜15日の攻略進行中として扱い、後続する占領行政・施設復旧・資源供給を先取りしない。

LineString / Polygon / time-slice UIは導入しない。実進攻路・海上航路・前線・占領範囲を描かず、広大な「日本占領地」を一枚の面で示すことによる偽の精密さと、未制圧のバターン・ラングーン・ジャワへの結果の逆投影を避ける。

## strong candidate

### S09-E「開戦初動――同盟・軍事占領・継続戦闘」

**extension strong candidate。**

12月25日時点では、香港・グアム・ウェークの軍事占領、タイの国家間同盟、フィリピン・マレーの継続戦闘という比較だった。本フェーズでは、

南方資源の確保は重要だが、国内の価格・配給・労働制度に新しい比較段階が成立しない限りS10へ機械的に追加しない。S13は12月1日で外交分岐が閉じており、戦争実施史を後付けしない。

# 10. phase-end audit necessity judgment

独立監査を定型では置かない。Crosscutting publication gate後に、次の具体的仮説が未解決で残るかだけ判定する。

候補：

1. マニラ占領をフィリピン攻略完了としてしまう
2. シンガポール陥落を南方作戦全体の完了としてしまう
3. 軍事占領・軍政・植民地行政・国家間同盟を一つの「日本支配」にまとめる
4. 油田・港湾占領を即時の資源供給成功へ直結させる
5. ABDAの設置を、現場の統合作戦能力が即座に完成したことと同一視する
6. 各戦域の局地的勝敗を、日本軍の全般的な一方的進撃へ均してしまう
7. 1942年2月15日時点で未制圧のバターン・ジャワ・ラングーンを後知恵で既成の日本支配圏に入れる

各年代の隣接接続確認、S09-E gate、通常validationで解消済みなら **no-audit** とし、重複する独立監査は実施しない。
