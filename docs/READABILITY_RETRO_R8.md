## 1. 結論

1906・1912・1915・1919・1923・1926・1929の7記事を全件Human Readability Auditし、7件すべてを実修正した。

R0でhigh候補だった1923年は **high 1 → 0** となった。100字以上文、120字以上文、分析語先行、広い指示語、初出用語集中もすべて0になった。修正後に残るmedium候補4件は、固有名詞・制度名・日付・読点の集中によるscreeningであり、主語・出来事・制度差を人間確認済みである。

このwaveでは、政党政治・帝国統治・金融制度を「回路」「構造」などの分析語より先に、内閣・政党・元老・軍・総督府・銀行・枢密院などの具体的な主体と手続で追えるよう修正した。

また、1906〜1923年の旧原稿では、後知恵や単純化を防ぐ「〜としない」「逆算しない」「区別する」が `contemporaryAssumptions` に残っていた。現行規約に合わせ、当時の制度・情報・財政・政治条件を肯定文で `contemporaryAssumptions` に置き、一般的な誤読防止を `interpretiveCautions` へ分離した。

## 4. 代表的な修正

### 4.1 1906〜1912年 — 桂園時代と大正政変を具体的な政治基盤で追う

- 1906では、桂太郎・西園寺公望の役割を、政友会・官僚・軍・貴族院・元老という具体的な政治基盤から説明した。
- 「複数の権力回路」という圧縮を避け、衆議院議席、官僚・軍との関係、元老の影響力を政策ごとに調整したことを直接記述した。
- 満鉄、統監府、韓国併合、工場法について、誤読への反論を本文の主文にせず、主体・制度・権限の状態変化を先に置いた。
- 1912では、大正改元後も憲法・議会・官僚制・軍・元老・貴族院・植民地統治が継続したことを冒頭で示した。
- 二個師団増設を兵員・給与・兵舎・装備などの恒常支出として説明し、大正政変を財政と内閣形成の具体的問題へ接続した。
- 青島・南洋群島では、軍事占領と戦後の法的地位を時間順に示した。

### 4.2 1915〜1919年 — 大戦景気・植民地統治・政治参加を主体別に分解

- 1915の対華二十一か条要求は、青島占領後の権益処理、最後通牒、中国政府の選択肢という順で説明し、後知恵による計画論を本文から外した。
- 112字だった二十一か条要求の説明を複数文へ分割し、要求内容・最後通牒・受諾を一文に詰め込まないようにした。
- 戦時景気では企業利益、賃金、生活費が同じ速度で動かなかったことを具体化し、工場法の保護範囲も肯定文で示した。
- 1919では、三・一運動の国際環境と朝鮮社会内部の組織を順に示し、「文化政治」も警察・教育・言論の具体的変更から説明した。
- パリ講和会議の山東・南洋・人種差別撤廃提案を別案件として整理し、100字超だった人種差別撤廃提案の文を分割した。
- 普通選挙運動・労働運動・女性運動を「回路」でまとめず、選挙法、団結・交渉、治安警察法改正という制度別に示した。
- ワシントン会議では四カ国条約・九カ国条約・海軍軍縮条約の対象と義務を具体化した。

### 4.3 1923年 — high候補を解消し、災害・復興・普通選挙・治安統制を分離

- summaryで第二次護憲運動・男子普通選挙法・治安維持法を一文へ集中させていた箇所を分割し、120字以上文とfirst-term-denseを解消した。
- 関東大震災では、地震・火災による被害と、流言・差別意識・軍警・自警団の行動を通じた人為的殺傷を別の因果として記述した。
- 帝都復興を後藤新平一人の構想へ集約せず、土地権利、財政、議会、自治体、住民との調整を具体化した。
- 男子普通選挙法の対象を満25歳以上の男性として明示し、女性・植民地朝鮮・台湾との制度差を肯定的な制度説明へ戻した。
- 治安維持法では、治安警察法による行政規制と刑事法上の取締りの違いを具体的に示し、1925年成立時と1928年以後の強化を分離した。

### 4.4 1926〜1929年 — 金融・治安・軍事政策の決定主体を明示

- 1926では、昭和金融恐慌を戦後不況・震災手形・銀行経営・台湾銀行問題という先行要因から説明した。
- 三・一五事件と治安維持法改正を「別の回路」とせず、普通選挙実施後に取締りが強化された事実を直接示した。
- 山東出兵は閣議決定、張作霖爆殺は関東軍内部の参謀らによる中央の正式決定を経ない行動として、命令経路を分けた。
- 1929では、金本位制の仕組みを金流出と国内信用の引締めとして具体化し、「この仕組み」という指示語を除いた。
- 1930年総選挙では民政党が過半数を得て政府を支えたことを示し、政党政治が実際に作動した状態を肯定文で記述した。
- 海軍省と軍令部を行政と軍令の異なる機関として説明し、ロンドン条約・統帥権問題を「政府対海軍」の一文へ潰さないようにした。

## 5. Human Auditで確認したこと

7件すべてについて次を確認した。

- summary / framingQuestionで、その年代の主要主体と状態変化を追える。
- 分析語より先に、内閣・政党・元老・軍・総督府・銀行・枢密院・相手国政府などの主体を置いた。
- 政党政治の発展を現在型の議院内閣制へ一直線に進む歴史として書いていない。
- 台湾・朝鮮・関東州・満鉄・戦時占領の法的地位を一つの「海外支配」へ潰していない。
- 大戦景気と生活費、普通選挙と治安統制、金融恐慌と昭和恐慌を、それぞれ異なる仕組みとして説明している。
- 1923年の震災被害と人為的殺傷を原因上区別し、犠牲者総数の不確実性を留保層へ残した。
- 1928年の山東出兵と張作霖爆殺、1930年の海軍省と軍令部を、異なる決定主体・命令経路として示した。
- 1901 → 1906、1906 → 1912、1912 → 1915、1915 → 1919、1919 → 1923、1923 → 1926、1926 → 1929、1929 → 1931 の接続を確認した。
- 一般的な誤読防止は `interpretiveCautions` へ、当時の制度・情報・財政・政治条件は `contemporaryAssumptions` へ分離した。

## 6. 史実・出典・リンクへの影響

このwaveは可読性監査であり、新規歴史調査ではない。

- 新しい史実主張: 原則追加なし。既存段落の内容を分割・具体化した。
- 既存の実質的な史実主張: 削除なし。
- 抽象圧縮・広い指示語・読者向け読み方指示・否定フレーミング: 整理・具体化。
- `contemporaryAssumptions` / `interpretiveCautions`: 現行規約に合わせて再配置。
- source ID / URL: 変更なし。
- glossary term ID: 変更なし。
- 地図・図版: 変更なし。
- 年代境界・routeKey: 変更なし。
