# 1. このフェーズを1941年6月22日〜7月24日に切る理由

6月21日まで、日本政府は南部仏印への進駐構想を内部で検討しながら、日米交渉も継続していた。6月22日（日本時間）、野村吉三郎駐米大使はハル国務長官から、5月末の日本案に対する米国側の修正案とオーラル・ステートメントを受け取った。これは交渉の即時打切り通知ではなく、なお非公式・予備的な交渉文書の往復だった。

同じ6月22日、ドイツがソ連へ侵攻した。日本にとっては、4月の日ソ中立条約と9月以来の日独伊三国同盟を同時に抱えたまま、北方と南方の優先順位を再検討する必要が生じた。独ソ戦開始をもって日ソ中立条約が自動的に消滅したわけでも、日本が即時に対ソ参戦を決めたわけでもない。

6月25日の大本営政府連絡懇談会は「南方施策促進ニ関スル件」を決定し、南部仏印への進駐を具体的な政府・統帥部方針へ引き上げた。7月2日の御前会議では「情勢ノ推移ニ伴フ帝国国策要綱」が決定され、南方政策を進めながら独ソ戦の推移にも備える枠組みが置かれた。ここでは、南部仏印進駐の政策決定、仏側との交渉、実際の軍進駐を時点別に分ける。

7月7日には関東軍特種演習（関特演）に伴う大規模な動員が始まった。これは対ソ作戦の可能性を現実の軍事準備として高めたが、それ自体を対ソ開戦命令と同一視しない。同時に日米交渉も7月10日・12日の政府内協議などを通じて継続し、南方政策と交渉の両立可能性が検討された。

外交方針をめぐる政府内対立は内閣改造へ波及し、7月16日に第2次近衛内閣が総辞職した。第3次近衛内閣の正式成立は7月18日であり、松岡洋右に代わって豊田貞次郎が外相となった。7月21日には新内閣下で政府・統帥部の調整が再開され、同時期に仏印との共同防衛に関する了解が成立する。

7月25日、米国は日本資産を凍結し、対日経済関係は新しい制度段階へ入る。したがって本フェーズは**資産凍結の直前、7月24日まで**とし、資産凍結、南部仏印への実際の進駐、7月29日の日仏印共同防衛議定書、8月1日の対日石油輸出制限強化は次フェーズへ送る。

# 7. A38 — 南部仏印進駐決定と基地・補給空間 map necessity / data-quality judgment

## 判定結果（2026-10-04）

**adopted / high。**

このフェーズの本文は、南部仏印進駐を外交・軍事上の「方針」として追うだけでは、なぜ米英蘭側が北部仏印進駐より強い警戒を示したのかを十分に説明しにくい。サイゴンとカムラン湾を南部仏印の主要基地要求地点として置き、北部仏印のハノイ・海防との距離差、さらにマレー半島・蘭印・フィリピンとの相対位置を同時に示すと、**中国向け補給遮断中心だった北部仏印から、東南アジア海域・英米蘭拠点へ接近できる基地・補給空間へ重心が移る意味**を地図で説明できる。

史料上の空間情報も地図化に十分である。1941年7月24日付の米国外交文書は、日本側に認められた施設としてカムラン湾の海軍基地、サイゴンの軍・海軍施設と軍用飛行場、コーチシナ・カンボジアの複数航空基地を報告している。JACARの7月24日第41回大本営政府連絡会議資料も南部仏印進駐細目を扱う。したがって「基地要求・計画段階の主要地点」という問いは一次史料・公的史料で支えられる。

一方、本フェーズ終点の7月24日は実進駐前である。7月28日以後の部隊配備・占領範囲・進軍経路をこの地図へ前倒ししない。A38では**Point中心**に縮退し、基地「圏」、作戦線、占領面をLineString / Polygonで推定しない。

### 採用する空間問い

- 北部仏印のハノイ・海防と、南部仏印のサイゴン・カムラン湾の距離・役割差
- サイゴン、カムラン湾など7月24日までに史料で確認できる主要基地要求地点
- タイ湾、マレー半島、蘭印、フィリピンとの相対位置
- 南部仏印進駐が、中国への補給遮断に加えて南方資源圏・英米蘭拠点への接近として認識された地理的理由

### データ品質方針

- Map ID候補: `southern-indochina-bases-1941`
- geometry: **Point only**
- geometryConfidence: **approximate**
- quality level: **Level C — Approximate / Schematic**
- 代表点は現在の同名都市・港湾の概略位置を使い、1941年の施設中心点・滑走路・軍港境界を復元した座標とは扱わない
- 背景地図の現代国境・現代行政界は1941年の支配境界ではないとreading noteで明示する
- 「コーチシナ・カンボジアの八つの航空基地」は7月24日の米側報告で総数を確認できるが、個々の地点を一次史料で確定できない限り八点へ機械的に割り当てない
- 7月28日以後の実進駐、部隊配置、進軍経路は次フェーズの時点情報として扱い、A38へ混在させない
- 既存 `northern-indochina-advance-1940` と `thai-indochina-mediation-1941` のPoint表示・label・popup/touch interactionを再利用できる

### 主要データ根拠

- JACAR「1941年7月24日 第41回大本営政府連絡会議（南部仏領インドシナ進駐細目）」

- FRUS 1941, Far East, Vol. V, doc. 235（Tokyo, July 23, 1941）：Indochina bases occupation決定との同時代認識

# 8. Crosscutting publication gate

## S09「対外支配の制度差」— ✅ pass / extension required

南部仏印進駐方針と日仏印共同防衛了解は、フランスの主権・植民地行政を形式上残しながら、日本軍の駐留・基地利用を南部へ拡張する制度状態を生む。これは1940年9月の北部仏印進駐と同系統の「既存主権・行政 + 外国軍駐留」だが、1941年7月には共同防衛了解、基地利用、南部への軍事アクセスが組み合わさり、比較軸を一段進める。

延長では、
- 領有・植民地直接統治
- 租借・会社権益
- 現地政府形式と軍事占領
- 他国主権・植民地行政を残した駐兵・基地利用
- 外交的調停・保障
を分離し、**主権・行政権と軍事アクセスが別主体へ配分される状態**として南部仏印を位置づける。年代記事の経緯を再掲するのではなく、北部仏印・仏タイ平和条約・南京政府などとの制度比較へ変換する。

## S10「産業社会の負担と保護」— hold / next phase

南部仏印進駐は資源獲得・供給安全保障と結びつくが、本フェーズは7月25日の米国による日本資産凍結の直前で切れる。S10の既存終点は、国外調達・貿易統制・輸送・国内配当が一つの制約系になったことまで説明している。

このフェーズだけを追加すると「南方へ進めば資源制約を改善できるという政策期待」を年代本文から再要約する比重が高く、対外決済・輸出統制・石油供給という制度状態の変化はまだ起きていない。したがって7月25日の資産凍結、7月28日の実進駐、8月1日前後の対日輸出制限強化を含む次フェーズでまとめて再判定する。

## S05「政治参加の回路」— hold

第2次近衛内閣総辞職と第3次近衛内閣成立は重要な政府形成過程だが、選挙、議会、政党、大政翼賛会、地域・職域組織など、S05が追う政治参加回路に新しい制度段階を加えていない。

内閣人事と政府・統帥部の政策調整は年代本文で扱う方が適切であり、S05へ追加すると「誰が政策を決めたか」と「国民・議員が政治へ参加する回路」を混同しやすい。よって延長しない。

## 新規「日米交渉」横断記事 — defer one more phase

6月22日の米側回答以後、日米交渉は南部仏印政策と並行して継続し、7月24日には米側の強い警告まで進んだ。ただし、この時点では交渉文書・軍事行動・経済圧力の三者のうち、経済圧力の制度転換がまだ発動していない。

独立横断記事の中心問いを「外交提案の往復」ではなく、**交渉条件・軍事的位置・経済圧力が互いの選択肢をどう狭めたか**に置くなら、7月25日の資産凍結と南部仏印実進駐まで含めた方が年代記事の再編集を避けやすい。新規記事は次フェーズのpublication gateで再判定する。

### Crosscutting gate 判定結果（2026-10-04）

- **S09 pass / extension implemented**：共同防衛了解によって、フランス主権・植民地行政を残したまま日本軍の駐留・基地利用を南部へ拡張する制度状態を追加した。北部仏印、仏タイ平和条約、南京政府などと比較し、主権・行政・軍事アクセス・外交的役割の配分差として本文へ実装済み。
- **S10 hold / next phase**：資産凍結前では供給制約の制度状態がまだ変わっておらず、年代記事の資源説明の再要約になりやすい。7月25日以後の金融・輸出・石油制約と一体で扱う。
- **S05 hold**：内閣交代は政策決定主体の再編だが、政治参加回路の新制度ではない。
- **新規「日米交渉」defer**：独立記事に必要な比較軸は形成されつつあるが、資産凍結・実進駐後まで含める方が「交渉・軍事的位置・経済圧力」の構造比較として成立しやすい。
