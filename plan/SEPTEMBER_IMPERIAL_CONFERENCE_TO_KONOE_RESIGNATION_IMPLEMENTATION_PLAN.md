# 1. このフェーズを1941年9月6日〜10月17日に切る理由

前フェーズは9月5日、昭和天皇が翌日の御前会議に先立って近衛文麿首相、杉山元参謀総長、永野修身軍令部総長から国策案と作戦見通しの説明を受けた時点で終えた。9月6日、第6回御前会議は9月3日に大本営政府連絡会議で決定されていた「帝国国策遂行要領」を正式な重要国策として決定した。

この要領は、対米英蘭戦争を辞さない覚悟の下で10月下旬頃を目途に戦争準備を進める一方、対米交渉を並行して継続し、10月上旬頃までに日本側要求を貫徹できる見込みを判断する構造を持った。公開本文では、9月6日を即時の開戦決定や宣戦布告と同一視せず、**外交と軍事準備を期限付きで並行運用する方針が正式な国策となった日**として扱う。

同じ9月6日、ワシントンでは野村吉三郎大使がハル国務長官に日本側提案を手交している。したがって「御前会議が外交を終わらせた」という説明は成立しない。以後も東京・ワシントン間で提案、質問、回答が往復し、日本側では中国和平条件や撤兵、三国同盟、通商原則などをどこまで明確化できるかが政策調整の中心になる。

9月13日の第52回大本営政府連絡会議では「日支和平基礎条件」が決定され、18日の第53回会議では、それまで米国へ示してきた日本側態度に不一致があるという問題認識から「最終的態度」を速やかに決める方針が確認された。9月20日の第54回会議では、日米国交調整に関する了解案が最終的に決定される。

9月25日の第55回会議は、外交の見通しを判断する時期を**遅くとも10月15日**とする。これはその日が来れば機械的に開戦するという命令ではなく、戦争準備と外交のどちらへ政策を切り替えるかを判断するための内部期限である。同日、豊田貞次郎外相は9月20日決定の了解案を野村へ送るよう訓令した。

10月2日、ハルは野村に対し、四原則の確認、中国・仏印からの撤兵などを含む覚書と首脳会談に関する回答を手交した。米側は首脳会談そのものを永久に拒絶したのではなく、会談前に基本的・重要な問題について明確な合意を作る必要を示した。日本側ではこの回答を受け、外交妥結の余地と中国からの撤兵をめぐる国内政策の限界が改めて問題になる。

10月12日の五相会議では、近衛・豊田が交渉妥結の余地を探す一方、東条英機陸相は中国からの撤兵に強く反対した。外交期限の到来だけでなく、**何を譲れば妥結とみなせるかを閣内で一致できないこと**が政権問題へ変わる。10月16日、第三次近衛内閣は総辞職した。17日、豊田外相は野村へ、内閣が変わっても日米交渉を継続する方針を伝えている。

10月18日には東条内閣が成立し、9月6日国策の再検討を新内閣自身の責任で行う段階へ移る。したがって本フェーズは**第三次近衛内閣の外交・軍事並行政策が政権内部の不一致によって行き詰まり、新内閣成立の前日まで**で切る。

# 8. A40 — 外交期限と南方作戦準備の空間 map necessity / data-quality judgment

## 判定対象

このフェーズでは「10月下旬までに戦争準備」という時間軸が外交へ圧力を与える。地図が理解を改善する可能性があるのは、その準備が抽象的な「戦争準備」ではなく、南部仏印を基点とするマレー・フィリピン・蘭印など複数方面の作戦・輸送準備として具体化している場合である。

ただし、**11月5日以後に正式示達された最終的な南方作戦計画を、9月6日〜10月17日時点の確定計画として逆投影しない**。A40を採用するには、本フェーズ時点で確認できる作戦準備資料・中央協定案・部隊準備命令などから、表示する地点・方面・状態を時点付きで裏付けられる必要がある。

### map necessity判定で確認する問い

- 9月6日〜10月17日時点で、南方作戦準備の対象方面がどこまで具体化していたか
- 南部仏印の基地位置とマレー・フィリピン・蘭印方面の相対関係が、外交期限と軍事準備期限の理解を実質的に改善するか
- A38 / A39との主題重複を避け、新しく「準備対象・複数方面・輸送制約」を示せるか
- 11月以後の完成計画を後知恵で混入せず、当時点の案・準備状態だけを表現できるか

### 判定結果 — adopted / high

A40は **adopted / high** とする。A38が南部仏印の基地要求、A39が南方資源空間と石油供給制約を扱ったのに対し、A40は9月6日国策後の「戦争準備」が、仏印・海南島・華南・台湾・奄美・パラオ・小笠原へ分散する準備地域と、マレー・フィリピン・蘭領東インドという複数対象方面を持つ広域準備だったことを示す。

根拠として、Japanese Monograph No. 45は9月6日の御前会議決定後、南方作戦用の兵力・資材・軍需品を上記地域へ移し始めたことを記し、11月6日の正式戦闘序列示達とは段階を分けている。U.S. Army Center of Military Historyは、1941年9月までにマレー・フィリピン・蘭領東インドへの大規模攻勢計画がほぼ整っていたと整理している。

11月以後の完成作戦を逆投影しないため、A40では侵攻ルート・上陸地点・作戦順序をLineString / Polygonで描かず、準備地域と対象方面を別カテゴリの模式Pointとして表示する。これにより本フェーズ時点で裏付けられる空間関係だけを可視化する。

### 実装・監査結果

- map ID: `southern-operation-preparation-1941`
- 掲載先: JH101「1941-09-25〜10-11」
- geometry: Point only
- Data Audit: passed
- Style Audit: passed
- Human Visual Audit: `not-required-reused-pattern`
- 再利用元: `southern-indochina-bases-1941` 等の既存point-only ThematicMap
- A39で監査済みの広域zoom対応を再利用し、`initialView.minZoom` を地図別に指定
- 最終作戦線、上陸地点、11月以後の正式戦闘序列は表示しない

### 採用時のデータ品質方針

- geometry候補: Point + schematic LineString / corridor
- 時点が異なる計画案を一つの確定作戦線へ融合しない
- 実航路・実進軍路と計画上の方面を区別する
- 海上LineStringはMAP_AUDIT_STANDARDのcartographic waypoint規則を適用する
- Polygonを使う場合は「作戦予定範囲」「支配範囲」「政治境界」を明確に分離する
- LineString / Polygon採用時はHuman Visual Audit必須
- 本フェーズ時点で十分な一次・公的史料が揃わない場合は**no-map**とし、11月以後の作戦計画具体化フェーズで再判定する

## S13「日米交渉と経済圧力」— ✅ pass / extension required

前フェーズで新設したS13は、1941年4月から9月5日までを「要求・譲歩 / 軍事的位置 / 経済的選択肢 / 時間」の四軸で比較し、9月初頭に外交判断と軍事準備へ政策上の期限が入るところまで扱っている。

本フェーズでは、この「時間」が単なる外部制約ではなく、**国内の政策調整と政権維持そのものを拘束する段階**へ進んだ。

- 9月6日、期限付きの外交・戦争準備並行方針が御前会議で正式な重要国策となった
- 9月13〜20日、日本側は中国和平条件・対米説明の不一致を認識し、了解案を一本化した
- 9月25日、外交見通し判断の内部期限を「遅くとも10月15日」と具体化した
- 10月2日、米側回答によって首脳会談前の基本問題調整が改めて前面化した
- 10月12〜16日、何を譲れば「外交成功」と判定できるかを閣内で一致できず、第三次近衛内閣が総辞職した
- 10月17日、総辞職後も交渉継続が訓令され、政権交代と外交打切りが別状態であることが明確になった

これはJH98〜102の時系列を再掲するだけでは見えにくい。S13では既存四軸を維持したまま、特に「時間」を**交渉加速 / 国内案一本化 / 譲歩コスト / 軍事準備停止判断 / 政権存立**へ作用する比較軸として延長できる。

延長後の終点は1941年10月17日とし、10月18日の東条内閣成立後の国策再検討、11月の甲案・乙案、11月26日のハル・ノートは先取りしない。

## S10「産業社会の負担と保護」— hold / no extension

本フェーズでも石油・船腹・備蓄などの資源制約は重要だが、7月末〜8月に成立した「取引可能性 / 決済 / 輸出許可 / 海上輸送 / 国内配当」という供給制約の制度構造に、新しい段階は追加されていない。

A40が扱うのは南方作戦準備の空間であり、国内配当や企業・家計負担の新制度ではない。S10を延長するとJH98〜102およびS13の資源制約説明を再掲する比重が高くなるため、今回はholdとする。

## S05「政治参加の回路」— hold / no extension

第三次近衛内閣総辞職は重要な政権変動だが、選挙・議会・大政翼賛会・地域／職域組織など、政治参加の回路に新しい制度類型を追加する出来事ではない。

内閣・統帥部・外務省間の政策調整はS13と年代記事で扱い、S05へ「政府内部の意思決定」を混入しない。

## S09「対外支配の制度差」— hold / no extension

中国・仏印からの撤兵は日米交渉の中心争点だが、本フェーズで新しい統治制度、法的地位、占領・保護・委任などの権限配分類型が成立したわけではない。

撤兵条件をめぐる交渉はS13の「要求・譲歩」軸で扱い、S09は既存の制度差比較を維持する。

## S12「秋丸機関と総力戦研究所」— hold / no extension

国力・資源・輸送力の認識は本フェーズの政策背景として引き続き重要だが、秋丸機関・総力戦研究所そのものについて、新しい活動段階や新規史料上の転換はこのフェーズでは確認していない。

# 10. phase-end audit necessity judgment — ✅ no-audit（2026-10-05）

独立監査は実施しない。

計画時に挙げた横断仮説を、JH98〜JH102、A40、S13延長をまとめて確認した結果、各問題は年代実装・Crosscutting gate・S13延長の中で既に処理されており、複数記事を再監査しなければ判定できない未解決仮説は残っていない。

- 9月6日の御前会議は、即時・無条件の開戦決定ではなく、外交と戦争準備の期限付き並行方針としてJH98・S13で明示
- 天皇の9月5日下問と9月6日の正式決定は段階を分け、拒否権発動のような単純化をしていない
- 9月20日の了解案は、その時点の日本政府・統帥部の態度一本化として扱い、11月の甲案・乙案と区別
- 9月25日の10月15日期限は、自動開戦日ではなく内部判断期限としてJH101・JH102・S13で一貫
- 10月2日の米側回答は首脳会談の永久拒絶・最後通牒として扱っていない
- 野村・豊田・近衛・東条・陸海軍の認識差を一枚岩へ圧縮せず、S13では「国内調整」を独立した制約として扱った
- 10月16日の近衛内閣総辞職と17日の外交継続を並べ、総辞職=外交打切り=開戦決定としていない
- 10月18日以後の国策再検討結果は先取りしていない
- S13延長はJH98〜102の時系列再掲ではなく、既存四軸、とくに「時間」が文書一本化・成功判定・政権存立へ作用する比較へ変換した

PROJECT_WORKFLOW_STANDARD 5.3の条件に照らし、ここで追加の独立「全体監査」を置くと既確認事項の再検査になる。したがって **no-audit** とし、通常の `npm run check` / CI / Pages確認へ進む。
