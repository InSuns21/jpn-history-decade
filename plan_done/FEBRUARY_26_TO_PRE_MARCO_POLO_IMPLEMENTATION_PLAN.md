# 1. このフェーズを1936年2月26日〜1937年7月6日に切る理由

1936年2月26日の二・二六事件は、青年将校らが部隊を率いて首相官邸など政治・軍事中枢を襲撃し、内大臣斎藤実・蔵相高橋是清・教育総監渡辺錠太郎らを殺害した武力行動である。事件は29日に鎮圧へ向かったが、そこで重要なのは「事件が起きた」ことだけではない。内閣、宮中、陸軍中央、戒厳、政党、財政官僚の間で、誰がどの命令権・人事権・政権形成力を持つかが事件前とは異なる条件で再調整された。

次の大きな境界は1937年7月7日の盧溝橋事件である。1936年から1937年7月6日までには、広田内閣、軍部大臣現役武官制の復活、日独防共協定、広田内閣総辞職、宇垣一成の組閣失敗、林銑十郎内閣、1937年総選挙、第1次近衛内閣成立が続く。一方、この時点では1937年夏以後の戦争拡大はまだ結果として確定していない。

したがってこのフェーズでは、

- 二・二六事件を「軍部支配完成」の一語で終わらせない
- 政党・議会・選挙が残る一方、首相選定・陸相選任・軍事政策へ届く回路がどう変化したかを分ける
- 陸軍内部の粛軍・人事再編と、政府全体の政策形成を同一視しない
- 華北・中国をめぐる軍事・外交上の緊張を、1937年7月以後の戦争から逆算しない
- 高橋是清死後の財政を、単純な「軍事費無制限化」としてではなく、予算・公債・金融・軍備計画の調整構造として追う

ことを中心にする。

# 3. JH33 — 1936年2月26日〜3月8日

**Status: completed / 2026-09-28**

## 中心問い

> 二・二六事件の武力行動に対し、宮中・岡田内閣・陸軍省・参謀本部・戒厳司令部はどのような権限と情報を持ち、なぜ鎮圧後の政権形成条件は2月25日以前と同じではなくなったのか。

## 必須テーマ

- 2月26日の襲撃と占拠
- 襲撃対象・殺害された政治家・軍人を役職とともに説明
- 岡田啓介首相が生存したことと、政府機能の混乱を分ける
- 陸軍大臣告示、軍事参議官会議などを時系列で分ける
- 昭和天皇、宮中、陸軍中央、決起将校を別主体として扱う
- 戒厳令と戒厳司令部が何をする制度かを中学校教科書レベルから説明
- 原隊復帰・鎮圧へ至る判断過程
- 事件後の処分・粛軍は後続ページとの接続点として扱い、3月8日までに確認できる状態を主軸にする
- 岡田内閣が3月9日の広田内閣成立まで在職した制度上の連続性を残す

## JH32→JH33 接続確認

JH32末尾の「2月25日時点では内閣・宮中・陸軍・政党・議会が別々の制度回路を保っていた」という状態から始める。

翌日に武力行動が起きたことを、前ページの全制度がすでに機能停止していた証拠として遡及説明しない。JH33では、事件によって**どの回路が直接攻撃され、どの回路がなお命令・鎮圧・政権継続に使われたか**を示す。

# 4. A19 — 二・二六事件の東京政治・軍事空間

**Status: completed / implemented / 2026-09-28**

## 判定結果

- **map necessity: pass**。永田町・三宅坂の政治・軍事中枢と、赤坂・麻布の部隊拠点が数km圏に集中していたことは、本文だけよりpoint mapで比較した方が理解しやすい。
- 首相官邸、高橋是清邸、三宅坂の陸軍中枢、歩兵第一連隊、歩兵第三連隊の5代表点に限定した。
- 国立公文書館・国立国会図書館は、首相官邸等への襲撃と永田町・三宅坂一帯の占拠を明示している。高橋是清邸は港区が現・高橋是清翁記念公園を邸宅跡と明記し、歩兵第一・第三連隊の跡地も港区の公的案内で現在地との対応を確認した。
- 1936年の道路網、決起部隊の移動経路、占拠範囲・警戒線は信頼できる再利用可能geometryを確保できないため描かない。
- 斎藤実邸・鈴木貫太郎邸・渡辺錠太郎邸などは事件上重要だが、今回の地図では現在地対応・位置精度を公的資料で十分確認できる地点へ絞り、網羅性より誤読回避を優先した。
- geometryConfidence は `approximate`。位置は施設跡または史料上の一帯を現在地へ対応させた代表点で、1936年の建物中心を測量復元したものではない。
- **Data Audit: passed / Style Audit: passed**。
- A12/A14/A16と同じpoint-only表示・点記号・ラベル・popup/touch interactionを再利用し、新しい線・polygon・interactionを導入していないため、MAP_AUDIT_STANDARDの再利用パターン例外により **Human Visual Audit: not-required-reused-pattern** とした。
- JH33の2月26日節直後へ配置し、後年または別テーマの地図を概観直後へ先出ししない。

## 地図が役立つ可能性

二・二六事件では、首相官邸、陸軍省周辺、赤坂・永田町など複数地点への襲撃・占拠と、政府・軍事中枢の近接性が事件理解に関係する。

したがって、単なる「東京で起きた事件」より、

- どの政治・軍事機関がどこに集中していたか
- 襲撃対象がどの程度近接していたか
- 占拠地点と政府・軍中央の位置関係

を代表点で示す価値があるかを判定する。

## 厳格な制限

- 1936年時点の道路・建物配置を現代OSMだけから再現しない
- 決起部隊の移動経路を推測線で結ばない
- 「占拠地域」のpolygonを根拠なく描かない
- 史料で位置を確認できる政治・軍事施設だけをpointとして使う
- 現在の住所や施設位置と1936年の所在地が同一であることを無確認で仮定しない
- point-onlyで十分なら、線・面を追加しない

既存point-only地図と同じ表示・凡例・interactionを再利用する場合は、MAP_AUDIT_STANDARDの再利用規則を適用する。

# 6. JH35 — 1937年1月23日〜6月3日

**Status: completed / 2026-09-28**

## 中心問い

> 1937年前半、政党・総選挙・衆議院が作動している一方、陸相を得られないことが組閣を阻む状態は、明治憲法下の内閣形成と政治参加の接続をどう変えたのか。

## 必須テーマ

- 1月23日の広田内閣総辞職
- 1月25日の宇垣一成への組閣大命
- 陸相候補を得られず1月29日に宇垣が組閣を断念した過程
- 軍部大臣現役武官制が「軍が首相を直接任命する制度」ではないことを明示
- 陸相を現役将官から確保できないことが内閣成立を制約した制度構造
- 2月2日の林銑十郎内閣成立
- 林内閣と政党・議会の関係
- 衆議院解散と1937年4月30日の第20回衆議院議員総選挙
- 選挙結果と首相選定・軍事政策を同一視しない
- 政党が選挙・議会で持つ力と、内閣形成で持つ力の差
- 林内閣退陣から近衛内閣成立直前まで
- 1937年6月4日の第1次近衛内閣成立は次ページへ送る

## S05との役割分担

JH35では1937年前半の政局を時系列で説明する。

S05「政治参加の回路」を延長する場合は、

```text
有権者
→ 衆議院議席
→ 政党の議会交渉力
→ 首相選定
→ 陸相確保
→ 内閣成立
```

の各接続が同じ強さではないことを長期比較する。

## 必須テーマ

- 1937年6月4日の第1次近衛文麿内閣成立
- 近衛を後の戦時首相像だけから逆算せず、成立時点の政権基盤を説明

- 1937年総選挙後の政党・議会との関係
- 軍事費・財政運営
- 華北に駐屯する日本軍、中国側軍事・行政主体、南京国民政府の制度的位置
- 1935年の冀東・冀察の制度差をそのまま「日本領」として引き継がない
- 日中間の緊張が存在しても、7月7日の武力衝突とその後の拡大を既定路線として書かない
- 7月6日時点で政府・現地軍・中国側が持っていた情報と選択肢を明確にする
- 7月7日の盧溝橋事件は次フェーズへ送る

## ページを約1か月にする理由

第1次近衛内閣成立は政権形成上の明確な境界であり、7月7日の盧溝橋事件は軍事・外交上の新しい境界になる。

この1か月を独立させることで、「近衛内閣が成立した時点で日中全面戦争が決まっていた」という後知恵を避け、**事件前の制度状態だけを切り出して読める**。

# 8. 財政・経済の主線

前フェーズは高橋財政を、

```text
恐慌
→ 財政拡張・金融緩和
→ 回復
→ 回復後の公債・歳出抑制
```

まで追った。

このフェーズでは高橋是清の死後を、

```text
高橋による抑制問題
→ 2月26日の高橋死去
→ 新しい蔵相・内閣の予算方針
→ 軍備計画と一般歳出
→ 国債・金融・物価の管理
```

として追う。

「高橋が死んだから財政規律が即座に消えた」という一因果にはしない。予算編成、既存軍備計画、景気、税収、公債市場、日本銀行、各省要求を分ける。

S02「石高制・貨幣経済・財政」は、財政拡張を止める主体・制度が高橋個人からどう移ったかという比較軸が成立する場合だけ延長する。

S10「産業社会の負担と保護」は、軍事費・救済・一般歳出の優先順位変更が家計・農村・企業・地域へ負担をどう戻したかを年代本文以上に比較できる場合だけ延長する。

# 9. 政治参加・政軍関係の主線

前フェーズでは、1936年2月20日の総選挙まで男子普通選挙・政党競争・議会が作動していた一方、政党総裁が首相となる接続は弱まっていた。

このフェーズではさらに、

```text
総選挙
→ 衆議院多数
→ 内閣への議会協力
→ 首相選定
→ 陸相選任
→ 内閣成立・存続
```

を分解する。

1937年の宇垣組閣失敗は、この接続差を具体的に示すため重要である。一方、軍部大臣現役武官制だけで1937年前半の全政局を説明しない。政党、元老・宮中、陸軍内部、首相候補、議会、世論などの役割を分ける。

## 新規横断記事候補

「軍部大臣・統帥・内閣形成」を長期的に比較する新規構造史は候補に留める。

publication gateでは、

- 1900年の軍部大臣現役武官制
- 1913年の制度変更
- 明治憲法下の統帥・軍政
- 1936年の現役武官制復活
- 1937年の宇垣組閣失敗

を一つの独立比較軸にしなければ理解しにくいかを判定する。

年代記事を並べ替えるだけで済むなら新規記事は作らず、S05への延長と内部リンクで処理する。

# 10. 外交・中国情勢の主線

1935年の華北では、冀東と冀察が異なる法的位置を持つ政治機構として成立した。

1936〜1937年7月6日は、

- 日本政府
- 外務省
- 陸軍中央
- 中国駐屯軍など現地軍
- 南京国民政府
- 華北地域勢力
- 中国共産党
- ソ連・ドイツなど第三国

を一枚岩にせず、外交・軍事・国内政治の制約を分ける。

日独防共協定は1936年11月時点の外交選択として扱い、1940年の日独伊三国同盟の前段階としてだけ説明しない。

A18でno-mapとした1935年華北の面的境界は、このフェーズでも新しい高品質geometryが得られない限り再度地図候補にしない。終点が少し延びただけで同じData Auditを繰り返さない。

# 12. 横断記事publication gate

**Status: completed / 2026-09-28**

JH33〜JH36を実装した上で、年代本文の再要約にならず、複数年代を同じ比較軸で読む必要があるかを判定した。

## S02「石高制・貨幣経済・財政」 — pass

**延長する。**

既存S02の終点は1936年2月25日で、「景気回復後、赤字公債・歳出拡張を誰がどこで抑えるか」を未解決論点として残している。二・二六事件後には高橋是清という予算査定上の強い抑制主体が失われ、広田内閣の馬場鍈一蔵相は公債漸減主義を放棄し、低金利・増税・公債を組み合わせて国防・産業政策を支える方向へ移した。

ここでは年代記事の「馬場財政」を再掲するのではなく、

```text
中央銀行信用を使える国家
→ 景気回復後の歳出抑制
→ 高橋による査定
→ 高橋死去
→ 馬場財政による公債漸減主義の放棄
→ 低金利・増税・軍備／産業計画
```

という長期比較軸が成立する。

財務省『大蔵省百年史』も、馬場財政を公債漸減主義の放棄と低金利政策、国防充実を優先する財政運営への転換として整理している。

**結論:** S02を1937年7月6日まで延長する。

## S05「政治参加の回路」 — pass

**延長する。**

S05はすでに、男子普通選挙が作動していても、衆議院多数と首相選定・軍事組織・行政権が同じ回路ではないことを中心問いとしている。

1937年前半には、

```text
有権者
→ 総選挙
→ 衆議院議席
→ 政党の議会交渉力

首相候補選定
→ 現役陸相候補の確保
→ 内閣成立
```

という二つの回路のずれが、宇垣組閣失敗と第20回総選挙によって具体化した。国立国会図書館は、宇垣一成が1937年1月に組閣を命じられた後、陸軍三長官会議が陸相候補を推挙せず、軍部大臣現役武官制の下で組閣を断念した経過を示している。JACARの普選年表では同年4月30日に第20回総選挙が実施され、有権者1,461万8,298人・投票率73.31%だったことが確認できる。

この比較はJH35の時系列叙述とは別に、「参加の入口」と「行政権形成への到達距離」を1874年以後の長期軸で比較できる。

**結論:** S05を1937年7月6日まで延長する。

## S09「対外支配の制度差」 — fail / no extension

**今回は延長しない。**

1936〜1937年7月6日の華北では、中国駐屯軍、冀察政務委員会、冀東政権、南京国民政府などの関係が変化し、外務省『日本外交文書』でも華北自治、密輸、関税、幣制、経済開発など複数の交渉案件が確認できる。

ただし、このフェーズでS09へ新たに加わる**法的制度類型**は確認できない。

- 冀東と冀察の法的差は1935年までのS09ですでに比較済み
- 中国駐屯軍は軍事主体であり、新しい統治制度類型そのものではない
- 1937年8月以後の北支那方面軍や占領統治機構は7月6日時点には未成立

したがって1936〜1937年7月6日の内容をS09へ追加すると、年代記事で扱った華北政策の再要約になりやすい。

**結論:** S09は1936年2月25日終点のままとし、新しい法的統治類型が成立した段階で再判定する。

## S10「産業社会の負担と保護」 — fail / no extension

**今回は延長しない。**

1936年2月26日〜1937年7月6日には、馬場財政、軍事費拡大、生産力拡充構想、企画庁設置など、国家支出・産業計画の優先順位は変化した。

一方、S10の独立比較軸は「誰が利益を得て、誰が費用を負い、その負担をどの制度へ移したか」である。このフェーズだけでは、軍事費・企画・公債の拡張が家計・農村・企業・地域へどのように具体的に転嫁されたかを、既存S10以上の粒度で比較できる材料がまだ不足している。

財政拡張そのものはS02、企画庁・軍備・産業政策はJH35〜JH36で説明できる。ここでS10を延長すると、支出政策の再要約になりやすい。

**結論:** S10は1936年2月25日終点のままとする。物価、租税、物資統制、賃金、家計・企業負担が明瞭に変化する次フェーズ以後で再判定する。

## 新規「軍部大臣・統帥・内閣形成」 — fail / no new article

**新規記事は作らない。**

1900年の現役武官制、1913年の制度変更、1936年の復活、1937年の宇垣組閣失敗は長期比較できる。ただし今回必要なのは「軍制そのものの通史」より、**選挙・議会・首相選定・軍部大臣人事がどこで接続し、どこで切れていたか**の比較であり、これはS05の既存中心問いに直接入る。

新規記事を作ると、現段階ではS05とJH34〜JH35の説明を並べ替える比率が高い。統帥・軍政・軍部大臣人事を独立記事にする必要性は、今後さらに制度的な比較事例が増えた段階で再判定する。

**結論:** 新規記事なし。軍部大臣現役武官制と宇垣組閣失敗はS05延長へ統合する。
