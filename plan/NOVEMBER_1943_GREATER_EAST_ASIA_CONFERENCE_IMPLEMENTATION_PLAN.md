## 中心問い

日本は、10月までに成立・改編したフィリピン、ビルマ、南京の汪兆銘政権などとの関係を、11月5〜6日の大東亜会議でどのような共同の政治目標として示したか。個々の政府の成立経緯・外交上の地位・日本軍への依存と、日本の戦争指導や軍事・経済協力の要求をどう接続したか。

これと並行して、11月1日の軍需省等の設置により国内の生産・交通通信行政が再編された。さらに11月20日からの米軍のタラワ・マキン上陸は中央太平洋防衛に新たな具体的な条件を生んだ。「大東亜共栄」の理念・国内の統制機構・実際の戦局を、別々の制度と時点に置いて記述する。

## phase cut 判定 — 予定年代記事 **2本**

**2本とする理由:** 11月1日の行政再編と5〜6日の外交会議は、国内の戦争遂行能力と提携政権を結びつける同じ政治段階で読める。一方、20日の米軍上陸は前段の外交会議とは独立して日本の島嶼防衛・補給計画を変える。この両者の間の11月8〜19日を、独立した状態変化の根拠なしに別記事へ分割しない。11月のみを一つの短いPLANにするため、4〜5本という標準記事数の例外を採用する。日付・境界は執筆時の追加史料で再検証する。

### JH176の本文で分ける制度・主体

| 代表・政治主体 | 会議での立場 | 政治上の位置と日本側との関係 |
| --- | --- | --- |
| 日本・東条英機 | 主催する日本の首相 | 5月31日決定の大東亜政略指導大綱が、諸政権との提携を対米英戦争の遂行へ結びつけた。国内では軍需・運輸通信行政も再編。 |
| 南京の汪兆銘政権・汪兆銘 | 中国を名乗る南京側政府の行政院長 | 10月30日に日華同盟条約署名・実施。重慶の蔣介石政権は別の政治・軍事主体として日本と交戦中であり、中国全域の代表権は争われていた。 |
| 満洲国・張景恵 | 国務総理大臣 | 日本の軍事的支援・影響下で成立した政府。フィリピン・ビルマの1943年の新政府とは成立経緯が異なる。 |
| タイ・ワンワイタヤコーン | ピブン首相の代理 | 独立国の首相本人ではなく代理代表。日本の占領下に発足したフィリピン・ビルマ政府と政治的背景が異なる。 |
| ビルマ・バー・モウ | 8月独立後の政府首脳 | 8月1日に成立した政権と同盟・秘密軍事協定。日本軍の駐留・軍事上の要求と民政の権限が併存。 |
| フィリピン・ラウレル | 10月発足の共和国大統領 | 10月14日成立、日比同盟条約と附属了解事項により日本軍への便宜供与を約した。10月の記事で説明した政府発足の過程は要約のみ。 |
| 自由インド仮政府・スバス・チャンドラ・ボース | 会議に**陪席** | 10月21日にシンガポールで樹立を宣言した独立運動の仮政府。共同宣言を採択した六政府と同列の署名国・承認国家として計数しない。 |

会議の代表構成は、共同宣言発表文と外務省側の調書原稿を照合する。理念の分析では、同宣言の「自主独立尊重」「互恵」「文化」「人種的差別撤廃」を同時代の**政治的主張**として掲げる。その実効性は、各政府の二国間条約・日本軍の作戦権限・各地域の政治参加や抵抗の記録と分けて判断する。5月の大綱が戦争協力の強化を目標にしたことと、11月共同宣言が提示する価値を、それぞれの文書に帰属させる。

11月1日の新省設置では、商工省・農林省・逓信省・鉄道省・企画院の改廃を説明し、軍需省による軍需工業行政の一元化と、運輸通信省の輸送・通信の行政調整を具体化する。旧来の物資不足・配給制度の一般論を新たに繰り返さず、「決定権・調整先・実務担当が変わること」に絞る。

### JH177の執筆上の前提

- 米海軍史の11月20日の上陸記録と、日本側の当時の情報・大本営の戦争指導判断を別々に示す。守備隊の戦闘・島嶼の喪失・輸送負担の時間的変化を優先し、後年の戦局からの目的論的な帰結説明を避ける。
- 11月下旬のカイロ会談は後世の外交記録で確認できるが、**共同声明の対外公表は12月1日**。11月記事で「日本政府が宣言を受けて政策を変えた」と書かない。発表後の受け止めは12月記事に譲る。
- 9月末の絶対国防圏策定は必要な前提を1〜2文へ圧縮する。防衛線・基地の位置関係を示すことが記事理解を改善する場合のみ、史料の時点と精度を明示して地図を検討する。
