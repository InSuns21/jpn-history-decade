# 1. このフェーズを1940年9月27日〜11月30日に切る理由

9月27日、日独伊三国条約が調印された。条約第三条は、欧州戦争または日中戦争に現に参加していない国から締約国の一国が攻撃された場合の相互援助を定めた。一方、調印前日の枢密院審査では、攻撃該当性や援助方法について三国協議と各国の判断が介在する説明がなされている。したがって、三国同盟を「その日に対米参戦が自動確定した条約」とは扱わず、対米抑止を意図した外交制度と、その解釈・運用の余地を分けて扱う。

国内では、7〜8月の既成政党解党を受け、10月12日に大政翼賛会が発足した。帝国議会・議員資格を残したまま、首相を総裁とする全国組織が中央から地方へ配置される新しい政治参加・動員回路が設けられた。ただし発足時点で一枚岩の「一国一党」が完成したわけではなく、旧政党系を含む諸勢力の抱合、組織の法的位置づけ、地方行政との関係をめぐる調整が続く。12月14日の実践要綱や1941年の改組は後段階として分ける。

対外経済では、米国が9月26日に公表した鉄鋼屑規制が10月15〜16日に実施段階へ入り、10月16日以後、鉄鋼屑の輸出許可は西半球諸国と英国に限られる制度へ移った。同じ10月16日、日蘭会商では三国同盟が日本・蘭印関係を害するものではないとの共同コミュニケが出されたが、小林一三代表は21日に帰国へ向かった。石油業者代表による交渉は11月に一応の妥結をみたものの、日本側が求める水準には届かなかった。会商自体は終結せず、後任の芳沢謙吉派遣へ続くため、「10月に蘭印交渉が完全決裂した」とは書かない。

中国戦争処理では、南京国民政府は3月30日に成立していたが、日本政府は即時承認せず、阿部信行特使による国交調整交渉と、松岡外相のもとでの対重慶和平工作を並行させた。11月13日の御前会議で支那事変処理要綱と日華基本条約・日満華共同宣言締結について最終的な意思確認がなされ、11月28日の大本営政府連絡懇談会で南京政府承認が決定された。11月30日に日華基本条約・日満華共同宣言が調印され、日本は南京政府を正式に承認した。

終点を11月30日とすることで、**三国同盟後の外交配置、国内新体制の組織化、南京政府「成立→交渉→正式承認」**という三つの状態遷移を一つのフェーズで閉じられる。

# 3. JH74 — 1940年9月27日〜10月11日

## 中心問い

> 日独伊三国同盟は日本の対米英・対蘭印関係にどのような新しい制約と期待を加え、国内の新体制組織化はどの段階にあったのか。

## 必須テーマ

- JH73からの接続
  - 北部仏印進駐直後
  - 日蘭会商継続中
  - 米鉄鋼屑規制強化は9月26日に公表済み、実施は10月中旬
  - 既成政党は解党済みだが大政翼賛会は未成立
- 9月27日 日独伊三国条約
  - 条約第三条の対象と相互援助
  - 枢密院審査で示された協議・援助方法の余地
  - 「自動参戦条項」と単純化しない
- 対米抑止という日本側の政策意図と、米国・蘭印側が同盟をどう受け取ったかを主体別に分ける
- 日蘭会商
  - 三国同盟成立により蘭側が硬化したこと
  - 交渉が直ちに終了したわけではないこと
- 大政翼賛会発足前
  - 新体制準備会で組織案が検討されている段階
  - 政党解体後・新全国組織成立前の移行状態をJH72/S05から受ける

## JH73→JH74 接続確認

JH73は9月26日、北部仏印進駐の実行と米鉄鋼屑規制強化の公表までを扱う。

JH74は翌27日、**三国同盟という新しい条約関係が成立し、既存の日蘭会商・対米関係・国内新体制準備がその条件下へ入る**ところから始める。

# 4. JH75 — 1940年10月12日〜10月21日

## 中心問い

> 政党解体後に設けられた大政翼賛会は、議会を残した日本政治へどのような新しい組織回路を加え、同時期の米国・蘭印との資源関係はどう変化したのか。

## 必須テーマ

- 10月12日 大政翼賛会発足
  - 近衛首相が総裁
  - 中央本部、道府県・市町村支部、中央・地方の協力会議
  - 政党の単純な後継組織としてではなく、国民運動・行政・議員・旧政党系勢力を抱え込む全国組織として説明
  - 帝国議会は存続している
  - 12月14日の実践要綱、1941年2月以後の法的位置づけ・改組を先取りしない
- 米国の鉄鋼屑規制
  - 10月15 既存許可残高の一部失効
  - 10月16 全鉄鋼屑を許可制とし、許可先を西半球と英国に限定
  - 石油全面禁輸ではない
- 日蘭会商
  - 10月16 共同コミュニケ
  - 三国同盟と蘭印関係の緊張を明示
  - 10月21 小林代表帰国へ
  - 会商自体は後任代表・現地交渉へ続く
- 北部仏印
  - 軍事進駐後、10月には経済交渉の予備協議も始まる
  - 12月30日開始の正式交渉とは分ける

## JH74→JH75 接続確認

JH74では「政党解体後・新組織成立前」を扱う。

JH75は、**10月12日に大政翼賛会という全国組織が成立し、同時に米国の資源輸出規制が発表段階から実施段階へ移る**ところを扱う。

# 5. JH76 — 1940年10月22日〜11月30日

## 中心問い

> 南京国民政府を正式承認するまで、日本政府は対重慶和平の可能性と南京側との条約関係をどのように並行処理し、11月末に何を制度として固定したのか。

## 必須テーマ

- 日蘭会商の継続
  - 小林代表帰国後も現地交渉は完全終了ではない
  - 石油業者代表の交渉は11月に一応の妥結
  - 日本側要求との差を明示
  - 11月下旬の芳沢謙吉派遣決定は次段階への接続
- 11月13日 御前会議
  - 支那事変処理要綱
  - 日華基本条約・日満華共同宣言締結についての最終意思確認
  - 南京政府承認と重慶和平工作を時間順に整理
- 対重慶和平工作
  - 秋に本格化
  - 11月28日に交渉打切りと南京政府承認を決定
  - 「南京政府を3月に作ったので11月承認は自動だった」と書かない
- 11月23日 大日本産業報国会
  - 労使関係・産業報国運動を全国的組織へまとめる動き
  - 既存S10の労働・企業統制との接続を確認
  - 労働組合と同義の組織として扱わない
- 11月28日 大本営政府連絡懇談会
  - 従来の連絡会議との制度差
  - 南京政府承認決定
- 11月30日 日華基本条約・日満華共同宣言
  - 日本による南京政府の正式承認
  - 3月30日の政府成立と区別
  - 日本・満洲国・南京政府の関係
  - 日本軍駐留・交通・顧問等を含む付属文書の存在
  - 正式承認が中国全域の実効支配や戦争終結を意味しない

## JH75→JH76 接続確認

JH75は国内新体制組織の発足と資源外交の転換を扱う。

JH76は、**外交・軍事・国内統制の枠が整えられる中で、中国戦争処理について「南京政府成立後の未承認状態」から正式な条約・国交関係へ移る**段階を扱う。

# 6. A33 — 1940年秋の外交・制度空間 map necessity / data-quality judgment

## 判定はJH74〜JH76実装後

候補テーマは以下。

- 日本・ドイツ・イタリアの条約関係
- 北部仏印への軍事駐留
- バタビアでの日蘭会商と石油交渉
- 南京政府・重慶政府・満洲国をめぐる条約／承認関係

ただし、これらは地理的距離より**条約・承認・行政・軍事権限の制度差**が中心であり、地図化すると異質な関係を同じ線種でまとめる危険がある。

JH76まで実装した後、次を判定する。

1. 読者が位置関係を保持できないことが理解上の主要障害か
2. LineString / point / approximate areaで答えられる明確な歴史的問いがあるか
3. 条約関係・承認関係を「支配領域」と誤読させない表現が可能か
4. A31/A32または遡及地図監査で得た既存geometryを再利用できるか

**制度関係図の方が適切ならno-mapとする。** 「地図を作れる」こと自体を採用理由にしない。

採用時は現行 `MAP_AUDIT_STANDARD.md` に従い、Level C approximate / schematic geometryも問いに十分なら利用可能とする。

# 7. Crosscutting publication gate

JH74〜JH76実装後に判定する。

## S05「政治参加の回路」— high candidate

- 政党解体後の大政翼賛会発足
- 帝国議会・議員の存続
- 首相総裁の全国組織、地方支部、協力会議
- 「選挙・議会」と「継続的な政治組織・国民運動」の分離

年代記事の大政翼賛会説明を再掲せず、1800年代以後の政治参加・媒介組織の比較軸へ変換できる場合のみ延長する。

## S09「対外支配の制度差」— high candidate

- 3月30日の南京政府成立と11月30日の正式承認の分離
- 日華基本条約・付属文書による形式的国交と日本軍の軍事的権限
- 南京政府の法形式と占領地の実効権限
- 重慶政府との戦争継続

A31時点の「成立したが未承認」という状態から、正式承認後の制度状態へ比較軸が変わるため有力。

## S10「産業社会の負担と保護」— candidate

- 大日本産業報国会の成立
- 既存の徴用・賃金・給与・設備・土地・輸送統制との接続
- 労使関係を企業・地域・国家の組織回路へ統合する新しい比較軸が成立するか

単なる組織名追加なら延長しない。

## S02「石高制・貨幣経済・財政」— hold unless evidence changes

この区間に新しい租税・公債・特別会計・通貨制度の状態遷移が確認できる場合のみ延長する。

## 新規横断記事

原則追加しない。

「枢軸外交」「南方資源外交」「新体制運動」は、既存S05/S09/S10と年代記事の組み替えになるだけなら独立記事化しない。1941年の資産凍結・南部仏印進駐・日米交渉まで比較材料が揃った時点で再判定する。
