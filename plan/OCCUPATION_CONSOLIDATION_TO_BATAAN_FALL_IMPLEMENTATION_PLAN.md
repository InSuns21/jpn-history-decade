# 1. このフェーズを1942年3月10日〜4月9日に切る理由

前フェーズの終点3月9日には、ジャワの蘭印軍へ全軍降伏命令が出され、ラングーンも日本軍の占領下へ移った。しかし南方・西太平洋の戦争は終結していない。フィリピンではバターンとコレヒドールが抗戦を続け、ビルマでは英印軍・中国遠征軍が中部へ後退しながら戦線を維持し、東ティモールでもゲリラ戦が残った。日本側も、占領した都市・港・資源拠点を継続運用する軍政と、次の作戦へ兵力・船舶・航空機を振り向ける必要を同時に抱えた。

3月10日には米空母機がラエ・サラモアを攻撃した。日本軍がニューギニア北東岸の拠点を確保しても、海上・航空優勢が無条件に固定したわけではないことが示された。同じ3月中旬、マッカーサーはフィリピンを離れてオーストラリアへ移り、フィリピン現地ではウェインライトを中心とする指揮へ移る。司令官の移動と、バターン・コレヒドールの抗戦継続を分けて扱う必要がある。

3月下旬、戦線はさらに分岐する。3月23日、日本軍はアンダマン諸島へ進出した。ビルマでは中国遠征軍第200師団がトングーで日本軍を阻止しようとし、英軍はプローム方面を支えたが、月末までにトングー防衛は撤退へ移り、プローム正面も強い後退圧力を受けた。プロームからの撤退は4月2日であり、3月末時点の状態と分けて扱う。ラングーン占領はビルマ戦役の終点ではなく、中国との連絡路、油田地帯、イラワジ・シッタン両河谷をめぐる中部ビルマ戦へ移る境界だった。

国内では3月25日の戦時海運管理令により、船舶の国家使用、船員の徴用・労務管理、船舶運営会による配船一元化の枠組みが整えられた。南方で資源拠点を占領しても、資源を日本本土や各戦域へ輸送する船舶・船員・配船能力が自動的に確保されるわけではない。軍事占領と輸送制度を接続する国内側の制度転換として扱う。

4月3日、日本軍はバターンへ最終攻勢を開始し、9日に米比軍主力が降伏した。同じ4月5〜9日、日本海軍機動部隊はセイロン島のコロンボ・トリンコマリーなどを攻撃し、英東洋艦隊とインド洋航路へ圧力をかけた。ここでは一方でフィリピンの残存戦線を終わらせる作戦が続き、他方で攻略済みの南方拠点を基盤に作戦半径がインド洋へ広がっている。

4月9日時点でもコレヒドールは降伏しておらず、ビルマ戦線も北方へ続き、東ティモールの抵抗も残る。このため4月9日を「フィリピン攻略完了」や「南方作戦完了」ではなく、**ジャワ・ラングーン攻略後の占領統治／輸送制度化と外周作戦の拡大が進む一方、バターンという大規模残存戦線が終端を迎えた境界**としてフェーズ終点に置く。

本フェーズは、**攻略後の軍政・外周基地への反撃 → 連合国側指揮再編とアンダマン／トングー戦 → 海運国家管理とビルマ中部防衛崩壊 → バターン最終攻勢とインド洋作戦**という状態遷移として1942年3月10日〜4月9日に切る。

# 3. JH126 — 1942年3月10日〜3月17日

## 中心問い

> ジャワ・ラングーン攻略後、日本軍は占領地を運営しながら次の作戦へ移り、連合国側はフィリピンの現地抗戦と広域指揮をどう切り分け始めたのか。

## 必須テーマ

- JH125からの接続
  - 3月9日のジャワ全軍への降伏命令
  - ラングーン占領後もビルマ戦線は北方へ継続
  - バターン／コレヒドール、東ティモールは未決着
- ジャワの第16軍軍政
  - 3月9日以後の軍政開始
  - 行政、治安、交通・通信、捕虜、資源・生産施設の管理を「攻略」と分ける
  - 旧蘭印植民地行政の人員・制度をどの範囲で利用したかは本文実装時に史料で確認
- ラングーン占領後のビルマ
  - 第15軍軍政の立ち上げ
  - 港湾・鉄道・道路を次の北進へ接続する後方化
  - 中国遠征軍・英印軍の中部ビルマ防衛
- 3月10日 ラエ・サラモア空襲
  - 米空母Lexington / Yorktown航空隊による攻撃
  - 日本軍は拠点を保持し、攻撃が即座の奪回に結びつかなかったこと
  - 「日本軍優勢＝反撃不能」ではなく、海空戦の競合が残る状態として扱う
- マッカーサーのフィリピン離脱
  - 3月11日前後のコレヒドール離脱から17日の豪州到着まで
  - 大統領命令、南西太平洋での新たな任務、フィリピン現地指揮との分離
  - 司令官離脱と守備隊の戦闘継続を同一視しない

## JH125→JH126 接続確認

JH125は、ジャワの組織的防衛が終わり、ラングーンが占領されても、バターン・ビルマ中北部・東ティモールに残存戦線がある状態で終わる。JH126では戦闘経過を再掲せず、**占領地の軍政開始／既占領拠点への米側反撃／フィリピン現地戦線と広域指揮の分離**へ進む。

- U.S. Army Center of Military Historyのマッカーサー離脱・フィリピン指揮再編資料

# 4. JH127 — 1942年3月18日〜3月24日

## 中心問い

> 連合国側がフィリピンとビルマで防衛線を再編する一方、日本軍はどこまで新しい作戦空間を広げたのか。

## 必須テーマ

- フィリピン
  - ウェインライトを中心とする現地指揮への移行
  - 3月下旬のバターン・コレヒドールへの航空・砲兵圧力
  - 補給不足、疾病、兵力消耗を最終攻勢前の制約として整理
- 3月23日 アンダマン諸島
  - ポートブレア占領
  - ベンガル湾・マラッカ海峡西側の海空交通に対する位置
  - 軍事占領成立と、その後の住民統治を分ける
- ビルマ
  - 中国遠征軍第200師団のトングー防衛
  - 日本軍第55師団などの北進
  - トングーがラングーン—マンダレー軸と東方交通の結節点であること
  - 英印軍・中国軍・米軍事顧問の指揮関係を一つの「連合軍」に潰さない
- 3月24日前後
  - バターンへの本格的砲爆撃強化
  - トングーの包囲圧力
  - 南西太平洋・太平洋戦域の連合国側責任区域再編が進む背景

## JH126→JH127 接続確認

JH126は、マッカーサーがフィリピンを離れても現地抗戦が続き、ビルマでは中部防衛線が形成される状態で終わる。JH127では、**現地指揮の再編が実際の守備条件を改善したか／アンダマン進出とトングー攻撃で日本軍の作戦空間がどう広がったか**へ進む。

## 図版publication gate候補

- Port Blair / Andamanの同時代公的資料
- U.S. Army CMHのBataan作戦図・写真

# 5. JH128 — 1942年3月25日〜3月31日

## 中心問い

> 戦場で占領地が増える一方、日本は船舶・船員・配船をどのように国家管理へ組み込み、ビルマ戦線と連合国側の広域指揮はどう再編されたのか。

## 必須テーマ

- 3月25日 戦時海運管理令
  - 全船舶の国家使用
  - 船員の徴用・労務管理
  - 船舶運営会を通じた国家使用船舶の一元運営
  - 占領地資源の獲得と、輸送能力・船腹配分を分離する
- 船腹制約
  - 軍需輸送、資源還送、民需輸送の競合
  - 「資源地を占領すれば資源問題が解決する」という単線因果を置かない
  - 実際の船腹量・損耗・配船比率は本文執筆時に公的統計・戦史で確認
- ビルマ
  - 3月末のトングー撤退
  - プローム方面の防衛危機・後退圧力（撤退は4月2日としてJH129へ送る）
  - 中国遠征軍と英軍が別軸で後退し、中央ビルマの防衛線が北へ移ること
- 連合国側広域指揮
  - 3月24〜30日前後の太平洋責任区域・SWPA/POA再編過程
  - マッカーサーの豪州移動と新戦域司令体制の制度化
  - 現地部隊の即時指揮改善と同一視しない
- 日本海軍
  - インド洋作戦への機動部隊移動をJH129への接続として扱う

## JH127→JH128 接続確認

JH127は、バターンへの圧力とトングー戦が強まり、日本軍がアンダマンまで進出した状態で終わる。JH128では、**戦域拡大を支える海運国家管理／トングー・プローム防衛の後退／連合国側の広域指揮再編**へ進み、前線の移動と制度の再編を別々に追う。

- 船舶運営会・戦時海運統制に関する公的史料

# 6. JH129 — 1942年4月1日〜4月9日

## 中心問い

> 日本軍は、フィリピンの残存大規模戦線を終わらせながら、なぜ同時にインド洋へ機動部隊を展開できたのか。その結果、何が終わり、何が残ったのか。

  - Mt. Samat周辺を含む防御崩壊
  - 4月9日 エドワード・キング少将によるバターン部隊降伏
  - バターン降伏とコレヒドール降伏を分ける

  - 4月9日の降伏成立時点で大量捕虜の移送・給養・衛生管理が新たな占領側負担になること
  - バターン死の行進の実施経過は4月10日以後の次フェーズへ送る
- インド洋作戦
  - 4月5日 コロンボ空襲
  - 4月9日 トリンコマリー攻撃
  - 英東洋艦隊・セイロン基地・インド洋航路への圧力
  - 空襲・艦艇撃沈と「インド侵攻開始」を分ける
- ビルマ
  - 中部から北方への後退戦継続
  - 日本軍増援と中国・英印軍の防衛再編

  - ジャワ・シンガポール・ラングーン等は占領統治段階

# 7. A46 — 「攻略後の外周展開と残存戦線」map necessity / data-quality judgment

## historical question

> 1942年4月9日時点で、日本軍の占領・軍政拠点、外周への攻撃対象、なお戦闘が続く残存戦線はどのように地理的に分岐していたのか。

## candidate features

- シンガポール／ジャワ／ラングーン — 占領統治・後方拠点
- ラエ／サラモア — 日本軍占領拠点＋米空母攻撃対象
- ポートブレア — 新規占領拠点
- トングー／プローム以北 — ビルマ継続戦線
- バターン — 4月9日主力降伏
- コレヒドール — 戦闘継続
- コロンボ／トリンコマリー — 日本海軍の攻撃対象
- 東ティモール — ゲリラ抵抗継続

## map necessityの初期評価

**medium-high candidate**。

A45は3月9日時点の「占領後管理／軍事占領／戦闘・抵抗継続」をPointで比較した。本フェーズでは、既占領地が後方・軍政拠点化し、その外側へニューギニア・アンダマン・インド洋の攻撃が伸びる一方、バターン・コレヒドール・ビルマ・東ティモールに異なる形の残存戦線が残る。単なる占領状態比較から、**後方化した拠点と外周作戦／残存戦線の空間分岐**へ問いが変わるため再判定価値がある。

ただし、A45のPoint類型に攻撃対象Pointを追加するだけで本文以上の理解が増えない場合はno-mapとする。地図採用を先に決めない。

## data-quality ceiling

- 占領状態・戦闘継続・攻撃対象はPoint中心で比較可能かを先に検討
- 日本軍の「勢力圏」を広域Polygonで一色に塗らない
- インド洋作戦やニューギニア方面をLineStringで示す場合、実航路ではなく作戦方向を示すschematic / waypoint-derived表現に限定し、Human Visual Audit必須
- ビルマ前線を精密front lineとして描かない。公刊戦史の時点図に依拠できる場合もgeneralized / schematicとして扱う
- A45 point-only表示を再利用する場合はHuman Visual Audit省略条件を満たすか判定する
- 新しい線・面・凡例・interactionを採用する場合はHuman Visual Auditを必須とする

## A46 判定記録（2026-10-08）

- **Map necessity: adopted**。A45（3月9日）の占領・抗戦分布に対して、A46ではセイロン島の日本軍空母空襲（コロンボ／トリンコマリー）とニューギニアの米軍空母反撃（ラエ／サラモア）が両端へ広がり、**日本軍の占領後軍政拠点／日米双方の攻撃対象／残存戦線・バターン主力降伏**を同一時点で空間比較できる。表だけでは「後方化と外周作戦の東西への拡張」を直感的に捉えにくい。
- **Geometry: Point only / Level B〜C**。11 representative Pointsを採用。ラエ・サラモアは2地点の模式的代表Point、ビルマ中北部は継戦域の概略Point。前線・占領範囲・制海権をPolygonで示さず、インド洋への実航路が史料で追跡できないためLineStringも作らない。地図が示すのは**位置関係と状態の分岐**であり、占領面積・艦隊移動経路・距離・戦線境界の定量資料ではない。
- **Historical status distinction:** ジャワ・ラングーン・シンガポールは軍政の開始／運用、ポートブレアは3月23日の新規占領、ラエ・サラモアは日本占領拠点への**米軍の反撃**、コロンボ・トリンコマリーは日本軍の**海空打撃先**、バターンは4月9日の主力降伏、コレヒドール・ビルマ・東ティモールは異なる抵抗の継続として明示。空襲先を占領地として表示しない。
- **Data Audit:** representative coordinate、歴史的状態・年月日・provenance・derivedFromSourceIds・geometryConfidenceを確認。原資料参照はJH126〜JH129の公的史料・戦史と接続。外部の歴史地図の境界・航路geometryは複製しない。
- **Style Audit:** 属性カテゴリと凡例6分類を照合し、色だけに依存せず「政・占・米・日・戦・降」の文字記号も併用する。既存ThematicMap rendererを再利用するが、**A45から凡例カテゴリと地理範囲を変更したため、point-only再利用例外は不適用**。
- **Human Visual Audit:** **pending-human**。バターン／コレヒドール、コロンボ／トリンコマリーの近接ラベル、セイロン〜ニューギニアを含む初期表示、desktop/tablet/mobile、タップ・popup・zoomを公開画面で確認するまで `draft` を維持し、公開完了扱いにしない。GeoJSON / map definitionをJH129の最終節直後へ配置し、先の時点を前節より先に見せない。
- **Next:** PR CI green → `draft / pending-human` のままmainへマージ → Pages deploy green → 公開実画面でHuman Visual Audit → 合格後に `published` 昇格 → Crosscutting publication gateへ進む。**Human Visual AuditはPRのマージ条件ではなく、地図のpublished昇格条件**。

# 8. Crosscutting publication gate

JH126〜JH129とA46判定後に、既存横断記事の延長・新規記事・holdを比較軸の厚みで判定する。

## S09-F「軍事占領から占領統治へ」候補 — strong re-evaluation candidate

前フェーズでは、香港・シンガポールに対してジャワ・ラングーンが占領直後で比較材料不足だったためholdした。本フェーズでは、

- ジャワ第16軍の軍政
- ビルマ第15軍の軍政
- 昭南特別市を含むシンガポール占領行政
- 香港占領地総督部
- アンダマンの軍事占領後統治

について、行政・警察／憲兵・食糧・通貨・交通・通信・現地行政人員・捕虜・住民統制のどこまで同じ粒度で比較できるかを再判定する。

**比較軸が3地域以上で成立する場合のみ公開候補化し、年代記事の占領地要約集になる場合はholdを維持する。**

## S10「産業社会の負担と保護」— extension candidate

3月25日の戦時海運管理令は、従来の価格・賃金・物資・設備利用統制に加えて、船舶・船員・配船を国家使用・徴用・一元運営へ組み込む制度転換である。S10の既存比較軸へ、

- 何を運ぶか
- 誰が船舶を使用するか
- 船員をどう配置するか
- 軍需・資源還送・民需の優先順位をどう調整するか

という「輸送能力そのものの配分」を追加できるかを判定する。

## hold候補

- S05「政治参加の回路」: この期間に国内の議会・政党・行政責任回路へ新しい制度段階があるかを確認。なければhold
- S02「財政」: 新しい租税・公債・会計・通貨制度転換がなければhold
- S13「日米交渉と経済圧力」: 1941年12月で終わる交渉史へ開戦後作戦を後付けしない
- 新規「第二段作戦」横断記事: 年代記事とA46の再編集になるなら追加しない

# 9. phase-end audit necessity judgment

独立監査を定型では置かない。Crosscutting publication gate後に、次の具体的仮説が未解決で残るかだけ判定する。

候補：

1. **ジャワ・ラングーン占領を、行政・治安・資源利用まで即時完成した状態として書いていないか**
2. **マッカーサー離脱を、フィリピン守備隊の指揮・抵抗消滅と同一視していないか**
3. **アンダマン占領やインド洋空襲を、インド侵攻開始へ拡張していないか**
4. **トングー／プローム後退を、3月末時点のビルマ戦役終結としていないか**
5. **戦時海運管理令を、船腹不足・輸送損耗そのものの解消として扱っていないか**
6. **4月9日のバターン降伏を、フィリピン全軍降伏やコレヒドール陥落と同一視していないか**
7. **ラエ・サラモア空襲を、連合国側が海空優勢を回復した転換として過大評価していないか**
8. **インド洋作戦とバターン最終攻勢を、日本側の無制約な戦力余裕の証明として単純化していないか**

各年代の隣接接続確認、A46 map audit、Crosscutting publication gate、通常validationで解消済みなら **no-audit** とし、重複する独立監査は実施しない。
