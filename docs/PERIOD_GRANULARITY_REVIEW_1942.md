## 現段階で分割保持を優先する境界

- **1942-02-15〜16（シンガポール陥落後）**：占領行政と中国系住民に対する検証・大量殺害は、単なる戦線前進ではない。統合の際にも主題を削らず、軍政の開始と住民への加害を独立の説明として確保する。
- **1942-04-09〜10（バターン降伏後）**：バターン死の行進は捕虜の移送・虐待・殺害の問題として説明の重みを保持する。事件日だけを理由に切っているかどうかとは区別する。
- **1942-04-18（日本本土初空襲）**、**04-30（翼賛選挙）**：前者は本土防空・海軍の作戦認識、後者は政治参加の制度状態を変える候補。前後の独立性を個別に判断する。
- **1942-06-03〜07（ミッドウェー海戦）**：空母戦力喪失と作戦中止は重大な戦略上の境界。
- **1942-08-07（ガダルカナル上陸）**：米軍が日本軍の建設中飛行場を確保し、戦争の主導権争いの条件を変えた。
- **1942-11-01（大東亜省施行）**、**11-12〜16（第三次ソロモン海戦による輸送船団喪失）**：行政権限の発効と大規模海上輸送の失敗という異なる転換を残す。
- **1942-12-21（対中国処理根本方針）**、**12-31（ガダルカナル撤退決定）**：対外統治・戦争目的と前線作戦方針で別々の重大な変化がある。

上記の「保持」は確定的な分割凍結ではない。統合可能性を否定せず、**説明責任が大きく、短縮で欠落させてはならない要素**を示す。

## 遡及統合を実施する際の順序とDoD

1. 高優先度6組から順に、既存のfrontmatter・本文・資料引用を全文読み、独立した中心問いと境界前後の権限・選択肢・負担を比較する。**機械的な日数合わせで統合しない。**
2. 統合案ごとに「維持／統合／一部統合」を決定し、廃止する公開URL・routeKey・記事ID・用語ID・本文アンカーと、参照元ページを棚卸しする。歴史記事間のリンク、横断記事の `relatedPeriods`、用語集 `content/glossary/periods/`、地図の参照を確認する。
3. 統合する場合は、事件・指揮・住民加害・制度の決定／施行／実施・史料出典を保持し、重複部分のみ圧縮する。変更後の既存リンクには遷移先の対応や適切なリダイレクトを設計し、リンク切れを作らない。
4. 新旧範囲の隣接接続・留保の分離・史実と出典を再査読し、`npm run check`・GitHub Actions・Pagesを確認する。
5. 期間・ID・URLに影響が大きいため、一度に1942年の全記事を改廃しない。5/17〜6/2の2記事を1記事に、8/10〜31の3記事を2記事に統合済み。7月1〜21日も統合済み。次は9月1〜17日などの候補を必要性順に再検討し、既存リンクと図版の保全を確認してから実施する。

## 1943年5月9日以後へ適用する方針

次のphase cutでは、5月9日から日付を順番に細分化しない。1943年5月末の大東亜政略の政府・軍中央判断、ビルマ独立の制度設計、フィリピンでの独立準備、物資・船舶・労務の配分、国内の食糧と生活を**同じ観測窓**で比較する。まず数週間〜約1か月のまとまりを候補に置き、異なる決定段階を一ページに収めると混同する場合だけ境界を狭める。4〜5記事はPLANの作業単位であり、数週間の時期を4〜5記事へ分割するためのノルマではない。

新しい14日未満の `published` 記事は `granularityDecision` に3点の根拠を残す。CIが機械確認できるのは理由欄の存在と記述量だけであり、意味的な判定は執筆・PRレビューで担保する。
