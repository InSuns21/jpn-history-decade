# 1. このフェーズを1931–1933年5月に切る理由

1931年以後は、年単位だけでは制度の状態遷移を潰しやすい。

1931年9月18日の柳条湖事件後、若槻内閣は不拡大方針を決めたが、関東軍の軍事行動は拡大した。1932年には上海事変、満洲国成立、五・一五事件、斎藤内閣成立、日本による満洲国承認が続き、1933年には国際連盟総会の勧告、脱退通告、塘沽停戦協定へ進む。

この密度では「1931–1935」のような一枚の年代ページにすると、誰がいつ何を決められたかが失われる。そこでページ境界自体を政治・軍事・外交上の選択肢が変わる局面に合わせる。

ただし、細分化を目的化しない。日単位・月単位を使うのは、境界前後で制度主体の選択肢・権限・外部制約が実際に変わる場合に限る。

# 2. 最初に行う基盤変更 — 年未満の年代ページを表現できるようにする

現行content compilerは `startYear / endYear` だけで年代ページの順序・連続性を検証し、前ページの `endYear + 1` を次ページの `startYear` に要求する。このままでは1931年を複数ページに分割できない。

JH26実装前に **JH26-A「subannual period range」** を行う。

**Status: completed / CI passed (2026-09-27)**

## 2.1 frontmatter

既存の `startYear / endYear` は互換性のため残し、任意の次フィールドを追加する。

```yaml
startDate: "1931-01-01"
endDate: "1931-09-17"
```

- 日未満へ細分化しない
- `YYYY-MM-DD` のISO形式
- 未指定の既存ページは `startYear-01-01` / `endYear-12-31` として内部正規化
- `startYear` / `endYear` はstartDate / endDateの年と一致させる

## 2.2 compiler / model

- period sortを `startYear` から正規化済み `startDate` へ変更
- gap / overlap判定を年ではなく日付範囲で行う
- 次ページのstartDateは前ページendDateの翌日であることを検証
- 既存1800–1930のfrontmatterは一括変更しない
- routeKeyは既存の年キーを維持しつつ、同一年内分割では `1931-09` のような一意キーを許容
- previousPeriodLabel / currentPeriodLabelの整合チェックは維持
- content model / template / navが年未満rangeでも破綻しないことを確認
- glossaryのperiod参照はrouteKey単位のまま維持

これにより「半年区切りをしたいから連続性CIを弱める」のではなく、**連続性CIそのものを日付粒度へ上げる**。

### JH26-A 実装結果

- `startDate / endDate` を `PeriodPageData` へ追加した
- 未指定の既存年代は `startYear-01-01 / endYear-12-31` へ内部正規化し、1800–1930のMarkdownは変更していない
- `startDate / endDate` の実在日付、`startYear / endYear` との年一致、範囲の前後関係を検証する
- period sortと隣接gap / overlap判定を日付単位へ変更した
- `1931` と `1931-09` のような同一年routeを既存route規則のまま利用できる
- 年単位互換、同一年連続、うるう日、gap、overlap、無効日付をfixtureで検証し `npm run check` に組み込んだ
- CIで既存1800–1930のcompile / lint / typecheck / buildがgreenであることを確認した

# 8. 経済史の接続

1931–1933では軍事外交だけを主線にしない。

JH25で扱った旧平価金解禁・世界恐慌・昭和恐慌から、

```text
金本位制維持
→ 国際通貨制度の動揺
→ 1931年末の金輸出再禁止
→ 為替変動
→ 財政拡張・金融緩和
→ 国債の日銀引受けを含む高橋財政
```

へ接続する。

S02「石高制・貨幣経済・財政」とS10「産業社会の負担と保護」は、新しい比較軸が成立する場合だけ延長する。年代本文の再要約にしかならない場合は更新しない。

# 9. 地図候補とpublication gate

地図は次を候補にするが、実装を前提にしない。

## A16 満州事変 1931年9–12月の軍事行動

地理が重要だが、最も誤精度化しやすい。実装条件は厳しくする。

- 日付付きの作戦・占領地点を一次史料・公的研究で検証できる
- 「満洲国」成立前後の政治境界を現代国境で代用しない
- 軍の進路線を根拠なしに直線補間しない
- 点だけで理解が改善するなら、無理にfront line polygonを作らない
- 日付の異なる状態を一枚の「日本支配地域」に潰さない

品質の高いgeometryが得られなければ no-map とし、日付付き地点表・本文で代替する。

## A17 1932–1933 国際連盟・外交

外交関係は空間表示より制度・時系列の方が理解を改善する可能性が高い。地図化の目的が成立しなければ no-map とする。

各候補はJH29まで実装後にpublication gateで判定する。新しい比較軸が立たない場合は更新しない。
