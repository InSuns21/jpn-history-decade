# 1. このフェーズを1937年8月13日〜11月12日に切る理由

前フェーズは8月12日、上海で本格交戦が始まる直前で止めた。外務省外交史料館は、8月13日に上海で日中両軍の交戦が始まり、14日に全面的な軍事衝突へ発展し、15日に日本政府が中国政府に対して強硬な措置をとる旨の声明を出したと整理している。

この境界では、華北の局地事件を現地解決する余地を探る段階から、華中の国際都市上海を含む複数戦線で軍事行動を継続する段階へ制度状態が変わる。

その後も一枚岩ではない。

- 8月中旬：上海で交戦開始。陸軍増派・海軍作戦・政府声明が接続する
- 8月下旬〜9月10日：増援と戦線拡大に加え、軍需工業動員、臨時軍事費特別会計、資金・為替・輸出入統制など国内制度が戦時対応へ組み替えられる
- 9月下旬〜10月25日：中国側では第二次国共合作が公表され、国際連盟でも日本の軍事行動が問題化する。日本側では支那方面艦隊・企画院など軍事・政策調整の中央化が進む
- 11月初旬：杭州湾上陸を含む作戦で上海正面の戦況が変わり、11月12日に日本軍が上海を占領する

11月12日は、約3か月続いた上海戦の軍事状態が大きく切り替わる境界である。ただし南京国民政府は存続し、11月20日の重慶への遷都表明、南京への進攻、トラウトマン工作の展開はその後の状態である。

したがって本フェーズは、

```text
8月13日 上海で交戦開始
→ 8月15日 政府方針の強硬化
→ 増援・航空／海上作戦・戦線拡大
→ 9月 戦時財政・資金・輸出入統制の制度化
→ 9〜10月 中国側抗戦体制・国際問題化／日本側指揮・企画機構の再編
→ 11月初旬 杭州湾方面から作戦条件が変化
→ 11月12日 上海占領
```

として扱う。

11月13日以後の南京進攻、11月20日の遷都表明、南京占領、トラウトマン工作の帰趨、1938年1月16日の第一次近衛声明は次フェーズへ送る。

# 3. JH40 — 1937年8月13日〜15日

## 中心問い

> 上海での交戦は、なぜ華北の戦闘とは別の危機として国家政策を変え、8月15日の政府声明へ接続したのか。

## 必須テーマ

- 8月13日の上海での日中両軍交戦開始
- 8月14日の全面的軍事衝突
- 日本海軍特別陸戦隊と中国側中央軍・保安部隊の制度的位置
- 上海共同租界・フランス租界・中国側市街が近接する国際都市条件
- 英米など第三国権益と、戦闘回避の外交が失敗した経過
- 8月15日の日本政府声明は、当時の政府表現として引用・説明し、サイト側の評価語として使わない
- 華北の「現地解決・不拡大」から何が変わり、何がなお残ったか
- 海軍の現地行動、陸軍増派、政府・外務省の判断を一主体にまとめない
- 中国側も上海現地部隊、南京国民政府、蒋介石の中央判断を分ける
- 民間人・租界居住者への戦闘影響を、確認できる史料の範囲で扱う。死傷者数は出典・対象範囲が一致しない限り精密数値を置かない

## JH39→JH40 接続確認

JH39は8月12日時点で、華北では大規模作戦が進んだ一方、上海では大山事件後も交戦回避の外交努力が残っていた状態で終わる。

JH40は翌13日の交戦開始から始める。したがって「大山事件が自動的に上海戦を起こした」とせず、現地兵力、租界、中央軍投入、日中双方の判断、第三国外交が重なって交戦へ移ったことを示す。

# 4. A21 — 1937年8月の上海都市政治・軍事空間

## map necessity

**候補: high / JH40実装時にData Auditを行って最終判定する。**

上海戦初期は、

- 上海共同租界
- フランス租界
- 中国側市街
- 虹口・閘北・江湾などの主要地区
- 黄浦江・呉淞口
- 日本海軍陸戦隊拠点
- 中国側部隊の主要展開区域

の近接が、戦闘と第三国外交を理解するための中心条件になる。

単純な「上海という一点」では、国際都市内部で軍事行動と租界中立・外国権益が接触する構造を説明できない。

## Data Audit方針

国立国会図書館には1937年8月製版の1:20,000「二万分一上海市街圖」が存在する。これを都市地形・街路・地名の同時代基準資料候補とする。

ただし、

- 同時代地図があることと、租界境界・部隊線のGIS geometryが自動的に確定することは別
- スキャン画像から境界を目視でなぞる場合は transformation / georeference / geometryConfidence を記録する
- 史料で境界・部隊位置を確認できない場合、精密polygonを作らずpoint / approximate areaへ落とす
- 現代上海行政界・道路網を1937年境界として代用しない
- 戦闘前線を根拠のない連続LineStringとして描かない

polygon / lineを使う場合はpoint-only visual-audit省略規則の対象外とし、Human Visual Auditを必須とする。

# 5. JH41 — 1937年8月16日〜9月10日

## 中心問い

> 上海戦が短期で終わらないなか、日本は宣戦布告をしないまま、どの制度を使って大規模な軍事行動を財政・資金・物資の面から継続可能にしたのか。

## 必須テーマ

- 上海への陸軍増援と、華北・華中で戦線が並行する状態
- 8月中旬以後の上海派遣軍・増援師団を、編制日・命令日・上陸日を混同せず確認
- 8月20日の軍需工業動員法発動に関する閣議決定
- 8月21日の中ソ不可侵条約と、中国側の対外支援環境
- 9月2日の「北支事変」から「支那事変」への日本政府上の呼称変更
- 第72回帝国議会
- 臨時軍事費特別会計
- 臨時資金調整法
- 外国為替管理法改正
- 輸出入品等に関する臨時措置
- 軍需工業動員法の適用拡大
- 「宣戦布告をしていない」ことと「戦闘規模が小さい」ことを同一視しない
- 1937年9月の制度を1938年の国家総動員法と同一視しない

## JH40→JH41 接続確認

JH40末尾では、上海で本格戦闘が始まり、日本政府が強硬声明を出した状態までを扱う。

JH41では、「政府が強硬化した」だけで終わらず、その方針を実際に継続するために**兵力・公債・会計・資金・輸入・為替をどう制度化したか**へ進む。

# 6. JH42 — 1937年9月11日〜10月25日

## 中心問い

> 戦時財政・資金統制を整えても上海戦が長期化したのはなぜか。日中双方は、軍事だけでなく国内組織・同盟・国際外交をどのように組み替えたのか。

## 必須テーマ

- 上海戦の長期化と追加増援
- 中国側中央軍の継続投入と、地域戦闘を国家的抗戦へ接続する政治判断
- 9月22〜23日の国民党・共産党の協力体制公表を、両組織の完全統合とは書かない
- 中ソ関係と対外支援
- 10月6日の国際連盟での対日批判・国際問題化
- 10月20日の支那方面艦隊編成
- 10月25日の企画院設置
- 海軍指揮の統合と、政府の経済・資源企画の中央化を同じ制度としない
- 統制制度が成立したことを、社会・企業・市場が即時に完全統制されたことと同一視しない
- 上海戦の長期化を「中国側の抵抗」一因だけで説明せず、都市地形、兵力投入、補給、作戦目的、国際都市条件を分ける

## JH41→JH42 接続確認

JH41は9月10日までに、戦闘継続のための財政・資金・物資制度が法制化されたところで終わる。

JH42では、その制度能力を持っても軍事的・政治的決着が得られず、日中双方がより長期の抗戦・動員を前提に組織と外交を変える過程を追う。

# 7. JH43 — 1937年10月26日〜11月12日

## 中心問い

> 上海正面で続いた消耗戦は、なぜ11月に作戦条件が変わって中国軍の退却へ至ったのか。それでも上海占領が戦争終結にならなかったのはなぜか。

## 必須テーマ

- 10月末時点の上海正面の戦況を、後の上海占領から逆算しない
- 上海正面以外からの兵力投入・迂回作戦が検討された条件
- 11月5日の杭州湾上陸
- 上海正面中国軍の側背・退路への影響
- 中国軍の退却過程
- 11月12日の上海占領
- 日本側の「上海を取れば政治的決着が得られる」という期待がどの程度存在したかは、政策文書・研究に基づき限定して書く
- 南京国民政府・中国中央軍が消滅していないこと
- 11月上旬に始まるトラウトマン仲介は、存在と初期条件のみ扱い、交渉の帰趨は次フェーズへ送る
- 11月13日以後の南京進攻を本ページの結果として先取りしない

## JH42→JH43 接続確認

JH42は10月25日、国内の企画機構と中国方面海軍指揮が再編されても上海正面で決着がついていない状態で終わる。

JH43は、既存正面の攻撃継続ではなく、杭州湾上陸など**戦場の空間構造を変える作戦**が上海の防御条件を変えた過程を中心にする。

# 8. A22 — 上海・杭州湾の作戦空間

## map necessity

**候補: high / JH43実装時にData Auditを行って最終判定する。**

JH43では、「上海正面で正面攻撃を続けた」だけでは11月の状態変化を説明できない。上海・杭州湾・蘇州方面の位置関係と、上陸によって側背・退路条件が変わることが中心論点になる。

国立国会図書館には1937年9月製版の1:100,000「上海蘇州近傍圖」があり、対象時期に近い地域地図として利用候補になる。

## Data Audit方針

- 同時代地図を基礎に、海岸・都市・主要交通路を確認する
- 上陸地点・部隊経路は戦史叢書や一次史料で確認する
- 上陸地点の精度が集落・海岸区間レベルならapproximate point / areaに落とす
- 推測した進軍経路を道路沿いの精密線として描かない
- 1937年の海岸線を現代海岸線で無注記代用しない
- route geometryが確定できない場合、上陸地点・主要都市・方向関係のpoint中心地図へ縮退する

line / polygonを使う場合はHuman Visual Audit必須。

# 9. Crosscutting publication gate

JH40〜JH43実装後に行う。年代記事の時系列を並べ替えるだけの新規横断記事は作らない。

## 既存記事の延長候補

### S02「石高制・貨幣経済・財政」

publication gate候補。

臨時軍事費特別会計、公債による大規模戦費調達、一般会計との分離が、7〜8月の「追加予算」から別段階へ進むため、独立した長期比較軸が成立する可能性が高い。

### S05「政治参加の回路」

publication gate候補。

第72回帝国議会が臨時軍事費・資金統制・為替・輸出入関係法を審議する一方、作戦方針自体は政府・統帥機関の別回路で進むため、「議会が何を決め、何を直接決めないか」という既存軸へ接続できる。

### S10「産業社会の負担と保護」

publication gate候補。

臨時資金調整、輸出入・為替統制、軍需動員が企業投資・原料配分・家計・金融市場へ負担を広げるため、「誰が費用を負担するか」の比較軸が更新される可能性がある。

### S09「対外支配の制度差」

現時点では延長を前提にしない。

上海占領だけでは、直ちに安定した新統治制度・法的地位が成立したことを意味しない。占領行政・傀儡政権・租界との制度関係が具体化した段階で再判定する。

## 新規横断記事候補

「戦時動員体制」だけを理由に新規記事を作らない。

1937年9月の制度は重要だが、S02・S05・S10で異なる比較軸から説明可能であり、1938年の国家総動員法などまで見ないと独立した長期構造記事にならない可能性が高い。publication gateで既存記事では説明できない問いが成立した場合のみ新規作成する。

# 13. このフェーズでしないこと

- 上海戦を大山事件一件の自動的結果として書かない
- 8月13日時点から11月12日の上海占領を必然として書かない
- 日本政府・陸軍・海軍・現地軍を「日本側」の一意思に畳み込まない
- 南京国民政府・国民党・共産党・現地部隊を「中国側」の一意思に畳み込まない
- 当時の「膺懲」等の政策語をサイト側の地の文の評価語として使わない
- 宣戦布告がないことを「戦争ではなかった」「規模が小さかった」と説明しない
- 戦時統制法が成立した瞬間に経済社会が完全統制されたと書かない
- 第二次国共合作を国民党・共産党の組織統合と書かない
- 国際連盟の判断だけから各国の政策が自動的に決まったと書かない
- 上海占領を中国中央政府の崩壊・降伏と同一視しない
- 11月13日以後の南京進攻・南京占領・第一次近衛声明をJH43へ先取りしない
- 同時代地図を根拠なく精密GISへ変換しない
- 現代上海の行政界・海岸線・道路網を1937年の歴史地理として無注記で使わない
- フェーズ末に理由のない全体監査を追加しない
