# 1. このフェーズの位置づけ

前フェーズは1873年までを扱い、

- 廃藩置県
- 戸籍
- 学制
- 徴兵令
- 地租改正

によって、中央政府が地方官・個人・土地へ全国共通の制度を及ぼし始めるところまでを実装した。

次の1874〜1890年では、その制度を持つ政府が、

- 誰の意見を政治へ入れるのか
- 地方の行政と議会をどう設計するのか
- 士族秩序の解体に伴う負担・反発をどう処理するのか
- 戦争・インフレ・デフレ・通貨制度をどう処理するのか
- 政党・集会・新聞・建白をどこまで認め、どこで規制するのか
- 憲法・内閣・地方制度・選挙・議会をどう組み合わせるのか

を具体的に決めていく過程を追う。

このフェーズの終点を1889年の憲法発布ではなく**1890年**とする。

憲法を公布したことと、その制度のもとで選挙を行い、帝国議会を開き、政府と議会が予算・法律をめぐって実際に関係を持ち始めることは同じではない。制度の「公布」ではなく「作動開始」までを見るため、1890年を区切りとする。

---

# 2. 歴史記述の中心原則

この時期は後世から「自由民権運動 → 憲法制定 → 帝国議会」という一直線の物語に見えやすい。以下を明示的に避ける。

## 2.1 自由民権運動を一枚岩にしない

建白・請願、結社、演説、新聞、政党、地域運動、農民層の政治参加、急進事件を同一視しない。

- 参加者の社会階層
- 地域
- 政治目標
- 政府との距離
- 時期

によって運動の性格が異なることを示す。

## 2.2 政府を「民権運動に押されただけ」の主体にしない

政府内部にも憲法・議会・地方制度をめぐる複数の構想があり、制度設計は民権運動への対応だけでなく、

- 行政能力
- 財政
- 官僚制
- 外交
- 欧州制度調査
- 地方統治
- 宮中と政府の関係

などの条件に規定された。

運動側と政府側の双方に選択肢と内部差があったことを記述する。

## 2.3 「士族反乱＝旧時代の抵抗」と単純化しない

士族反乱は、家禄・帯刀・軍事的地位だけでなく、政府人事、外交論、地域政治、旧藩以来の人的結合など複数の背景を持つ。

佐賀、熊本、秋月、萩、鹿児島を一つの同質な反乱として扱わない。

## 2.4 松方財政を「健全化」または「弾圧」の一語で評価しない

不換紙幣整理、財政収支、正貨蓄積、中央銀行設立と、

- 物価下落
- 農産物価格
- 農村負債
- 土地所有
- 地方政治運動

を分けて確認する。

政策目的と地域社会への影響を同じ評価語へ潰さない。

## 2.5 憲法発布を「民主国家の完成」にしない

1889年の憲法は政治参加の制度を作ったが、

- 選挙権は限定されていた
- 貴族院は公選のみでは構成されなかった
- 天皇大権が規定された
- 内閣と議会の関係はその後の政治運用で具体化した
- 地方自治にも中央政府の監督が強く残った

という制度上の条件を扱う。

一方で、議会の予算・立法への関与や選挙という新しい政治回路も過小評価しない。

# 9. JH15 — 1886–1890

## 中心問い

> 憲法、内閣、地方制度、選挙、議会は、どのような権限配分として組み合わされ、1890年にどこまで実際の政治制度として作動し始めたのか。

## 必須テーマ

- 内閣制度の定着
- 学校令
- 条約改正問題
- 三大事件建白運動
- 保安条例
- 枢密院
- 市制・町村制
- 大日本帝国憲法
- 皇室典範は公開範囲と制度的位置づけを確認して必要な範囲で扱う
- 衆議院議員選挙法
- 限定選挙権
- 貴族院
- 司法制度
- 1889年東海道線全通
- 1890年第1回衆議院議員総選挙
- 1890年第1回帝国議会
- 府県制・郡制

## 記述上の注意

- 「憲法＝政府対民権派の妥協」と一文で要約しない。
- プロイセン参照だけで制度全体を説明せず、日本国内の既存官制・宮中制度・地方制度との接続を見る。
- 選挙権の範囲は人数・比率を使う場合、年・定義・出典を確認する。
- 教育勅語を単なる教育政策または後世の戦時体制の前史としてだけ扱わず、1890年時点の教育制度・国家理念との関係で説明する。
- 1890年を「立憲国家完成」と断定しない。議会と政府の関係はここから運用上の対立・慣行形成へ入る。

## 優先地図候補 A6

**1872〜1890年の鉄道網拡大**

長期企画の主題地図候補「鉄道網の拡大」を、このフェーズで初めて具体的に検討する。

比較候補：
- 1872
- 1882
- 1889/1890

ただし現代鉄道路線を過去へそのまま投影しない。

- 廃線・経路変更・現在線との差を処理できる
- geometry provenanceが追跡できる
- historical routeとして偽の精密さを出さない

条件を満たせない場合は、主要開業区間を表・概念図で示し、地図化を見送る。

# 12. 横断記事の役割分担

年代記事：
- その時点の選択肢・制約
- 前期間との差分
- 同時代の政治・経済・社会の接続

横断記事：
- 長期の制度変化
- 用語・制度間の因果関係
- 同一テーマの地域差・時期差

たとえば松方財政はJH14で1882–1885年の社会状態として説明し、S08では1870年代の紙幣増発から中央銀行・兌換制度までの長期変化を整理する。

同じ説明を双方へ丸ごと複製しない。

# 16. Source / date audit

この時期は1873年以降なので、原則として西暦と新暦が一致する。

ただし、
- 法令原文に明治年月日だけがある場合
- 旧暦時代からの制度経緯を説明する場合
- 1873年以前との比較

では、前フェーズの暦規約を維持する。

確認対象：

- 法令公布日と施行日
- 官職就任日
- 政党・結社の成立日
- 戦争・反乱の開始終了
- 選挙日
- 帝国議会開会日
- 鉄道開業日
- 金融制度の制定・開業・銀行券発行の区別

「制定」「公布」「施行」「開業」を同義にしない。

# 17. CI / compiler

## JH12-A 年代連続性guard

**Status: completed (2026-09-27)**

`scripts/compile-content.mjs` で隣接年代の `previous.endYear + 1 === current.startYear` を検査し、暗黙の年代gapをbuild前validation errorにする。既存1800–1873もこのguardを通過することをCIで確認する。

content compilerへ以下を追加する。

- 前ページ `endYear + 1` と次ページ `startYear` が一致すること
- 不一致ならbuild前validation error
- 既存1800–1873にも適用し、全期間が連続していることを確認

## 維持するvalidation

- frontmatter
- period ID / route
- previousPeriodLabel
- crosscutting relatedPeriods
- source ID / unused source
- glossary
- core term
- map ID
- map audit metadata
- instruction length
- lint
- typecheck
- build

規模増加に対して、全用語×全年代の総当たり走査は行わない。
