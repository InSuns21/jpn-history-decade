# 1. このフェーズを1942年2月16日〜3月9日に切る理由

前フェーズの終点2月15日には、シンガポールで英連邦軍が降伏した。一方、フィリピンではバターン・コレヒドール、ビルマではラングーン方面、蘭印ではジャワ本島が未決着であり、ティモールでも日本軍の本格侵攻前だった。したがって2月15日は南方作戦の終点ではなく、占領統治の開始と残存戦線の攻略が同時に進む局面への入口である。

2月16日以後、シンガポールでは日本軍の占領行政が始まり、18日前後から華人住民を対象とする検問・選別と大量殺害へつながる粛清が進んだ。香港でも2月19日に香港占領地総督部が編成され、20日から第23軍軍政庁の業務を引き継いで軍政を開始した。ここでは「守備隊を降伏させた」状態から、警察・治安・行政・食糧・通貨・住民統制を継続的に運用する制度へ移る。

同じ時期、日本軍は作戦空間をさらに南と西へ広げた。2月19日にはダーウィンを大規模に空襲し、19〜20日にはバリ島周辺、20日にはティモールへ侵攻した。ティモールでは西部の主力守備隊が23日に降伏した一方、東部山地ではオーストラリア独立中隊などの抵抗が続いた。主要守備隊の降伏と島全体の抵抗終結は同じ時点ではない。

ビルマでは17師団がシッタン川方面へ後退し、2月22〜23日の橋梁爆破によって多数の部隊が重装備を失った。蘭印では、英米蘭豪を束ねていたABDA最高司令部が25日に事実上消滅し、ジャワ防衛はオランダ側を中心とする体制へ再編された。統合司令部の解体は、連合国軍の存在そのものが消えることではなく、戦域横断の最高指揮枠組みが維持できなくなった制度変化である。

2月27日のジャワ海海戦では、カレル・ドールマン少将指揮の連合艦隊が日本軍のジャワ侵攻船団阻止を試みて大きな損害を受けた。28日夜から3月1日のスンダ海峡海戦などを経て、日本軍は3月1日にジャワ本島へ上陸した。これにより、海上で侵攻船団を阻止する段階から、ジャワ島内で飛行場・都市・道路をめぐる地上戦へ状態が移る。

3月5日までに日本軍はバタヴィアへ入り、6〜7日にはバンドン方面の防御線へ圧力をかけた。3月7日に英側はラングーンから撤退し、8日に日本軍が市内へ入った。同じ8日、ジャワではカリジャティで降伏交渉が行われ、9日に蘭印軍司令官がジャワの連合軍へ降伏命令を放送した。ここでABDA時代の「マレー障壁」を一体として守る構想は崩れ、ジャワとラングーンという二つの主要拠点が日本軍の占領下へ移る。

ただし3月9日時点でも、フィリピンのバターン・コレヒドールでは米比軍が抗戦を続け、ティモールではゲリラ戦が続き、ビルマでも戦線は北部へ移っただけである。また蘭印全域を一日で行政的に掌握したわけでもない。このため3月9日を「南方作戦完了」ではなく、**主要な植民地中枢・交通拠点の攻略が進み、戦線が残存拠点と占領統治へ再編された境界**としてフェーズ終端に置く。

本フェーズは、**軍事降伏後の占領統治開始 → 南方・ビルマ戦線の追加拡大 → ABDA最高司令部解体 → ジャワ侵攻船団阻止の失敗 → ジャワ本島地上戦 → ジャワ降伏・ラングーン占領**という状態遷移として1942年2月16日〜3月9日に切る。

# 3. JH122 — 1942年2月16日〜2月20日

## 中心問い

> 守備隊の降伏後、日本軍は占領した都市をどのような行政・治安・住民統制へ切り替え、同時に次の作戦をどこまで広げたのか。

## 必須テーマ

- JH121からの接続
  - 2月15日のシンガポール降伏
  - パレンバン攻略進行中
  - バターン・ビルマ・ジャワは未決着
- シンガポール
  - 軍事占領から占領行政への移行
  - 「昭南」呼称の使用開始
  - 軍政機構、治安、食糧、通貨、交通・通信の管理
  - 2月18日前後からの華人住民の検問・選別と、その後の大量殺害
  - 粛清を「戦闘の延長」で済ませず、占領下の住民統制・暴力として位置づける
- 香港
  - 2月19日 香港占領地総督部編成
  - 2月20日 第23軍軍政庁から業務移管
  - 防衛隊・憲兵隊・民治部などの役割分担
  - 12月26日の臨時軍政から、より恒常的な占領統治機構への移行
- 2月19日 ダーウィン空襲
  - 日本海軍機動部隊・基地航空隊による攻撃
  - 豪州北部の港湾・航空基地・補給拠点への打撃
  - 「豪州侵攻開始」とせず、ティモール・蘭印攻略を支える作戦環境として扱う
- 2月19〜20日 バリ島周辺／バドゥン海峡
  - ジャワへ接近する航空・海上拠点
- 2月20日 ティモール侵攻
  - オランダ領西ティモールとポルトガル領東ティモールの制度差
  - 豪・蘭部隊、ポルトガル中立、現地住民を一括しない

## JH121→JH122 接続確認

JH121は、シンガポールで軍事的降伏が成立し、その直後から占領行政・捕虜管理・都市機能管理が必要になる状態で終わる。JH122では前ページの戦闘経過を再掲せず、**占領地で誰が警察・行政・食糧・住民統制を担うか**へ直ちに進む。同時に、蘭印・豪州北方への作戦拡大を並行して示し、「占領統治の開始」と「新規攻略の継続」を同一段階へまとめない。

## 図版publication gate候補

- National Archives of Singaporeの占領初期資料・旧フォード工場展示資料
- JACAR「香港占領地総督部命令」
- Australian War Memorialのダーウィン空襲／ティモール侵攻写真

採用時は、粛清・住民被害を装飾的な戦争写真にしない。史料画像が制度や占領下生活の理解を具体化するかを優先する。

# 4. JH123 — 1942年2月21日〜2月25日

## 中心問い

> 連合国側の守備線と統合指揮は、各戦域の後退が重なる中でどのように分解したのか。

## 必須テーマ

- ビルマ
  - 17師団のシッタン川方面への後退
  - 2月22〜23日のシッタン橋をめぐる戦闘と爆破
  - 多数の兵員が渡河できても重装備・車両を失うことの作戦上の意味
  - ラングーン防衛が兵力数だけでなく、道路・橋梁・補給・港湾で制約されること
- ティモール
  - 2月23日 西ティモールの主力守備隊降伏
  - 東ティモール山地の独立中隊等の抵抗継続
  - 「主力降伏」と「島全域の抵抗終結」を分ける
- ABDA
  - 2月25日 Wavell離脱、ABDA最高司令部の消滅
  - オランダ軍がジャワ防衛の中心へ戻る
  - 最高司令部解体と各国部隊・艦艇の即時消滅を分ける
- フィリピン
  - バターン・コレヒドールの抗戦継続を残存戦線として維持
  - マッカーサー退避命令は、必要なら戦域指揮再編の補助線として扱う

## JH122→JH123 接続確認

JH122は、日本軍がティモールへ侵攻し、ビルマではラングーンへ向けた圧力が強まる状態で終わる。JH123では、**ティモール主力降伏後の残存抵抗／シッタン橋喪失による装備・補給能力低下／ABDA最高司令部解体**へ進み、各戦域の敗北を「連合国軍が一斉に崩壊した」と均さない。

## 図版publication gate候補

- Australian War MemorialのSparrow Force／ティモール関連資料
- シッタン橋・ビルマ撤退の公的戦史図版
- ABDA指揮系統を示す同時代文書・公刊戦史図

# 5. JH124 — 1942年2月26日〜3月1日

## 中心問い

> ジャワ侵攻前夜、連合国艦隊はなぜ侵攻船団を止められず、海上戦の敗北は3月1日の地上戦開始へどうつながったのか。

## 必須テーマ

- 2月27日 ジャワ海海戦
  - カレル・ドールマン少将指揮のABDA残存艦隊
  - 目的は日本軍ジャワ侵攻船団の阻止
  - 航空偵察・通信・共同訓練・戦術統一・兵力損耗の制約
  - De Ruyter / Java等の喪失
- 2月28日〜3月1日
  - スンダ海峡海戦
  - USS Houston / HMAS Perth喪失
  - 東部でもHMS Exeter等の脱出失敗
- 3月1日 ジャワ本島上陸
  - 西部・中東部の複数上陸点
  - Kalijati飛行場など航空拠点への急進
- 海戦の帰結
  - 海上阻止能力の低下
  - 上陸船団が地上兵力を投入できる条件
  - 「海戦敗北だけがジャワ降伏を決めた」という単線因果にしない

## JH123→JH124 接続確認

JH123はABDA最高司令部が解体された一方、艦艇・航空機・地上軍はジャワ防衛のため戦闘を続ける状態で終わる。JH124では、残存海軍戦力が**侵攻船団阻止という具体的任務**へ投入され、その失敗後にジャワ地上戦が始まる。組織の解体と戦闘能力の消滅を同日扱いしない。

## 図版publication gate候補

- U.S. Naval History and Heritage CommandのJava Sea Campaign図・艦艇写真
- Java Sea Combat Narrativeの作戦図
- 公的機関所蔵のHouston / Perth / De Ruyter関連写真

# 6. JH125 — 1942年3月2日〜3月5日

## 中心問い

> 日本軍のジャワ上陸後、飛行場・道路・都市の確保は守備側の防御配置と植民地政府の選択肢をどう狭めたのか。

## 必須テーマ

- 西ジャワ
  - Kalijati飛行場確保後の航空運用
  - Merak / Banten方面からBatavia・Buitenzorg方向への前進
  - Eretan Wetan方面からBandung高原への圧力
- 3月5日 バタヴィア
  - 日本軍の市内進入
  - 首都・行政中枢の喪失
  - 都市占領と蘭印全域の降伏を分ける
- 連合側
  - Bandung高原へ防衛を集中
  - 通信・航空・道路・兵站・士気の制約
  - 植民地政府・軍司令部の移動と退避
- 東・中部ジャワ
  - Surabaya等への圧力を、必要な範囲で全島の同時進行として扱う
- 占領実務への入口
  - 都市・飛行場確保後に必要となる警備、捕虜、交通・通信、行政施設管理

## JH124→JH125 接続確認

JH124は3月1日に複数地点からジャワ本島へ上陸し、海上阻止戦から地上戦へ移る状態で終わる。JH125では、**上陸地点→飛行場→道路→都市**という地上作戦の連鎖へ入り、海戦の再説明をしない。Batavia占領後もBandung方面の防御が残ることを次ページへ渡す。

## 図版publication gate候補

- Netherlands Ministry of Defence / NIOD系のジャワ侵攻・Batavia資料
- U.S. Army CMH *East Indies* の「Japanese Landings on Java」作戦図
- Batavia進入またはKalijati飛行場に関する権利確認済み写真

# 7. JH126 — 1942年3月6日〜3月9日

## 中心問い

> ジャワの降伏とラングーン占領は、南方戦線のどの拠点・補給路・指揮構造を変え、どの戦争をなお残したのか。

## 必須テーマ

- ジャワ
  - 3月6〜7日 Bandung北方での戦闘
  - 3月8日 Kalijatiでの降伏交渉
  - 蘭印総督と蘭印軍司令官の役割を分離
  - 3月9日 降伏命令の放送
  - ジャワの組織的軍事抵抗の終結と、その後の占領行政・捕虜収容を分ける
- ビルマ
  - 3月7日 ラングーン撤退
  - 港湾・石油施設・軍需物資の破壊／放棄
  - 3月8日 日本軍のラングーン進入
  - 中国向け海上補給の入口喪失
  - 英中軍は北方へ後退し、ビルマ戦役自体は継続
- 同時点の残存戦線
  - フィリピン：バターン・コレヒドール
  - ティモール：ゲリラ戦
  - ビルマ：中北部へ後退戦
- 3月9日の状態
  - 主要植民地中枢の軍事占領
  - 占領行政・治安・資源利用・捕虜管理の負担増
  - 南方作戦の「攻略段階」から、残存戦線と占領統治が重なる段階への移行

## JH125→JH126 接続確認

JH125はBataviaが占領されてもBandung高原に防御が残る状態で終わる。JH126では、Bandung方面の防御崩壊とKalijati交渉を受けて、**軍司令官の降伏命令という制度的終点**まで進む。同時にラングーンでは港湾・補給路の喪失が起こるが、ビルマ全土の制圧とはせず、北方への戦線移動を残す。

## 図版publication gate候補

- Kalijati降伏交渉・ジャワ降伏に関するNIOD / オランダ公的機関資料
- U.S. Army CMH *Burma, 1942* のRangoon撤退・補給路図
- Rangoon港湾の撤退・破壊を示す権利確認済み公的戦史図版

# 8. A45 — 「ABDA解体後の占領拠点と残存戦線」map necessity / data-quality judgment

JH126後に判定する。

## historical question

> 1942年3月9日時点で、南方・ビルマ・フィリピンの主要地点は「占領行政」「組織的降伏」「戦闘継続」「ゲリラ抵抗」のどの状態に分かれていたのか。

## candidate features

- 香港
- シンガポール
- バタヴィア / バンドン
- ラングーン
- 西ティモール / 東ティモール
- バターン / コレヒドール
- パレンバン
- ダーウィン（攻撃対象・連合側後方拠点として必要な場合のみ）

## map necessityの初期評価

**medium-high candidate**。

A44は2月15日時点の「占領後管理／軍事占領／継続戦闘／同盟国」をPointで比較した。本フェーズでは、その後約3週間で香港・シンガポールの行政制度が進み、ジャワ・ラングーンが新たに軍事占領へ移る一方、バターン・ティモール・ビルマ北部には抵抗が残る。**同じ広域で状態類型が短期間に組み替わること**自体が中心論点になるため、A44の単純延長ではなく3月9日時点の比較地図として再判定する価値がある。

ただし、JH126本文とA44だけで差分が十分に理解できる場合はno-mapとする。地図採用を先に決めない。

## data-quality ceiling

- A44と同様、まずPoint中心で状態類型の比較を検討する
- Java全域・Burma全域・Timor全域を一色の占領Polygonで塗らない
- Javaの上陸地点・進撃経路をLineString化する場合は、U.S. Army CMH等の作戦図を根拠にwaypoint-derived / schematicとして扱う
- 3月9日時点の「降伏命令」と、個別部隊の降伏・残存抵抗の時間差を属性で扱う
- point-onlyでA44の表示を再利用する場合は、Human Visual Audit省略条件を満たすか監査する
- LineString / Polygon / 新interactionを採用する場合はHuman Visual Audit必須

# 9. Crosscutting publication gate

JH122〜JH126とA45判定後に実施する。

## S09-E「開戦初動――同盟・軍事占領・継続戦闘」

S09-Eは1942年2月15日まで、守備隊降伏・都市占領・軍政機構・国家政府の存続・残存戦線を比較している。本フェーズでは、香港占領地総督部、シンガポール軍政、ジャワ占領、ラングーン占領が重なり、比較軸が「どこまで軍事占領が進んだか」から「占領後にどの統治制度が立ち上がったか」へ移る可能性が高い。

### S09-F strong candidate

新規記事候補：

**S09-F「軍事占領から占領統治へ――香港・昭南・ジャワの行政化」**

候補比較軸：

- 軍事指揮と民政・軍政機構の関係
- 警察・憲兵・治安機関
- 食糧・通貨・交通・通信
- 現地行政組織・住民代表機構の利用
- 捕虜・抑留者・住民統制
- 軍事占領成立日と行政制度始動日の時間差

S09-Eを無限延長せず、**戦闘状態の比較から占領統治制度の比較へ問いが変わった時点でS09-Fへ分ける**。ただしJH122〜JH126実装後に、比較材料が十分かをpublication gateで最終判定する。

## hold / 再判定

- S10「産業社会の負担と保護」: 南方資源の占領が国内配給・価格・労働制度へ新しい段階を生んだ史料がこの期間だけで成立するか再判定。単なる「資源獲得」を理由に延長しない
- S13「日米交渉と経済圧力」: 交渉史は12月1日終端を維持
- S05「政治参加の回路」: 国内政治参加制度の新段階がなければhold
- S12（研究・政策接続系列）: 新しい比較軸がなければhold

# 10. phase-end audit necessity judgment

独立監査を定型では置かない。Crosscutting publication gate後に、次の具体的仮説が未解決で残るかだけ判定する。

候補：

1. **シンガポール降伏後の住民統制を、戦闘の単純な延長として扱っていないか**
2. **香港占領地総督部の成立と、12月26日からの第23軍軍政庁を同一制度として潰していないか**
3. **ティモール主力降伏を島全域の抵抗終結としていないか**
4. **ABDA最高司令部解体を、連合国側戦力の即時消滅と同一視していないか**
5. **ジャワ海海戦だけをジャワ降伏の単独原因にしていないか**
6. **3月9日のジャワ降伏を蘭印全域の即時・完全な行政掌握へ拡張していないか**
7. **ラングーン占領をビルマ戦役の終結としていないか**
8. **3月9日を南方作戦全体の完了として扱い、バターン・ティモール・ビルマ北部の残存戦線を消していないか**

各年代の隣接接続確認、A45 map audit、S09 publication gate、通常validationで解消済みなら **no-audit** とし、重複する独立監査は実施しない。
