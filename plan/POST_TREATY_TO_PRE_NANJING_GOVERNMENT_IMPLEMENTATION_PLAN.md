# 1. このフェーズを1940年1月27日〜3月29日に切る理由

直前フェーズは1月26日の日米通商航海条約失効で終えた。1月27日以後、日本は米国との通商航海条約を欠く状態へ入ったが、民間貿易・外交関係・最恵国待遇等の実務は国内法・行政措置で継続可能だった。ここから重要なのは、**「条約がなくなった」ことと「対米経済関係が断絶した」ことを分けて追うこと**である。

同時に、国内では国家総動員法にもとづく統制がさらに具体化する。

1. **2月1日:** 1939年12月に公布されていた工場事業場使用収用令・土地工作物管理使用収用令が施行され、工場・事業場・土地・工作物の利用権へ行政が介入できる制度が動き始める。
2. **2月1日:** 海運統制令が公布・施行され、船舶・海運を総動員上の配分対象として扱う制度が強まる。一方、同日公布の陸運統制令は施行時期が後であり、1940年2月に全面施行された制度として扱わない。
3. **2月2日:** 衆議院本会議で斎藤隆夫が日中戦争の処理を批判する、いわゆる「反軍演説」を行う。演説の一部削除、懲罰手続へ進み、議会内の批判回路とその制約が明確になる。
4. **2月13日:** 農林省令第13号「米糠配給統制規則」が公布され、米糠の配給統制が加わる。JACAR年表の「米穀配給統制規則」表記は、同日『官報』第3929号の法令名に従って訂正して扱う。
5. **3月7日:** 斎藤隆夫の除名が衆議院本会議で議決され、議会内批判の制度的境界が変わる。
6. **3月30日:** 汪兆銘を首班とする南京国民政府が成立する。これは占領地政治機構の制度状態が変わるため、次フェーズの開始点とする。

したがって本フェーズは、**無条約状態に入った対米関係、総動員統制の利用権・輸送・農業副産物流通への拡張、議会内での戦争処理批判と除名まで**を扱い、南京国民政府成立は次の状態として切り分ける。

## S10「産業社会の負担と保護」 — passing

S10の1940年1月26日時点の残存論点には、1939年12月29日に公布された工場・事業場・土地工作物の使用収用制度が2月施行後にどのような追加制約を生むか、という問いが明示されている。

JH66ではこの問いが実際に次段階へ進んだ。

- 工場事業場使用収用令・土地工作物管理使用収用令が2月1日に施行され、生産設備・土地・工作物の**利用権そのもの**が総動員上の行政命令へ接続された。
- 海運統制令は、物資だけでなく**輸送能力を誰がどの条件で利用するか**を統制対象へ加えた。
- 2月13日の米糠配給統制規則は、農業副産物の流通にも細分化された配給統制が及ぶ例となる。

したがってS10は、1939年秋の「価格・賃金・物資の取引条件」から、1940年2月の**生産設備・土地・輸送力という資産・能力の利用権**へ行政介入が広がる比較として延長する。法令列の再掲にはしない。

# 7. phase-end audit necessity judgment

独立監査は定型化しない。

候補仮説:

- 条約失効後の実務継続を「日米関係改善」と書いていないか
- 2月1日の統制令群を「この日から政府が全国の工場・土地・輸送を自由に徴用できた」と過剰一般化していないか
- 斎藤隆夫除名を「議会が完全に機能停止した日」と一本道化していないか
- 反軍演説を後の大政翼賛会成立や太平洋戦争から逆算していないか
- 南京国民政府成立を3月29日以前へ先取りしていないか
- S05/S10が年代記事の再編集になっていないか

各年代の隣接確認とpublication gateで解消済みなら独立監査不要とする。

## Judgment result — 2026-10-02

**独立phase-end auditは不要**と判定する。

- **無条約状態＝日米関係改善の読み替え:** JH66は、条約失効後も通商・外交の実務が続いたことを「共通条約を欠いたまま各国の国内法・行政措置へ依存する状態」として記述している。通商継続を関係改善や安定の証拠として扱っておらず、後の輸出規制・資産凍結・石油禁輸・開戦も別の政策判断として分離済みである。
- **2月1日統制令群の過剰一般化:** JH66は工場・事業場・土地・工作物の使用・管理・収用を「必要時に行政命令の対象にできる法的手段」と説明し、全国の工場・土地が一斉に接収された状態とは分離している。陸運統制令の公布と後年施行も分けており、追加監査を要する対象・時点混同は残っていない。
- **斎藤除名＝議会機能停止の一本道化:** JH66/JH67は代表質問、速記録削除、懲罰委員会、秘密会、除名を別の制度段階として追い、政党・帝国議会が制度上存続したこと、各政党内の異論と大量棄権があったことも本文へ置いている。制度の存続と批判的議員を保護する政治的余地を分けて説明できている。
- **反軍演説の後知恵化:** 史料読解ページは「反軍」という通称を現代的な反戦・平和主義へ置き換えず、斎藤の国家競争観、戦争目的・終結条件、汪兆銘新政府の統治能力、国民負担、内閣責任という演説内部の論理を一次史料に沿って分解している。後の政党解消・大政翼賛会・太平洋戦争を演説の意味へ逆算していない。
- **南京国民政府成立の先取り:** JH66/JH67とも3月29日までは「樹立準備」「成立直前」とし、3月30日の成立を次フェーズの制度境界としている。JH67は成立と日本政府の正式承認も別時点として明示している。
- **S05/S10と年代記事の役割重複:** JH66/JH67は1940年2〜3月の出来事と制度手続を時系列で説明する。一方S05は「参加・批判の入口」と「議院内部の制裁権限」、S10は「取引条件の統制」から「設備・土地・輸送力の利用権統制」への長期比較へ変換している。年代記事の再編集にはなっていない。

以上は隣接年代確認、史料ページの役割分離、Crosscutting publication gateで既に処理済みであり、複数ページをまとめて再監査しなければ判定できない未解決仮説は残っていない。現行規約どおり、追加の独立全体監査は置かず通常のCI / Pages / 完了処理へ進む。
