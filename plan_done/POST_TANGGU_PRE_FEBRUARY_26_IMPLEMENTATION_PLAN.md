# 1. このフェーズを1933年6月〜1936年2月25日に切る理由

1933年5月31日の塘沽停戦協定は、1931年9月から続いた満州事変の大規模な軍事行動に一つの区切りを与えた。ここから1936年2月25日まで、日中間で1937年型の全面戦争が始まっていたわけではない一方、国内政治・財政・軍縮外交・陸軍内部・華北政策には別々の緊張が蓄積した。

終点を1936年2月25日とするのは、翌26日の二・二六事件が、首相・内大臣・蔵相など政治中枢への武力襲撃、戒厳、陸軍人事と政権形成へ直接影響する明確な制度状態の変化だからである。事件そのものと鎮圧後は次フェーズへ分ける。

この期間を「軍国主義化が直線的に進んだ時期」とは書かない。1936年2月20日には男子普通選挙下の総選挙が実施されており、政党・議会・選挙の回路も依然作動していた。二・二六事件前夜までに、どの制度が残り、どの接続が弱まり、どの主体間対立が強まったかを個別に追う。

# 6. 経済・財政の主線

前フェーズの高橋財政を「積極財政で回復した」で終わらせない。

```text
1931年末 金本位制離脱
→ 財政拡張・金融緩和
→ 日銀国債引受け
→ 景気・物価の回復
→ 回復後も国債・軍事費を増やし続けるのか
→ 高橋による抑制志向と各省・軍の歳出要求
```

この段階では、恐慌から脱出するための政策と、回復後の財政規律が同じ政策ではないことを明確にする。

S02「石高制・貨幣経済・財政」は、高橋財政を「拡張」から「抑制問題」まで延長することで新しい比較軸が成立する場合だけ更新する。

S10「産業社会の負担と保護」は、景気回復が都市雇用・農村所得・企業利益へどのように異なって現れたかという比較が成立する場合だけ更新する。

# 7. 政治参加と統治の主線

1932年以後、政党総裁を首相とする慣行は中断したが、政党・議会・男子普通選挙は残った。

このフェーズでは、

```text
普通選挙
→ 衆議院議席
→ 政党の政策交渉力
→ 内閣構成・首相選定
```

を一つの回路とせず、それぞれの接続強度を追う。

1936年2月20日の総選挙を置くことで、「二・二六事件前には議会政治が消滅していた」という後知恵を避ける。

S05「政治参加の回路」は、選挙が継続しても行政権形成・軍事政策への実効性が変わるという比較軸が年代本文以上に明確になる場合だけ延長する。

# 8. 憲法解釈・言論の扱い

1935年の天皇機関説問題では、次を分ける。

- 美濃部達吉の憲法学説
- 貴族院での攻撃
- 政党・軍・国家主義団体の政治的利用
- 内務行政による出版処分
- 岡田内閣の国体明徴声明
- 明治憲法の条文そのもの
- 宮中・元老・枢密院などの反応

「天皇機関説が突然生まれた」「政府が一日で立憲主義を廃止した」とは書かない。学説として広く認知されていた状態から、政治的に排撃され政府公式見解が変更される過程を追う。

# 9. 地図候補

## A18 1935年の華北をめぐる政治・軍事空間

**Status: completed / no-map (2026-09-28)**

### 判定結果

- 空間構造自体は重要だが、今回は地図化しない
- 外務省『日本外交文書』と日中歴史共同研究により、塘沽停戦区域をめぐる交渉、通州での冀東防共自治委員会成立、北平での冀察政務委員会成立など、制度・主体・主要地点は確認できる
- 一方、1935年の同一基準時点について、塘沽停戦区域、冀東側の統治範囲、冀察政務委員会の管轄、南京国民政府の行政区、現地日本軍の実効的影響範囲を、法的地位ごとに分離して再利用できるvector geometryは確認できなかった
- 研究書・概説には面的な模式図も存在するが、公開用GeoJSONへ転用できるライセンス・一般化精度・基準時点・境界定義が揃わず、独自トレースは偽の精密さを生むため採用しない
- 現代の河北省・北京市・天津市などの境界を1935年の政治境界として代用しない
- 北平・天津・通州だけのpoint-only案も不採用とする。今回の中心問いは都市位置ではなく、**法的地位・管轄・軍事的影響が一致しない複数の空間**を区別することにあり、政治機構を所在地一点へ縮約すると説明力より誤読リスクが大きい
- JH32本文の「冀東防共自治委員会・政府」と「冀察政務委員会」の制度差、および外務省・現地軍・南京国民政府・地域勢力の主体分解の方が地図より理解を改善する

再検討条件：

- 1935年時点の停戦区域・行政管轄・冀東側統治範囲について、基準日と境界定義を明示した再利用可能な歴史GIS / vector dataが得られる
- 協定区域、行政管轄、実効支配・軍事影響を別layer・別凡例で表現できる
- 出典ライセンスと加工履歴を追跡でき、現代境界の代用や無根拠な補間を避けられる

新規MapLibre実装はないため Data / Style / Human Visual Audit は対象外。

# 14. このフェーズでしないこと

- 二・二六事件を1933年から必然だった結果として書かない
- 「軍部」を単一意思主体として使わない
- 皇道派・統制派を全陸軍将校が明確に二分されていた固定組織として扱わない
- 天皇機関説問題を単なる学説史、または単なる軍部圧力だけに縮約しない
- 華北の政治組織・協定区域を満洲国や日本領と同一視しない
- 高橋財政を「軍事費拡張」だけ、または「景気回復成功」だけで説明しない
