# 1. このフェーズを1939年9月16日〜1940年1月26日に切る理由

直前フェーズは1939年9月15日のノモンハン停戦で終えた。この時点で対ソ大規模戦闘は停止したが、中国国民政府との戦争、占領地統治、国内総動員、日米通商航海条約の終了予告、欧州戦争への不介入という課題は残った。

9月16日以後は、軍事戦線の拡大よりも、**戦争を続ける国内経済と対外関係の制度条件をどう維持するか**が前面へ出る。

1. **総動員行政の統轄強化。** 9月29日、「国家総動員法等ノ施行ノ統轄ニ関スル件」により、国家総動員法の施行をめぐる内閣総理大臣の調整権限が強化された。
2. **価格・賃金統制の包括化。** 10月18日に価格等統制令、賃金臨時措置令などが公布され、20日から施行された。価格・運賃、賃金、会社職員給与などを9月18日水準へ結びつける統制が制度化された。
3. **供給・物資統制の拡張。** 12月には小作料、貿易品目、総動員物資の使用・収用、木炭、米穀配給などへ統制が広がった。
4. **阿部内閣の中国戦争処理と対外関係。** 阿部内閣は欧州戦争への不介入を維持しつつ中国での戦争処理を優先したが、国内の物価・供給問題、対米関係、対中新中央政府構想を同時に扱う必要があった。
5. **内閣交代。** 1940年1月14日に阿部内閣が総辞職し、16日に米内光政内閣が成立した。内閣交代は中国での戦争や総動員制度を消すものではなく、既存の制約を新内閣が引き継ぐ。
6. **日米通商航海条約の失効。** 1月26日、1911年の日米通商航海条約は前年7月の終了通告どおり失効した。これにより条約上の通商関係は新しい状態へ移ったが、同日から全面禁輸や日米戦争が始まったわけではない。

したがってこのフェーズは、**ノモンハン後の「平穏化」ではなく、軍事衝突の一つが止まった一方で、国内統制と対米制度条件がより深く組み替わる時期**として扱う。

終点は1940年1月26日とする。7月26日の終了通告から半年間存続していた日米通商航海条約が実際に失効し、日米関係が「終了予告中」から「無条約状態」へ移るためである。1月27日以後は、米内内閣のもとで新しい対米・対独伊・対中政策を処理する次フェーズとする。

# 3. JH63 — 1939年9月16日〜10月17日

## 中心問い

> ノモンハンの大規模戦闘が止まっても、なぜ国内統制は緩まず、むしろ価格・賃金の包括統制へ向かったのか。

## 必須テーマ

- JH62からの接続
  - ノモンハンは停戦
  - 中国での戦争は継続
  - 阿部内閣は欧州戦争への不介入を基本とする
  - 日米通商航海条約は1940年1月26日まで効力を残す
  - 電力・石炭・米などの供給制約は継続
- 9月29日の国家総動員法施行統轄
  - 国家総動員法にもとづく個別命令が増えるなか、内閣総理大臣の統轄・調整を強める制度変更として扱う
  - 「総動員法がこの日に新しく成立した」と誤記しない
- 物価・賃金問題
  - 8月末までに物価統制実施要綱が整えられていたこと
  - 10月の包括的な価格・賃金統制へ進む背景として、供給不足・戦時需要・生活費問題を説明する
  - 9月18日は後続の価格・賃金統制で基準日として使われるが、この日だけで全価格・賃金が自動的に凍結されたように書かない
- 阿部内閣の政策状態
  - 欧州戦争への不介入
  - 中国戦争処理を優先する方針
  - 対米関係・国内経済統制・対中新中央政府構想を並行処理していること
- 10月18日の統制勅令公布直前で切る

## JH62→JH63 接続確認

JH62は「北方の大規模戦闘を停戦へ移した一方、中国戦争・欧州戦争不介入・対米関係・国内供給統制が残った」と終える。

JH63は、**軍事衝突が一つ止まっても戦争需要と供給制約は残り、行政統制が緩和ではなく包括化へ進む**ところから始める。

# 4. JH64 — 1939年10月18日〜12月31日

## 中心問い

> 国家総動員法の包括的権限は、1939年秋に企業・労働者・消費者の日常的な価格・賃金・供給条件へどう具体化したのか。

## 必須テーマ

- 10月18日公布・20日施行の統制勅令群
  - [[term:price-control-order-1939|価格等統制令]]候補
  - [[term:temporary-wage-measures-order-1939|賃金臨時措置令]]候補
  - 会社職員給与臨時措置令
  - 電力調整令
  - 軍需品工場事業場検査令
- 価格・賃金の「9月18日水準」
  - 法令上の基準・引上げ制限と、実際の市場価格・生活費・所得が完全に固定されたことを区別する
  - 闇取引・実効性などを扱う場合は、この時点の史料で確認できる範囲に限定する
- 12月の統制拡張
  - 小作料統制
  - 輸出入統制品目の追加
  - 総動員物資使用収用令
  - 木炭配給統制
  - 11月25日の米穀搗精等制限令
  - 12月27日の朝鮮米穀配給調整令は朝鮮の制度として法域を明示し、内地の米穀統制と分ける
  - 12月29日に公布され、1940年2月施行予定となる工場事業場・土地工作物の使用収用制度は「公布」と「施行」を分ける
- 企業・労働者・消費者への負担配分
  - 企業: 価格・給与・資金・物資利用の制約
  - 労働者: 賃金決定の制約
  - 家計: 電力・燃料・米など基礎物資の供給条件
  - 農村: 小作料・米穀統制
- 中国戦争・汪兆銘工作
  - 新中央政府樹立準備が続いていることは扱うが、1940年3月30日の南京国民政府成立を先取りしない
- 日米関係
  - 条約失効まで残り1か月となるが、12月時点では条約はなお有効
  - 米国側でも失効後の措置を検討していたが、すべての措置が事前に確定した計画として書かない

## JH63→JH64 接続確認

JH63は、総動員行政の統轄強化と供給・物価問題が、包括的統制の直前まで進んだ状態を扱う。

JH64は10月18日の勅令群によって、**統制の対象が政策上の計画から価格・賃金・給与・電力という日々の取引条件へ具体化する**状態を扱う。

# 5. JH65 — 1940年1月1日〜1月26日

## 中心問い

> 内閣が交代し、日米通商航海条約が失効したとき、日本の対米関係と国内政策は何が変わり、何が残ったのか。

## 必須テーマ

- 年初の阿部内閣
  - 中国戦争処理、物価・供給問題、日米条約失効への対応を抱えていたこと
  - 条約改定・暫定的な取決めの可能性がなお議論されていたこと
- 1月14日の阿部内閣総辞職
  - 一つの外交事件だけへ原因を還元せず、国内政治・中国戦争処理・経済問題を含む政権運営の行き詰まりとして史料に沿って説明する
- 1月16日の米内内閣成立
  - 海軍大将米内光政を首相とする新内閣
  - 内閣交代後も中国戦争・総動員統制・条約失効問題を引き継ぐ
- 1月26日の日米通商航海条約失効
  - 1911年条約が終了する
  - 1939年7月26日の「終了通告」と1940年1月26日の「実際の失効」を明確に分ける
  - 条約失効で米国の政策選択肢が広がる一方、同日から全面禁輸・石油禁輸・戦争状態へ移ったとは書かない
  - 失効直前にも、相互の通商上の取扱いをどうするか協議・行政対応が検討されていたことを扱う
- フェーズ末の状態
  - 米内内閣成立直後
  - 中国戦争継続
  - 国内統制継続
  - 欧州戦争継続
  - 日米関係は無条約状態へ
  - 1940年春の汪兆銘政権成立や、その後の対独伊政策は次フェーズ

## JH64→JH65 接続確認

JH64は、国内統制が日常経済へ深く入り、日米条約失効が近づいた状態までを扱う。

JH65は、**阿部内閣から米内内閣への政治的な担い手の交代**と、**日米通商航海条約の終了予告から実際の失効への制度状態の変化**を分けて説明する。

# 6. 地図方針

このフェーズでは、**現時点で独立した主題地図候補を設定しない。**

中心テーマは、
- 総動員法にもとづく権限・統制対象の拡張
- 価格・賃金・企業給与・物資・米の制度的統制
- 内閣交代
- 日米通商航海条約の失効

であり、空間分布より制度・権限・時間状態の違いが理解の中心になる。

次の場合のみ実装中にmap necessity judgmentを新設する。

- 1939年末の長江航行・外国権益など、地理を見ないと外交上の権限差が理解しにくい論点が本文の中心へ入る
- 全国統制の地域差について、同時点・同定義・再配布可能なデータが得られ、地図が本文理解を実際に改善する
- 1940年1月時点の対米通商構造について、地域・港・輸送経路そのものが中心問いになる

単に「全国で統制された」ことを示すために日本列島を一色で塗る地図は作らない。

# 7. Crosscutting publication gate

JH63〜JH65を実装した後、既存横断記事へ新しい比較軸が加わる場合だけ延長する。

## S10「産業社会の負担と保護」

最有力候補。

- 職業能力把握・雇入れ制限・徴用から、価格・賃金・給与・電力・燃料・米へ統制対象が広がる
- 「誰が働くか」だけでなく、「いくらで売買するか」「いくら賃金を払うか」「どの物資を使えるか」へ選択条件が広がる
- JH64の法令列を再掲せず、負担・選択制約の種類がどう増えたかを比較軸にする

## S05「政治参加の回路」

候補。

- 阿部内閣の退陣と米内内閣成立
- 総動員法施行をめぐる内閣総理大臣の統轄強化
- 政党・議会・行政命令・内閣の政策回路の距離

既存S05に新しい権限比較が加わる場合だけ延長し、単なる内閣交代史にはしない。

## S09「対外支配の制度差」

原則保留。

汪兆銘を中心とする新中央政府はこのフェーズでは準備段階であり、1940年3月30日の南京国民政府成立前に制度完成を先取りしない。既存政権統合の制度差が実際に変わったと確認できる場合だけ延長する。

## S02「石高制・貨幣経済・財政」

原則保留。

価格・賃金・配給統制は重要だが、それだけでは新しい財政・租税・公債・通貨制度の比較軸にならない。新しい国家財政の調達・会計制度が確認できた場合だけ延長する。

## 新規横断記事

原則追加しない。

「統制経済」「日米開戦への道」を新規記事化すると、S10や年代記事との重複、または1941年の結果から1939〜40年を逆算する危険がある。既存記事で扱えない独立比較軸が確認できた場合だけ別計画で検討する。

# 8. phase-end audit necessity judgment

フェーズ末の独立監査を定型的には置かない。

候補仮説:

- 価格等統制令・賃金臨時措置令の成立を「国民生活が一日で完全統制された」と書いていないか
- 9月18日基準を、9月18日に全国の価格・賃金が自動凍結された出来事として逆算していないか
- 日米通商航海条約失効を、石油禁輸・資産凍結・日米開戦と同一の出来事へ圧縮していないか
- 阿部内閣退陣→米内内閣成立を、対独伊・対米政策が全面的に反転したと単純化していないか
- 汪兆銘新中央政府の準備を、1940年3月の政権成立へ一本道で書いていないか
- S10延長がJH64の法令列を再掲するだけになっていないか

各年代の隣接確認、Crosscutting publication gate、content validationで解消済みなら独立監査不要と判定する。

# 12. このフェーズでしないこと

- ノモンハン停戦を、対ソ政策全体の最終確定や「南進決定」として扱わない
- 欧州戦争不介入を、対独伊関係の消滅や米英との協調確定と同一視しない
- 価格等統制令・賃金臨時措置令の法令成立だけから、実際の全価格・全賃金が完全に固定されたと断定しない
- 9月18日という基準日を、その日に包括統制が公布・施行された日と誤認しない
- 国民徴用・賃金統制・配給統制を、対象・根拠条文・施行時期を区別せず一つの「統制経済」に潰さない
- 1940年1月26日の条約失効を、同日の全面禁輸・石油禁輸・資産凍結・開戦と同一視しない
- 米国側の内部検討文書を、確定済みの対日行動計画として扱わない
- 阿部内閣から米内内閣への交代を、対中戦争や国内総動員の全面的な政策転換とみなさない
- 汪兆銘新中央政府の準備を、1940年3月30日の政権成立を既定の結果として記述しない
- 制度が全国適用であることだけを理由に、意味の薄い日本列島一色塗りの地図を作らない
- フェーズ末に理由のない全体監査を追加しない
