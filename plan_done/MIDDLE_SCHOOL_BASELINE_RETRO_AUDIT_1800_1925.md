# 中学歴史前提 遡及監査 — 1800–1925

Status: completed

## 目的

公開本文の前提知識を「高校日本史を既習」から「中学校の歴史教科書を読んだ程度」へ変更する。

ただし、内容の到達点、史実の精度、制度差、因果分析、大学入試論述にも利用できる構造化は下げない。難しい内容を削るのではなく、初見読者が現在の分析水準まで登れる説明の階段を追加する。

## 監査基準

- 高校日本史で詳しく扱う制度・役職・政治勢力・法令・条約・金融用語は、初出時に「何をする仕組み／主体か」を短く説明する
- 人物名には、その場の因果理解に必要な役割を添える
- 事件名・制度名を知識の圧縮記号として使わず、「何が起き、何が変わったか」を本文で読めるようにする
- 用語リンクを開かなくても主文の因果を追えるようにする
- summary / snapshot / changes / framingQuestion も本文と同じ前提知識で読むことができるようにする
- 易しくするために制度差・地域差・不確実性・論争点を削らない
- 一文で足りる基礎説明に長い入門講座を挿入せず、本文の主線を保つ

正本は `standards/CONTENT_AUTHORING_STANDARD.md` 3.2 とした。

## 今後の運用

1926年以後は、この基準を各年代ページの通常DoDへ含める。

新ページでは、
1. 中学歴史レベルから読める入口を置く
2. 高校日本史レベルの固有名詞を機能説明へ展開する
3. その上で従来どおり制度・権限・負担・市場・国際関係の分析まで進む

という順序を標準とする。

この監査を毎フェーズの独立工程として反復しない。具体的な再発兆候がある場合のみ横断監査を行う。
