## 1. 中心問いと観測軸

**中心問い：** 日本政府と軍中央は、ビルマなど占領地域の将来の帰属や独立をどう位置づけ、現地の軍事上の支配と行政・経済活動をどのように組み合わせようとしたか。国内では、統制会への行政官庁職権の委譲が産業行政の担当者をどう変えたか。ガダルカナル撤退の実施後、陸海軍の作戦・対独伊協力・世界情勢判断はどのように再検討され、船腹・資源・工場・食糧・住民生活にはどの制約が残ったか。

政治史を背骨として**社会状態を同時に観測する**。各記事では、該当する変化がある軸を優先し、①内閣・大本営政府連絡会議・省庁・軍中央の決定、②ビルマ・中国・南方占領地で誰が行政・治安・生産を担うか、③海軍・陸軍・民需の船腹と港・燃料・前線補給、④鉄鋼・石炭・アルミニウム・造船・航空機と金融・労務の配分、⑤日本国内と占領地住民の食糧・移動・雇用・営業の条件を接続する。

決定・腹案・官報公布・法令施行・会合での協議・派遣命令・現場での実施を分ける。**1月14日の独立施策はビルマの即時独立ではない。1月21日の公布は2月1日の職権委譲令施行ではない。12月31日の撤退決定は2月の撤収実施でも2月9日の公表でもない。** これらの違いは本文の具体説明で示し、同じ留保を繰り返さない。

## 2. phase cutの根拠と比較すべき状態

1. **1月14日 — ビルマ独立施策と占領地帰属腹案。** 大本営政府連絡会議の「大東亜戦争完遂ノ為ノ緬甸独立施策ニ関スル件」と「占領地帰属腹案」が占領地域ごとの将来の政治的地位を検討した。ビルマの独立準備と、日本が直接領有・支配する地域等を検討する腹案を区別する。中国の南京政府との1月9日協定と一括して「占領地が独立した」としない。日本側の戦争目的・軍事指揮・物資調達と、現地の住民・政治指導者の利害を具体化する。防衛研究所『戦史叢書』第103巻の所収政策文書・JACAR年表、JACAR Ref.C12120153600をアンカーとする。
2. **1月21日公布／2月1日施行 — 行政官庁職権委譲令（昭和18年勅令第26号）。** 1942年11月17日の方針に続いて、商工行政などにおける許認可・報告・監督等の一部を統制会等の産業団体へ委ねる法的仕組みが定められた。鉄鋼・石炭・鉱業・セメントなど委譲対象と例外・大臣の関与を条文ごとに確認する。全行政権の民間移管、官庁の消滅、即日の増産という説明はしない。官報公布日と施行日を分けてJH161→JH162へ接続する。
3. **2月1・4・7日撤収／2月9日公表 — ガダルカナルからの撤退。** 1942年12月31日の日本軍の正式決定が、第17軍残存部隊の夜間収容へ移った。撤収が完了した後に国内向けの「転進」発表がなされた。救出できた兵員、失われた補給能力、夜間に動かす艦艇・燃料・護衛と、発表の情報上の性格を分ける。撤退によって直ちに国内の輸送制約が解消したと書かない。
4. **2月20日を中心とする対独伊調整。** 大本営政府連絡会議は独伊への連絡使に与える訓令を決め、2月26日には対米英戦争に関する三国協力強化策を議論した。日本側の訓令・協議と、ドイツ・イタリアの同意、実際の軍事資源の移動・作戦共同化を分離する。独ソ戦下の情勢認識と日ソ中立条約に関する判断は同時代の情報・制約に限って扱う。
5. **2月27日 — 「世界情勢判断」。** 政府・軍中央が海外戦局の見通しを再検討し、対米英戦争・対独伊関係と作戦・物的国力の調整を続けた。史料の表現と採択形式を本文作成前に原記録と照合する。ガダルカナル撤退が世界戦局認識へ持った意味を、後世からの必然的敗北認識として先取りしない。
6. **3月10日 — 「緬甸独立指導要綱」。** 1月14日に決めたビルマ独立施策を、現地指導や軍事・外交・経済上の取決めに接続する段階。実際の独立宣言と政府発足は後の時点であり、ここでは日本の政策・準備と現地に残る軍事・経済的な権限・負担を扱う。3月12日の商工経済会法公布も、国内の産業組織との関係を確認する補助候補とする（施行・実務の時点差を要照合）。
7. **3月18日 — 次フェーズへの入口。** 戦時行政特例法等が首相による戦時行政の指揮・調整と重要産業への対応を改める局面。2月1日の統制会への職権委譲と役割・法的構成が異なるため、前日の3月17日で本フェーズを閉じる。

## 4. 隣接接続・執筆・採用判定のゲート

- **JH159→JH160：** JH159で成立した南京政府との共同宣言・租界還付協定は中国における政府間の合意。1月14日には、ビルマや他の占領地の帰属・独立について日本の政府・軍中央が別個に方針を決める。前記事の制度説明は1〜2文に圧縮し、新記事で地域ごとの政策・主体・現場権限の差へ入る。JH159の租界引渡し未完了、対重慶戦争、ガダルカナル撤収準備、海運・五重点産業・家庭の負担を突然消さない。
- **JH160→JH161：** 南方占領地の帰属方針から、国内の統制会への行政職権委譲を扱う。対外支配の独立施策と国内産業団体への行政権限委譲を同じ「独立」「自治」と形容しない。地域別の軍政と輸送・生活制約は継続状態として短く接続。
- **JH161→JH162：** 1月21日の公布から2月1日の法令施行へ移る。委譲された行政行為と従来の大臣・官庁に残る職権を確認。ガダルカナルでは1942年末の撤退決定と準備から2月の実際の艦艇収容へ移り、日程や戦果を戦後の結果から逆算しない。
- **JH162→JH163：** 2月9日の国内公表から、撤収後も続く対米英作戦・日独伊連絡・生産輸送上の制約へ焦点を移す。「転進」という公表上の語と軍事上の作戦目的変更を峻別する。撤収成功を他方面での自由な兵力運用・船腹回復と同一視しない。
- **JH163→JH164：** 2月20・26日の同盟国との連絡方針・協議から、2月27日の世界情勢判断と3月10日のビルマ独立指導方針へ移る。内外の議論・決定と現地実行・民衆の生活状態が別の速度で変わることを示す。
- **JH164→次期：** 3月18日の戦時行政特例による首相権限等の変更を別フェーズで扱い、1月の産業団体への個別職権委譲と比較する。3月10日決定のビルマ政策を同日独立実現とせず、次の実行状況を継続観測する。
- **政治史と生活の均衡：** 官制や法令の説明だけで一ページを満たさない。中国・ビルマ・南方の現地住民の労務・生産・治安、日本国内の工場・炭鉱・農村・都市家庭の配給・取引・輸送を、確かな当期変化がある場合は差分、そうでなければ簡潔な持続状態として述べる。未確認の全国一律改定、即時増産、独立と生活改善の同一視を避ける。
- **資料・図版・用語：** 重要用語は全体辞書IDを再利用し、初出の制度は役割を本文で説明する。各記事公開前に官報・議事録・地図・写真・現地行政文書を史料図版候補として検討し、権利・時点・出典が整わない場合は理由付きnoImageを記録。前期間からの連続noImage警告への対応は本当に必要な史料図版かを基準にする。
- **主題地図：** JH160/JH164のビルマ独立・南方占領地帰属では地域別政策の空間差が主題化する余地がある。現代の境界を旧領有権に投影せず、史料の時点・法的性格（腹案・軍政・独立予定）を確認したうえで地図要否を各記事実装時に判定する。A49/A50はガダルカナルで再利用を優先。新地図はData/Style/Human Visual Auditを通過しない限りpublishedとしない。
- **横断記事 publication gate：** JH160〜164成立後、S09「占領統治」の地域別の軍政／独立政策の比較軸が増えたか、S10「戦時統制と資源配分」の11月方針→1月公布→2月施行による職権移転が既存の中心問いを実質的に変えるかを判定する。S05「政治参加」は選挙・議会・代表・政策参加の実際の変化が確認できた場合だけ再判定する。中国の外交協定、ビルマの政策、統制会の国内法令を一つの曖昧な「自治」史へ統合しない。新規横断記事は年代史・既存横断記事と異なる比較軸を立証できる場合のみ追加。
- **検証とアーカイブ：** 各記事で前記事との隣接接続、出典、本文、用語、図版・地図判定を完了してpublishedにする。通常は npm run check → PR CI → merge → main CI → 公開変更時Pages success。フェーズ末独立監査は複数ページ／横断記事にまたがる固有の未解決監査仮説があるときに限る。完了後にStatusをcompletedとしてplan_doneへ一意に移動する。
