# 1. このフェーズを1938年1月17日〜5月19日に切る理由

直前フェーズは、1938年1月16日の第一次近衛声明で終えた。

この時点で日本政府は国民政府との公式な和平交渉を打ち切り、日本側が支援する別の中国側政治主体を育成する方向へ政策の重心を移した。一方、中国国民政府とその軍は存続しており、戦争そのものは終わっていない。

1月17日以後は、少なくとも三つの問題が並行する。

1. **占領地をどの政治機構で統治するか。** 1937年12月の華北・中華民国臨時政府に続き、1938年3月28日には南京で中華民国維新政府が成立する。
2. **長期化する戦争へ国内制度をどう対応させるか。** 国家総動員法案は2月19日に政府から第73回帝国議会へ提出され、審議を経て3月24日に成立、4月1日に公布、5月5日に施行される。
3. **軍事作戦をどこまで拡大するか。** 南京占領後の陸軍中央には当面の戦面不拡大方針があったが、現地軍の作戦要求と戦況の変化を受けて徐州作戦が実施され、5月19日に日本軍が徐州を占領する。

したがって、この期間を

```text
1月16日 第一次近衛声明
→ 国民政府との公式和平回路を閉じた後の戦争処理が課題化
→ 占領地新政権工作と国内総動員法制の準備が進む
→ 2月19日 国家総動員法案提出
→ 2月24日 衆議院本会議で本格審議開始
→ 3月24日 法案成立
→ 3月28日 南京で中華民国維新政府成立
→ 4月1日 国家総動員法公布
→ 4月初旬 徐州作戦へ
→ 5月5日 国家総動員法施行
→ 5月19日 徐州占領
```

という、**外交回路の閉鎖後に、政治・国内動員・軍事作戦の三方向で長期戦の制度が具体化する期間**として扱う。

5月19日を終点にするのは、徐州という要地の占領が軍事的な区切りになる一方、中国軍主力の包囲・殲滅という目的は達成されず、その後に武漢・広東方面へさらに作戦を広げるかが改めて政策問題になるためである。

5月20日以後の近衛内閣改造、五相会議、武漢攻略決定、黄河決壊、武漢・広東攻略などは次フェーズへ送る。

# 3. JH48 — 1938年1月17日〜2月23日

## 中心問い

> 国民政府との公式な和平交渉を打ち切った後、日本政府と軍は、戦争を終える代わりに何を整えようとしたのか。

## 必須テーマ

- 1月16日の第一次近衛声明直後に残った未解決問題
  - 中国国民政府と中国軍は存続
  - 占領地域の治安・行政
  - 新政権工作
  - 戦費・物資・労務の長期確保
- 新政権工作を、声明を出しただけで中国の政治秩序を置き換えられたかのように書かない
- 1937年12月成立の中華民国臨時政府と、その後の華中側の政権工作
- 陸軍中央が南京占領後に当面の戦面不拡大を志向したこと
- 現地軍と陸軍中央の作戦要求が必ずしも一致しなかったこと
- 国家総動員法案の準備と2月19日の政府提出
- 国家総動員法を「戦争が始まったので突然生まれた制度」とせず、1937年の臨時資金調整・輸出入統制・軍需工業動員法適用などとの接続を示す
- ただし1938年法成立前に、政府が同法の全権限を既に持っていたかのように先取りしない
- 帝国議会が存続し、法案が議会審議を必要とした制度状態を明示する

## JH47→JH48 接続確認

JH47は、国民政府との公式な和平回路を閉じ、新政権工作・占領統治・追加軍事作戦・戦費・物資が同時に残るところで終わる。

JH48は、その未解決問題が「別の中国側政治主体を育てる」「国内の動員制度を広げる」「軍事作戦の拡大を抑える／進める」という別々の政策回路へ分かれて具体化するところから始める。

# 4. JH49 — 1938年2月24日〜3月31日

## 中心問い

> 長期戦に必要な人員・物資を政府が広く統制できるようにする国家総動員法は、帝国議会のどのような審議を経て成立し、同じ時期の占領地政治工作とどう並行したのか。

## 必須テーマ

- 2月24日の衆議院本会議での国家総動員法案第一読会
- 法案が「戦時（戦争に準ずる事変を含む）」の人的・物的資源を統制運用する枠組みを定義したこと
- 政府へ命令制定を広く委ねる構造と、議会側で権限範囲・立法権との関係が争点になったこと
- 2月末〜3月の委員会審議
- 有名な個別発言や議場騒動だけを、法案成立の全説明にしない
- 3月24日の法案成立
- 成立と施行を区別する。3月24日に社会全体が総動員状態へ一斉に切り替わったとは書かない
- 3月28日の南京・中華民国維新政府成立
- 中華民国維新政府を中国国民政府の消滅や中国全土の新中央政府成立と同一視しない
- 1937年12月の華北・中華民国臨時政府との関係
- 「占領地に中国側政府形式を置く」という共通点だけで両政府を同一制度として扱わず、地域・組織・権限を確認する
- 国内の総動員法制と占領地政権工作を、一つの中央集権化政策として因果直結させない。並行する戦争処理の制度化として位置づける

## JH48→JH49 接続確認

JH48は、総動員法案が政府提出され、長期戦への制度整備が議会審議へ入る直前で終える。

JH49は、政府案が議会という既存の立法回路で審議される段階から始め、成立した法律の権限構造と、同時期に占領地で進む新政権工作を分けて追う。

# 5. JH50 — 1938年4月1日〜5月19日

## 中心問い

> 国内では国家総動員法が公布・施行される一方、軍事面ではなぜ「戦面を広げない」方針から徐州作戦へ移り、徐州を占領しても戦争を終えられなかったのか。

## 必須テーマ

- 4月1日の国家総動員法公布
- 5月5日の施行
- 法律が人的・物的資源の統制について政府へ広い命令権限を与えたこと
- 法の公布・施行と、個別の統制命令が現実に適用される時期を区別する
- 1937年の個別統制法制と1938年の包括的な総動員法制の差
- 台湾・朝鮮・樺太への適用は、内地と同一制度が自動的に同日に適用されたと書かず、施行関係法令を確認する
- 1938年春の陸軍中央の戦面不拡大方針
- 北支那方面軍など現地側の徐州作戦要求
- 台児荘方面の戦況を、徐州作戦を自動的に決定した一事件として単純化しない
- 4月初旬の徐州作戦発動
- 徐州が交通・軍事上の結節点だったこと
- 5月19日の徐州占領
- 中国軍主力が包囲完成前に退却し、日本側の主力包囲・殲滅という目的が達成されなかったこと
- 徐州占領を中国側の降伏や華中・華北戦線の終結と同一視しない
- 5月19日時点で、次の作戦拡大、占領地維持、総動員制度の実装が同時に残ったこと

## JH49→JH50 接続確認

JH49は国家総動員法案が成立し、中華民国維新政府が成立したが、法律はまだ公布・施行前、占領地政治機構も中国全土の政治的決着にはなっていないところで終える。

JH50は4月1日の公布から始め、国内制度が施行へ進む過程と、軍事面で不拡大方針が徐州作戦へ転じる過程を並行して追う。

# 6. A25 — 徐州・津浦／隴海鉄道の作戦空間

**Status: completed / 2026-09-29**

## map necessity 判定

**採用 / high。**

JH50で説明する徐州の軍事的重要性は、都市名そのものより、**華北と華中を結ぶ南北交通軸と、河南方面へ延びる東西交通軸が徐州で交差すること**にある。

本文だけでも「津浦鉄道と隴海鉄道の交点」と説明できるが、

- 済南—徐州—浦口／南京方面が南北方向に並ぶこと
- 海州—徐州—開封・鄭州方面が東西方向に延びること
- 台児荘が徐州北東側の作戦空間に位置すること
- 徐州占領が「中国全体の中枢を取る」ことではなく、交通結節点を押さえる作戦だったこと

は、地図の方が短時間で把握できる。

したがってA25は、**徐州作戦の戦闘経過図ではなく、徐州が作戦目標になった交通地理を示す地図**として採用する。

## Data Audit 判定

**pass。ただし「主要地点point＋津浦／隴海鉄道のapproximate LineString」を上限とする。前線・包囲線・進撃矢印は実装しない。**

### 1. 徐州作戦の軍事史料

防衛研究所の戦史叢書第89巻『支那事変陸軍作戦〈2〉昭和十四年九月まで』は、第二章「不拡大方針の破綻と徐州会戦」で作戦計画・経過を扱い、付図「徐州会戦経過概要図」を持つ。

- source: https://www.nids.mod.go.jp/military_history_search/SoshoView?kanno=089
- 利用方針: 徐州会戦の作戦範囲、主要地点、交通軸、作戦段階の照合に使う
- 付図の部隊位置・進撃線・包囲線をそのままGISへトレースしない
- 日本側戦史のみから中国軍の正確な全配置・退却経路を確定しない

戸部良一「日中戦争の拡大と日本陸軍 1937年7月〜1938年10月」は、2月の戦面不拡大方針から現地軍の要求を受けて徐州作戦を認可する過程と、徐州占領後も中国軍主力を捕捉できなかったことを整理している。

- source: https://www.nids.mod.go.jp/event/proceedings/forum/pdf/2019/02_tobe.pdf
- 利用方針: 地図のhistoricalQuestionを「都市攻略」ではなく「交通結節点と会戦機会」に置く根拠として使う
- 論文本文から日付別の部隊線を推定して描かない

### 2. 1930年代中国鉄道の歴史GIS

中央研究院「近代歴史地理資訊平台（MHGIS）鉄路」には、1865〜1970年を対象とする鉄道路線のvector情報があり、路線図・地形図・同時代地図を参照して作成されたことが明示されている。

- source: https://mhdb.mh.sinica.edu.tw/MHGIS/railway/
- provider: 中央研究院近代史研究所／人社中心GIS專題中心
- temporal coverage: 1865–1970
- 利用方針: 津浦鉄道・隴海鉄道の歴史的線形、主要駅・結節関係のクロスチェックに使う
- 同サイト自身が駅の増減は完全には再現していないと説明しているため、駅一覧の完全性を前提にしない

同プラットフォームの説明では、確実な路線図がある場合はそれを参照し、ない場合は初期地形図を参照して鉄道路線を描いている。A25のように「1938年に存在した交通軸」を確認する用途には適合する。

ただし、MHGISサイトの公開説明だけでは、**そのvectorデータを本リポジトリへコピーして再配布できるライセンス条件までは確認できない**。したがって、実装時にMHGIS geometryを直接取り込む場合は再配布条件を別途確認する。現段階では、歴史線形の検証・control sourceとして扱う。

### 3. 同時代鉄道図

中央研究院GIS專題中心の「鐵路歷史地圖 WMTS」には、次の歴史鉄道図が公開されている。

- 「津浦全路平面圖」
- 「津浦鐵路全圖」
- 「1933 中華民國鐵路全圖」
- source: https://gis.sinica.edu.tw/railroad/

これらはgeoreferenced rasterとして、津浦鉄道の全体線形と1930年代前半の全国鉄道網を確認する補助史料として有用である。

- 利用方針: 津浦・隴海の経由地域、交点、主要都市の位置関係をクロスチェックする
- WMTS画像をサイトへ複製して再配布しない
- rasterを精密にトレースして「測量済み中心線」のようなLineStringを作らない

Library of Congress所蔵の1931年中国全図は、同館Geography and Map Divisionのdigitized collectionとして、権利注記がない限りfree to use and reuseと明示されている。

- source: https://www.loc.gov/item/2016587371/
- publication: 1931
- 利用方針: 1930年代初頭の中国鉄道・主要都市の広域関係を、再利用条件が明確な別資料としてクロスチェックする
- A25の鉄道路線geometryをこの一枚だけから精密復元しない

### 4. geometry の上限

A25で公開可能なgeometryは次に限定する。

| 対象 | geometry | confidence | 用途 |
|---|---|---|---|
| 徐州 | representative Point | derived | 津浦・隴海鉄道の交点 |
| 台児荘 | representative / approximate Point | derived / approximate | 徐州北東側の主要戦闘地点 |
| 済南 | representative Point | derived | 津浦鉄道北側の主要都市 |
| 浦口／南京 | representative Point | derived | 津浦鉄道南側・華中側の位置参照 |
| 海州 | representative Point | derived | 隴海鉄道東端側の位置参照 |
| 開封 | representative Point | derived | 隴海鉄道西方の主要都市 |
| 鄭州 | representative Point | derived | さらに西方の鉄道結節点 |
| 津浦鉄道 | generalized LineString | approximate / derived | 南北交通軸 |
| 隴海鉄道 | generalized LineString | approximate / derived | 東西交通軸 |

鉄道路線は、同時代鉄道図・MHGISの歴史線形を複数箇所で照合し、主要経由地点を持つgeneralized lineとして作る。**主要都市同士を数本の直線だけで結んだ線にはしない。**

geometryConfidenceは、正確な歴史測量線形を再配布するものではないため、原則として approximate とする。control pointと変換手順をprovenanceへ記録する。

### 5. 描かないgeometry

A25では次を描かない。

- 日本軍・中国軍の精密な進撃路
- 日付別前線
- 包囲線
- 師団・軍団の配置polygon
- 中国軍主力の退却路
- 台児荘戦の局地的戦線
- 現代中国鉄道の線形を1938年の津浦・隴海鉄道として無注記で流用したLineString
- 現代行政界を1938年の政治境界として使うpolygon

A25のhistoricalQuestionは「どの部隊がどの道を進んだか」ではなく、**徐州が二つの幹線鉄道の交点であり、華北・華中と内陸をつなぐ位置にあったこと**である。作戦線を追加すると、史料精度の問題に対して説明価値の増加が小さい。

## 実装時のaudit条件

A25はLineStringを含むため、point-only再利用規則は使えない。

実装する場合は、

1. 津浦・隴海鉄道の主要control pointを同時代鉄道図とMHGISで照合
2. generalized lineの生成手順をprovenanceへ記録
3. 1938年までに開通済みの区間だけを表示
4. geometryConfidenceをapproximate / derivedとして明示
5. Data Audit
6. Style Audit
7. Desktop / Tablet / Touch / Mobileを含むHuman Visual Audit
8. 背景地図は現在の位置参照であり、1938年の行政界・道路網ではないことを公開注記

を通す。

鉄道2路線は色だけでなく線種・ラベルでも識別し、徐州の「交点」を視覚的に読み取れることをHuman Visual Auditで確認する。

## 判定結果

**A25は地図あり。データ品質は「主要地点point＋歴史資料から一般化した津浦／隴海鉄道LineString」なら実装可能。**

歴史GISと1930年代の鉄道図により、二つの鉄道の存在・交点・主要経由地を十分に照合できる。一方、徐州会戦の部隊移動・包囲線を公開GISとして精密に復元する必要性もデータ品質もない。

したがってA25は、**「徐州の交通結節性は線で地図化する／作戦経過は線で地図化しない」**という境界で採用する。

## S05「政治参加の回路」

**publication gate候補。**

国家総動員法は、帝国議会で審議・成立した一方、成立後の具体的統制の多くを政府命令へ委ねる構造を持つ。

「議会が法を成立させる回路」と「成立後に政府が命令で統制を具体化する回路」の距離を、S05の長期比較軸として説明できる場合は延長する。

## S09「対外支配の制度差」

**publication gate候補。**

3月28日の中華民国維新政府は、1937年12月の中華民国臨時政府と並ぶ新たな占領地政治機構である。

華北と華中で異なる政府形式が置かれ、日本軍・日本政府との権限関係や将来統合の構想を比較できる場合は延長する。

## S10「産業社会の負担と保護」

**publication gate候補。**

国家総動員法が、労務・物資・生産・配給などについて政府が統制命令を出せる包括的枠組みを作ったことで、1937年の資金・輸出入統制から比較軸が更新される可能性が高い。

ただし法律の条文を列挙するだけにせず、具体的な統制命令が社会へどう及ぶかは施行時期を確認して延長範囲を決める。

## S02「石高制・貨幣経済・財政」

**publication gateで再判定。**

国家総動員法それ自体は財政制度ではない。支那事変特別税、軍事費、公債その他の財政措置が既存S02の比較軸を更新する場合だけ延長する。

## 新規候補「戦時動員体制」

1937年の臨時資金調整・輸出入統制・軍需工業動員法適用から、1938年国家総動員法の包括的枠組みへ移る制度変化は、新規横断記事になり得る。

ただし、
- S02の戦費・会計
- S05の議会・権限
- S10の民間資金・物資・労務への負担

を再編集するだけなら作らない。

**「国家が別々の省庁・法令で扱っていた資金・物資・労務を、戦時の人的・物的資源として横断的に統制する制度へどう組み替えたか」**という独立した中心問いが成立する場合だけpublication gateを通す。

# 11. このフェーズでしないこと

- 1月16日の第一次近衛声明を、その後の軍事拡大を自動決定した命令として扱わない
- 「和平打ち切り＝直ちに全面的な作戦拡大」と書かない
- 国家総動員法を、1937年以前に存在しなかった統制の突然の出現として書かない
- 逆に1937年の個別統制法制と1938年国家総動員法を同一制度として扱わない
- 国家総動員法の成立・公布・施行・個別命令発動を同じ時点として扱わない
- 帝国議会が存在しなかった、または法案審議が無意味だったと結果から逆算しない
- 中華民国維新政府の自己正当化文言をサイト側の評価語として使わない
- 中華民国臨時政府と維新政府を「傀儡政権」の一語だけで制度差なく処理しない
- 陸軍中央・北支那方面軍・中支那方面の部隊を「日本軍」の一意思に畳み込まない
- 徐州作戦を台児荘の戦闘一件の必然的結果として書かない
- 徐州占領を中国軍の壊滅・国民政府の降伏と同一視しない
- 5月20日以後の内閣改造、五相会議、武漢・広東攻略、黄河決壊をJH50へ先取りしない
- 同時代の作戦図・鉄道図を根拠なく精密GISへ変換しない
- フェーズ末に理由のない全体監査を追加しない
