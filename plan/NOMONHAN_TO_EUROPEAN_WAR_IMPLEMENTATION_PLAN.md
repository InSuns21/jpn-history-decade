# 1. このフェーズを1939年5月11日〜9月15日に切る理由

直前フェーズは1939年5月10日で終えた。中国国民政府との戦争、汪兆銘工作、占領地統治、国家総動員法にもとづく人的・物的統制、対独伊協定強化交渉が同時進行するなか、翌5月11日に満蒙国境で交戦が始まり、ノモンハン事件へ発展した。

アジア歴史資料センターは、5月11日の満洲国軍・モンゴル人民共和国軍の交戦を端緒として日ソ両軍の軍事衝突へ拡大し、9月15日の停戦協定で終結したと整理している。

- source: https://www.jacar.go.jp/learning/term.html?uid=Y50C200081
- 利用方針: 事件の開始・終結と、関東軍・日本政府／大本営の方針差を確認する
- 「事件」という名称から小規模な偶発衝突と誤読させず、長期の大規模戦闘へ拡大したことを本文で説明する

この期間には、ノモンハンだけでなく、日本の政策選択を変える複数の外部制約がほぼ同時に加わる。

1. **対ソ国境戦の拡大。** ノモンハンでは局地的な国境紛争から大規模な地上・航空戦へ拡大し、8月20日以後のソ連・モンゴル側攻勢で日本軍は大きな損害を受けた。
2. **天津租界をめぐる対英対立。** 6月14日、日本軍は天津のイギリス・フランス租界を封鎖し、占領下の華北に残る外国権益と日本軍の軍事・治安要求が直接衝突した。
3. **国内総動員の一段の具体化。** 7月8日に国民徴用令が公布され、国家総動員法にもとづく人的資源統制は、職業能力の把握や雇入れ制限から、必要な労務を国家が徴用できる制度へ広がった。
4. **日米関係の制度的な悪化。** 7月26日、米国政府は1911年の日米通商航海条約を6か月後に終了させる旨を日本政府へ通告した。これは直ちに石油禁輸を意味しないが、既存条約が将来の対日経済措置を制約していた条件を外す方向へ進む重要な制度変化だった。
5. **欧州外交の前提崩壊。** 8月23日に独ソ不可侵条約が成立し、日本政府が進めていた防共協定強化・対独伊連携の前提が崩れた。平沼内閣は8月28日に総辞職し、8月30日に阿部内閣が成立した。
6. **欧州戦争開始とノモンハン停戦。** 9月1日にドイツがポーランドへ侵攻して欧州戦争が始まるなか、大本営はノモンハン作戦停止へ動き、9月15日に停戦協定が成立した。

したがってこのフェーズは、単に「ノモンハン事件を扱う期間」ではなく、**中国での長期戦を維持する日本に、対ソ戦・対英摩擦・対米条約関係の変化・欧州同盟環境の崩壊が重なり、1939年夏までの外交・軍事前提が短期間で再編される時期**として扱う。

終点は1939年9月15日とする。ノモンハン停戦協定の成立により、5月以来の対ソ武力衝突は一つの区切りに達する。一方、欧州戦争はすでに始まり、阿部内閣は新しい国際環境の下で対中戦争・対米英関係・国内統制を処理する必要が残るため、9月16日以後を次フェーズとする。

# 3. JH59 — 1939年5月11日〜6月13日

## 中心問い

> 中国で長期戦を続けていた日本に、なぜ満蒙国境の局地衝突が別の大規模軍事制約として加わったのか。

## 必須テーマ

- JH58からの接続
  - 中国国民政府は抗戦を継続
  - 汪兆銘工作・占領地統治・国内総動員・対独伊交渉が未完了
  - その状態へ対ソ国境戦が追加される
- 5月11日の満蒙国境での交戦
  - 満洲国とモンゴル人民共和国の国境線認識の差
  - 満洲国軍・関東軍・モンゴル軍・ソ連軍という主体を区別する
  - 日本とソ連の正式な宣戦布告を伴う国家間全面戦争として扱わない一方、実際の戦闘規模を「小事件」に縮小しない
- 5月下旬の戦闘拡大
  - 現地での増援と戦闘の反復
  - 関東軍の現地判断と、大本営・政府が中国戦線との資源配分を考える立場の差
- 国境線そのものが争点だったこと
  - 後世の確定国境を1939年の共有前提として投影しない
  - 地図を使う場合は双方の主張線・地形・戦闘地点を区別する
- 天津租界問題の緊張
  - 4月の暗殺事件後、犯人引渡しをめぐる日本軍と英側の対立が6月まで未解決だったこと
  - 6月14日の封鎖開始直前までを扱う

## JH58→JH59 接続確認

JH58は、中国戦線・占領統治・国内統制・対独伊外交を同時に抱えた状態のまま5月10日で終わる。

JH59は、その翌日に満蒙国境で新たな武力衝突が始まり、日本の軍事資源と政策調整に「対ソ国境」という別方向の制約が加わるところから始める。

# 4. A29 — ノモンハンの国境主張・ハルハ河・戦闘空間

**Status: planned / map necessity・data-quality judgment を JH59 実装後に実施**

## map necessity 候補

**高い。**

ノモンハン事件では、国境線の認識差、ハルハ河、ノモンハン周辺の地形、兵站距離が事件の理解そのものに関わる。地点名だけの本文では、「どの線を国境とみなし、どの河川・草原を越えて戦闘が展開したか」が把握しにくい。

防衛研究所が公開する『戦史叢書 第027巻 関東軍〈1〉対ソ戦・ノモンハン事件』には、ノモンハン付近地形概要図、7月上旬・7月下旬・8月下旬の戦闘経過要図などが含まれる。

- source: https://www.nids.mod.go.jp/military_history_search/SoshoView?kanno=027
- 候補用途: 地形、主要地点、作戦段階の確認
- 注意: 戦史叢書の作戦図をそのまま現代GIS上の精密geometryとみなさず、公開地図に転記する場合は尺度・基準点・一般化方法を記録する

## Data Audit で必ず確認すること

- 1939年時点の「国境」を単一の確定線として描かない
- 満洲国／日本側の主張線とモンゴル人民共和国／ソ連側の主張・認識を、史料上区別できる場合だけ別レイヤーにする
- 現代のモンゴル・中国国境を1939年の歴史境界として流用しない
- ハルハ河など自然地形を現代データで補助する場合は、歴史主題geometryとの役割を分ける
- 部隊位置・進撃線は、日付が確認できるものだけを時点付きで表示する
- 損害規模を記号サイズや面積に直接変換する場合は、双方で定義が揃う数値のみ使う
- exact front line を復元できない場合は schematic / approximate と明示する

A29は「戦闘の再現」より、**国境争点・地形・兵站距離がなぜ局地衝突を大規模戦へ拡張し得たか**を示す地図を優先する。

# 5. JH60 — 1939年6月14日〜7月25日

## 中心問い

> 対ソ戦闘が続くなか、日本軍が天津の外国租界へ圧力をかけ、国内では徴用制度を整備したことは、戦争がどこまで多方面化していたことを示すのか。

## 必須テーマ

- 6月14日の天津英・仏租界封鎖
  - 日本軍が租界周辺で通行・物資移動を制限したこと
  - 犯人引渡し要求だけでなく、占領下華北に残る外国権益・通貨・治安権限をめぐる対立へ広がったこと
  - 英国政府、在華英当局、日本外務省、日本軍現地当局の立場を一つにまとめない
- 7月のノモンハン戦闘
  - 関東軍の攻勢と戦闘の大規模化
  - 戦車・砲兵・航空兵力を含む戦闘へ拡大したこと
  - 個々の作戦の勝敗を事件全体の帰趨と同一視しない
- 7月8日の国民徴用令公布、15日施行
  - 国家総動員法第4条にもとづく人的動員制度
  - 1月の職業能力申告、3月の雇入れ制限・技能者養成からの制度的な進展
  - 徴兵制と徴用を区別する
- 物資・生産・労務統制の継続
  - 中国戦線と対ソ戦の双方を支える国内資源制約として扱う
- 7月22日のCraigie–Arita formula
  - 天津問題をめぐる日英交渉の一段階
  - 英国が日本の中国政策全体を承認した文書とは扱わない
- 7月25日時点で
  - 天津問題は未解決
  - ノモンハン戦闘は継続
  - 翌26日に米国が日米通商航海条約廃棄を通告する

## JH59→JH60 接続確認

JH59は対ソ国境戦の開始と天津問題の緊張までを扱う。

JH60は天津封鎖によって対英対立が可視化され、同時に国内では人的動員制度が強化されることで、日本が中国・ソ連・英権益・国内資源を同時に処理する状態へ進む。

# 6. A30 — 天津租界封鎖と占領下華北の法域空間

**Status: planned / map necessity・data-quality judgment を JH60 実装後に実施**

## map necessity 候補

**中。採否は歴史境界geometryの品質で決める。**

天津問題では、「日本軍が占領下の都市全体を単一の法域として自由に扱えた」のではなく、英・仏租界という外国権益空間が残り、その境界で通行・警察・通貨・政治犯引渡しをめぐる摩擦が起きたことが重要である。

アジア歴史資料センターは1939年6月14日の英・仏租界封鎖と、その直前の外務省・北支那方面軍の資料を紹介している。

- source: https://www.jacar.go.jp/exhibition/shuhou/nenpyo/nenpyo19390614.html
- 候補用途: 封鎖対象、法域差、軍事占領と租界権益の関係
- 注意: 正確な1939年租界境界polygonを信頼できる史料から作れない場合は no-map とする

## Data Audit で必ず確認すること

- 現代天津市境界・行政区を1939年の租界境界へ流用しない
- 英租界・仏租界・日本租界その他の歴史的法域を混同しない
- 封鎖線を「日本が租界内部を占領した境界」として描かない
- 正確な封鎖検問所が確認できない場合は無理にpoint化しない
- 歴史地図からpolygonをトレースする場合は出典・基準年・変換手順を残す
- geometryが弱い場合は代表地点＋模式的な法域関係図へ落とすか、地図自体を採用しない

# 7. JH61 — 1939年7月26日〜8月22日

## 中心問い

> 米国との条約関係が変化し、ノモンハンでも大規模攻勢を受けたとき、日本の対外制約はどのように増えたのか。

## 必須テーマ

- 7月26日の米国による日米通商航海条約廃棄通告
  - 1911年条約を6か月後に終了させる通告
  - 通告そのものと、1940〜41年の個別輸出規制・資産凍結・石油禁輸を分ける
  - 米国側が条約を経済・通商政策上の制約として再検討していたこと
  - 日本側が政治的意味も含めて受け止めたこと
- 日米関係の状態遷移
  - 「米国との戦争が決まった」と書かない
  - 一方で、既存条約の継続を前提にした関係から、6か月後の無条約状態も見据える関係へ移ったことを説明する
- ノモンハンの持久戦
  - 7月下旬〜8月中旬の戦闘継続
  - 日本側の損耗・補給・増援の制約
- 8月20日のソ連・モンゴル側総攻撃
  - 第23師団を中心とする日本軍が大きな損害を受けたこと
  - 8月20日を「突然の敗北」だけで説明せず、それ以前からの損耗・情報・火力・兵站条件と接続する
- 8月の国内経済統制
  - 配当統制、電力供給制限、米穀配給統制など
  - 戦争だけを単独原因とせず、供給制約と統制行政の具体化として扱う
- 8月22日時点で
  - ノモンハンの戦況は日本側に厳しい
  - 対米条約関係は終了予告済み
  - 対独伊協定強化交渉は続いている
  - 翌23日に独ソ不可侵条約が成立し、外交前提が急変する

## JH60→JH61 接続確認

JH60は、対ソ戦・対英租界問題・国内徴用が同時に進む状態までを扱う。

JH61は、そこへ米国との条約関係の変化が加わり、さらにノモンハン戦場で大規模攻勢を受けることで、日本の外部制約が軍事・外交の両面で増える状態を扱う。

# 8. JH62 — 1939年8月23日〜9月15日

## 中心問い

> 独ソ不可侵条約と欧州戦争開始は、日本の対独伊外交・内閣・対ソ戦処理をどのように組み替えたのか。

## 必須テーマ

- 8月23日の独ソ不可侵条約
  - 日本が対ソ連携を想定して強化しようとしていた防共協定の前提と衝突したこと
  - 日本政府が独ソ条約を受け、対独伊協定強化交渉を停止する方向へ動いたこと
  - 「ドイツに裏切られた」という同時代の表現は、当時の日本側認識として帰属を明示する
- 8月28日の平沼内閣総辞職
  - 独ソ条約を予見できなかったことと外交方針再検討が辞職理由に結びついたこと
  - ノモンハンだけを単独原因として説明しない
- 8月30日の阿部内閣成立
  - 欧州情勢への不介入・自主的外交を模索する出発点
  - 内閣交代だけで中国戦線・対米英問題・総動員が解消したわけではない
- 9月1日のドイツによるポーランド侵攻と欧州戦争開始
  - 日本にとって欧州列強の資源・関心配分が変わる外部環境
  - この時点で日本の参戦や三国同盟締結を既定路線にしない
- 9月3日の大本営によるノモンハン作戦中止命令
  - 現地関東軍との統帥関係
  - 戦場の軍事状況と欧州外交環境の双方が事件処理へ影響したこと
- 9月15日の停戦協定
  - モスクワで停戦が合意されたこと
  - 事件の軍事的区切りと、国境画定問題の完全解決を区別する
- フェーズ末の状態
  - 中国での戦争は継続
  - 天津問題・対英関係の問題は残る
  - 日米通商航海条約はまだ6か月の予告期間中
  - 阿部内閣は欧州戦争下で新外交方針を組み立てる必要がある
  - 国内統制はさらに拡張途上

## JH61→JH62 接続確認

JH61は、対米条約関係の変化とノモンハン戦況悪化までを扱う。

JH62は、独ソ不可侵条約によって日本の対欧州外交の前提が崩れ、内閣交代と欧州戦争開始を経て、対ソ武力衝突を停戦へ収束させる状態を扱う。

# 10. Crosscutting publication gate

JH59〜JH62と採用地図を実装した後、既存横断記事へ新しい比較軸が実際に加わる場合だけ延長する。

## S05「政治参加の回路」

候補:
- 関東軍の現地軍事判断と大本営・政府の統制
- 対独伊協定強化をめぐる政府・陸海軍・在外大使の調整
- 独ソ不可侵条約後の平沼内閣総辞職と外交方針再編

年代記事の事件列を再掲せず、**誰がどの手続・権限で軍事・外交方針を決め、どこで統制が効きにくかったか**という比較軸が増える場合だけ延長する。

## S09「対外支配の制度差」

候補:
- 日本軍占領下の華北と、英・仏租界という外国権益空間の法域差
- 満洲国・モンゴル人民共和国の国境主張と、日本軍・ソ連軍が介入する構造

既存記事の対象概念と合わない場合は無理に延長しない。国境紛争そのものを「対外支配制度」の一類型へ押し込めない。

## S10「産業社会の負担と保護」

候補:
- 国民徴用令による人的資源動員
- 8月の配当統制・電力供給制限・米穀配給統制
- 戦争継続が企業・労働者・消費者へ及ぼす行政統制の拡大

JH60/JH61の制度説明を複製せず、**統制対象が登録・採用・就業から徴用・価格・供給へ広がる長期変化**として比較できる場合だけ延長する。

## S02「石高制・貨幣経済・財政」

このフェーズで新しい財政制度・租税制度・戦費調達方式の比較軸が確認できない場合は延長しない。物価・配当・供給統制だけを理由に財政記事へ押し込まない。

## 新規横断記事

原則追加しない。

「北進と南進」「枢軸外交」「日米開戦への道」などは、1939年時点の複数の未確定選択肢を後世の結果から整理しすぎる危険がある。既存横断記事で不足する独立比較軸が確認できた場合だけ別計画で検討する。

# 11. phase-end audit necessity judgment

フェーズ末の独立監査は自動では追加しない。

JH59〜JH62の隣接接続確認、A29/A30のmap audit、Crosscutting publication gate、通常のcontent validationを終えた時点で、次のような**複数ページを同時に見ないと判定できない具体的仮説**が残る場合だけ監査を行う。

候補仮説:

- JH59〜JH62を通して「ノモンハンの敗北 → 南進 → 日米開戦」という後知恵の一本道を暗黙に作っていないか
- 天津封鎖・日米条約廃棄通告・独ソ不可侵条約を、すべて一つの「対米英開戦準備」へまとめていないか
- 関東軍、大本営、陸軍省、内閣、外務省の主体と権限を混同していないか
- JH62で独ソ不可侵条約を平沼内閣退陣の唯一原因として単純化していないか
- S05/S09/S10延長が年代本文の再編集になっていないか

各年代実装時に解消済みで未解決仮説が残らなければ、**独立監査不要**と判定してCI / Pages / 完了処理へ進む。
