# 1. このフェーズを1937年11月13日〜1938年1月16日に切る理由

直前フェーズは11月12日の上海占領で止めた。

11月12日時点では、日本軍は上海周辺で軍事的優位を得たが、中国軍主力と南京国民政府は存続し、上海から南京へ進むことも、どこまで追撃することも、政治的決着の方法も確定していなかった。トラウトマン駐華ドイツ大使を仲介とする和平工作も始まっていた。

防衛研究所の研究は、杭州湾上陸作戦の計画段階で陸軍中央に南京攻略を既定方針とする構想はなく、上海戦後に第10軍など現地軍が南京進撃へ傾き、大本営が進出限界線を設けても現地軍がそれを越え、12月1日に大本営が南京攻略を正式命令した経過を整理している。

したがって11月13日以後の中心問題は、単なる「上海の次は南京」という地理的連続ではない。

~~~text
11月12日 上海占領
→ 上海以西への追撃・進出範囲が新しい政策問題になる
→ 現地軍の進撃と中央の制限がずれる
→ 11月20日前後 大本営設置・中国側の首都移転方針・南京安全区準備
→ 12月1日 南京攻略を正式命令
→ 12月12日 パネー号事件
→ 12月13日 南京占領
→ 南京占領後も中国政府は抗戦継続
→ 南京で非戦闘員殺害・略奪・性暴力・捕虜処遇上の重大な加害が発生
→ トラウトマン工作は戦況変化を受けて再び動く
→ 12月22日 日本側が条件を追加・変更
→ 1938年1月11日 御前会議で対中処理方針を決定
→ 1月14〜15日 和平交渉継続をめぐり政府・参謀本部で対立
→ 1月16日 第一次近衛声明
~~~

という状態遷移として扱う。

外務省外交史料館は、11月上旬に始まったトラウトマン工作が、南京攻略を挟んで12月の条件変更、1938年1月の中国側回答、交渉打ち切り、1月16日の「爾後国民政府ヲ対手トセズ」とする声明へ至ったと整理している。

1月16日は重要な境界である。軍事的には南京を占領しても中国政府を屈服させられず、外交的には国民政府との講和交渉を続ける余地が政策上大きく狭められた。JACARもこの声明を、南京占領後も抗戦を続ける国民政府に対し、交渉による解決を打ち切る方針を示したものとして整理している。

このため本フェーズは1938年1月16日で区切る。

1月17日以後の国家総動員法案要綱、公的な新政権工作の進展、徐州作戦へ向かう軍事拡大などは次フェーズへ送る。

# 3. JH44 — 1937年11月13日〜30日

**Status: completed / 2026-09-29**

## 中心問い

> 上海を占領した後、南京攻略がまだ陸軍中央の既定方針ではなかったのに、なぜ日本軍の進撃は南京方面へ広がったのか。

## 必須テーマ

- 11月12日の上海占領直後に残っていた選択肢
- 上海派遣軍・第10軍・中支那方面軍の関係
- 第10軍を中心とする南京進撃志向
- 上海派遣軍の損耗・休養要求と、その後の進撃への傾斜
- 参謀本部・大本営側の作戦範囲制限
- 進出限界線（制令線）が、なぜ現地軍の進撃を止める装置として十分に機能しなかったのか
- 11月20日の大本営設置を、後の太平洋戦争期の大本営と連続させすぎず、1937年時点の陸海軍最高統帥機関として説明する
- 中国政府の南京からの首都機能移転
- 重慶遷都の日付は、JACAR内でも11月10日・11月20日の記載差があるため、**決定・表明・実際の政府機能移転を分けて史料確認してから本文へ置く**
- 南京安全区の準備。11月21〜22日には外国人を中心とする国際委員会が民間人避難区域を提案している
- トラウトマン工作の初期段階と、中国政府が当初の日本側和平条件を受け入れなかったこと
- 上海占領から南京占領までを最初から一本の既定作戦として書かない

## JH43→JH44 接続確認

JH43は、上海占領によって上海正面の軍事状態が変わった一方、中国軍・南京国民政府・和平工作が残り、「どこまで進むか」が次の判断問題として残るところで終わる。

JH44は、その未解決問題が現地軍の追撃と中央の制限のずれとして具体化したところから始める。

# 4. A23 — 上海・南京間の進攻空間

**Status: completed / 2026-09-29**

## map necessity 判定

**採用 / high。**

JH44の中心は、上海占領後の追撃がそのまま「南京攻略命令」から始まったのではなく、現地軍の西進と中央の進出制限がずれながら、南京方面への戦場拡大を既成事実化していった点にある。

防衛研究所の戸部良一論文は、杭州湾上陸を計画した段階の陸軍首脳部には南京攻略構想がなく、第10軍・上海派遣軍が南京進撃へ傾いた後、大本営が制令線で進撃を抑えようとしたが、現地軍がこれを越え、12月1日に南京攻略命令へ至ったと整理する。また、上海から南京までは約300kmとされる。

したがってA23では、**上海と南京の間に太湖・長江下流域・複数の主要都市を含む広い作戦空間があり、「上海の次が自動的に南京」ではなかったことを可視化する**意義が大きい。

一方、JH44で説明したいのは日ごとの戦闘経路ではなく、追撃範囲と中央統制のずれである。精密な進撃線が作れない場合でも、主要都市の位置関係だけで地図の説明価値は残る。

## Data Audit 判定

**pass。ただし「主要都市のrepresentative / approximate point＋地理ラベル」を上限とする。進撃路・退却路・制令線・鉄道／道路のLineStringは実装しない。**

### 1. 上海—南京間の同時代地域図

国立国会図書館所蔵「最新上海南京近傍詳圖」は、1937年10月刊、縮尺1:500,000で、上海附近1:150,000・南京附近1:100,000の分図を含む。

- source: https://ndlsearch.ndl.go.jp/books/R100000002-I000011194813
- publication: 1937.10
- scale: 1:500,000
- 利用方針: 上海・蘇州・無錫・常州・鎮江・南京、長江・太湖などの広域位置関係と同時代地名を照合する
- 地図画像をそのままGISへトレースして作戦線・道路線を生成しない

「南京廣徳近傍圖」は大日本帝國陸地測量部作成、1937年製版、縮尺1:250,000である。

- source: https://ndlsearch.ndl.go.jp/books/R100000002-I000008284371
- publication: 1937
- scale: 1:250,000
- 利用方針: 南京東方・南東方の地名と広域位置関係をクロスチェックする
- 1937年の作戦日時ごとの部隊配置図としては使わない

### 2. 1937年の交通網

国立国会図書館所蔵「江蘇浙江交通明細地圖」2版は、1937年9月刊、縮尺1:400,000である。

- source: https://ndlsearch.ndl.go.jp/books/R100000002-I000008284331
- publication: 1937.9
- scale: 1:400,000
- 利用方針: 上海—南京間の鉄道・道路・水運を含む交通網が存在したこと、主要都市と交通軸の位置関係を確認する
- 紙地図上の線をそのまま現代座標へ移して公開LineStringにしない
- 再利用可能な歴史GIS vector geometryが確認できないため、交通軸は本文・popupの説明に留める

### 3. 南京進撃と中央統制

防衛研究所の戸部良一「日中戦争の拡大と日本陸軍　1937年7月～1938年10月」は、上海戦後の南京進撃について、

- 杭州湾上陸を計画した段階の陸軍首脳部には南京攻略構想がなかったこと
- 第10軍、続いて上海派遣軍が南京進撃へ傾いたこと
- 大本営が制令線で進撃を抑えようとしたこと
- 現地軍が制令線を越えたこと
- 12月1日に大本営が南京攻略を正式命令したこと

を整理している。

- source: https://www.nids.mod.go.jp/event/proceedings/forum/pdf/2019/02_tobe.pdf
- 利用方針: A23のhistoricalQuestionと期間区分を裏づける
- 論文本文だけから日付別の部隊位置・進撃経路を推定してGIS化しない

戦史叢書第86巻『支那事変陸軍作戦〈1〉昭和十三年一月まで』は、より詳細な作戦経過を確認する補助資料とする。

- source: https://www.nids.mod.go.jp/military_history_search/SoshoView?kanno=086
- 利用方針: 作戦段階・命令・主要地点の確認に使う
- 作戦図を精密GIS geometryへ無批判にトレースしない

### 4. geometry の上限

A23で公開可能なgeometryは次に限定する。

| 対象 | geometry | confidence | 用途 |
|---|---|---|---|
| 上海 | representative Point | derived / approximate | 直前戦場・東端 |
| 蘇州 | representative Point | derived / approximate | 上海西方の主要都市 |
| 無錫 | representative Point | derived / approximate | 太湖北東側の主要都市 |
| 常州 | representative Point | derived / approximate | 南京へ向かう中間都市 |
| 鎮江 | representative Point | derived / approximate | 南京東方・長江沿いの主要都市 |
| 南京 | representative Point | derived / approximate | 西端・次の作戦目標となる都市 |
| 長江 | ラベルのみ | approximate | 南京・鎮江と河川空間の関係 |
| 太湖 | ラベルのみ | approximate | 上海—南京間の地理的制約の識別 |

必要に応じて松江などを補助pointに加えてよいが、**「地図を埋めるため」の地点追加はしない。**

### 5. 描かないgeometry

A23では次を描かない。

- 第10軍・上海派遣軍の進撃路
- 中国軍の退却路
- 日付ごとの前線
- 制令線
- 京滬鉄路・道路を再現したLineString
- 現代の行政界を1937年の境界として扱うpolygon

同時代地図から交通軸・地名を確認できても、スキャン画像を現代座標へ移す工程にはgeoreferencing誤差とトレース判断が入る。A23のhistoricalQuestionに対し、そこまでの精密geometryは必要ない。

MapLibreの背景地図に現代道路・行政界・現在の水際線が表示される場合は、公開注記で**背景地図は現在の位置参照であり、1937年の道路・行政界・水際線を示すものではない**と明示する。

## 実装時のgeometry方針

**point-onlyを基本とする。**

A23が可視化するのは、部隊の一本の経路ではなく、**上海から南京まで約300kmの間に複数都市・太湖・長江下流域が広がること**である。主要都市をpointで置き、popup / 本文で「追撃範囲」「交通軸」「中央の制限」を説明する方が、地図の精度とJH44の中心問いに合う。

既存のHuman Visual Audit済みpoint地図と同じmarker・label・popup・touch interactionを再利用し、実装がpoint featureだけなら、MAP_AUDIT_STANDARDの再利用規則により個別Human Visual Auditを省略できる。line / polygonを追加する場合はこの例外を失い、Data / Style / Human Visual Auditをやり直す。

## 判定結果

**A23は地図あり。データ品質はpoint中心表現なら実装可能。**

1937年10月の上海—南京地域図、1937年の南京周辺図、1937年9月の江蘇・浙江交通図により主要都市・河川・湖沼・交通網の広域関係を同時代資料で照合できる。一方、11月13〜30日の実際の進撃線・制令線・退却線を公開GISとして十分な精度で復元できるvector根拠は確認できない。

したがって、A23は**「上海—南京間の広域空間は地図化する／進撃線や交通線は地図化しない」**という境界で採用する。

# 6. JH46 — 1937年12月14日〜31日

**Status: completed / 2026-09-29**

## 中心問い

> 南京を占領した後、日本軍の統制は市内の兵士・捕虜・民間人をどこまで管理できたのか。また、その加害と第三国問題は軍事的勝利をどのような政治・外交問題へ変えたのか。

## 必須テーマ

- 南京入城後に起きた非戦闘員殺害、略奪、性暴力、放火など
- 武装解除した中国兵・捕虜の扱い
- 「南京事件」「南京大虐殺」などの用語は、史料・研究・政府見解に応じて定義を明示する
- 日本政府は現在、南京入城後に非戦闘員の殺害や略奪行為等があったことは否定できないとしている一方、犠牲者の具体的人数については諸説があり政府として特定数を認定していない
- 被害者数は、対象期間・対象地域・兵士／民間人・埋葬記録・推計方法が異なる数字を無条件に並べない
- 「人数に論争がある」ことを、殺害・略奪・性暴力等の存在そのものが未確定であるかのように書かない
- 南京安全区国際委員会、外国人宣教師・大学関係者、外交官などによる同時代記録
- 安全区は主権的な中立地帯ではなく、民間人保護を目的に外国人らが設定を試みた区域であること
- 日本軍側史料・戦史叢書にある軍紀・処分・捕虜処遇の記述
- 12月12日のパネー号事件について、日本政府の謝罪・外交処理が進んだこと
- 英米など第三国の権益・船舶をめぐる緊張
- 南京攻略後、トラウトマン工作が再び動いたこと
- 12月22日に日本側が新たな条件をドイツ経由で中国側へ提示したこと
- 南京占領によって和平条件が緩和されたと単純化しない。戦況有利化を背景に日本側条件は追加・変更された

## 史料バランス

南京での加害は、単一国・単一立場の史料だけで確定しない。

最低限、

- 日本側の軍・外交史料
- 南京安全区国際委員会など現地外国人の同時代記録
- 米国外交文書
- 日中歴史共同研究など研究史整理

を組み合わせる。

日本政府の現在の見解そのものは歴史事実の唯一の証拠ではなく、**現在の政府見解として位置づける**。

# 7. A24 — 南京市街・安全区・長江の空間

**Status: completed / 2026-09-29**

## map necessity 判定

**採用 / high。**

JH45〜JH46では、南京を単なる「首都」という一点ではなく、城壁内外・長江沿岸・下関方面・安全区という異なる空間が重なる都市として読む必要がある。

とくに安全区は、民間人保護を目的に外国人らが設定を試みた区域であり、その境界と南京市街の位置関係を示すことで、

- 安全区が南京全市ではなく城内西北寄りの一部だったこと
- 長江・下関方面と安全区が同一空間ではないこと
- 大学・病院・外国人施設などが安全区の運用拠点になったこと
- 12月13日の軍事占領後も、民間人保護・捕虜／敗残兵処遇・軍紀という別の統治問題が残ったこと

を本文だけより短く把握できる。

したがってA24は地図化する価値が高い。

## Data Audit 判定

**pass。ただし、公開geometryは「安全区のapproximate polygon＋1937年に照合できる代表point」を上限とする。城壁線・長江水際線・加害地点群は精密vector化しない。**

### 1. 南京安全区の境界文書

米国国務省FRUSの1937年11月22日電報は、安全区案の境界を当時の道路・交差点で具体的に記録している。

- east: North Chung Shan Road, Hsin Chieh Kou → Shansi Road Circle
- north: Shansi Road Circle → Sikang Road
- west: Sikang Road → Hankow Road intersection → Shanghai Road / Han Chung Road intersection
- south: Han Chung Road → Hsin Chieh Kou
- source: https://history.state.gov/historicaldocuments/frus1937v03/d776

これは安全区の**制度上の境界記述**として採用できる。

ただし道路名の文章記述だけから現代座標へ直接変換しない。

### 2. 1937年南京の歴史GIS / 同時代地図

南京大学の研究者らによる「1909年、1927年、1937年南京城市歴史地名データセット」は、1937年断面について蘇甲栄編『新南京地図』1937年訂正版（主図1:20,000）を基図とし、地方志等を補って歴史地名をGIS化している。

- Liu Yuxuan, Yu Bingchen, Xu Haiyang, Chen Gang, “A dataset of urban historical place names in Nanjing (1909, 1927 and 1937)”
- DOI: 10.11922/csdata.2017.0001.zh
- data DOI: 10.11922/sciencedb.548
- format: ESRI Shapefile
- time slices: 1909 / 1927 / 1937
- source: https://www.sciengine.com/CSD/doi/10.11922/csdata.2017.0001.zh

同データを可視化した1937年南京地名図はgeoreference情報を持ち、CC BY 4.0で公開されている。

- source: https://zh.wikisource.org/wiki/File:%E6%B0%91%E5%9B%BD%E5%8D%97%E4%BA%AC%E5%9F%8E%E5%B8%82%E5%9C%B0%E5%90%8D%E5%9C%B0%E5%9B%BE_(1937).jpg
- 利用方針: 1937年の地名・道路系・施設位置を照合する歴史座標参照として使う

### 3. 12月時点の運用確認

Yale University Library Nanking Massacre Project所収の1937年12月10日付「Report by Nanking Safety Zone on boundaries of Zone」は、安全区南西境界について唐生智側との合意が成立したこと、区域内の兵士を確認・退出させるためのinspectionを行うことを記録している。

- NMP0139
- source index: https://adhoc.yalepages.org/Collections/Nanking/findingaid.html
- document: https://adhoc.yalepages.org/Media/PDFs/Nanking/NMP0139.pdf

この史料は、11月22日の提案境界が単なる机上案ではなく、南京攻略直前に現地で境界・非軍事化を運用対象としていたことを確認するために使う。

安全区polygonは、**FRUSの境界記述を意味の正本とし、1937年歴史GIS／同時代市街図上で道路・交差点を照合して生成するderived geometry**とする。現代道路座標をそのまま頂点列として採用しない。

### 5. 描かないgeometry

A24では次を描かない。

- 現代南京の行政界
- 現代道路中心線を流用した「1937年安全区の精密境界」
- 城壁全周の精密LineString
- 1937年当時の長江水際線を装うpolygon / LineString
- 日付別の日本軍進入経路
- 捕虜・敗残兵の移送経路
- 殺害・性暴力・略奪などの個別事件を大量に並べたpoint群
- 出典ごとに位置精度・期間・被害類型が異なる地点を一つの「南京事件分布」として統合したheatmap

個別加害地点は、事件の存在を空間的に強調するほど位置・期間・分類定義の誤差が大きな意味を持つ。A24のhistoricalQuestionは被害地点の網羅的分布ではなく、**安全区・市街・長江／下関の位置関係**なので、ここでは扱わない。

### 6. 実装時の audit 条件

安全区polygonを含むため、point-only再利用例外は使わない。

実装する場合は、

1. 1937年歴史GIS／同時代地図から使用するcontrol pointを記録
2. FRUS境界文を各polygon辺へ対応付け
3. transformation historyをprovenanceへ記録
4. geometryConfidenceをapproximateとする
5. Data Audit
6. Style Audit
7. Desktop / touchを含むHuman Visual Audit

を通す。

公開注記では、背景地図が現在の位置参照であり、1937年の道路・行政界・水際線そのものではないこと、安全区polygonは同時代境界記述と1937年地理資料から復元した概略範囲であることを明示する。

## 判定結果

**A24は地図あり。安全区はapproximate polygonとしてデータ品質を満たせる。**

FRUSが安全区境界を道路・交差点で具体的に記録し、1937年1:20,000市街図を基にした歴史GISが利用できるため、現代道路の逆投影に頼らず概略polygonを構成できる。一方、城壁・長江水際線・個別加害地点群を同じ精度でvector化する根拠は揃っていない。

したがってA24は、**「安全区の概略面＋歴史地名pointを地図化する／城壁・河岸・加害地点群は精密geometryにしない」**という境界で採用する。

# 13. このフェーズでしないこと

- 上海占領を南京攻略の自動的な前段階として書かない
- 現地軍の先行行動と中央の正式命令を同一視しない
- 「大本営」を1941年以後の対米英戦争期の制度イメージだけで説明しない
- 日本政府・陸軍省・参謀本部・中支那方面軍・上海派遣軍・第10軍を「日本側」の一意思に畳み込まない
- 南京国民政府・南京防衛軍・中国軍退却部隊を「中国側」の一意思に畳み込まない
- 首都占領を国家降伏と同一視しない
- 南京での加害を「戦闘の混乱」だけで処理しない
- 被害人数に研究上の幅があることを理由に、非戦闘員殺害・略奪・性暴力・不適切な捕虜処遇の存在まで未確定扱いしない
- 逆に、定義・対象期間・対象地域の異なる被害推計から一つの精密な人数を作らない
- 南京安全区を日本軍・中国軍双方が法的に承認した完全な中立地帯として書かない
- パネー号事件から「日米開戦がこの時点で必然だった」と逆算しない
- トラウトマン工作の各段階で、後の1月16日声明を既定結果として書かない
- 1938年1月16日時点から国家総動員法成立や徐州・武漢攻略を必然として書かない
- 同時代地図を根拠なく精密GISへ変換しない
- 現代南京の道路・行政界を1937年の市街・安全区境界として無注記で使わない
- フェーズ末に理由のない全体監査を追加しない
