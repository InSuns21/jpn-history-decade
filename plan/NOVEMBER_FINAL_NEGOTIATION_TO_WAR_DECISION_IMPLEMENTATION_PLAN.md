# 1. このフェーズを1941年11月6日〜12月1日に切る理由

前フェーズは11月5日の第7回御前会議で終えた。この日、日本政府は新しい「帝国国策遂行要領」と対米交渉の甲案・乙案を正式決定した。政策の重心は12月初頭の武力発動準備へ移ったが、12月1日午前0時までに対米交渉が成功すれば武力発動を中止する条件も残された。

したがって11月6日以後は、**決定済みの条件分岐を実際の外交へ投入し、その条件が成立するかどうかを確認する段階**である。11月7日に野村吉三郎大使が甲案をハル国務長官へ手交し、11月中旬には来栖三郎特命全権大使がワシントンへ到着する。交渉は中国からの撤兵・駐兵、三国同盟、通商無差別などの争点を残したまま、甲案から乙案へ移る。

11月20日前後、日本政府は乙案を「最終案」と位置づけ、南部仏印から北部仏印への移駐、通商・資産凍結解除などを組み合わせた限定的妥協を提示する。一方、米国側でも全面的な原則案とは別に一時的なmodus vivendi（暫定協定）案が検討された。したがってこの期間を、11月5日の時点ですべての外交結果が確定していたかのように書かない。

11月26日（米時間）、ハル国務長官は暫定協定案を提示せず、太平洋全域の包括的合意の基礎案と口頭声明を野村・来栖に渡した。日本時間では11月27日となる。後世「ハル・ノート」と呼ばれるこの文書は、日本側乙案への受諾回答ではなく、中国・仏印からの撤兵など従来からの原則差を大きく残す内容だった。公開本文では、これを**文書そのものに明示的な開戦期限を置く「最後通牒」だったと断定せず**、米側が暫定協定を検討した過程、日本側の受け止め、11月27日以後の政府・統帥部の政策手続を分けて追う。

日本時間11月27日の第73回大本営政府連絡会議は、対米交渉不成立を前提に12月1日の御前会議で国家意思を決定する手続を整える。11月29日の第74回会議では御前会議議題、開戦決意に伴う国内外措置、独伊への外交措置などが詰められる。

12月1日の第8回御前会議で「対米英蘭開戦ノ件」が正式決定される。これは11月5日の「戦争準備と期限付き外交」の条件付き方針とは制度段階が異なる。ここで初めて、11月5日国策が残していた「交渉成功なら武力発動を中止する」分岐が閉じ、国家の正式意思として米英蘭への開戦が決まる。

このため本フェーズは、**甲案実施 → 来栖参加・交渉再活性化 → 乙案実施 → 米側回答と暫定協定不採用 → 日本側の交渉不成立判断 → 12月1日の正式開戦決定**で一つの状態遷移をなす。

# 8. A42 — 最終外交と作戦発動準備の空間 map necessity / data-quality judgment

## 判定対象

11月5日国策は外交成功時の武力発動中止条件を残しながら、軍事側には12月初頭の作戦準備完成を求めた。11月後半には外交交渉がワシントンで続く一方、軍事準備も別系統で進む。

A42は「外交の進行」と「軍事準備の空間」を一枚に重ねれば分かりやすいように見えるが、次の危険がある。

- 11月5日時点の計画と、12月8日以後に実現した侵攻経路を混同する
- 実際の艦隊・輸送船団の移動を、政治決定の確定時期より前から「開戦決定済み」の証拠として読ませる
- A40「外交期限と南方作戦準備の空間」と主題が重複する
- ハワイ、マレー、フィリピン、蘭印など広域を一枚に入れ、精度や時点差を偽装する

### map necessity判定で確認する問い

- JH107〜JH111の中心問いは、地図がないと理解しにくい空間関係を含むか
- A40との差分として、11月後半に新しく確定・移動した作戦空間を同時代史料で時点付きに示せるか
- 実際の作戦航路を描く場合、命令時点・出撃時点・攻撃時点を分けられるか
- 外交上の期限と軍事上の準備時点を、地理的位置と同じ視覚変数へ無理に混ぜないか
- LineString / Polygon採用に足る位置精度・時点精度・provenanceがあるか

### データ品質方針

- 12月8日の実績から11月中の計画geometryを逆算しない
- 作戦命令・部隊移動・集結地を使う場合は、その史料の日付と計画／実行の区別を属性化する
- 海上ルートはcartographic waypointと史料上の経由点を区別する
- A40の再掲で足りる場合はno-map
- LineString / Polygon採用時はData Audit / Style Audit / Human Visual Audit必須

## 判定結果 — **adopted / high**

A42は **採用** とする。A40の9〜10月段階では「準備地域」と「作戦対象方面」を模式点で示し、11月の正式作戦序列・具体的集結・出撃は意図的に逆投影しなかった。11月6日以後は、同じ南方空間に対して制度段階と実行準備の双方で新しい状態が生じているため、A40の焼き直しではない。

- Japanese Monograph No. 45は、11月6日に大本営が南方軍・南海支隊・支那派遣軍へ、対米交渉不成立時の任務を示す命令を発し、南方軍主力を仏印・華南・台湾・南西諸島・南洋諸島へ集結させるよう命じたと記録する。9月6日後の一般的な「準備地域」から、正式な作戦準備命令を受けた「集結地域」へ段階が変わった。
- 米海軍公式戦史は、真珠湾攻撃部隊が11月22日までに択捉島単冠湾へ集結し、11月26日に出航したことを示す。11月25日の命令には、対米交渉が成功した場合は部隊を帰投・再集結させる条件も残されていた。したがって軍事準備の具体化と外交分岐の残存を同じ時点構造として読める。
- 米陸軍公式戦史も、11月6日に南方軍へ詳細作戦準備を命じ、11月20日には攻撃命令が出された一方、外交交渉の結果が判明するまで作戦開始を待つ条件が付されたと整理する。JH107〜JH111の「外交継続と作戦発動準備の並行」を、制度説明だけでなく空間配置でも補強できる。
- A40との主題差は、A40が**9〜10月の準備範囲と対象方面**、A42が**11月の正式集結命令と具体的な集結・出撃準備地点**を扱う点に置く。A42ではA40の対象方面を全面再掲せず、11月に史料上の段階が変わったfeatureを優先する。
- ワシントンを軍事準備地点と同じ地図へ点表示すると、外交交渉の場所と作戦空間を同一の地理変数として読ませやすい。そのため外交側はreadingNoteと時点注記で示し、地図geometryは軍事準備の空間へ限定する。
- 海上進攻路・真珠湾までの実航路・南方侵攻線はこの地図では描かない。11月中の準備段階を示す目的には、正式集結地域の代表Pointと、単冠湾など史料で確認できる集結・出撃Pointで足りる。これにより12月8日以後の実績経路を逆投影する危険を避ける。
- Point geometryは「地域の代表点」または「集結・出撃地点」として属性を分ける。仏印・華南・台湾・南西諸島・南洋諸島は広域命令のラベルアンカーであり、部隊の精密駐屯地を意味しない。単冠湾は史料で確認できる具体的集結地点として別カテゴリにする。
- 新しいLineString / Polygon / time-slice rendererは不要で、既存のpoint-only ThematicMap表示・凡例・popup/touch interactionを再利用できる。実装時はData Audit / Style Auditを行い、変更がPoint featureと既存表示パターンに限定されることを確認した場合のみHuman Visual Audit再利用例外を適用する。

**data-quality judgment:** 採用に必要な時点・役割・空間粒度は確保できる。南方軍の広域集結地域はJapanese Monograph No. 45、単冠湾の集結・出航と外交成功時の帰投条件は米海軍公式戦史、11月6日・20日の作戦準備段階は米陸軍公式戦史で相互に確認できる。一方、個別部隊の正確な駐屯地・海上航路・上陸地点まで確定する根拠はこの判定段階では採用しないため、A42はPoint中心の模式地図として実装する。

# 9. Crosscutting publication gate 候補

## S13「日米交渉と経済圧力」

**extension candidate。**

11月5日時点のS13は「12月1日まで外交、成功なら武力発動中止」という条件分岐の成立までを扱う。本フェーズでは、その分岐が実際の甲案・乙案交渉へ投入され、米側暫定協定案の検討と不採用、11月26日米側文書、日本側の不成立判断を経て、12月1日に正式開戦決定へ閉じる。

新しい比較軸は、単なる事件追加ではなく、**政策上の条件分岐が実交渉の結果によってどのように解消されたか**である。年代記事の再編集にならず、この変化を比較として書ける場合に限り延長する。

## S10系列「産業社会の負担と保護」

**原則hold。**

このフェーズの中心は外交・開戦意思決定であり、新しい配給・価格・賃金・労働配置・企業統制の制度段階が成立しない限り延長しない。

## S12「秋丸機関と総力戦研究所」

**原則hold。**

11月後半の政策判断と研究成果の類似・不一致だけで直接因果を作らない。研究所・秋丸機関の新活動、政策担当者による直接参照など新史料が確認できた場合だけ再判定する。

## S09系列「対外支配の制度差」

**conditional hold。**

11月22日の「対タイ措置要領」は将来の対タイ政策を考える重要史料だが、この時点ではまだ12月以後の軍事進入・同盟形成・権限配分が実現していない。計画文書だけで新しい支配制度類型を成立扱いせず、実施段階は次フェーズで再評価する。

## S05系列「政治参加の回路」

**hold。**

政府・統帥部の国家意思決定手続を、国内の政治参加制度史へそのまま混入しない。

# 10. phase-end audit necessity judgment 候補仮説

実装後、独立監査が必要かを具体的仮説で判定する。

候補：

1. **11月5日ですでに12月1日の開戦決定まで不可逆に確定していたように読めないか**
2. **甲案・乙案を固定文書として扱い、11月中の修正・提示順・現地大使案との差を消していないか**
3. **来栖派遣を「和平派の最後の賭け」「時間稼ぎ」など単一意図で説明していないか**
4. **米側が11月26日までmodus vivendiを検討した事実を落とし、最初から包括案しかなかったように書いていないか**
5. **いわゆる「ハル・ノート」を明示的期限付きの最後通牒と断定していないか**
6. **「ハル・ノート」だけを開戦の単独原因にしていないか**
7. **11月27日の第73回連絡会議を12月1日の御前会議による正式開戦決定と同一視していないか**
8. **11月27日以後の外交接触の存続と、日本政府内部での妥結見込み喪失を混同していないか**
9. **日本時間・ワシントン時間の日付差によって会談・電報の因果順序を逆転していないか**
10. **12月1日の正式開戦決定を12月8日の戦闘開始・宣戦布告と同一視していないか**

既存実装で解消済みなら **no-audit** とする。横断記事をまとめて見なければ検出しにくい矛盾が残る場合だけ targeted audit を立てる。
