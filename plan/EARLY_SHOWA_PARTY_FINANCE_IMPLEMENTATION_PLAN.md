# 1. このフェーズの位置づけ

前フェーズは1925年までを扱い、

- 男子普通選挙の制度化
- 治安維持法の成立
- 政党内閣という政治慣行の拡大
- 都市化・産業化・労働運動
- 植民地統治の制度差
- ワシントン体制
- 関東大震災と復興

までを公開品質化した。

1926年以後は、これらの制度が「成立した」ことより、**実際に運用されたとき何が起きたか**を中心にする。

この時期には、

- 1927年の金融恐慌
- 1928年の最初の男子普通選挙
- 無産政党の議会進出
- 三・一五事件と治安維持法改正
- 山東出兵・済南事件
- 張作霖爆殺事件とその政治処理
- 1929年の世界恐慌
- 浜口雄幸内閣
- 1930年の金輸出解禁
- ロンドン海軍軍縮条約と統帥権をめぐる政治対立
- 浜口首相狙撃
- 1930年国勢調査

が重なる。

ただし、これらを「政党政治が崩壊して軍部が台頭し、満州事変へ向かった」という一本道にはしない。各時点で、政党内閣・軍・官僚・枢密院・財界・有権者・社会運動・中国側政治主体などが持っていた異なる目的・権限・制約を分けて記述する。

# 2. なぜ1930年で切るか

このフェーズは **1926–1930** とし、1931年を含めない。

理由は、1931年9月の満州事変を境に、軍事行動・現地軍と政府の関係・国際連盟・中国側の対応・国内政治の変化が短い間隔で連鎖し始めるためである。

1926–1930は、

- 1925年に成立した制度の運用
- 政党政治の競争
- 金融・通貨政策
- 中国政策
- ワシントン体制下の軍縮

を一つのまとまりとして読むことができる。

一方、1931年以後は5年単位を機械的に維持せず、**年・半年・重要局面単位まで解像度を上げる候補**とする。

満州事変以後を1929–1931の一ページへ押し込まない。

# 3. このフェーズの中心問い

1. 1925年に成立した男子普通選挙は、1928年の最初の総選挙で政治参加の入口をどう変え、何を変えなかったか。
2. 普通選挙・無産政党の進出と、治安維持法による取締り拡大は、どのように別々の制度回路で同時進行したか。
3. 1927年金融恐慌では、銀行・企業・政府・日本銀行・預金者の間で信用不安と救済負担がどう配分されたか。
4. 田中義一内閣期の山東出兵・済南事件・張作霖爆殺事件では、政府・外務省・陸軍・関東軍の意思決定をどこまで区別できるか。
5. 1929年の世界恐慌と1930年の金輸出解禁は、日本の企業・労働・農村・金融にどのような制約を与えたか。
6. 浜口内閣の緊縮財政・協調外交は、当時どの制約と政策目的の中で選択されたか。
7. ロンドン海軍軍縮条約をめぐる対立は、内閣・海軍・軍令部・枢密院・政党・世論のどの権限関係を争点化したか。
8. 1920年代後半の政党政治を、後の崩壊を知った視点だけでなく、その時点で機能していた制度・支持基盤・限界の両方からどう説明するか。

# 4. 歴史記述の中心原則

## 4.1 1931年以後を1920年代へ逆算しない

金融恐慌、山東出兵、張作霖爆殺事件、統帥権をめぐる論争を、すべて「軍国主義化の前兆」とだけ説明しない。

各事件では、その時点で誰が何を決められたか、政府・軍・政党・官僚・枢密院などの権限がどこで一致し、どこで食い違ったかを具体化する。

## 4.2 普通選挙と治安統制を単純な相殺関係にしない

1928年には1925年改正選挙法による最初の男子普通選挙が実施される一方、治安維持法による取締りも拡大した。

しかし、

- 選挙権の資格
- 政党・労働運動・社会運動への参加
- 結社・思想に対する刑事規制
- 警察行政
- 女性・植民地住民などの制度的位置

は別の回路である。

「民主化したが弾圧された」という一文だけで処理しない。

## 4.3 金融恐慌・世界恐慌・昭和恐慌を混同しない

1927年金融恐慌は、第一次世界大戦後から続く企業・銀行整理、震災手形、台湾銀行などの信用問題と結びつく。

1929年に始まる世界恐慌と、1930年の金輸出解禁後に深刻化する国内不況は、時点・経路・政策対応を分けて書く。

「1929年に世界恐慌が起きたので日本経済が即座に一様に崩壊した」としない。

## 4.4 金解禁を結果だけで評価しない

1930年の金輸出解禁は、その後の不況を知った後世から単純に「誤策」と断定するのではなく、

- 国際金本位制への復帰という当時の政策目標
- 為替・物価
- 財政規律
- 貿易
- 国際金融
- 国内の賛否

を区別する。

政策の意図と、実際に生じた結果を分ける。

## 4.5 中国政策では日本側の制度だけを書かない

北伐、南京国民政府、山東情勢、張作霖・張学良など中国側の政治・軍事的主体と選択を背景化しない。

山東出兵や済南事件を「日本が中国へ進出した」という一文へ縮約せず、現地情勢・居留民保護という日本政府側の説明・軍事行動・中国側の主権と政治統合をめぐる動きなどを区別する。

## 4.6 関東軍と日本政府を一枚岩にしない

張作霖爆殺事件では、現地軍の行動、陸軍中央、政府、天皇、政党政治上の責任処理を分ける。

後の満州事変を知っているからといって、1928年時点ですでに政府が一貫した満洲占領計画を共有していたかのようには書かない。

## 4.7 統帥権問題を「軍が政治を支配した」で終えない

ロンドン海軍軍縮条約では、

- 内閣の条約締結・外交政策
- 海軍省と軍令部
- 枢密院
- 政党間対立
- 天皇の制度的位置
- 世論・右翼運動

を区別する。

1930年時点の対立を、その後の政治秩序の結果から逆算して「この時点で憲政が終わった」とはしない。

## A14 1930年人口・都市化

**Status: implemented / Data Audit passed / Style Audit passed / Human Visual Audit exempt by reused point-pattern rule (2026-09-27)**

1920年人口地図A12との比較候補。

e-Stat / 総務省統計局で、昭和5年（1930年）国勢調査の第5巻「市町村別人口」と、市郡・市部郡部・人口階級別市町村数などの全国表が公的統計として確認できる。したがって1930年時点の自治体名と人口値は、A12と同様に公的統計へ固定できる。

一方、1920年と1930年の間には市制施行・合併・編入があり、同名自治体でも市域が同一とは限らない。現代市区町村polygonや1930年の境界を1920年へ遡及して、面積当たり人口や単純な増減率を塗り分ける方法は採用しない。

実装する場合は、1930年国勢調査の当時自治体を都市代表点で示し、A12と同じ人口階級・凡例設計を再利用する。1920年との比較は「同じpolygonの人口増減」ではなく、各調査時点の都市規模を並べる比較とし、市域変更が大きい都市には注記を付ける。

A14はJH25の「1930年国勢調査」節の直後に配置した。A12と同じMapLibreコンポーネント、人口階級、凡例、point interactionを再利用し、変更は1930年のpoint feature・ラベル・属性値に限定した。Data / Style Auditは実施し、Human Visual Auditは地図監査標準の再利用point-only例外により省略した。

監査する。

- 1930年国勢調査の市町村別人口を同一基準で抽出できるか
- 1920年と1930年で自治体の合併・編入・市制施行が異なることをどう扱うか
- 歴史的市域polygonを偽装せず、都市代表点または別の比較表現で都市成長を示せるか
- 1920年A12との比較が単なる「人口が増えた都市一覧」を超え、都市化・産業・交通の理解に寄与するか

## A15 山東・満洲をめぐる政治／軍事空間

**Status: completed / no-map for now (2026-09-27)**

JH24完成後に再評価した。山東・済南・北京・南京・奉天の位置関係は本文理解に有用だが、今回の中心は単なる都市位置ではなく、北伐の進行、山東出兵という軍事行動、南満洲鉄道の権益、関東州という租借地、張作霖爆殺事件地点を制度上異なる空間として区別することにある。

外務省『日本外交文書』、国立国会図書館の山東出兵閣議決定、アジア歴史資料センターの年表・関東軍解説から出来事・組織・時点は固定できる。一方、現在のリポジトリには、1927〜1928年時点の北伐進路・山東出兵範囲・南満洲鉄道線・関東州境界を、出典・基準時点・一般化精度つきで同一品質に再利用できるvector geometryがない。

主要都市だけを点で置くと、地図は位置確認以上の説明力を持たず、鉄道権益・租借地・軍事行動範囲を点記号へ潰すことになる。逆に歴史地図から独自トレースすると、法的地位・時点・位置精度を偽装しやすい。

したがってA15は現段階ではno-mapとする。JH24本文では、南京→山東→北京／奉天という政治的文脈と、政府決定の山東出兵／関東軍内部が主導した張作霖爆殺事件の意思決定経路を文章で分離する。

再検討条件：
- 南満洲鉄道・関東州について基準時点と法的地位を伴う再利用可能geometryがある
- 北伐・山東出兵を時点別に表現できる出典付き経路または範囲データがある
- 済南・奉天の事件地点について位置精度を明示できる
- 都市点・鉄道線・租借地polygon・軍事行動を別layer / 別凡例で表現できる

新規MapLibre実装はないため Data / Style / Human Visual Audit は対象外。

候補地点・空間：

- 山東
- 済南
- 北京・南京など北伐の政治的文脈
- 南満洲鉄道沿線
- 奉天
- 張作霖爆殺事件地点

ただし、

- 軍事行動範囲
- 鉄道権益
- 租借地
- 都市
- 事件地点

は地理的意味が異なる。

同じ点・線記号へ潰さず、基準時点・法的地位・位置精度・出典を揃えられる場合だけMapLibre化する。

地図化できない場合はno-map理由を記録し、本文で空間関係を説明する。
