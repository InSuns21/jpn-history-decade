## 1. 中心問いと観測軸

**中心問い：** 1942年10月末に軍中央が従来の戦争指導大綱を維持した後、11月の日本では政府の対外行政、陸海軍の作戦と補給、産業を統制する主体、船舶・資材・労力の配分と住民生活がどう変化したか。

政治史・政策決定を背骨に、**政治・権限、外交・占領地、軍事・輸送、産業・金融・労務、主食・衣料・地域の暮らし**を同じ期間の状態として観測する。官制日付だけで切らず、戦場で輸送可能性が独立して変わる11月12〜15日も区切りに採用する。戦闘の日付の列へ戻さず、海上輸送能力の変化が兵員の補充、工業原料の確保、予算・政策上の選択肢とどう関わるかを説明する。制度変更がない軸は短い継続状態として記し、全節を均等に埋めない。

各記事で **（A）当期に変わった状態／（B）継続する制約と負担／（C）次期への未決定事項** を区別し、史料により決定・公布・施行・実務上の実現を区分する。軍の作戦命令と閣議決定、東京の官制と占領地の軍政、工業生産の目標と実績、船の沈没と国内全体の配船能力を混同しない。

## 2. phase cutの史料上の根拠

1. **11月1日：大東亜省官制（勅令第707号）公布・同日施行。** 従来の拓務省・興亜院・対満事務局などの所管を組み替え、外務省に残る「純外交」と大東亜省の諸般の政務・在外公館への指揮監督権を区別する。省の発足を現地軍政の一斉移管と記述しない。9月1日の設置方針、9月11日の官制要綱からの実施段階を説明する。
2. **11月12〜15日：第三次ソロモン海戦（米側記録ではNaval Battle of Guadalcanal）。** 日本側は飛行場砲撃と増援輸送を企図し、戦艦・輸送船等を損失。日本軍のガダルカナルへの大規模船団補給能力が著しく狭まり、現地の糧秣・弾薬・兵員補充の条件が変わった。10月末時点の増援課題から新たな実行結果へ移る独立転換点。米側公刊史と防衛研究所の史料紹介を組み合わせ、戦果と補給実績を区別する。
3. **11月17日：閣議が官庁権限の統制会への委譲方針を決定。** 産業部門ごとの統制会へ許認可等の仕事を移す行政方針の変化。**行政官庁職権委譲令は1943年1月21日公布、2月1日施行**であり、1942年11月17日にその法令が施行されたように書かない。11月18日の日銀による政府保証軍需手形向け優遇措置は同時期の資金供給の別軸として観測する。
4. **11月27日：臨時生産増強委員会設置要綱と鉄鋼・石炭・アルミニウムの生産確保措置を閣議決定。** 委員会の対象は鉄・アルミニウム・石炭・船舶・航空機の5部門。鉄鋼等については商工・逓信・鉄道・厚生・農林・大蔵・陸海軍などに資材、電力、海陸輸送、労務・食糧確保の措置を割り振った。**目標・役所の分担と現場で達成された量は別**。原文は他産業や国民生活への影響を許容しており、工場・炭鉱労働者の生活物資の特配、労働者の配置・移動、朝鮮人労働者に関する統制措置も具体的に検討する。委員会の初会合は12月16日とされ、11月27日の決定と分離する。
5. **11月30日：ルンガ沖夜戦。** 日本側は米巡洋艦を撃沈する戦果を挙げたが、補給作戦の目的達成は別問題として残った。11月中旬の大型船団損耗後、駆逐艦中心の輸送を使う制約を観測する。**新しい内閣の制度変更を示す日ではない**ため単独記事への細分化はしない。
6. **12月10日：御前会議で「当面ノ戦争指導上作戦ト物的国力トノ調整並ニ国力ノ維持増進ニ関スル件」を決定。** 軍の作戦・物的国力・政府の戦争指導を結ぶ一段上の判断。今回の4記事を12月9日で閉じ、次フェーズの入口とする。12月21日の対中国処理方針、12月31日のガダルカナル撤退決定も次フェーズの候補として留保する。

**4本とする理由：** 11月1日は官制施行、12日はガダルカナルの海上輸送条件の重大な転換、17日は産業行政の職権委譲方針、27日は重要産業への優先配分という、それぞれ異なる主体・結果を伴う変化点である。12〜16日の5日間は短いが、輸送船団を使った増援の実行結果が作戦継続の制約を変えたため独立記事とする。11月30日の海戦を5本目にすると同じ補給課題を短期間で重ねやすいのでJH155内に置く。12月10日には作戦と国力について新たな最高レベルの政策判断があり、JH155の終点は12月9日が自然である。

**隣接接続：** JH151末尾の①大東亜省施行待ち、②次のガダルカナル増援・輸送、③戦争指導大綱維持下での配分という3論点をJH152の冒頭で各1〜2文の前提に圧縮する。JH152→153は船団準備から喪失・実行可能性への変化、JH153→154は現場の輸送喪失と国内の行政委譲方針が同時に進む状態、JH154→155は統制会への委譲方針から重点産業・省庁別の具体的な資材・輸送・労務配分へ移る状態としてつなぐ。隣接接続確認は各記事の実装内で完了させ、公開直後の重複監査を追加しない。

## 4. 記事実装時の確認

- **政治／統治：** 大東亜省と外務省の所管、関東局・南洋庁、占領地の現地軍政・軍の統帥を分ける。省庁再編とその実行能力を証拠なしに同一視しない。
- **軍事／海運：** 10月30日の大綱維持、11月中旬の輸送船損耗、30日の戦果と補給、軍徴用船A/B・国家使用船Cの配分を時点ごとに記述する。全国船腹減少などの定量評価は出典・対象範囲確認後に行う。
- **産業／労務：** 17日の委譲決定と翌年の施行を区別する。27日の原史料に即して5産業の委員会設置目的と、鉄鋼・石炭・アルミニウムの具体的な生産確保措置を分け、目標値を生産実績としない。労働者の供出・配置、朝鮮からの移入と移動制限は強制性・地域差・当事者を省略せず扱う。
- **国内生活／地域差：** 米穀通帳・衣料切符制度を継続観測。11月27日の重点部門への食糧・生活物資の特別配分を、全国全家庭の配給量変更と区別する。昭和館書誌が示す11月29日の東京の蔬菜配給要綱は、決定文書・適用範囲・施行方法を確認してから記述する。
- **占領地・対外関係：** 東京の新省が所管する行政と、南方各地の軍政・調達・労務を個別資料で具体化する。政府の意図と地域で実行された施策を分離する。
- **図版：** 官制・閣議文書、官報、輸送・工場・食糧配給の史料画像と写真を候補とする。各記事公開前に権利・説明上の必要性を判定し、採用しない場合は理由付きnoImage。
- **地図：** 既存A49（南太平洋広域）・A50（ガダルカナル周辺地点）で足りるか記事ごとに判断する。新しい海上輸送経路・産地と工場・港の流れなど地理的関係が中心問いになる場合にのみ採用し、Data / Style / Human Visual Auditの必要条件を満たす。
- **横断記事：** S05-E（政治参加）、S09-F（占領統治）、S10-D（資源配分）と新規横断記事の延長は**JH152〜155の記事成立後**に対象・史料・既存記事との役割重複を判定。毎回の定型増補はしない。
- **検証：** 各記事の原稿・用語ID・source ID・内部リンク・図版要否・隣接記事確認→`npm run check` →PR CI→merge→main CI→公開変更時のPages。phase-end独立監査は具体的な未解決仮説がある場合のみ。
