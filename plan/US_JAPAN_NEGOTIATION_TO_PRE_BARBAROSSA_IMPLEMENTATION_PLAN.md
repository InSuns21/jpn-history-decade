# 1. このフェーズを1941年4月23日〜6月21日に切る理由

4月22日、松岡外相は欧州・ソ連訪問から帰国し、その日の大本営政府連絡懇談会で「日米諒解案」を含む対米国交調整が政府内の正式な検討課題へ戻った。翌23日以後は、松岡、近衛首相、陸海軍、外務省、野村吉三郎駐米大使が、案の内容と三国同盟・中国戦争・南方政策との整合を詰める段階に入る。

5月3日の連絡懇談会では対米中間回答が了解され、松岡は野村へ、ハル国務長官にオーラル・ステートメントを示すとともに、野村自身の思いつきという形で日米中立条約案を提示して米国側の反応を見るよう訓令した。これは交渉打切りではなく、日本政府が4月案をそのまま受ける前に条件と米国側の反応を探る段階だった。

5月12日、日本政府は4月の「日米諒解案」へ修正を加えた日本側対案を正式に野村へ訓令し、野村はハルへ手交した。以後、日米双方は中国問題、三国同盟、欧州戦争、南方政策、通商・経済関係などをめぐって文言修正を続ける。

同時に南方では別の外交・経済回路が制度化された。5月6日、前年12月から続いていた日仏印正式経済交渉が妥結し、居住航海条約などの諸協定が調印された。5月9日には仏タイ平和条約が東京で調印され、3月11日の調停条項が正式な条約関係へ進んだ。外務省の整理では、日本は仏・タイ双方と保障・政治的了解に関する議定書を結び、日本に対抗する性質の協定を第三国と締結しないとの確約も得た。

6月になると南方政策の軍事的側面がさらに強まる。6月6日の対南方施策要綱は仏印・タイで軍事基地を確保する方向を含み、16日の連絡懇談会では松岡が南部仏印進駐の強行に難色を示した。17日には、1940年9月以来続いていた日蘭会商が正式に打ち切られた。18日には仏印資源開発の調査団派遣が閣議決定される。

この間も日米交渉は続き、6月1日（日本時間）には米国側対案が野村へ手交された。日米双方は修正案を往復させていたが、6月22日（日本時間）にはハルが5月31日案への米国政府訂正案とオーラル・ステートメントを野村へ手交する。同じ6月22日、ドイツはソ連への侵攻を開始する。対米交渉と三国同盟・日ソ中立条約の前提が同日に大きく動くため、**6月21日までを一つのフェーズ**とし、二つの衝撃は次フェーズの冒頭へ送る。

# 7. A37 — 仏タイ平和条約の国境・日本の調停保証 map necessity / data-quality judgment

JH86〜JH89実装後に判定する。

## 判定結果（2026-10-04）

**adopted / high。**

本文では、3月の東京調停で「どの地域が争点か」を追う段階から、5月9日の平和条約で「どの地理規則を組み合わせて国境を構成するか」へ情報状態が変わった。メコン河の主航路中央線、北緯15度、子午線、トンレサップ湖上の20km円弧という順序は、文章だけより地図で読む価値が高い。

一方、1941年5月時点の条約線を精密な測量済み境界として復元できるデータ状態ではない。条約は境界画定委員会の作業を予定しており、タイ外務省の外交史は新境界の標定完了を1942年7月11日としている。このためA37では、条約本文が直接指定する地理規則を **schematic / approximate** として可視化し、現代国境・現代州境の無注記流用は行わない。

A35は交渉過程のpoint-only地図として既に監査済みであり、A37は条約成立後のLineStringを含むため、同一definitionへ時点切替を追加せず別mapとした。JH86の `peace-treaty-boundary-structure` 直後へ配置し、A35との連続性は本文・popupで説明する。

- Map ID: `franco-thai-peace-treaty-1941`
- Data Audit: passed
- Style Audit: passed
- Human Visual Audit: pending-human（`HVA-013`）
- 公開状態: draft / 監査中表示
- 誤読防止: 条約規則の模式図であり、1941年5月の測量済み確定境界、日本の主権範囲、現代国境を表さない

## 地図候補

- 5月9日仏タイ平和条約が定めた国境線
- メコン川上の主たる航路中央線
- 北緯15度線
- シェムリアップ州・バッタンバン州境
- トンレサップ湖
- 3月A35で示した交渉対象地域との対応

## 判定基準

**map necessity は high candidate。**

3月時点のA35は、交渉途中案と主要争点地域をpoint-onlyで示した。5月9日の平和条約は国境線の構成を条文で具体的に定めており、ここでは**交渉対象の相対配置から、正式条約で確定した境界構造へ情報状態が変わる**。

条約本文に基づいてLineStringを作る場合も、現代行政境界を無注記で代用せず、
- 条文で明記された河川中央線・緯線・州境・湖上円弧
- 歴史的州境を現代境界から推測する部分
を属性と表示で区別する。

条約本文だけでは復元できない区間は approximate / schematic として明示し、精密な測量境界を主張しない。LineStringを採る場合はData / Style / Human Visual Auditを実施する。

既存A35を拡張する方が読者に連続性を示せる場合は、新規mapを増やすよりA35 definitionの時点切替・別レイヤ化を優先する。

# 8. Crosscutting publication gate

## S09「対外支配の制度差」— ✅ pass / extended

5月9日の仏タイ平和条約と同時の保障・政治的了解は、3月時点の「日本が外交調停を主導する」状態から一段進む。

延長する場合は、
- タイは独立国
- 仏印ではフランス植民地行政が存続
- 日本は直接統治権を取得していない
- 日本が将来の紛争調停・対第三国協定に関する政治的役割を制度化
という層を比較する。

「影響力」を領有・保護国・軍事占領と同じ色で扱わない。

## S10「産業社会の負担と保護」— ✅ pass / extended

5月15日の貿易統制令は、国家総動員法第9条の発動として対外貿易の行政統制を強める。

4月4日の物資動員計画から、
- 国内配当
- 輸入許可
- 外貨・第三国調達
- 貿易統制
がどう接続するかを比較できる場合は延長する。

日仏印経済協定・日蘭会商は「国外から何を調達できるか」という供給条件として接続し、外交記事の再編集にはしない。

### Crosscutting gate 判定結果（2026-10-04）

- **S09 pass**：1941年5月9日の仏タイ平和条約を、領有・租借・軍事駐留とは別の「主権・行政を移さず、第三国が調停・保障上の役割を制度化する」類型として追加した。タイの独立、仏印のフランス主権・植民地行政、日本の調停・保障を分離して比較する。
