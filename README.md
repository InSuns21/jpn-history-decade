# jpn-history-decade

**1800年から現代までの日本史を、10年単位を基本に社会構造の変化として読むプロジェクト。**

政治史を主軸に、経済・社会・人口・外交・軍事・技術・交通・情報・文化・災害・地理などを横断し、各時代を「その時点の人々から見た社会」として定点観測します。

## コンセプト

単なる出来事年表ではなく、各年代について次を追います。

- その時代の政治制度と権力関係
- 経済・人口・都市・農村・身分などの社会構造
- 外交・軍事・技術・情報環境による制約
- 前の年代から変わったこと／変わらなかったこと
- 同時代人にとっての「当たり前」
- 次の変化につながる構造的な課題や緊張

> 歴史を「事件の列」ではなく、社会システムの状態遷移として読む。

## 時間粒度

基本は10年単位です。

ただし、幕末・戦前戦中・占領期・現代など変化が速い時期は、5年・数年単位まで解像度を上げます。

## 地理・主題地図

地理情報が歴史理解に有効なテーマでは **MapLibre** を利用します。

地図は各年代に機械的に配置せず、藩領、街道、港、鉄道、都市人口、工業地域、災害、戦災、人口移動など、**空間構造そのものが論点になる場合だけ主題地図として使用**します。

## コンテンツ構成

- **年代史** — 各時代の社会を定点観測
- **テーマ史** — 経済・人口・外交・技術などを時代横断で追跡
- **構造史** — 幕藩体制、中央集権化、都市化、情報速度など長期構造を分析
- **主題地図** — MapLibre による空間構造の可視化
- **史料・出典** — 一次史料、公的統計、研究文献などへの導線

## まず扱う範囲

最初は **1800〜1850年代** を10年単位で作成し、江戸後期の社会構造がどのように変化したかを追います。

その後、幕末以降は歴史変化の速度に応じて時間粒度を細かくします。
