# 1. このフェーズを1940年12月1日〜1941年1月21日に切る理由

11月30日までに、日本政府は南京国民政府を正式承認し、国内では大政翼賛会と大日本産業報国会という全国組織を発足させていた。一方、両組織が実際に何を担うか、経済統制を企業・業界へどう組み込むか、蘭印・仏印からどのように資源を確保するかは未確定のまま残った。

12月7日、閣議は「経済新体制確立要綱」を決定した。要綱は公益優先、官民協力、生産力増強を掲げ、重要産業を中心とする経済団体を政府の政策立案・実施へ接続する方針を示した。企画院案をめぐっては企業の所有・経営への統制範囲が争点となっており、決定された要綱を「企業私有の即時否定」や単純な全面国有化として扱わない。

12月14日には「大政翼賛会実践要綱」が発表され、10月の発足時には未確定だった運動の実践方針が具体化した。ただし、翌1941年2月の公事結社認定・政治活動禁止や、その後の改組は後段階である。12月14日時点で大政翼賛会の法的位置づけが最終確定したとは書かない。

対外経済では、芳沢謙吉特使が12月28日にバタビアへ到着し、日蘭会商を新しい代表のもとで再開した。12月30日には東京で日仏印正式経済交渉も始まり、北部仏印進駐後の関係が通商・資源条件の交渉へ広がった。

1941年1月16日、芳沢代表は蘭側へ具体的要求事項を示した。外務省『日本外交文書』は、1月21日の松岡外相の議会演説に蘭側が強く反発し、対案提出を再検討して会商が停滞したと整理している。したがって、**国内新体制の具体化と南方資源交渉の再始動が進み、日蘭会商が再び停滞へ入る1月21日**をフェーズ終点とする。

# 6. A34 — 1940年12月〜1941年1月の南方資源交渉 map necessity / data-quality judgment

## 判定 — no-map

**map necessity: no-map / data-quality judgment: 地理精度ではなく、現在の中心問いと地図表現が一致しない。**

JH77〜JH79を実装した結果、この区間で読者が理解すべき変化は、資源産地の位置そのものより、**蘭印と仏印で異なる法的・軍事的前提のもと、資源・企業活動・交通・通信をめぐる交渉が別々の制度回路で進んだこと**にあると確認した。

### 候補別の判定

| 候補 | 地理データ | 判定 |
|---|---|---|
| 東京・バタビア・ハノイ | 都市の代表点は高確度で置ける | 不採用。三都市を線で結ぶと、外交交渉・資源輸送・軍事進駐という異なる関係を同じ「経路」に見せやすく、距離も中心問いではない |
| 蘭印の石油・ゴム・錫等の供給地域 | 蘭印が重要物資供給先であることは公的史料で確認でき、スマトラ・ボルネオ等への開発要求も第一次提案に現れる | 不採用。JH79の核心は産地分布より、入国・鉱業・漁業・企業活動・沿岸航海・航空・通信という制度条件へ要求が広がった点にある。産地面だけを強調すると交渉の射程を狭く見せる |
| 日本向け資源輸送経路 | schematic LineStringは作成可能 | 不採用。1941年1月時点の会商は将来の供給条件・活動権を交渉中であり、一本の輸送線を置くと確定済みの物流回廊が存在したかのように見せる |
| 仏印の資源供給地・港 | 港や主要都市は置ける | 不採用。正式経済交渉は12月30日に始まった段階で、5月の協定成立やその後の資源調査を先取りして資源分布を交渉結果のように見せるべきではない |
| 蘭印・仏印の領域polygon | 概略polygon自体は作成可能 | 不採用。蘭印は外交交渉中心、仏印はフランス植民地行政存続下に日本軍駐留が重なる状態であり、同じ面表現へまとめると制度差を弱める |

### data-quality judgment

東京・バタビア・ハノイのpoint、蘭印・仏印のおおまかな地域polygon、資源・交通のschematic geometryは、現行のMAP_AUDIT_STANDARD.mdが許容する approximate / schematic 表現で作成できる。したがって、今回のno-mapは「完全なGeoJSONがない」「境界精度が足りない」という理由ではない。

問題は、地図が支えられる主張の上限にある。

- 日蘭会商の第一次提案は、石油等の買付量だけでなく、入国、企業活動、鉱業・漁業、航空、沿岸航海、通信など複数の制度条件を扱う。
- 日仏印正式経済交渉は継続中であり、1941年1月21日時点では5月の協定成立前である。
- 蘭印と仏印では、日本軍駐留の有無、植民地行政との関係、交渉の圧力条件が異なる。

この状態をMapLibreで表すために地図線・面を増やすと、**交渉対象の位置関係より制度関係の種類を読み違える危険の方が大きい**。A33と同様、必要なら制度関係図の方が適する。

### 今後の再判定条件

A34自体はno-mapで閉じる。ただし、1941年春〜夏に以下がそろった段階では、別の地図工程として再判定する。

- 日蘭会商の対案・第二次提案・打切り
- 日仏印経済協定成立
- 南部仏印進駐
- 英米蘭の資産凍結・輸出制限
- 石油・ゴム・錫等の供給地、港、航路が政策選択の制約として本文の中心問いになること

その時点なら、単なる「交渉都市」ではなく、**資源供給圏・港・海上輸送・軍事進駐の位置関係が外交選択肢をどう狭めたか**という独立した空間問いを立てられる。

### 監査工程

A34はno-mapのため、GeoJSON / map definitionを追加せず、Data Audit / Style Audit / Human Visual Auditは発生しない。

次工程は **Crosscutting publication gate** とする。

# 7. Crosscutting publication gate

## 判定

**S05 / S10 を延長、S09 / S02 は hold、新規横断記事は追加しない。**

JH77〜JH79を年代記事として完成させたうえで、出来事の再掲ではなく既存横断記事の比較軸そのものが増えるかを判定した。

### S05「政治参加の回路」— pass

前フェーズまでのS05は、政党解体後も帝国議会・議員資格が残る一方、10月12日に大政翼賛会という全国組織が置かれたところまで扱っている。

12月14日の[[term:taisei-yokusankai-practical-guidelines-1940|大政翼賛会実践要綱]]と12月16〜18日の[[term:temporary-central-cooperation-council-1940|臨時中央協力会議]]によって、この全国組織は「存在する組織」から、中央の方針を地方・職域へ伝え、地方・各分野の意見を中央へ集約する協議回路を実際に動かす段階へ進んだ。

S05へ加える比較軸は、実践要綱の項目を再掲することではない。**政党の地方支部・議員団が担っていた継続的な意見集約回路が失われた後、大政翼賛会の支部・協力会議が別種の参加・動員回路として運用され始めたこと、ただし立法権・行政権や候補者選定機能まで同一ではなかったこと**を比較する。

1941年2月の公事結社認定・政治活動禁止や、その後の改組は後段階として残す。

したがってS05は1941年1月21日まで延長する。

### S10「産業社会の負担と保護」— pass

前フェーズまでのS10は、価格・賃金・資産・物資等への行政統制と、大日本産業報国会による職場単位の勤労動員・労務秩序を別の層として扱っている。

12月7日の[[term:economic-new-system-outline-1940|経済新体制確立要綱]]は、ここへさらに**企業・業界団体を政府の経済政策の立案・実施へ接続する中間組織**という層を追加した。これは個々の企業へ命令を出すだけでも、職場内の労務組織を整えるだけでもない。

S10では次の三層を分けて比較できる。

1. 価格・賃金・資産・物資等への直接的な行政統制
2. 大日本産業報国会による職場・労務単位の継続的組織化
3. 経済新体制による企業・業界団体と政府の政策回路の組織化

ここで重要なのは、経済新体制を企業の即時国有化・私有財産廃止として扱わず、**企業活動の裁量をどの組織経路で国家計画へ接続するかという統制の形の変化**として比較することである。

したがってS10は1941年1月21日まで延長する。

### S09「対外支配の制度差」— hold

JH78〜JH79では、蘭印と仏印の制度条件の違いを明示した。

- 蘭印：オランダ植民地政府との外交交渉。日本軍は駐留していない。
- 仏印：フランス植民地行政が存続しつつ、日本軍が北部へ駐留している。その上で正式経済交渉が進む。

ただし、この制度差自体は北部仏印進駐までにS09へ既に導入済みである。1940年12月30日の正式経済交渉開始、1941年1月16日の芳沢第一次提案、1月21日の会商停滞は重要だが、**新しい支配権・駐留権・行政権・外交承認が成立したわけではない**。

日仏印経済協定が成立する5月、日蘭会商が打ち切られる6月、南部仏印進駐と資産凍結が続く7月には制度状態が大きく変わるため、その段階で再判定する。

したがってS09は今回延長しない。

### S02「石高制・貨幣経済・財政」— hold

経済新体制と南方資源交渉は、企業・業界組織、資源輸入、通商条件の再編として重要である。

しかし1941年1月21日までのこの区間では、S02が追う租税、公債、通貨制度、中央銀行信用、特別会計などに新しい制度状態は確認できない。資源不足や輸入制約が財政へ影響することと、財政金融制度そのものの状態遷移は分ける。

したがってS02は今回延長しない。

### 新規横断記事 — no

「南方資源外交」を独立記事にすると、現段階ではJH78〜JH79の再編集になりやすい。

1941年春〜夏には、日蘭会商の対案・第二次提案・打切り、日仏印経済協定、南部仏印進駐、英米蘭の資産凍結・輸出制限まで一続きの比較材料がそろう。**外交交渉で資源を得る回路が、経済制裁と軍事進駐によってどのように閉じていくか**という長期軸を立てられる段階で新規横断記事を再判定する。

## 次工程

**S05 / S10 extension** を実装する。S09 / S02と新規横断記事には変更を加えない。

# 8. phase-end audit necessity judgment

## 判定 — no-audit

独立したフェーズ末監査は実施しない。

計画時に挙げた候補をJH77〜JH79、A34、S05、S10と突き合わせた結果、いずれも各年代の隣接接続確認またはCrosscutting publication gate / extensionで解消済みだった。

- **経済新体制確立要綱＝企業の即時国有化／私有財産の廃止**：JH77とS10で「企業ハ民営ヲ本位」、企画院案の「所有と経営の分離」が最終要綱へ採用されなかったこと、企業・業界団体を国家計画へ接続する制度再編であることを分離済み。
- **大政翼賛会実践要綱＝一党制の法的完成**：JH78とS05で、12月14日は活動方針と協力会議の運用具体化であり、1941年2月の公事結社認定・政治活動禁止は後段階として分離済み。
- **芳沢第一次提案＝蘭印資源の確保成功**：JH79で、1月16日は具体的要求の提示段階であり、蘭側が対案提出を検討していた交渉中の状態として記述済み。
- **1月21日の蘭側反発＝日蘭会商の正式打切り**：JH79で1月21日を会商停滞、正式打切りを6月17日として時点分離済み。
