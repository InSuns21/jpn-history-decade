# 1. このフェーズの位置づけ

前フェーズは1911年までを扱い、

- 帝国議会と政党の政策交渉
- 日清・日露戦争後の財政・公債・国際金融
- 金本位制
- 台湾・韓国・関東州・南満洲鉄道の制度差
- 1910年韓国併合
- 1911年関税自主権回復
- 1911年工場法公布

までを公開品質化した。

1912年以降は、明治国家の制度を「作る」段階ではなく、その制度の上で、

- 内閣と政党の関係
- 産業化と労働・生活問題
- 選挙と議会外の政治参加
- 植民地統治と被支配地域の運動
- 第一次世界大戦と国際秩序
- 災害と治安・情報
- 都市化と大衆社会

が同時に変化する段階として扱う。

終点は1925年とする。

1925年には衆議院議員選挙法改正によって男子普通選挙が制度化される一方、治安維持法も成立する。政治参加の入口が広がることと、国家が許容する政治活動の範囲が同時に再定義された時点であり、1912年から続く政治参加・社会運動・治安政策の変化を一区切りにできる。

1926年以降は、普通選挙の実施、昭和金融恐慌、田中義一内閣、満州事変へ向かう別フェーズとして扱う。

# 2. このフェーズの中心問い

フェーズ全体では次を追う。

1. 政党が議会内で影響力を増しても、内閣・軍・貴族院・官僚・元老との権限関係はどう残ったか。
2. 第一次世界大戦は日本の産業・貿易・財政・労働市場・都市生活をどう変えたか。
3. 工場法施行、労働運動、女性運動、農民運動は、産業社会の負担をどの制度へ持ち込もうとしたか。
4. 1918年米騒動は、物価・流通・地域社会・警察・新聞・政党政治をどう接続したか。
5. 原敬内閣を「本格的政党内閣の完成」とせず、どこまで政党政治が政府運営へ入り、何がなお別の権力基盤に残ったか。
6. 朝鮮・台湾などの植民地統治は、第一次世界大戦後の民族運動・統治方針の変更によってどう変わったか。
7. ワシントン体制は軍縮と協調だけでなく、中国・太平洋・植民地・海軍・国内政治へどのような制約を与えたか。
8. 1923年関東大震災では、災害対応・流言・治安・メディア・暴力・復興行政がどう結びついたか。
9. 1925年の普通選挙法と治安維持法を、民主化と反動という二語だけでなく、政治参加の拡大と統制対象の再設定としてどう理解するか。

# 3. 歴史記述の中心原則

## 3.1 「大正デモクラシー」を完成へ向かう物語にしない

政治参加は拡大したが、

- 衆議院だけが国家権力の唯一の基盤ではない
- 貴族院、軍、官僚、元老、枢密院などが残る
- 女性参政権は実現していない
- 植民地住民に内地と同じ国政参政権が一様に与えられたわけではない
- 治安立法・警察行政による統制も並行する

ことを維持する。

「政党政治が発達した → 民主主義が完成した」という直線にはしない。

## 3.2 第一次世界大戦を「好景気の原因」だけにしない

戦争は、

- 欧州からの輸入減
- アジア市場での輸出拡大
- 海運・造船・重化学工業
- 物価上昇
- 労働需要
- 実質生活費
- 貿易・金融
- 中国政策
- 海軍・軍需

を異なる経路で変えた。

「戦争景気」で一括せず、誰が利益を得て、誰が物価上昇や労働条件の負担を受けたかを分ける。

## 3.3 米騒動を単一事件・単一原因にしない

1918年の米騒動は地域差が大きい。

- 米価
- 流通
- 投機・買占めへの認識
- 出兵・軍事需要
- 家計負担
- 地域の商取引
- 新聞報道
- 警察・軍の対応

を分け、全国で同じ主体・同じ要求だったようには書かない。

## 3.4 原敬内閣を現在の議院内閣制と同一視しない

政友会を基盤とする政党内閣であることは重要だが、

- 首相任命
- 元老
- 貴族院
- 軍
- 官僚
- 枢密院

の制度的基盤が残る。

「選挙で多数を取った党が自動的に政権を作る」現在の制度へ遡及しない。

## 3.5 植民地統治を内地政治の付記にしない

朝鮮では1919年三・一運動とその後の統治方針変更、台湾でも政治・社会運動と植民地行政の変化を、現地社会の主体を含めて扱う。

日本側公文書だけでなく、韓国国史編纂委員会、國史館臺灣文獻館など被支配地域側の史料・研究へ接続する。

## 3.6 関東大震災では災害と暴力を分離しない

地震・火災・避難・行政機能の混乱だけでなく、

- 流言
- 警察・軍・自警団
- 朝鮮人・中国人・社会運動家への暴力
- 報道
- 戒厳
- 復興行政

を検証可能な範囲で区別して扱う。

被害数・殺害数は定義と推計差を確認し、未確定値を単一の正確な数として書かない。

## 3.7 普通選挙法と治安維持法を「前進と後退」の一言で終えない

1925年の二法は同じ政治状況の中で成立するが、単純な一対の因果として扱わない。

- 誰に選挙権が拡大したのか
- 誰はなお排除されたのか
- 何を取り締まり対象として制度化したのか
- 政党政治・社会運動・植民地統治との関係は何か

を分けて扱う。

## A12 1920年人口・都市化

都市点・人口規模だけで中心問いを改善できるか再評価する。

## A13 関東大震災

- 避難
- 復興区域
