# 1. このフェーズを1937年8月13日〜11月12日に切る理由

前フェーズは8月12日、上海で本格交戦が始まる直前で止めた。外務省外交史料館は、8月13日に上海で日中両軍の交戦が始まり、14日に全面的な軍事衝突へ発展し、15日に日本政府が中国政府に対して強硬な措置をとる旨の声明を出したと整理している。

この境界では、華北の局地事件を現地解決する余地を探る段階から、華中の国際都市上海を含む複数戦線で軍事行動を継続する段階へ制度状態が変わる。

その後も一枚岩ではない。

- 8月中旬：上海で交戦開始。陸軍増派・海軍作戦・政府声明が接続する
- 8月下旬〜9月10日：増援と戦線拡大に加え、軍需工業動員、臨時軍事費特別会計、資金・為替・輸出入統制など国内制度が戦時対応へ組み替えられる
- 9月下旬〜10月25日：中国側では第二次国共合作が公表され、国際連盟でも日本の軍事行動が問題化する。日本側では支那方面艦隊・企画院など軍事・政策調整の中央化が進む
- 11月初旬：杭州湾上陸を含む作戦で上海正面の戦況が変わり、11月12日に日本軍が上海を占領する

11月12日は、約3か月続いた上海戦の軍事状態が大きく切り替わる境界である。ただし南京国民政府は存続し、11月20日の重慶への遷都表明、南京への進攻、トラウトマン工作の展開はその後の状態である。

したがって本フェーズは、

```text
8月13日 上海で交戦開始
→ 8月15日 政府方針の強硬化
→ 増援・航空／海上作戦・戦線拡大
→ 9月 戦時財政・資金・輸出入統制の制度化
→ 9〜10月 中国側抗戦体制・国際問題化／日本側指揮・企画機構の再編
→ 11月初旬 杭州湾方面から作戦条件が変化
→ 11月12日 上海占領
```

として扱う。

11月13日以後の南京進攻、11月20日の遷都表明、南京占領、トラウトマン工作の帰趨、1938年1月16日の第一次近衛声明は次フェーズへ送る。

# 3. JH40 — 1937年8月13日〜15日

## 中心問い

> 上海での交戦は、なぜ華北の戦闘とは別の危機として国家政策を変え、8月15日の政府声明へ接続したのか。

## 必須テーマ

- 8月13日の上海での日中両軍交戦開始
- 8月14日の全面的軍事衝突
- 日本海軍特別陸戦隊と中国側中央軍・保安部隊の制度的位置
- 上海共同租界・フランス租界・中国側市街が近接する国際都市条件
- 英米など第三国権益と、戦闘回避の外交が失敗した経過
- 8月15日の日本政府声明は、当時の政府表現として引用・説明し、サイト側の評価語として使わない
- 華北の「現地解決・不拡大」から何が変わり、何がなお残ったか
- 海軍の現地行動、陸軍増派、政府・外務省の判断を一主体にまとめない
- 中国側も上海現地部隊、南京国民政府、蒋介石の中央判断を分ける
- 民間人・租界居住者への戦闘影響を、確認できる史料の範囲で扱う。死傷者数は出典・対象範囲が一致しない限り精密数値を置かない

## JH39→JH40 接続確認

JH39は8月12日時点で、華北では大規模作戦が進んだ一方、上海では大山事件後も交戦回避の外交努力が残っていた状態で終わる。

JH40は翌13日の交戦開始から始める。したがって「大山事件が自動的に上海戦を起こした」とせず、現地兵力、租界、中央軍投入、日中双方の判断、第三国外交が重なって交戦へ移ったことを示す。

# 4. A21 — 1937年8月の上海都市政治・軍事空間

**Status: completed / 2026-09-28**

## map necessity 判定

**採用 / high。**

上海戦初期では、上海共同租界、フランス租界、中国側市街、虹口・閘北・江湾、黄浦江・呉淞口、日本海軍陸戦隊拠点、中国側主要展開地域の近接そのものが、軍事行動と第三国外交を理解するための条件になる。

単純な「上海」という一点では、

- なぜ日本海軍陸戦隊の拠点と中国側部隊が都市内部で近接したか
- なぜ租界への戦闘波及が第三国外交の問題になったか
- なぜ華北とは異なる軍種・統治空間を持つ戦場だったか

を説明できないため、本文だけより地図の寄与が大きい。

## Data Audit 判定

**pass。ただし、精密な戦線復元ではなく「租界polygon＋軍事・地理地点point」の混合表現に限定する。**

### 1. 上海共同租界

Virtual Shanghai の Resource ID 224「Police districts in the International Settlement (1928-1934 and 1935-1945)」は、1935〜1945年の共同租界警察区13区を shapefile で提供している。

- source: https://www.virtualshanghai.net/Data/Tables?ID=224
- license: CC BY 4.0
- temporal coverage: 1935–1945
- 利用方針: 1935–45年警察区polygonを dissolve / union して共同租界の外周を導出する
- geometryConfidence: derived
- 個々の警察区を1937年の軍事境界として扱わず、共同租界の統治空間を示すためだけに用いる

### 2. フランス租界

Virtual Shanghai の Resource ID 223「Census districts in the French Concession (1937)」は、1937年人口調査に用いられた270 census block のvector mapを shapefile で提供している。

- source: https://www.virtualshanghai.net/Data/Tables?ID=223
- license: CC0 1.0
- temporal coverage: 1937
- 利用方針: census block polygonを dissolve / union して1937年フランス租界の外周を導出する
- geometryConfidence: derived
- 人口調査区内部の細分はA21の中心論点ではないため表示しない

### 3. 同時代都市地形・地名

国立国会図書館は大日本帝国陸地測量部「二万分一上海市街圖」を所蔵している。

- source: https://ndlsearch.ndl.go.jp/books/R100000002-I000008307139
- publication: 1937.8
- scale: 1:20,000
- 利用方針: 虹口・閘北・江湾・黄浦江・呉淞口などの同時代地名・位置関係の照合に使う
- スキャンを無根拠にトレースして道路・行政界・戦線geometryを生成しない

### 4. 1937年8月の兵力配置

Virtual Shanghai eAtlas ID 274「Initial position of Japanese and Chinese troops in August 1937」は、1937年8月初期の日中両軍配置と共同租界・フランス租界の位置関係を1:20,000で示している。

- source: https://www.virtualshanghai.net/Maps/eAtlas?ID=274
- author: Christian Henriot
- cartographer: Nicolas Bozon
- 利用方針: 軍事地点の大まかな地区配置を研究上のクロスチェックに使う
- eAtlas画像の線・面をトレースして再配布可能geometryへ変換しない
- 中国軍防御線・部隊線は連続LineStringとして実装しない

### 5. 中国側市街

Virtual Shanghai 自身が、1937年の中国側Municipalityについては対応するcensus survey mapが現存しないと説明している。そのため、

- 「中国側市街」全体を精密polygonで塗らない
- 南市・閘北・江湾など本文理解に必要な地区は representative / approximate point として扱う
- 現代上海行政界を1937年の境界として代用しない

## 実装時のgeometry方針

A21を実装する場合は次に限定する。

| 対象 | geometry | confidence |
|---|---|---|
| 上海共同租界 | 1935–45 police district polygonsをunionしたPolygon / MultiPolygon | derived |
| 上海フランス租界 | 1937 census block polygonsをunionしたPolygon / MultiPolygon | derived |
| 海軍特別陸戦隊司令部・虹口・閘北・江湾・呉淞口など | representative Point | approximate |
| 中国側部隊 | 部隊線を描かず、史料で地区まで確認できる場合だけapproximate Point / area | approximate |
| 中国側市街全体 | **描かない** | — |
| 戦闘前線・進軍路 | **描かない** | — |

polygonを含むため、point-only再利用規則は使わない。実装した場合はData Audit / Style Auditに加え、Desktop / Tablet / Mobileを含むHuman Visual Auditを必須とする。

## 判定結果

**A21は地図あり。データ品質は限定条件つきで実装可能。**

核心は「精密な上海戦線図」を作ることではなく、**共同租界・フランス租界という外国統治空間と、日中両軍の主要地点がどれほど近接していたかを可視化すること**に置く。

ライセンスが明示されたHistorical GISを利用できる租界境界と、概略精度しか保証できない軍事地点を同じ精度に偽装しない。これにより、A21を空間理解に有効な地図として採用しつつ、史料以上の精密さを避ける。

# 8. A22 — 上海・杭州湾の作戦空間

**Status: completed / 2026-09-29**

## map necessity 判定

**採用 / high。**

JH43の状態変化は、上海正面だけを見ても説明しにくい。杭州湾北岸への上陸によって、上海正面の南西側に別の作戦軸が生じ、上海・松江・金山衛・蘇州・嘉興方面の位置関係そのものが中国軍の側背・退路条件を変えた。

防衛研究所の戦史叢書第72巻は「杭州湾上陸作戦（H作戦）」を独立節として扱い、第86巻は上海方面の作戦拡大を「対支全面作戦への転移」の流れで扱う。また、防衛研究所の戸部良一論文は、第10軍が1937年11月5日に杭州湾へ上陸し、上海戦線の中国軍の側背を脅かしたことを整理している。

したがってA22の核心は、戦闘日誌を地図化することではなく、**上海正面と杭州湾北岸の位置関係がなぜ作戦条件を変えたのか**を読者が一目で把握できるようにすることにある。

## Data Audit 判定

**pass。ただし「主要地点のapproximate point＋本文注記」を上限とし、進軍路・退却路のLineStringは実装しない。**

### 1. 同時代の地域地図

国立国会図書館は大日本帝国陸地測量部「上海蘇州近傍圖」を所蔵している。

- source: https://ndlsearch.ndl.go.jp/books/R100000002-I000008300106
- publication: 1937.9
- scale: 1:100,000
- 利用方針: 上海・蘇州・松江などの位置関係、同時代地名、主要交通軸の照合に用いる
- 地図画像をそのまま再配布するのではなく、地点・位置関係のクロスチェック資料として使う

国立国会図書館の外邦図目録には、同じ陸地測量部による1:250,000「上海杭州近傍圖」も1937年資料として掲載されている。

- source: https://ndlsearch.ndl.go.jp/rnavi/maps/post_307
- scale: 1:250,000
- temporal coverage: 1937
- 利用方針: 上海から杭州湾北岸・杭州方面までを一枚で確認し、A22の広域位置関係を照合する
- 中央研究院デジタル典蔵にも同名図があり、1937年11月刊行・1:250,000と記録されている
- 1937年11月刊行図は作戦当日の一次的な配置図ではないため、部隊位置・進軍線の直接根拠には使わない

### 2. 杭州湾上陸作戦

防衛研究所の戦史叢書第72巻『中国方面海軍作戦〈1〉昭和十三年四月まで』は、第五章第一節として「杭州湾上陸作戦（H作戦）」を置いている。

- source: https://www.nids.mod.go.jp/military_history_search/SoshoView?kanno=072
- 利用方針: 上陸作戦の存在、海軍側の作戦構成、作戦時期の確認に使う
- 作戦図をそのままGISのline / polygonへトレースしない

戦史叢書第86巻『支那事変陸軍作戦〈1〉昭和十三年一月まで』は、上海方面への派兵・中北支戦線の拡大・十月の攻勢・全面作戦への転移を扱う。

- source: https://www.nids.mod.go.jp/military_history_search/SoshoView?kanno=086
- 利用方針: 陸軍側の作戦段階と上海戦終盤の位置づけを確認する
- 日本側戦史のみで中国側の意図・退却理由全体を確定しない

防衛研究所の研究報告「日中戦争の拡大と日本陸軍 1937年7月〜1938年10月」は、第10軍が11月5日に杭州湾へ上陸し、上海戦線の中国軍の側背を脅かしたことを整理している。

- source: https://www.nids.mod.go.jp/event/proceedings/forum/pdf/2019/02_tobe.pdf
- 利用方針: 「上陸によって上海正面の空間条件が変わった」というA22のhistoricalQuestionを裏づける
- 論文の概説を精密な部隊経路の根拠にはしない

### 3. 上陸地点・主要地点の位置精度

A22で必要なのは、少なくとも次の位置関係である。

| 対象 | geometry | confidence | 用途 |
|---|---|---|---|
| 上海 | representative Point | derived / approximate | 上海正面の基準 |
| 松江 | representative Point | derived / approximate | 上海南西側の主要地点 |
| 金山衛付近 | approximate Point | approximate | 11月5日上陸の代表位置 |
| 蘇州 | representative Point | derived / approximate | 上海西方・退路側の位置関係 |
| 嘉興 | representative Point | derived / approximate | 杭州湾北岸から西方への広域関係 |
| 杭州湾 | ラベルのみ | approximate | 上陸海域の識別 |

地点座標は、同時代地図上の集落位置を基準にクロスチェックして採る。現在の行政区中心・駅位置・道路交差点などを1937年地点の代用品として無注記で使わない。

### 4. 海岸線・経路の扱い

A22では次を**描かない**。

- 上海正面の連続戦線
- 中国軍の退却路
- 第10軍の進軍路
- 「包囲」を示す閉じたpolygon
- 1937年海岸線としての現代海岸線geometry

MapLibreの背景地図が現代地形を表示する場合は、公開注記で「背景地図は現在の位置参照であり、1937年の海岸線・行政界を示さない」と明示する。

同時代地図で経由地を確認できても、道路・堤防・水路に沿う精密routeが確定しない限りLineStringへ昇格させない。A1で問題になったような、少数地点を直線で結んだ「もっともらしい進軍路」は作らない。

## 実装時のgeometry方針

**point-onlyを基本とする。**

A22が説明するのは「どの道を何km進んだか」ではなく、**上海正面に対し、杭州湾北岸から別軸が成立したという位置関係**である。主要地点をpointで示し、popup / 本文で「上陸」「上海正面」「退路側」を説明する方が、史料の精度と読解目的に合う。

既存のHuman Visual Audit済みpoint地図と同じmarker・label・popup・touch interactionを再利用し、変更がpoint featureだけなら、MAP_AUDIT_STANDARDの再利用規則により個別Human Visual Auditを省略できる。line / polygonを追加する場合はこの例外を失い、Data / Style / Human Visual Auditをやり直す。

## 判定結果

**A22は地図あり。データ品質はpoint中心表現なら実装可能。**

1937年の同時代地域図で主要都市・湾岸の位置関係を照合でき、防衛研究所資料で杭州湾上陸作戦と上海正面への作戦上の影響を確認できる。一方、精密な進軍路・退却路・前線geometryを公開できるだけの再利用可能なGIS根拠は確認できない。

したがって、A22は**「広域の位置関係は地図化する／作戦線は地図化しない」**という境界で採用する。

# 9. Crosscutting publication gate

**Status: completed / 2026-09-29**

JH40〜JH43を踏まえ、年代記事の時系列を並べ替えるだけの横断記事は作らず、既存記事の長期比較軸が実際に更新される場合だけ延長した。

## publication gate 判定 — 2026-09-29

| 候補 | 判定 | 理由 |
|---|---|---|
| S02「石高制・貨幣経済・財政」 | **延長** | 7〜8月の一般会計追加予算から、9月の臨時軍事費特別会計へ移り、戦費を一般会計と分けて「事変」終結までを一会計年度として処理する枠が成立した。単なる軍事費増加ではなく、継続戦費をどの会計・公債で処理するかというS02固有の比較軸が更新された。 |
| S05「政治参加の回路」 | **延長** | 上海への派兵・作戦判断は政府・軍の回路で進む一方、第72回帝国議会は臨時軍事費特別会計、資金調整、為替・輸出入統制などを法制化した。「作戦を誰が決めるか」と「戦争継続の権限を誰が法律にするか」を分けて比較できるため、既存の中心問いが更新された。 |
| S10「産業社会の負担と保護」 | **延長** | 7〜8月の税・公債による費用負担に加え、臨時資金調整、為替、輸出入、軍需動員によって、資金・外貨・輸入物資・生産能力の用途へ優先順位をつける制度が成立した。「誰が払うか」から「誰が限られた資源を使えるか」へ負担配分の比較軸が広がった。 |
| S09「対外支配の制度差」 | **延長しない** | 11月12日の上海占領は軍事状態を変えたが、このフェーズ内では上海を新しい安定統治制度・法的地位として比較できるだけの制度形成は扱っていない。占領行政・租界との制度関係・新たな政治機構が具体化した段階で再判定する。 |
| 新規「戦時動員体制」 | **新規作成しない** | 1937年9月の制度群は重要だが、S02が財源・会計、S05が議会と意思決定、S10が民間資金・物資の配分をそれぞれ扱える。現段階で新規記事を作るとJH41の制度列挙を再編集しやすく、1938年の国家総動員法などを含む長期比較軸が成立した時点で再判定する方がよい。 |

通過したS02・S05・S10だけを1937年11月12日まで延長した。S02は**国家が戦費を何で、どの会計で調達するか**、S05は**作戦判断と議会立法がどこで別れ、どこで接続するか**、S10は**資金・外貨・物資の優先配分が民間の選択条件をどう変えるか**を担当し、同じ9月10日の法令を三記事で時系列再要約しないよう役割を分けた。

## phase-end audit necessity judgment — 2026-09-29

**独立監査は不要と判定する。**

JH40〜JH43の隣接接続は各年代ページの実装時に確認済みで、publication gateでは横断記事との役割重複を明示的に確認した。今回残り得た具体的な横断問題は、S02とS10が戦時経済制度を重複して説明すること、S05がJH41の第72回帝国議会節を再要約することだった。

これに対し、S02を「財源・会計」、S05を「意思決定と立法の制度回路」、S10を「民間資金・物資の配分」と分離し、各記事本文にも役割差を明記した。S09は制度比較の材料が成立していないため延長せず、新規「戦時動員体制」も年代記事の再編集になるため作成していない。

したがって、複数年代・横断記事を同時に再監査しなければ検出できない具体的な未解決仮説は残っていない。規約どおり、理由のないフェーズ末全体監査は追加せずCI / Pages確認へ進む。
