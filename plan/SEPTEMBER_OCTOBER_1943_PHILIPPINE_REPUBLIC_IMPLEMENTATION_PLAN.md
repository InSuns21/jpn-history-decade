## 中心問い

1943年9月に現地政治家が憲法を採択し、占領下の政治組織が承認し、議会・大統領の人事を整える一方、日本軍は作戦・駐留・輸送と占領秩序の維持に関与した。制度上の政治的独立を設ける過程で、議会の代表選出、実際の行政、対日協力・軍事権限、各地の抵抗がそれぞれどの組織の責任に置かれたかを追う。

8月のJH172で、ビルマは独立宣言・政府発足まで進み、フィリピンは憲法起草の準備段階にあった。新フェーズではフィリピンの憲法採択から独立宣言までの**異なる段階**を混同しない。国内の企業整備・物資統制の一般的説明を繰り返すことは避け、現地政府に生じる固有の義務・資源利用だけを扱う。

## 予定記事数と粒度

10月記事を開始する際は `npm run audit:previous -- --next JH174` 相当のJH173全文追跡査読を通常の執筆工程に含める。公的史料間で10月の共和国発足日・式典日・条約の日付が異なる場合は、先に用語の違いと個々の原文を照合して境界を再判定する。フィリピンの地域差と抵抗運動は、日本軍に協力した政治家だけで住民全体を代表させず、具体的な資料が得られた範囲で記述する。
