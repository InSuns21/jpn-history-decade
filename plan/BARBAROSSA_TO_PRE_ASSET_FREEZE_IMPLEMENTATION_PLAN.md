# 1. このフェーズを1941年6月22日〜7月24日に切る理由

6月21日まで、日本政府は南部仏印への進駐構想を内部で検討しながら、日米交渉も継続していた。6月22日（日本時間）、野村吉三郎駐米大使はハル国務長官から、5月末の日本案に対する米国側の修正案とオーラル・ステートメントを受け取った。これは交渉の即時打切り通知ではなく、なお非公式・予備的な交渉文書の往復だった。

同じ6月22日、ドイツがソ連へ侵攻した。日本にとっては、4月の日ソ中立条約と9月以来の日独伊三国同盟を同時に抱えたまま、北方と南方の優先順位を再検討する必要が生じた。独ソ戦開始をもって日ソ中立条約が自動的に消滅したわけでも、日本が即時に対ソ参戦を決めたわけでもない。

6月25日の大本営政府連絡懇談会は「南方施策促進ニ関スル件」を決定し、南部仏印への進駐を具体的な政府・統帥部方針へ引き上げた。7月2日の御前会議では「情勢ノ推移ニ伴フ帝国国策要綱」が決定され、南方政策を進めながら独ソ戦の推移にも備える枠組みが置かれた。ここでは、南部仏印進駐の政策決定、仏側との交渉、実際の軍進駐を時点別に分ける。

7月7日には関東軍特種演習（関特演）に伴う大規模な動員が始まった。これは対ソ作戦の可能性を現実の軍事準備として高めたが、それ自体を対ソ開戦命令と同一視しない。同時に日米交渉も7月10日・12日の政府内協議などを通じて継続し、南方政策と交渉の両立可能性が検討された。

外交方針をめぐる政府内対立は内閣改造へ波及し、7月16日に第2次近衛内閣が総辞職した。第3次近衛内閣の正式成立は7月18日であり、松岡洋右に代わって豊田貞次郎が外相となった。7月21日には新内閣下で政府・統帥部の調整が再開され、同時期に仏印との共同防衛に関する了解が成立する。

7月25日、米国は日本資産を凍結し、対日経済関係は新しい制度段階へ入る。したがって本フェーズは**資産凍結の直前、7月24日まで**とし、資産凍結、南部仏印への実際の進駐、7月29日の日仏印共同防衛議定書、8月1日の対日石油輸出制限強化は次フェーズへ送る。

# 3. JH90 — 1941年6月22日〜6月24日

## 中心問い

> 米側回答と独ソ戦開始が同じ日に起きたとき、日本政府は対米・対独・対ソ・南方の政策をどのように組み直す必要に迫られたのか。

## 必須テーマ

- JH89からの接続
  - 日蘭会商は6月17日に正式打切り
  - 南部仏印進駐構想は政府・軍部内で検討中
  - 日米交渉は6月21日時点で未終結
- 6月22日 米側回答
  - 5月末日本案への米国側修正
  - オーラル・ステートメント
  - 「非公式・予備的・無拘束」の交渉段階を維持
  - 野村が交渉継続可能性を探る
  - 11月のハル・ノートと同一視しない
- 6月22日 独ソ戦開始
  - ドイツの対ソ侵攻
  - 日ソ中立条約は存続
  - 三国同盟との関係を再検討
  - 北進・南進を二者択一の固定路線として後知恵で整理しない
- 6月23〜24日
  - 独ソ戦の情報収集と政府・軍中央の方針調整
  - 南方政策が独ソ戦の結果待ちだけで停止したわけではないこと

## JH89→JH90 接続確認

JH89は、日米交渉継続・日蘭会商打切り・南部仏印構想という複数回路が並行した状態で終わる。JH90では6月22日に、**対米交渉の新回答と欧州戦争の地政学的変化が同時に加わる**。結果を知る後世から「ここで対米戦が決まった」「ここで北進が復活した」と一本道にしない。

## 図版 publication gate

- 6月22日の米側回答・オーラルステートメント
- 独ソ戦開始を伝える同時代新聞・外交電報
- 日ソ中立条約との関係を示す外交文書

人物写真だけでなく文書・新聞紙面を優先候補に含める。

# 4. JH91 — 1941年6月25日〜7月2日

## 中心問い

> 独ソ戦が始まった直後、日本はなぜ南部仏印進駐を具体化し、7月2日の御前会議では北方と南方をどのような条件付き選択肢として残したのか。

## 必須テーマ

- 6月25日「南方施策促進ニ関スル件」
  - 南部仏印進駐を具体方針化
  - 仏印側との交渉と必要時の軍事的実施を分ける
  - 決定日と実際の進駐開始日を分ける
- 独ソ戦への対応
  - 対ソ情勢を観察
  - 日ソ中立条約の制度状態
  - ドイツ勝利を確定結果として前提化しない
- 7月2日 御前会議
  - 「情勢ノ推移ニ伴フ帝国国策要綱」
  - 南方政策の推進
  - 対ソ武力行使を条件付きの可能性として扱う
  - 対英米戦争の危険を認識しつつ南方施策を進める構図
- 政策決定の階層
  - 連絡懇談会／連絡会議
  - 閣議
  - 御前会議
  - 現地軍への命令
  を一つの「決定」に圧縮しない

## JH90→JH91 接続確認

6月22日の外生ショックを受けて、JH91では政府・軍中央が**南方施策を具体的な国策へ変換する**。独ソ戦の開始だけで北方優先へ反転したのではなく、南方進出を進めながら対ソ機会も条件付きで検討する複線状態として描く。

## 図版 publication gate

- 「南方施策促進ニ関スル件」
- 7月2日「情勢ノ推移ニ伴フ帝国国策要綱」
- 御前会議関係資料
- 南部仏印の港湾・基地候補を示す権利確認済み史料地図

# 5. JH92 — 1941年7月3日〜7月17日

## 中心問い

> 関特演で北方の軍事準備を拡大しながら、なぜ日本政府は日米交渉と南方政策も並行して続け、第2次近衛内閣の総辞職に至ったのか。

## 必須テーマ

- 7月7日 関東軍特種演習（関特演）
  - 大規模動員・対ソ作戦準備
  - 演習名による秘匿
  - 開戦命令とは区別
  - 独ソ戦の戦況が判断条件
- 7月10日・12日前後の日米交渉方針協議
  - 6月22日米側回答への日本側対応
  - 当初案維持と修正余地
  - 交渉継続と南部仏印政策の緊張
- 松岡外相と政府内調整
  - 対独・対ソ・対米方針をめぐる差
  - 人物の性格だけで内閣総辞職を説明しない
- 7月16日 第2次近衛内閣総辞職
  - 内閣改造による外相交代へつながる
  - 第3次近衛内閣の正式成立は7月18日
- 7月17日
  - 組閣過程として扱い、成立日を前倒ししない

## JH91→JH92 接続確認

7月2日の国策要綱は南方推進と対ソ機会検討を同時に残した。JH92では、その複線方針が**関特演という軍事準備と日米交渉という外交手続の並行**として具体化し、政府内の外交方針差が内閣改造へ接続する。

## 図版 publication gate

- 関特演関係の公文書・動員資料
- 7月の日米交渉関係電報
- 第2次近衛内閣総辞職・組閣関係資料

# 6. JH93 — 1941年7月18日〜7月24日

## 中心問い

> 第3次近衛内閣は外相を交代させても、なぜ南部仏印政策を引き継ぎ、米国の強い反応を招く直前まで日米交渉も維持したのか。

## 必須テーマ

- 7月18日 第3次近衛内閣成立
  - 近衛文麿首相続投
  - 豊田貞次郎外相
  - 松岡外相の退任
  - 「内閣が変わった＝国策が全面転換した」としない
- 7月21日 新内閣下の大本営政府連絡会議
  - 南部仏印進駐方針の継承
  - 対米交渉の処理
- 日仏印共同防衛
  - 7月21日前後の了解成立を一次史料で確認
  - 仏印のフランス主権・植民地行政存続と、日本軍の基地・駐留要求を分ける
  - 7月29日の正式議定書は次フェーズ
- 米国側の反応
  - 南部仏印進駐計画への警戒
  - 7月25日の日本資産凍結は次フェーズの開始点
- フェーズ終点
  - 7月24日時点では資産凍結前
  - 7月28日の実際の南部仏印進駐開始を先取りしない

## JH92→JH93 接続確認

JH92の内閣総辞職は外交方針の調整方法を変えるが、7月2日の国策要綱を消去しない。JH93では、**外相交代後も南部仏印政策が継承され、対米交渉もまだ形式上は続く**という状態を示す。

- 南部仏印進駐前の基地・港湾関係史料
- 米側外交文書

# 7. A38 — 南部仏印進駐決定と基地・補給空間 map necessity / data-quality judgment

JH90〜JH93実装後に判定する。

## 候補となる空間問い

- 北部仏印と南部仏印の距離・役割差
- サイゴン、カムラン湾など主要港湾・基地候補
- タイ湾、マレー半島、蘭印、フィリピンとの相対位置
- 南部仏印進駐が「中国への補給遮断」だけでなく南方資源圏・英米蘭拠点への接近として認識された地理的理由

## 判定基準

map necessityは**candidate / 未判定**とする。

採用する場合も、7月25日以前は「進駐方針・交渉・基地要求」の段階であり、7月28日以後の実際の配備を前倒ししない。都市・港湾のPointを中心にし、LineStringやPolygonを採る場合は、作戦進路・占領範囲・基地圏を精密に復元できる史料があるかを別途確認する。

- 現代国境・現代行政界を1941年の支配境界として使わない
- 代表点は approximate と明示できる
- 実際の進駐後の配備と政策決定段階をlayer/timeで分けられないなら地図化しない
- LineString / Polygonを含む場合は Data / Style / Human Visual Audit を実施する

# 8. Crosscutting publication gate

## S09「対外支配の制度差」— strong candidate

南部仏印進駐方針と日仏印共同防衛了解は、フランスの主権・植民地行政を形式上残しながら、日本軍の基地利用・駐留を拡大する制度状態を生む。

延長する場合は、
- 領有
- 植民地統治
- 軍事占領
- 駐兵・基地利用
- 外交的保障・調停
を同一の「支配」に圧縮しない。

## S10「産業社会の負担と保護」— gateで再判定

南部仏印進駐は資源獲得・供給安全保障と結びつくが、7月25日の資産凍結前に切るため、経済制裁の制度転換そのものは次フェーズに属する。年代記事の南方資源説明の再要約にしかならない場合はholdし、資産凍結後にまとめて延長する。

## S05「政治参加の回路」— hold candidate

内閣総辞職・組閣は重要な政治過程だが、選挙・議会・国民組織など政治参加回路の新制度ではない。新しい比較軸が確認できなければ延長しない。

## 新規「日米交渉」横断記事 — reconsider / likely defer one more phase

6月22日回答で交渉の前提は変わるが、7月25日の資産凍結と南部仏印実進駐を含めた方が、外交文書と経済圧力の接続を一まとまりで説明しやすい。独立記事化はgateで再判定する。

# 9. phase-end audit necessity judgment 候補

- 6月22日米側回答を11月のハル・ノートや最後通牒と同一視していないか
- 6月22日独ソ戦開始を日ソ中立条約の自動失効として書いていないか
- 独ソ戦開始から「北進」または「南進」の一方が自動的に決まったと書いていないか
- 6月25日・7月2日の政策決定を7月28日の南部仏印実進駐と同一視していないか
- 7月2日国策要綱を対英米開戦決定へ短絡していないか
- 関特演を対ソ開戦命令・開戦決定と同一視していないか
- 日米交渉継続を妥結可能性が高かった証拠として扱っていないか
- 第2次近衛内閣総辞職を松岡個人だけで説明していないか
- 第3次近衛内閣の成立日を7月17日と誤記していないか（正式成立は7月18日）
- 日仏印共同防衛了解をフランス主権の消滅・日本の領有と同一視していないか
- 7月25日の資産凍結、7月28日の実進駐、7月29日の議定書を先取りしていないか
- 後知恵で「真珠湾への一本道」にしていないか

具体的な未解決横断仮説が残らなければ独立監査は実施しない。
