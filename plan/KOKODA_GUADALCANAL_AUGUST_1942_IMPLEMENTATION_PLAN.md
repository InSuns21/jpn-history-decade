## 1. フェーズの問いと境界

**中心問い：** 1942年7月下旬から8月末、米軍の島嶼上陸、日本軍の海上反撃・ガダルカナル奪回、パプアの山地進攻とミルン湾攻略は、どの拠点・航空兵力・船舶・陸上交通をめぐって競合し、現場の選択肢をどう変えたか。

7月21日までに、日本軍の横山先遣隊はパプア北岸のゴナ周辺に上陸し、豪州第39大隊B中隊・パプア歩兵大隊はココダ方面で警戒していた。米軍はウォッチタワー作戦の指揮・輸送・上陸準備を具体化していた。次期はこの**準備・先遣の状態**から、7月下旬のパプアでの接触、8月7日の米軍上陸、海上戦闘、航空基地の運用、複数の陸上戦闘へと変わる。

**前期から継ぐ未解決論点（JH141のnextIssues）：**
- 7月21日の北岸上陸から豪州・パプア前進部隊との最初の接触まで、横山先遣隊の行動とココダ飛行場・通路の争奪。
- 北岸の海上荷揚げとココダ道の徒歩・人力輸送の接続、後続増援と患者後送の制約。
- 米軍の洋上演習・上陸・空母航空援護・補給荷揚げの実施、および日本海軍の反撃に対する現地判断。
- ルンガ岬飛行場の建設段階から米軍の占領・整備・航空隊配備まで、島内と海上の制空制海の関係。

**フェーズ終点を8月31日とする理由：** 8月26日以降、パプアのイースラバとミルン湾では陸上戦闘が同時に進行し、30〜31日頃には守備・後退・飛行場防御の条件が変わる。一方、ミルン湾からの日本軍撤収は9月初旬で、8月31日の段階では最終決着として記述しない。9月1日以後の海陸作戦と指揮判断は次フェーズへ送る。

## 2. 年代ページ分割：5本

日数による均等割はせず、**作戦準備→初期接触→上陸・海戦→航空基地稼働→反攻戦・複数戦線の陸上戦闘**の変化点を採用する。4本だと8月21日のイル川方面攻撃・24日の空母戦と26日以後のイースラバ／ミルン湾を一記事へ詰め込むため、規約の5本例外を採用する。

**境界の確認事項：**
- AWMの概要年表はアワラ接触を**7月23日**、同館の研究資料では**7月22日**と記す場合がある。「最初の交戦日」の判断は活動・報告の定義と史料を確認してJH142本文で扱い、一方だけを無説明で確定日付にしない。
- ココダの占拠は**7月28〜29日前後**の夜間の戦闘・指揮官負傷・退却を区別する。**8月8日の豪州側一時奪回**とその後の再退却も別の状態変化として区別する。
- サボ島沖海戦は**8月8日夜〜9日未明**。夜戦での日本軍の戦果と米輸送船の残存・撤収決定を区別し、輸送船を撃滅したとは書かない。
- **20日**の米航空機到着、**21日**のイル川方面地上戦、**24日**中心の第二次ソロモン海戦、**25/26日夜**のミルン湾上陸は主体・現地時刻を照合する。米海軍は空母戦の範囲を23〜25日とする記述もある。
- **26〜31日**のイースラバとミルン湾は、軍指揮・地形・増援・輸送を別々に追う。戦闘終結や日本軍全撤収を8月末へ前倒ししない。

### JH142（次工程）：接続と必須事項

JH141の末尾は、米軍の上陸実行準備と日本軍の21日ゴナ北岸上陸で終わる。JH142冒頭は横山先遣隊と豪州・パプア側の偵察接触から直接始め、7月中旬の作戦構想は1〜2文に圧縮する。その後、アワラ→オイビ→ココダ→デニキの行動順、現地飛行場・伝令・山路・補給の制約、米軍のコロ島演習からガダルカナル方面出撃への移行を扱う。8月7日の上陸の結果はJH143へ送る。図版は飛行場・地形・上陸訓練・当時の写真を対象に権利と時点を調べ、採用・理由付き不採用を決定する。

## 3. 主題地図 A50：採否・品質判定（年代記事の後）

**候補：** 「ガダルカナルの飛行場・上陸浜・サボ島沖海戦と海上補給の空間」。

A49はラバウル〜ガダルカナル／パプアの広域関係とココダ山岳路を既に扱う。A50は、その地図では読みにくい**ルンガ岬飛行場・ツラギ／ガブツ・タナンボゴ・サボ島周辺の位置関係、上陸輸送と夜間水上戦、ヘンダーソン飛行場の近接防御**を新しい問いとして持てる場合に限って採用する。重複なら不採用。

- **Data Audit:** NHHC等の公刊戦史・作戦図に出典を付け、1942年8月の地点・時点、現代背景地図との違い、模式と実測の区別、出典画像の再配布権を検査する。移動航路や戦線を精密な地理線に偽装しない。
- **Style Audit:** 上陸地点、飛行場、軍事活動の海域を同じ点記号で混同せず、画面密度・ラベル・凡例・popupの史実説明を確認する。共通の精度留保を各Pointへ繰り返さない。
- **Human Visual Audit:** LineString／Polygonや新規の表示ロジックを採用するなら **pending-human / draft** としてPages上で実表示を確認し、承認後にのみpublished化する。既にHVA済みの同形式Point-onlyを再利用する場合は、規約に従って例外根拠を記録しData/Styleを完了させる。
- 地図の未採用・保留も判断根拠をPLANに記録する。先に地図を完成させるために記事の因果・境界を変更しない。

## 4. Crosscutting publication gate

年代5本とA50判断の後、独立した制度・比較軸の増減を調べる。

- **S05-E「政治参加の回路」:** 日本国内の議会・翼賛政治会などの実際の制度変更に関係する史料がある場合のみ延長。軍司令部の作戦命令を政治参加制度の変化と混同しない。
- **S09-F「軍事占領から占領統治へ」:** ガダルカナルの飛行場・地域占領やパプアの軍事行動を、民政・軍政の新たな行政機構と自動的に同一視しない。住民統治の職掌・権限が実証できる場合だけ延長。
- **S10-D「戦時統制と資源配分」:** 空母航空隊・輸送船・人力運搬の現場配分と、日本国内の配船機構・法令上の権限変更を区別する。具体的な国内制度変更がなければhold。
- **新規横断記事:** ガダルカナル・ココダ・ミルン湾の戦記をまとめ直すだけの総集編は作らない。年代を跨ぐ独立した比較軸と十分な出典が得られる場合だけ検討する。

## 5. phase-end audit necessity judgment

独立した全体監査は定型的に追加しない。各JHページの前後接続、A50の監査、横断publication gateとCIで処理できない、**複数記事・戦域を同時に見ないと解決できない具体的な矛盾**が残った場合だけ仮説を明記して独立監査を計画する。候補は、(1) サボ島沖海戦の日本軍戦果と輸送船の残存・米撤収、(2) ココダ方面の占領・一時奪回と増援時期、(3) 8月20日の飛行場航空隊到着とその後の海上補給の相互関係、(4) 8月末のイースラバ／ミルン湾戦況と9月初めの後続結果、の主張の衝突に限る。通常確認で解消済みなら **no-audit** として完了処理へ進む。
