# 1. このフェーズを1938年10月28日〜1939年5月10日に切る理由

直前フェーズは、1938年10月27日の武漢三鎮占領で終えた。広東と武漢を占領しても中国国民政府は内陸で戦争を継続し、日本側には「主要都市を占領すれば政治的決着に達する」という見通しを組み直す必要が残った。

この期間では、少なくとも五つの回路が並行する。

1. **戦争目的・対中政治構想の再定義。** 10月29日に有田八郎が外相に就任し、11月3日の第二次近衛声明は「東亜新秩序」を掲げた。12月22日の第三次近衛声明は、善隣友好・共同防共・経済提携を対中関係調整の原則として示した。
2. **汪兆銘工作の表面化。** 汪兆銘は12月18日に重慶を離脱してハノイへ移り、日本側との和平・新中央政府構想に関わる動きが表面化した。ただし、この時点で1940年の南京国民政府成立を既定の結果として書かない。
3. **占領地政策の機構化。** 12月には興亜院が設置され、1939年3月には華北・華中などの連絡部が置かれる。軍事占領、現地政権、政府内調整、経済統制を接続する制度設計が進む。
4. **国内総動員の具体化。** 平沼内閣成立後も国家総動員法にもとづく人員・生産力統制が具体化し、1月の国民職業能力申告令、3月の工業就業規制・従業員雇入制限など、対象者・企業の行動を行政命令で直接調整する範囲が広がる。
5. **軍事・外交上の長期戦化。** 2月の海南島占領、3月の南昌作戦など軍事圧力は続く一方、対独伊協定強化をめぐって政府・陸軍・海軍・在外大使の間に条件差が残る。中国戦線だけで政策が完結しない状態が強まる。

したがって、この期間は、武漢占領後の日本が「戦争終結」ではなく、**政治秩序の再定義・対中協力者の組織化・占領統治・国内動員・追加作戦を組み合わせた長期戦の仕組みへ移る時期**として扱う。

終点は1939年5月10日とする。5月11日に満蒙国境で交戦が始まり、ノモンハン事件へ発展する。これは、張鼓峰事件とは別の規模で対ソ武力衝突が中国戦線・対独伊外交・軍事資源配分へ新しい制約を加えるため、次フェーズの開始点とする。

# 3. JH55 — 1938年10月28日〜12月21日

## 中心問い

> 広東・武漢を占領しても戦争が終わらなかったとき、日本政府は軍事的成果をどのような政治秩序へ結びつけようとしたのか。

## 必須テーマ

- JH54からの接続
  - 広東・武漢占領後も中国国民政府が存続し、政治的決着が得られていない
  - 占領地統治・対中条件・海外補給・国内動員が未解決のまま残る
- 10月29日の有田八郎外相就任
- 11月3日の第二次近衛声明
  - 「東亜新秩序」を戦争目的・対中政治構想として示したこと
  - 日満華の協力、防共、経済協力という日本側の構想
  - 中国側や米英などが同じ秩序認識を共有したと書かない
- 11月の対独伊防共協定強化方針
  - 協定強化を検討していたこと
  - 対象国、武力援助義務、公開／秘密条件をめぐり政府内に差があったこと
- 12月の興亜院設置
  - 占領地・対中政策を政府内で調整する機構としての位置づけ
  - 現地軍・外務省・既成政権を一元的に完全支配した機関とは書かない
- 12月18日の汪兆銘重慶離脱
  - 日本側との接触・和平工作の経過
  - 国民政府内部の政治対立
  - 離脱時点では新政権成立も支持拡大も確定していないこと
- 12月21日時点で、翌日の第三次近衛声明により対中条件がさらに具体化される直前にあること

## JH54→JH55 接続確認

JH54は、軍事占領の拡大が戦争終結に直結せず、「占領後をどう政治的に処理するか」が未解決で終わる。

JH55は、その未解決問題に対して、日本政府が第二次近衛声明・興亜院・汪兆銘工作などを通じて、軍事占領を政治秩序へ接続しようとする状態から始める。

# 4. JH56 — 1938年12月22日〜1939年1月4日

## 中心問い

> 第三次近衛声明は、長期化した日中戦争の政治的な出口をどのような条件で示そうとしたのか。

## 必須テーマ

- 12月22日の第三次近衛声明
  - 善隣友好・共同防共・経済提携
  - 第二次近衛声明との連続と具体化
  - 声明を中国側が受諾した合意文書として扱わない
- 汪兆銘の重慶離脱後の動き
  - ハノイでの活動
  - 12月末の和平呼びかけ
  - 汪本人の構想、日本側の条件、重慶国民政府の方針を分ける
- 第一近衛内閣末期の政策状態
  - 軍事的決着が得られないまま、政治工作・占領地統治・総動員が継続していること
- 1939年1月4日までに近衛内閣が退陣へ至る経過
- 1月5日の平沼内閣成立は次ページの境界とする

## JH55→JH56 接続確認

JH55は、「東亜新秩序」という大枠と、汪兆銘離脱による政治工作の表面化までを扱う。

JH56は、第三次近衛声明によって対中関係の条件がさらに具体化され、その構想を残したまま政権が交代するところを扱う。

# 5. JH57 — 1939年1月5日〜2月9日

## 中心問い

> 近衛内閣から平沼内閣へ交代しても、日中戦争・総動員・対独伊外交の基本課題はどこまで変わり、どこまで引き継がれたのか。

## 必須テーマ

- 1月5日の平沼内閣成立
  - 有田外相・板垣陸相・米内海相など主要閣僚
  - 内閣交代を対中政策の全面転換と同一視しない
- 1月7日公布・21日施行の国民職業能力申告令
  - 国家総動員法にもとづく人的資源把握
  - 後の国民徴用令とは制度段階を分ける
- 1月17日の生産力拡充計画要綱
  - 長期戦を支える生産力・資源配分の政策として扱う
- 対独伊協定強化交渉
  - 1月26日の五相会議方針
  - 対象を主としてソ連とする政府方針、武力援助義務への留保
  - 陸軍・在独伊大使・海軍・外務省の立場を一つに潰さない
- 汪兆銘工作が継続していること
- 2月10日の海南島上陸を、次の軍事・空間状態への境界とする

## JH56→JH57 接続確認

JH56は第三次近衛声明を残して近衛内閣が終わる。

JH57は平沼内閣がその対中政策・占領地政策・総動員・対独伊協議を引き継ぎ、政権交代だけでは長期戦の制度課題が解消しない状態から始める。

# 6. JH58 — 1939年2月10日〜5月10日

## 中心問い

> 中国戦線で追加の軍事圧力をかけながら、国内動員と対独伊外交も進めることは、日本の政策選択をどのように複雑化させたのか。

## 必須テーマ

- 2月10日の海南島上陸・占領作戦
  - 華南沿岸・仏印方面に近い地理的位置
  - 対外補給路への圧力、海軍拠点、占領統治の複数目的
  - 後の「南進」の完成形を1939年2月へ投影しない
- 2月24日のハンガリー・満洲国の防共協定参加
  - 防共協定の拡大と、より強い軍事同盟をめぐる交渉を区別する
- 3月の南昌作戦
  - 華中での軍事圧力継続
  - 汪兆銘工作と軍事作戦が並行していたこと
  - 一つの作戦結果を中国側の抗戦能力全体の消滅へ一般化しない
- 3月17日の生産力拡充委員会
- 3月30日の工業就業規制・従業員雇入制限令など
  - 労働力配分への行政介入が具体化すること
- 3月〜4月の対独伊協定交渉
  - 大島・白鳥両大使と政府方針の差
  - 武力援助義務・対象国をめぐる条件差
- 4月〜5月の汪兆銘工作
  - ハノイから上海への移動
  - 新中央政府構想が進むが、政権成立はまだ先であること
- 5月初めの重慶空襲
  - 都市への航空攻撃を長期戦の一手段として扱う
  - 被害は中国側史料・研究も含めて確認し、日本側軍事記録だけで評価しない
- 5月10日時点で残る未解決問題
  - 中国国民政府は抗戦を継続
  - 汪兆銘工作は政権樹立に至っていない
  - 対独伊協定の条件は確定していない
  - 総動員はさらに強化途上
  - 対ソ国境では翌日から新たな武力衝突が始まる

## JH57→JH58 接続確認

JH57は、平沼内閣が長期戦の制度課題を引き継ぎ、海南島作戦直前までを扱う。

JH58は、海南島占領を契機に華南の軍事・海上空間へ圧力を広げつつ、華中作戦・総動員・汪兆銘工作・対独伊交渉を同時に進める状態から始める。

# 7. 地図候補

## A28 — 海南島占領と華南・仏印方面の対外交通空間

### map necessity / data-quality judgment を行う理由

JH58で重要なのは、海南島占領を単なる「島の占領」としてではなく、

- 広東・香港
- 海南島北部／南部
- 仏印沿岸
- 広西・雲南へ続く交通方向
- 南シナ海の海上交通

の位置関係から読むことである。

A27で扱った香港—広東—武漢の交通構造を南西へ延長できる可能性があるため、A28は新規地図実装を前提にせず、まず map necessity / data-quality judgment を行う。

### Data Auditで確認すること

- 1939年2月の上陸・占領地点をどの精度まで公開できるか
- 海口・三亜など代表地点のhistorical position
- 仏印・広西・雲南方面への交通路を、当時の整備状態以上に精密化しないこと
- 海南島占領を後の北部仏印進駐・南方作戦の「必然的第一歩」として地図化しないこと
- 戦史付図の進撃線・部隊配置を無断トレースしないこと
- 現代国境・現代道路を1939年の軍事／物流経路として無注記利用しないこと

A28が採用された場合は LineString / corridor を含む可能性が高いため、point-only Human Visual Audit省略規則は原則使わない。

# 8. Crosscutting publication gate

JH55〜JH58とA28判定後、既存横断記事を次の比較軸で延長できるか判定する。年代記事の再要約だけになる場合は延長しない。

## S05「政治参加の回路」

優先確認。

- 第二次・第三次近衛声明がどの政府内調整を経て公的方針になったか
- 平沼内閣期の五相会議で、対独伊協定の対象国・援助義務をどの主体が調整したか
- 在外大使の主張と政府訓令が食い違う場合、最終方針がどこで形成されたか

個別外交史の再記述ではなく、「政策形成へ参加できる主体と決定回路」という既存軸へ回収できる場合だけ延長する。

## S09「対外支配の制度差」

優先確認。

- 興亜院設置と1939年3月の各連絡部
- 華北・華中の既成政権と、日本政府／現地軍／興亜院の関係
- 汪兆銘を中心とする新中央政府構想
- 海南島の軍政機構

「現地に中国人政府がある／ない」だけでなく、法的形式・軍事占領・行政指導・経済統制の権限差を比較できる場合に延長する。

## S10「産業社会の負担と保護」

優先確認。

- 国民職業能力申告令
- 生産力拡充計画
- 工業就業規制
- 従業員雇入制限
- 技能者養成

1938年の「採用人数認可」から、1939年の人的資源把握・就業移動・技能養成へ行政介入が広がる比較軸が成立する場合に延長する。

## S02「石高制・貨幣経済・財政」

条件付き確認。

生産力拡充・物資動員が強化されても、それだけで財政構造記事を延長しない。新しい戦費調達・会計・金融統制の比較軸が史料で確認できる場合だけ通過させる。

## 新規横断記事

「東亜新秩序」「戦争目的」「汪兆銘工作」を独立記事にする場合は、JH55〜JH58とS05/S09を再編集するだけにならないかを先に判定する。独立した長期比較軸が不足する場合は作らない。
