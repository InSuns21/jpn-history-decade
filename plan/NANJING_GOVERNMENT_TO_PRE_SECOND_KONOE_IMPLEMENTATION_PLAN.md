# 1. このフェーズを1940年3月30日〜7月21日に切る理由

直前フェーズは3月29日、南京の新中央政府がまだ成立していない状態で終えた。翌3月30日、汪兆銘を首班とする南京国民政府が成立する。ただし、日本政府は同政府を即時に正式承認せず、阿部信行を大使として派遣して国交調整・条約交渉へ進んだ。したがって、**「政権が成立した」ことと「日本が正式承認した」ことを別の制度状態として追う必要がある。**

同じ春から夏にかけて、国内外の条件が急速に変化する。

1. **3月30日:** 南京国民政府成立。占領地政治機構は新しい枠組みへ移るが、日本の正式承認はまだ先である。
2. **4月:** 物価統制機構の再編、石炭配給統制法、米穀の強制出荷措置など、戦時経済の配分・供給統制が続く。
3. **4〜6月:** 欧州でドイツ軍の攻勢が拡大し、5月10日のベネルクス侵攻、6月22日の独仏停戦協定までに西欧の戦局が大きく変わる。この変化は日本の対蘭印・仏印政策の選択肢とリスク評価を変えたが、同じ日に南方武力進出が自動決定されたわけではない。
4. **6月:** 日本は仏印経由の援蒋ルート遮断を強く求め、フランス側は石油・トラックなど中国向け輸送の停止へ動く。6月29日、有田八郎外相は「国際情勢ト帝国ノ立場」を放送し、欧州戦局変化を踏まえた南方政策の方向を公に示した。
5. **6月24日以後:** 近衛文麿が枢密院議長を辞任して新体制運動への参加を表明し、7月6日の社会大衆党解党を皮切りに既成政党の解党が進み始める。
6. **7月16日:** 米内内閣が総辞職する。7月17日に近衛へ組閣の大命が下り、22日に第2次近衛内閣が成立する。

したがってこのフェーズは、**南京国民政府成立後の対中政治処理、欧州戦局急変による南方政策の再評価、国内の戦時統制、新体制運動による政党秩序の解体開始、米内内閣の終焉**を一つの状態遷移として扱う。

終点は7月21日とする。翌22日の第2次近衛内閣成立後は、基本国策要綱、世界情勢の推移に伴う時局処理要綱、松岡外交など、政府の政策主体と決定文書が新しい段階へ移るためである。

# 3. JH68 — 1940年3月30日〜5月9日

## 中心問い

> 南京国民政府が成立しても日本政府が即時承認しなかったのはなぜで、その間も中国戦争と国内統制はどのように続いたのか。

## 必須テーマ

- JH67からの接続
  - 3月29日時点では南京国民政府は成立前
  - 米内内閣、日米無条約状態、総動員統制は継続
  - 斎藤隆夫除名後も帝国議会・政党は制度上存続
- 3月30日の南京国民政府成立
  - 汪兆銘を首班とする政府の成立
  - 既存の占領地政治機構との関係を確認する
  - 日本政府の即時正式承認と同一視しない
- 日本側の国交調整
  - 阿部信行を特命全権大使として派遣し、条約交渉へ進む構想
  - 7月開始の正式交渉を3〜4月へ先取りしない
- 中国戦争
  - 南京政府成立で重慶国民政府との戦争が終結したとは書かない
  - 南京政府の成立目的・統治能力・日本軍占領との関係を具体化する
- 4月の戦時経済統制
  - 物価対策審議会・価格形成委員会
  - 石炭配給統制法
  - 米穀強制出荷措置
  - 制度の公布・施行・実際の適用を分離する
- 5月10日のドイツ西方攻勢開始直前で切る

## JH67→JH68 接続確認

JH67は、南京国民政府成立前日までを扱う。

JH68は、**新政府が実際に成立したが、日本による正式承認と中国戦争終結はまだ実現していない**という新しい制度状態から始める。

# 4. A31 — 南京国民政府成立後の占領地政治機構と法域 map necessity / data-quality judgment

## 判定結果 — no-map

**A31 は no-map とする。**

空間的な論点自体は重要だが、今回の中心命題は「どこを一つの政府が面として支配したか」ではなく、**南京国民政府の名目的な中央政府枠組み、華北政務委員会という地域行政、日本軍の占領権力、重慶国民政府の抗戦・統治が重なっていた制度差**である。これを一枚の行政領域polygonへ落とすと、異なる権限と実効性を同じ「支配地域」として読ませる危険が大きい。

### map necessity

- 南京・北京・重慶などの代表地点を置けば、政治機構の所在地は示せる。
- しかしpoint-only地図では、南京政府と華北政務委員会の制度的な重なり、日本軍占領との権限差、重慶側との実効支配差というA31の中心論点を表現できない。
- schematic zoneを追加しても、連続した法域・実効支配範囲が確定していたような視覚的印象を作りやすく、本文より正確な説明にならない。
- JH68本文は、南京政府成立・華北政務委員会の残存・日本の正式承認留保・重慶との戦争継続を制度関係として既に説明しており、地図追加による理解改善は限定的である。

したがって map necessity は**制度配置の補助としては存在するが、地図でなければ説明できない水準には達しない**と判定する。

### data-quality gate

フェーズで使用している外務省・JACAR・国立国会図書館資料から、次は確認できる。

- 1940年3月30日に南京国民政府が成立したこと
- 旧華北臨時政府・華中維新政府が1940年3月で区切られ、その後に南京政府と華北政務委員会の制度系列が並ぶこと
- 日本による正式承認が3月30日ではなく11月30日であること
- 重慶国民政府との戦争が継続していたこと

一方、今回確認した史料セットでは、**1940年3月30日〜5月9日の同一時点について「南京政府の名目的管轄」「日本軍の軍事占領・実効支配」「重慶政府の実効支配」を別属性で再現できる、公開利用条件の明確なGIS／境界データ**は確保できない。

- 現代の省境・国境を1940年の政治・軍事境界として流用しない。
- 後世の概説地図から精密polygonを起こさない。
- 前線・占領地域・行政管轄を一つの面へ統合しない。
- 都市点だけへ縮退すると「法域」というA31の問いを失うため、point-only実装もしない。

以上から data-quality gate は公開polygonを許可できる水準に達していない。

### 結論

新規mapは追加しない。JH68の本文と、後工程のS09「対外支配の制度差」で、**政府成立・地域行政・軍事占領・実効支配・外交承認を別の制度軸として説明する**方を優先する。

地図変更がないため、このA31では Data Audit / Style Audit / Human Visual Audit は発生しない。

次は **JH69「1940-05-10〜06-28」** へ進む。

# 5. JH69 — 1940年5月10日〜6月28日

## 中心問い

> 欧州でドイツ軍が急速に優勢になったことは、日本の南方政策と中国への補給遮断策にどのような新しい選択肢と制約を生んだのか。

## 必須テーマ

- 5月10日のドイツ軍によるベネルクス侵攻
  - 欧州戦局急変が日本の蘭印・仏印認識へ与えた影響
  - 欧州の軍事結果だけで日本の政策を自動決定したと書かない
- 蘭印
  - オランダ本国の危機と蘭印の現状維持問題
  - 日本政府が重要物資供給を求めたこと
  - 「蘭印占領決定」へ先取りしない
- 仏印・援蒋ルート
  - 日本が仏印経由の中国向け輸送停止を要求
  - 6月中旬、仏印側が石油・トラックなどの輸送停止へ動く
  - 北部仏印進駐はまだ後の段階であり、この時点の要求・監視・交渉と分ける
- フランス
  - 6月22日の独仏停戦協定
  - フランス本国の軍事的敗北が仏印当局の交渉余地を狭めたこと
- 新体制運動の始動
  - 6月4日の近衛の新党構想表明
  - 6月24日の枢密院議長辞任・新体制運動推進表明
  - 既成政党がこの時点で一斉消滅したとは書かない
- 6月29日の有田外相演説直前で切る

## JH68→JH69 接続確認

JH68は南京政府成立後も対中戦争・国交調整・国内統制が続く状態を扱う。

JH69は、**欧州の軍事バランス急変が東南アジアの植民地と援蒋ルートを日本外交のより直接的な政策対象へ変える**ところから始める。

# 8. 地図以外の横断論点

## 欧州戦局を日本史へ接続する際の原則

- ドイツ軍の勝利を、日本の対英米戦争が不可避になった原因として一本道化しない
- 欧州列強の本国危機が、蘭印・仏印の防衛・交渉条件をどう変えたかを具体化する
- 日本政府、外務省、陸軍、海軍、現地軍の政策判断を同じ主体としてまとめない
- 「南進論」を一つの完成済み政策として扱わず、資源・援蒋ルート・対英米関係・対独伊関係など複数の目的を分ける

## 南京国民政府を扱う際の原則

- 3月30日の成立と11月30日の日本による正式承認を分ける
- 南京政府の名目的管轄と、日本軍の占領権力・実効支配を分ける
- 重慶国民政府との戦争継続を明示する
- 「傀儡政権」という評価語だけで制度関係の説明を代替しない。日本側の軍事・外交・顧問機構がどの権限を保持したかを具体化する

# 9. phase-end audit necessity judgment

独立監査は定型化しない。

候補仮説:

- 南京国民政府成立＝日本の正式承認・中国戦争終結、と圧縮していないか
- ドイツの西欧勝利＝日本の南進・対英米戦決定、と一本道化していないか
- 仏印援蒋ルート遮断と北部仏印進駐を同一時点へまとめていないか
- 新体制運動開始＝全政党即時解党＝大政翼賛会成立、と圧縮していないか
- 米内内閣崩壊を単一人物・単一事件だけで説明していないか
- S05/S09/S10が年代記事の再編集になっていないか

各年代の隣接確認、Crosscutting publication gate、content validationで解消済みなら独立監査不要とする。
