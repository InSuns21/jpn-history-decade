# 1. このフェーズの位置づけ

前フェーズは1890年までを扱い、

- 大日本帝国憲法の発布と施行
- 内閣・枢密院・裁判所・地方制度
- 第1回衆議院議員総選挙
- 第1回帝国議会
- 日本銀行券を軸とする紙幣整理
- 地方行政と政治参加

までを公開品質化した。

1891年以降は、制度を「作る」段階から、制度を実際に運用し、その運用が戦争・外交・産業化・社会問題と結びつく段階へ入る。

この時期の中心課題は、

- 憲法上の制度と実際の政治運用はどのように違ったか
- 政府・政党・衆議院・貴族院はどのような取引と対立を重ねたか
- 戦争を遂行するための財政・軍事・物流・情報能力はどのように形成されたか
- 日清・日露戦争の結果は国内政治・財政・産業・対外関係をどう変えたか
- 産業化の利益と負担は、地域・階層・性別・職種によってどう異なったか
- 台湾・韓国・南満州などへの支配・権益拡大を、日本国内だけの視点でなくどう記述するか
- 条約改正は一度の条約で完結したのではなく、どの段階を経て進んだか

である。

フェーズ終点は1911年とする。

1894年の日英通商航海条約、1899年の改正条約施行を経て、1911年には関税自主権回復に至る。また同年に工場法が成立するが、施行は1916年であり、明治後期の産業化が社会政策上の課題を制度化し始めた段階を示す。1912年以降は明治天皇死去、政変、第一次世界大戦へつながる別フェーズとして扱う。

# 3. 歴史記述の中心原則

## 3.1 初期議会を「藩閥対民党」だけで固定しない

1890年代の議会では政府と民党の対立が重要だが、

- 政党間対立
- 政党内部の分裂・再編
- 政府と政党の妥協
- 貴族院
- 官僚
- 元老
- 軍
- 地方政治家

など複数の主体が関与する。

「政府対議会」という一軸だけで説明しない。

## 3.2 戦争を国内近代化のためのイベントとしてのみ扱わない

日清・日露戦争は、

- 外交交渉
- 朝鮮・清国・ロシアなど他国・地域の政治
- 軍事作戦
- 兵站
- 財政
- 公債
- 徴兵
- 情報
- 国内世論
- 戦後処理
- 占領・植民地統治

を接続して扱う。

後世から「当然に起きた戦争」として書かず、当時存在した外交上の選択肢・制約・認識を確認する。

## 3.3 日本政府・軍・政党・国民を一枚岩にしない

「日本は〜した」という主語を不用意に多用しない。

政策主体、議決主体、軍事主体、支持・反対・負担を負った社会集団を可能な範囲で分ける。

## 3.4 植民地化を東京の制度史だけで書かない

台湾統治、韓国への介入・保護国化・併合、南満州での権益拡大は、

- 条約・法制度
- 軍事・警察
- 行政
- 土地・税
- 交通・企業
- 抵抗・交渉
- 現地社会

を区別する。

「領有した」「統治した」で終えず、支配の制度と被支配社会側の応答を扱う。

## 3.5 産業化を総生産の増加だけで評価しない

産業化は、

- 生産量
- 企業
- 銀行・金融
- 鉄道・港湾
- エネルギー
- 輸出入
- 労働時間
- 女性・年少労働
- 農村からの労働移動
- 鉱害・公害
- 都市化

を可能な範囲で接続する。

「産業革命」という総括語を使う場合も、業種・地域・時期の差を消さない。

## 3.6 条約改正を一日で完成した制度として扱わない

少なくとも、

- 1894年の日英通商航海条約調印
- 1899年の改正条約施行
- 1911年の関税自主権回復

を区別する。

「調印」「批准」「施行」「完全回復」を同義にしない。

1891〜1911年は、政治運用・戦争・産業化・対外支配の状態変化が速いため、4区間に分ける。

# 7. 中間監査 E — 1891–1895

**Status: completed (2026-09-27)**

JH15末尾の「帝国議会の運用」「条約改正」「鉄道・軍事動員」「軍事・外交・宮中・内閣・議会の権限関係」という次期論点が、JH16の初期議会、条約改正、日清戦争の戦時動員へ連続していることを確認した。

初期議会は「超然主義の政府と民党が対立し、やがて政党政治へ進む」という一本道にはしていない。第1議会での民党側の分裂を伴う妥協、1891年の解散、1892年の選挙干渉、1893年の和協の詔勅を並べ、対立・行政権力による介入・政策取引が同時に形成された過程としている。

条約改正は1894年の日英通商航海条約の調印と5年後の施行を区別し、関税自主権の全面回復も1911年まで残す。日清戦争は8月1日の宣戦から突然始めず、朝鮮国内の甲午農民戦争、清・日本の派兵、景福宮占領、豊島沖海戦という段階を分けた。韓国国史編纂委員会の年表、清・朝鮮関係を扱う中央研究院の研究紹介、台湾側の公的アーカイブも用い、朝鮮・清・台湾を日本の政策説明だけの背景にしないよう補強した。

戦争遂行では、徴兵軍だけでなく軍事公債・臨時軍事費・鉄道輸送・海運・兵站・広島臨時議会を接続した。下関条約後も、三国干渉による遼東半島返還と台湾での武装抵抗を置くことで、「戦勝＝無制約な外交優位・即時の安定統治」とはしていない。

監査結果：
- 第1議会から初期議会政治への接続あり
- 「超然主義→政党政治」の一本道化なし
- 1894年条約調印 / 1899年施行 / 1911年関税自主権回復を分離
- 日清戦争を不可避化せず、宣戦前のエスカレーションを明示
- 朝鮮・清・台湾の主体と資料を補強
- 戦争と国内政治・財政・金融・交通・兵站を接続
- 新規地図は追加していないためMap Audit対象なし

# 8. JH17 — 1896–1900

**Status: completed (2026-09-27)**

日清戦後経営を賠償金の単純な「産業化資金」とせず、戦費精算、陸海軍拡張、製鉄所、台湾経費、準備基金、金本位制の金準備へ分け、なお増税・公債が必要だった財政構造として実装した。政府と政党の関係は、自由党の政府接近、1898年の憲政党・第1次大隈内閣、短期分裂、1900年の立憲政友会まで連続して扱った。

産業化では製糸・紡績など軽工業、1899年全国工場統計、1897年労働組合期成会、女性労働を含む工場労働問題、1900年治安警察法を接続した。台湾統治は1896年六三法と1898年以後の総督府による地域社会への介入を、内地の府県制度とは異なる法的枠組みとして記述した。条約改正は1894年調印と1899年実施を分離し、1900年北清事変まで東アジアの国際関係を接続した。

## 中心問い

> 日清戦争後の資金・国際環境・政治再編は、日本の財政・産業・政党政治をどのように変えたのか。

## 必須テーマ

- 日清戦争後の財政・軍備拡張
- 賠償金の利用
- 産業・交通・軍事インフラへの投資
- 1897年貨幣法と金本位制
- 日本銀行・金融制度
- 製糸・紡績・鉱業・鉄道
- 都市労働・女性・年少労働
- 台湾総督府による統治制度の形成
- 1898年第1次大隈内閣
- 政党合同と分裂
- 1899年改正条約施行
- 1900年立憲政友会
- 1900年治安警察法
- 北清事変と列国協調
- 社会運動・労働運動の初期展開

## 記述上の注意

- 賠償金を「産業化の原資」と一語でまとめず、用途を確認する。
- 金本位制を単なる近代化指標として扱わず、貿易・為替・金融政策との関係を見る。
- 産業化を重工業だけで説明しない。輸出産業としての製糸、綿紡績、鉱業などの比重を見る。
- 第1次大隈内閣を後世の本格的政党内閣と同じ制度として扱わない。
- 台湾統治の制度化を、日本本土の行政制度の単純コピーとして書かない。

# 9. JH18 — 1901–1905

**Status: completed (2026-09-27)**

官営八幡製鉄所と足尾鉱毒問題を並置し、産業化の供給能力と環境・地域社会への負担を同じ状態遷移として実装した。1901年社会民主党と治安警察法、第1次桂内閣、政友会との調整も接続し、政党政治の発達を政治参加全般の自由化と同一視していない。

外交・戦争では、第1回日英同盟を開戦決定とせず、満韓問題をめぐる対露交渉の継続、国交断絶・軍事行動・宣戦の段階、戦時増税・国内公債・外債・正貨確保を扱った。戦費支出約18.7億円、その8割余を公債・借入金に依存した財政構造を確認し、軍事力を国際金融から切り離していない。

## 中心問い

- 政府・政友会・貴族院の関係
- 1901年官営八幡製鉄所操業
- 足尾鉱毒問題と田中正造
- 産業化と環境・地域社会
- 1902年日英同盟
- ロシア・日本・韓国・清国をめぐる外交
- 日露戦争
- 徴兵・兵站・鉄道・海運・通信
- 戦時増税
- 国内外公債
- 戦争遂行と日本銀行・金融市場
- 第一次・第二次日韓協約
- ポーツマス条約
- 日比谷焼打事件

- 軍事作戦だけでなく、財政・外債・輸送・補給・外交を扱う。

# 10. JH19 — 1906–1911

**Status: completed (2026-09-27)**

日露戦後経営を、戦前5億円台から戦争末20億円超へ増えた政府債務、戦時税継続、国債整理、軍備・鉄道・植民地支出の競合として実装した。桂園時代は首相二人の交代暗記ではなく、政友会・官僚・貴族院・軍・元老の政策調整として扱った。

# 13B. 1800–1911 接続監査

**Status: completed (2026-09-27)**

1800〜1911年の19年代ページと7本の横断記事を、幕藩体制末期から明治末まで一本で読み直した。既存の1800〜1890接続監査と1891〜1911全体監査を接続し、年代境界で説明の主語・制度・因果が不連続に切り替わっていないか、逆に「中央集権化」「立憲化」「産業化」「帝国化」を一つの近代化過程として均していないかを重点的に確認した。

年代間の接続は維持できている。1800年代の商品経済・商人信用は幕藩体制の外側に生まれた近代化要因ではなく、領主財政を支える一方で制約にもなる仕組みとして描かれている。幕末の外交・海防・軍事負担は幕府の突然の無能力化ではなく、従来の分担統治では処理しにくい全国規模の同時調整を増やした問題として1860年代へ接続する。1868年の政権交代、1871年の廃藩置県、1873年の全国制度、1890年の憲法・議会はいずれも完成点とせず、次の運用・負担・参加・権限調整を生む節目として扱っている。

長期構造の役割分担も維持できている。

- S01「幕藩体制」は、分権的な権限配置がなぜ機能し、幕末に調整負荷が増えたかを扱う。
- S04「幕藩体制から中央集権国家へ」は、政権交代と全国を直接把握する行政能力の形成を分ける。
- S07「地方行政と政治参加」は、中央集権と地方参加を反対語にせず、地方階層ごとの任命・議決・監督を比較する。
- S05「政治参加の回路」は、建白・結社・選挙・議会・政党を、入口・参加資格・実効性・制約で比較する。
- S02「石高制・貨幣経済・財政」は、近世の市場・商人信用から、全国税制・中央銀行・公債・国際金融までを、誰が現在と将来の負担を引き受けるかという軸で接続する。
- S03「対外窓口から条約港へ」は、四つの口から条約港・常設外交への転換に限定し、後の帝国外交の総年表へ延長しない。
- S09「対外支配の制度差」は、台湾・韓国・関東州・南満洲鉄道を同一の「帝国領域」にまとめず、法的根拠・主権状態・統治主体・権限範囲を比較する。

この通読で、政治参加史には追加補強が必要と判断した。1890年に帝国議会が始まったことを「国政選挙制度が全国へ一様に成立した」と読み替える余地があったため、S05へ制度の**地理的適用範囲**という比較軸を追加した。1889年衆議院議員選挙法は沖縄県などを当初適用除外とし、1900年改正後も沖縄で実際に施行されるのは1912年だった。また1910年併合後の朝鮮では大日本帝国憲法と帝国議会の参政制度がそのまま適用されたわけではない。これにより、政治参加の拡大を納税資格・性別だけでなく、地域ごとの制度適用差からも読めるようにした。

この補強は、国内の中央集権化と対外支配を一つの「均質な国民国家形成」へまとめないためにも重要である。明治政府は国内で府県・戸籍・地租・徴兵・学校・議会など全国制度を増やしたが、1895年以後に権限を拡大した台湾・韓国・関東州・南満洲鉄道では、領土・主権制約・租借・企業権益という異なる法的形態を併存させた。国家能力の拡大は、統治制度の一様化と同義ではない。

財政面でも「近代化＝市場から自立した国家」という逆転した読み方は避けられている。近世から領主財政は市場・商人信用へ依存し、明治政府は税・通貨・中央銀行を全国制度化した後も、公債市場、金本位制、外国公債へ依存範囲を広げた。変化したのは市場依存の有無ではなく、信用を動員できる主体・時間・地理的範囲と、その返済負担を制度化する能力だった。

対外関係も「開国したので帝国化した」という一本道にはしていない。S03は幕末の外交制度転換で役割を終え、1890年代以後は各年代記事で条約改正・戦争・外交交渉を扱い、S09では戦争の結果生じた支配・権益を制度差へ組み替える。日清・日露戦争はいずれも開戦前の選択肢・交渉・現地政治を残し、後の植民地支配から逆算して必然化していない。

監査結果として、新しい通史横断記事は追加しない。S02・S05・S09がすでに異なる長期比較軸を担っており、ここで「1800〜1911の近代化」を一記事にまとめると年代ページの再要約と目的論化を招くためである。新規地図も追加せず、既存Map Audit状態に変更はない。

**監査結果：1800–1911の接続は、S05の制度適用範囲補強後、公開品質で成立している。**
