# 1. このフェーズの位置づけ

前フェーズは1890年までを扱い、

- 大日本帝国憲法の発布と施行
- 内閣・枢密院・裁判所・地方制度
- 第1回衆議院議員総選挙
- 第1回帝国議会
- 日本銀行券を軸とする紙幣整理
- 地方行政と政治参加

までを公開品質化した。

1891年以降は、制度を「作る」段階から、制度を実際に運用し、その運用が戦争・外交・産業化・社会問題と結びつく段階へ入る。

この時期の中心課題は、

- 憲法上の制度と実際の政治運用はどのように違ったか
- 政府・政党・衆議院・貴族院はどのような取引と対立を重ねたか
- 戦争を遂行するための財政・軍事・物流・情報能力はどのように形成されたか
- 日清・日露戦争の結果は国内政治・財政・産業・対外関係をどう変えたか
- 産業化の利益と負担は、地域・階層・性別・職種によってどう異なったか
- 台湾・韓国・南満州などへの支配・権益拡大を、日本国内だけの視点でなくどう記述するか
- 条約改正は一度の条約で完結したのではなく、どの段階を経て進んだか

である。

フェーズ終点は1911年とする。

1894年の日英通商航海条約、1899年の改正条約施行を経て、1911年には関税自主権回復に至る。また同年に工場法が成立するが、施行は1916年であり、明治後期の産業化が社会政策上の課題を制度化し始めた段階を示す。1912年以降は明治天皇死去、政変、第一次世界大戦へつながる別フェーズとして扱う。

# 3. 歴史記述の中心原則

## 3.1 初期議会を「藩閥対民党」だけで固定しない

1890年代の議会では政府と民党の対立が重要だが、

- 政党間対立
- 政党内部の分裂・再編
- 政府と政党の妥協
- 貴族院
- 官僚
- 元老
- 軍
- 地方政治家

など複数の主体が関与する。

「政府対議会」という一軸だけで説明しない。

## 3.2 戦争を国内近代化のためのイベントとしてのみ扱わない

日清・日露戦争は、

- 外交交渉
- 朝鮮・清国・ロシアなど他国・地域の政治
- 軍事作戦
- 兵站
- 財政
- 公債
- 徴兵
- 情報
- 国内世論
- 戦後処理
- 占領・植民地統治

を接続して扱う。

後世から「当然に起きた戦争」として書かず、当時存在した外交上の選択肢・制約・認識を確認する。

## 3.3 日本政府・軍・政党・国民を一枚岩にしない

「日本は〜した」という主語を不用意に多用しない。

政策主体、議決主体、軍事主体、支持・反対・負担を負った社会集団を可能な範囲で分ける。

## 3.4 植民地化を東京の制度史だけで書かない

台湾統治、韓国への介入・保護国化・併合、南満州での権益拡大は、

- 条約・法制度
- 軍事・警察
- 行政
- 土地・税
- 交通・企業
- 抵抗・交渉
- 現地社会

を区別する。

「領有した」「統治した」で終えず、支配の制度と被支配社会側の応答を扱う。

## 3.5 産業化を総生産の増加だけで評価しない

産業化は、

- 生産量
- 企業
- 銀行・金融
- 鉄道・港湾
- エネルギー
- 輸出入
- 労働時間
- 女性・年少労働
- 農村からの労働移動
- 鉱害・公害
- 都市化

を可能な範囲で接続する。

「産業革命」という総括語を使う場合も、業種・地域・時期の差を消さない。

## 3.6 条約改正を一日で完成した制度として扱わない

少なくとも、

- 1894年の日英通商航海条約調印
- 1899年の改正条約施行
- 1911年の関税自主権回復

を区別する。

「調印」「批准」「施行」「完全回復」を同義にしない。

# 12. 地図必要性監査

このフェーズでは戦争・植民地・鉄道・工業地域など地図化したくなる主題が多いが、誤ったgeometryは文章より強く誤解を与えるため、実装前に必ず必要性とデータ品質を判定する。

## A7 日清・日露戦争と東アジア

戦線や軍の進路を描く場合は、信頼できる歴史地図・公文書・軍事史料から時点別geometryを構築できる場合のみ実装する。

現代国境線の上に矢印を引いただけの模式図を「歴史地図」として公開しない。

地図化できない場合は、
- 主要戦場
- 条約で移転した権利・地域
- 講和交渉
を表・時系列・制度図で示す。

## A8 1890年代〜1910年代初頭の産業・鉄道

A6で歴史鉄道路線geometryのprovenance不足が判明しているため、同じ問題を未解決のまま再実装しない。

再検討条件：
- 開業時点別の線形が確認可能
- 1906年国有化前後の事業者区分が確認可能
- 廃線・経路変更を処理可能
- 同一精度で全国比較可能

条件を満たさなければ表・路線開業年表を優先する。

## A9 植民地統治

台湾・韓国・関東州・南満州鉄道附属地などを一枚の「日本領」色塗り地図にまとめない。

法的地位、統治制度、時点が異なるため、地図を作る場合はレイヤーと注記で区別できることを必須とする。

### 地図の公開条件

- Data Audit passed
- Style Audit passed
- Human Visual Audit passed
- desktop / tablet-touch / mobile確認
- 現代境界を歴史境界として誤認させない
- 戦線・領域・権益の意味を凡例で区別
- 被支配地域を単なる色面にしない

既存S02「石高制・貨幣経済・財政」は1890年まで実装済み。

次の軸が年代記事とは別に比較可能なら延長を検討する。

- 金本位制
- 日清・日露戦争の戦費
- 増税
- 国内外公債
- 日本銀行
- 戦後財政
- 植民地財政との関係

「戦争があったので財政が膨張した」という年代要約になる場合は延長しない。

# 15. Source / date audit

この時期は法令・条約・戦争・制度変更が多く、「成立した日」を一種類にしない。

確認対象：

- 法律：公布 / 施行
- 条約：調印 / 批准 / 批准書交換 / 発効
- 戦争：軍事行動開始 / 宣戦 / 講和
- 政党：結党 / 改称 / 合同 / 解党
- 内閣：任命 / 総辞職
- 鉄道：法成立 / 買収 / 国有化実施
- 工場：設立 / 操業開始
- 植民地制度：条約 / 軍事占領 / 行政機関設置 / 法令施行

とくに、
- 日英通商航海条約
- 下関条約
- 日英同盟
- ポーツマス条約
- 日韓協約
- 韓国併合条約
- 貨幣法
- 鉄道国有法
- 工場法

は制度上の段階を混同しない。

数値については、
- 戦費
- 公債
- 賠償金
- 生産量
- 輸出入
- 工場労働者数
- 人口
- 鉄道営業距離

の定義と対象年を確認する。
