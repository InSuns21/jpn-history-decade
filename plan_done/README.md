# plan_done

完了済みの**実装計画**を保管する。

## 移動条件

- 計画内の完了条件を満たしている
- 必要な監査が完了している
- CI が green
- GitHub Pages deploy が green
- 計画書の Status が `completed`

となった時点で、`plan/` からこのフォルダへ移動する。

## 運用

- 未完了計画を整理目的だけで移さない。
- コピーではなく移動する。
- 完了計画は当時の設計判断・受入条件の履歴として保持する。
- 後日大規模な再実装が必要になった場合は、過去計画を書き換えるのではなく新規計画を `plan/` に作る。
- 長期企画書は個別フェーズ完了だけでは移動しない。
