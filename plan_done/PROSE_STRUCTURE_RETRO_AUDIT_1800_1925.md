# 1800–1925 本文構造・留保表現 遡及監査

Status: completed

## 目的

1800–1925年の既存公開本文について、史実の正確さを守るための留保が本文の主線を隠し、年代間の状態遷移や制度・負担・権限のつながりを読み取りにくくしていないかを遡及監査した。

## 新しい判定基準

- 本文は「何ではないか」ではなく、まず「何が何を変えたか」を肯定文で示す
- その変化が次の選択肢・制約をどう変えたかを書く
- 一般的な誤読防止は `contemporaryAssumptions` へ寄せ、本文で反復しない
- 必要な留保・史料上の不確実性・地域差は削除しない
- 見出しも可能な限り状態変化・因果・接続を示す

詳細は `standards/CONTENT_AUTHORING_STANDARD.md` 1.1 に正本化した。

## 主な修正

- 「鎖国ではない」「幕府衰退だけではない」から始めず、幕藩体制を実際に動かした分担・市場・情報・財政を先に説明
- 幕末では、外国船来航を事件列ではなく、外交・海防・財政・朝廷・諸藩の調整負荷が増す状態遷移として再構成
- 明治国家形成では、中央集権化を制度名の列ではなく、任命・徴税・戸籍・兵役・地方行政の権限移転として明示
- 初期議会以後は、「議院内閣制ではない」という留保より、予算・法案を通じて政府が政党との交渉を必要とするようになった変化を先に記述
- 第一次世界大戦期は、戦時景気→物価・生活負担→社会運動→政党政治への圧力という接続を強化
- 1919–1925年は、政治参加の拡大、植民地統治、戦後恐慌、国際協調、治安法制を別々の出来事ではなく、それぞれが制度上どの入口・負担・制約を変えたかで接続
- 横断記事では、比較の結論を否定形で置かず、制度差・権限差・負担配分を肯定文で提示

## 定量的な補助監査

本文中の「ではない」「わけではない」「同一視」「だけでは」「とは限ら」「とみな」「としない」「とは別」「ただし」「一方」を補助指標として数えた。

- 監査前: 620件
- 監査後: 358件
- 約42%減

この数値は品質ゲートではない。「一方」や必要な留保も数えるため、ゼロを目標にしない。目的は、留保が段落・節の主張を代替していないかを発見することにある。

主要見出しに含まれていた「〜ではない」「〜だけでは」型の見出しは、状態変化を示す見出しへ改稿し、監査後は0件とした。

## 維持したもの

- 史実上必要な不確実性
- 地域差・主体差
- 論争的テーマでの出典に基づく限定
- 後知恵を避ける `contemporaryAssumptions`
- 既存の用語ID、出典ID、地図参照、年代境界

## 今後

1926年以後はこの監査を独立工程として毎回繰り返さず、各年代の執筆・隣接年代確認・フェーズ全体監査の中で `CONTENT_AUTHORING_STANDARD.md` 1.1 を適用する。再度の全期間遡及監査は、具体的な再発兆候がある場合だけ行う。
