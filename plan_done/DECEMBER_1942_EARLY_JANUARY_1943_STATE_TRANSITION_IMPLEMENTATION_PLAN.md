## 1. 中心問いと観測軸

**中心問い：** 1942年11月に政府が五重点産業への投入物と労務の優先配分を決めた後、政府と陸海軍中央は、作戦上の需要と船舶・資材・生産能力の限界をどのように調整し、中国政策とソロモン方面の作戦目標をどう変更したか。それぞれの選択は、占領地の統治、輸送と工場の稼働、労働者・家庭の生活にどのような新しい条件と継続負担をもたらしたか。

**政治史を背骨とする社会状態観測。** 毎記事で①内閣・御前会議・軍中央・対外行政の決定主体、②作戦・兵站・徴用船と国家使用船、③鉄鋼・石炭・軽金属・造船・航空機への投入物と資金・労働、④中国の南京政府と重慶政府、占領地の軍政、⑤米穀・衣料・工場／炭鉱の生活供給と地域差を確認する。史料上の新しい変化がない軸は継続状態として簡潔に示し、制度・戦闘・配給制度の説明を毎記事で長く繰り返さない。

政策の「決定」／「会合・準備」／「対外文書の署名」／「軍の命令」／「現地の実行結果」を分離する。1942年末のガダルカナル撤退決定を1943年2月の撤収実施と混同せず、南京政府への条約上の約束と現地の支配・行政権の実際の変更も分ける。米穀通帳や衣料切符、朝鮮人労働者への移動制限などについて、新たな措置を確認できる場合だけ「当期の変化」とし、従来の負担は継続状態とする。

## 2. phase cutの史料上の根拠

1. **12月10日：御前会議（御前での大本営政府連絡会議）。** 「当面ノ戦争指導上作戦ト物的国力トノ調整並ニ国力ノ維持増進ニ関スル件」を決定。11月27日の生産・輸送・労務に関する各省庁の重点措置と、陸海軍の作戦要求を国の戦争指導の判断として結び直す。既に損耗している前線輸送と国内生産の両方を起点に説明する。JACARの年表と連絡会議解説、議事録Ref.C12120189300をアンカーとし、文書全文を精査するまで具体的な数値・部隊移動・船舶配分を断定しない。
2. **12月16日：臨時生産増強委員会初会合。** 11月27日の設置要綱・生産確保閣議決定が実務の協議へ移る確認点。初会合の開催自体を、即時の増産や現物到着とみなさない。**12月10日の作戦・国力調整と同じJH156**で扱う（16日を単独境界とするだけの独立した政策変更は確認できない）。
3. **12月21日：御前会議「大東亜戦争完遂ノ為ノ対支処理根本方針」。** 南京の汪兆銘政権（文書の「国民政府」）の政治力を強め、同政権の対米英戦争協力を求める。日本の租界・治外法権などの見直し、現地での物資獲得、重慶の蔣介石政権への和平工作を原則行わない方針を一つの政策として決めた。南京の政権と重慶の政権、政策上の意図と実現を区別する。
4. **12月31日：ガダルカナル島撤退の正式決定。** 天皇臨席の大本営会議で同島からの撤退が正式に決定された。11月の大型輸送船団の損耗と12月に続く補給難を受け、島の保持・奪回という作戦目標を撤退へ切り替えた。現地の食糧不足・海上航空優勢・港湾と船腹の制約を主要な説明項目とし、撤退の実行は1943年2月1・4・7日の後続作戦であることを明確にする。これを12月10日の決定そのものの内容として先取りしない。
5. **1943年1月9日：対中国方針の対外的な具体化。** 南京政府との「戦争完遂に付ての協力に関する日華共同宣言」、租界還付・治外法権撤廃等に関する日華協定が署名され、南京政府が米英へ宣戦した。**12月21日の日本側政策決定→1月9日の政府間文書**という別の段階を扱う。協定に規定された委員会設置・行政権還付の後続実施と、南京政府の実際の統治能力・占領地軍政の存続は区別する。
6. **1943年1月14日：次フェーズの自然な入口。** ビルマ独立施策と占領地帰属腹案が大本営政府連絡会議で決定される。12月21日〜1月9日の対中国方針の展開を1月13日で閉じ、占領地ごとの独立・帰属方針を新しい主線として次期へ送る。

**4本とする理由：** 12月10日は政軍・生産を一体として調整する決定、21日は対中国政策、31日は作戦目標の転換、翌1月9日は対外合意という主体・行為・結果の異なる四つの転換点である。12月16日の初会合は11月27日の決定に続く実務段階で、10日の政策と分離すると一つの因果を重複説明しやすい。年の切れ目だけで分割するのではなく、31日の作戦決定を独立記事の入口とする。1月14日はビルマおよび占領地全体の帰属方針という別の政治的主線が開くため今回の終点を1月13日とする。

## 4. 隣接接続と執筆ゲート

- **JH155→JH156：** JH155の未解決点は「五重点産業へ配る物資・船腹・電力・労力と作戦要求の調整」「委員会の実行状況」「ガダルカナルの少量補給」。冒頭では11月27日の具体策と前線の補給制約を1〜2文に圧縮し、12月10日に政府・軍中央が何を判断したかへ早く入る。16日の初会合は11月の要綱制定とは別の事実として説明。
- **JH156→JH157：** 生産・作戦の戦争指導方針から、南京政府の戦争協力・対中国資源調達・政治的な統治方針へ焦点を移す。10日決定の再説明を増やさず、同時期の資源制約が続いていることだけ明示。
- **JH157→JH158：** 中国政策の決定と、ソロモンで補給・持久が行き詰まる現地制約を同時期の別の決定として接続する。12月21日の対中国方針と12月31日の島撤退との間に直接の因果を作らない。
- **JH158→JH159：** ガダルカナル撤退の「決定／準備」は継続、1月9日の対外協定・共同宣言は当期の新しい外交事実とする。中国と太平洋で政策の実行段階が異なることを示しつつ、両者の因果を過剰につながない。
- **JH159→次期：** 1月14日のビルマ独立施策・占領地帰属と1月21日の統制会への官庁職権委譲令は次期の状態変化。12月21日の対中国方針／1月9日の署名を先に把握できる構成を維持する。
- **本文：** 重要用語は初出で役割説明＋辞書ID参照、決定と実施を混同しない。同時代の前提・読み方の留保は専用フィールドへ分離。抽象語によるまとめや仮想読者への反論を主文にしない。
- **暮らし・地域差：** 船舶の軍需・民需配分、製鉄・炭鉱の就労と移動統制、食糧・衣料の供給条件を状態として接続。12月に全国一律で配給が変わったなどの未確認事実を追加しない。
- **図版：** 御前会議文書、官報・日華協定、当時の写真・食糧補給記録等から理解向上の候補を各記事で検討。権利・出典・時点を確認し、必要な場合のみ採用。見送るときは理由付きnoImage。
- **地図：** ガダルカナルでは既存A49/A50の利用可能性を先に確認し、中国の統治・租界の位置関係が中心問いとなる場合のみ新主題地図を検討。新規地図はData/Style/Human Visual Auditの条件を満たすまで公開完了としない。
- **横断記事：** S05（政治参加）、S09（占領統治）、S10（戦時統制・資源配分）の延長と新規横断記事は、JH156〜159成立後に**新しい横断比較軸と史料**がある場合のみ追加。毎記事で定型更新しない。
- **検証：** 各記事実装時に直前記事の接続確認・史料・重要用語・図版要否・地図採否を完了→`npm run check`→PR CI→merge→main CI→公開変更時Pages確認。独立したphase-end監査は通常ゲートで解けない具体的な横断問題が残る場合のみ行う。
